## 3. **生態学的ハイパーサイクル（Eigen の理論の実体化）**

ハイパーサイクルとは：

- A が B を増やし
- B が C を増やし
- C が A を増やす

という **自己強化型の循環構造**。

MBT55 の場合：

1. 分解 → 栄養供給

5. 健康 → 有機物供給
6. 有機物 → 再び分解へ

これは「生態系エンジン」と呼ぶべき構造です。
