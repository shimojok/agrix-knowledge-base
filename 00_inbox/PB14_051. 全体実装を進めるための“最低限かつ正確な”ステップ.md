    ```python

    app.include_router(registry.router)
    ```

### 2. 「全体として動くか」の最初の確認

1. **backend 起動**
    
    ```bash
    uvicorn backend.main:app --reload
    ```
    
2. **ブラウザで確認**
    
    - `http://localhost:8000/docs` に `/registry/...` が出ているか
    - `GET /registry/chain/status` が `200` で返るか（length ≥ 1, is_valid = true）
3. **Dashboard 起動**
    
    - `npm run dev`（または `pnpm dev` 等）
    - `http://localhost:3000/dashboard/registry` にアクセス
    - 最初は空に近いが、「Chain length」が 1（Genesis）になっていれば OK
