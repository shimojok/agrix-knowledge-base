そうです。材料としてのアミノ酸と、代謝における主体者の腸内細菌の立ち位置が異なります。

---

# Architecture｜その整理が本質です

はい。ここで**「栄養素」と「代謝主体」を分離する**と、かなり明確になります。

### 従来の栄養学モデル

```
食事
 ↓
アミノ酸・脂質・糖質・ミネラル
 ↓
人体
 ↓
代謝
```

アミノ酸は基本的に、**人体が利用する「材料・基質」**として扱われます。

一方、腸内細菌は単なる材料ではありません。

```
Food
 ↓
Substrate
 ↓
Microbial Ecosystem
 ↓
Biotransformation
 ↓
Metabolite
 ↓
Host Signaling
```

つまり腸内細菌は、**材料を別の生理活性物質へ変換する「代謝主体」**として位置付けられます。

---

# 1. 「材料」と「代謝主体」を分ける

この違いをHealthBook/MIOSでは明確に定義できます。

|Layer|役割|
|---|---|
|Nutrient|生体を構成・維持する材料／エネルギー源|
|Phytochemical|微生物・宿主双方の代謝基質／シグナル前駆体|
|Microbiome|変換・合成・分解を担う生物学的代謝主体|
|Metabolite|変換によって生じる機能性分子|
|Host|代謝物を受容し、生理応答を起こす主体|

特に重要なのが、

> **Microbiomeは「栄養素」ではなく、宿主の代謝能力を拡張する生物学的システムである。**

という位置付けです。

---

# 2. エクオールは、この概念を非常に明確に示す

```
大豆
 ↓
イソフラボン
 ↓
ダイゼイン
 ↓
【腸内微生物】
 ↓
エクオール
 ↓
ERβ等
 ↓
Host Response
```

人間自身がダイゼインを食べただけでは、**腸内細菌による変換がなければエクオールという代謝物は同じ形では得られません。**

したがって、

**「大豆を摂取した」**

と

**「大豆由来成分をエクオールへ変換できる」**

は全く別のPhenotypeです。

---

# 3. ここから「Microbial Metabolic Capacity」という概念が生まれる

これはHealthBook/MIOSにとって非常に重要です。

```
Human Genome
      +
Microbial Genome
      ↓
Total Metabolic Capacity
      ↓
Metabolome
      ↓
Host Phenotype
```

つまり、人間の代謝能力を評価するとき、

> **Human Metabolism ≠ Human Genomeだけ**

となります。

より正確には、

> **Host Metabolism + Microbial Metabolism**

です。

---

# 4. 「必須腸内細菌」より一段進んだ概念

したがって、先ほどの

**Essential Microbial Functions**

も、さらに整理できます。

### Functional Capacity

```
Microbiome
   │
   ├── Nutrient transformation
   ├── Vitamin synthesis
   ├── SCFA production
   ├── Bile acid transformation
   ├── Phytochemical transformation
   ├── Equol production
   └── Xenobiotic transformation
```

ここで「必須」なのは必ずしも**菌種**ではなく、

> **宿主にとって必要な代謝機能**

です。

例えば、エクオールの場合、

```
菌A
 ┐
菌B ├──→ Equol Functional Capacity
菌C │
菌D ┘
```

という**機能的冗長性**があり得ます。

したがって、

> 「A菌がいるか？」

より、

> **「エクオール産生機能が存在するか？」**

を評価する方が本質的です。

として捉える、という意味です。
