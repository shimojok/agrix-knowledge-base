# 🌱 **MBT55 生態学的ハイパーサイクル — メカニズム説明文（正式版）**

MBT55 の生態学的ハイパーサイクルとは、  
**微生物代謝・電子移動・栄養循環・有機酸生成・無機化・再固定化** が  
連続的に結びつき、  
**土壌生態系を自己触媒的に再生させる循環構造（Hypercycle）** である。

このハイパーサイクルは、以下の 5 つの主要プロセスが  
**相互強化的に連鎖することで成立する**。

---

# ① **有機物分解 → 有機酸生成（Lactate / Acetate / Butyrate）**

MBT55 群は、土壌中の有機物を高速に分解し、  
以下の **短鎖脂肪酸（SCFA）プール** を形成する：

- 乳酸（Lactate）
- 酢酸（Acetate）
- 酪酸（Butyrate）

これらは **炭素通貨（Carbon Currency）** として機能し、  
後続の微生物代謝のエネルギー源となる。

---

# ② **電子移動（Electron Shuttling）による Redox 制御**

SCFA の生成に伴い、  
MBT55 群は **電子供与体／電子受容体** を介して  
土壌の **Redox（酸化還元）環境を安定化** させる。

- Fe³⁺ → Fe²⁺
- Mn⁴⁺ → Mn²⁺
- NO₃⁻ → NO₂⁻ → N₂
- SO₄²⁻ → S²⁻

この電子移動は、  
**病害抑制・根圏活性化・窒素循環の安定化** を同時に引き起こす。

---

# ③ **窒素循環（Nitrogen Cycle）の再構築**

MBT55 は、窒素循環の全プロセスに関与する微生物群を活性化し、  
**肥料依存を減らしながら、N₂O 排出を抑制する唯一の生態系モデル** を形成する。

- 固定（N₂ → NH₄⁺）
- 鉱化（有機 N → NH₄⁺）
- 硝化（NH₄⁺ → NO₂⁻ → NO₃⁻）
- 反硝化（NO₃⁻ → N₂O → N₂）

特に、**N₂O → N₂ の完全反硝化** が強化されるため、  
温室効果ガスの排出が大幅に低減する。

---

# ④ **栄養カスケード（Nutrient Cascade）の形成**

電子移動と窒素循環の安定化により、  
以下の栄養素が **可溶化 → 吸収可能形態へ変換** される：

- P（リン）
- K（カリウム）
- Ca / Mg
- Fe / Mn / Zn / Cu
- Si（ケイ素）

これにより、植物は **ストレス耐性・品質・収量** を同時に向上させる。

---

# ⑤ **植物根圏の活性化 → 免疫誘導（ISR）**

SCFA プールと電子移動により、  
植物根圏では以下の現象が起きる：

- 根毛伸長
- 代謝活性の上昇
- フェノール類の増加
- 病害抵抗性（ISR）の誘導
- 水分利用効率の向上

これにより、植物は **病害・乾燥・塩害・温度ストレス** に強くなる。

---

# 🔄 **MBT55 ハイパーサイクルの“自己触媒性”**

上記 ①〜⑤ のプロセスは **互いを強化し合う**。

- 有機酸 → 電子移動を促進
- 電子移動 → 窒素循環を安定化

- 栄養カスケード → 根圏活性化
- 根圏活性化 → 有機物供給が増加
- 有機物供給 → 有機酸生成が増加

この **自己強化ループ（Hypercycle）** により、  
MBT55 は **外部入力が少なくても、土壌生態系を自律的に再生** させる。
