# ☕ コーヒーの「さび病（Coffee Leaf Rust）」  
### 🌍 **世界的な被害状況（最新研究より）**
- **被害は世界中の主要コーヒー産地に拡大**  
  19世紀にスリランカで発見されて以来、アジア・アフリカ・中南米のほぼ全域に拡散。  [agriculture.institute](https://agriculture.institute/crop-production-technology/coffee-leaf-rust-symptoms-impact-control/)
- **収量損失は深刻：35〜75%の減収**  
  世界規模の多地点試験（IMLVT）では、深刻な発生時に**35〜75%の収量減**が確認。  [World Coffee Research](https://worldcoffeeresearch.org/news/2025/coffee-leaf-rust-knows-no-borders-neither-does-coffee-science)
- **2011–2013年の中米パンデミックでは30億ドル超の損害**  
  中米での大流行は、2021年までに**30億ドル以上の経済損失**を発生。  [agriculture.institute](https://agriculture.institute/crop-production-technology/coffee-leaf-rust-symptoms-impact-control/)
- **55以上のレース（系統）が存在し、進化が速い**  
  病原菌 Hemileia vastatrix は**55以上の生理レース**が確認され、抵抗性育種を上回るスピードで進化。  [World Coffee Research](https://worldcoffeeresearch.org/news/2025/coffee-leaf-rust-knows-no-borders-neither-does-coffee-science)
- **気候変動が被害拡大を加速**  
  気温上昇・干ばつ・降雨パターンの変化により、病害の発生地域が拡大。  
  ハワード・シュルツ氏も「気候変動はコーヒーの品質と供給を脅かす最大要因」と警告。  [TIME](https://time.com/5318245/coffee-industry-climate-change/)

### 🔥 **ハワード・シュルツ氏が危機感を示す理由**
- スターバックスはコスタリカに自社農園を持ち、**気候変動による病害拡大を現場で観測**。  
- 2050年までに**高品質アラビカの生産地の半分が消失する可能性**がある研究結果を重視。  [TIME](https://time.com/5318245/coffee-industry-climate-change/)

# 🐝 養蜂の「チョーク病（Chalkbrood）」  
### 🌍 **世界的な被害状況**
- **世界中の養蜂で発生する代表的な真菌病**  
  Ascosphaera apis による幼虫感染症で、**世界的に広く分布**。  [openknowledge.fao.org](https://openknowledge.fao.org/server/api/core/bitstreams/21f67594-8a16-495e-994e-a9da9c1f5f14/content)
- **幼虫の大量死亡とコロニー弱体化を引き起こす**  
  感染幼虫は白〜黒の「ミイラ状（mummies）」になり、巣箱内外に蓄積。  
  重症化すると**蜂群の生産性が大幅に低下**。  [Ministry for Primary Industries](https://www.mpi.govt.nz/dmsdocument/50056/direct)
- **感染拡大力が非常に強い：胞子は15年以上生存**  
  胞子は巣箱・土壌・蜜・花粉・器具に付着し、**15年以上感染力を保持**。  [Ministry for Primary Industries](https://www.mpi.govt.nz/dmsdocument/50056/direct)
- **世界的に増加傾向：蜂群損失の一因に**  
  近年の研究では、**蜂群損失や生産性低下との関連が強まっている**と報告。  [Academia.edu](https://www.academia.edu/127647920/Review_on_Chalkbrood_Disease_of_Honey_Bee)
- **環境ストレス（低温・高湿度・農薬・栄養不足）が発生を助長**  
  気候変動による湿度変化やストレス増加が、世界的な発生増加の背景に。  [ResearchGate](https://www.researchgate.net/profile/Bekiyad-Daro/publication/376032329_Review_on_Chalkbrood_Disease_of_Honeybee/links/65677f8c3fa26f66f439ba0a/Review-on-Chalkbrood-Disease-of-Honeybee.pdf)
