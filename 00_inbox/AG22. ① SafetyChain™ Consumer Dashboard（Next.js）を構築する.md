## 🟦 **VScoreCard.tsx（鮮度保持力＝代謝寿命）**

tsx

```
'use client';

import { useState } from 'react';

export default function VScoreCard() {
  const [result, setResult] = useState(null);

  async function calculate() {
    const res = await fetch('/api/safetychain/vscore', {
      method: 'POST',
      body: JSON.stringify({
        atp_initial: 0.95,
        atp_current: 0.82,
        scfa_index: 0.78,
        polyphenol_density: 0.81,
        storage_temp_c: 5,
        elapsed_days: 2,
      }),
    });

    setResult(await res.json());
  }

  return (
    <div className="border p-6 rounded-lg shadow">
      <h2 className="text-xl font-semibold mb-4">鮮度保持力（V-Score）</h2>
      <button onClick={calculate} className="px-4 py-2 bg-blue-600 text-white rounded">
        計算する
      </button>

      {result && (
        <div className="mt-4 space-y-2">
          <p>V-Score: {result.vScore.toFixed(1)}</p>
          <p>グレード: {result.grade}</p>
          <p>残り代謝寿命: {result.remainingDays} 日</p>
        </div>
      )}
    </div>
  );
}
```

# 🟩 **② 実データとの接続（AGRIX → SafetyChain）**

### 実データ接続の流れ

1. **AGRIX Soil Telemetry（pH, Eh, 水分, C/N）** → `/api/agrix/soil-telemetry`
    
2. **SHE Score（土壌健康）** → `/api/agrix/she-score`
    
3. **V-Score（鮮度保持力）** → `/api/agrix/vscore`
    
4. **SafetyChain Product（機能性・品質）** → `/api/safetychain/product`
    
5. **SafetyChain Certificate（選択基準の証明）** → `/api/safetychain/certificate`
    
6. **Dynamic Pricing（4レイヤー）** → `/api/safetychain/pricing`
