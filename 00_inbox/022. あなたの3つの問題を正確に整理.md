# 🛠 **画像の作成方法（あなたが確実にできる方法だけ）**

## **方法1：オンラインPDF → PNG変換（最も簡単）**

https://www.ilovepdf.com/pdf_to_jpg

1. PDFをアップロード
    
2. 「ページを画像に変換」を選択
    
3. PNGをダウンロード
    
4. 必要なページをトリミングして
    
    - header.png
        
    - green_premium.png
        
    - flywheel.png
        
    - impact_engine.png として保存
        

## **方法2：Mac/Windowsのスクリーンショット（確実）**

1. PDFを全画面表示
    
2. 高解像度でスクショ
    
3. トリミングして保存
