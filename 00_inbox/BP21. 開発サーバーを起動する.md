### なぜエラーが出たのか？
- `cd PBPE-Dashboard/dashboard` は、**PBPE-Dashboardフォルダの中にさらにもう一つPBPE-Dashboardフォルダがある**とコンピュータが探してしまうため、エラーになりました。
- `package.json` はルートフォルダ (`/workspaces/PBPE-Dashboard/`) には**ありません**。`dashboard` フォルダの中にあるので、そこに移動してから `npm` コマンドを実行する必要があります。

これで以前のようにダッシュボードが起動するはずです。

---

おっしゃる通りです。

通常、Pythonを使ったWebアプリケーションでは `app.py` が起点となりますが、**このPBPE-Dashboardプロジェクトではそれが不要な設計になっています**。

理由は、**フロントエンド（React）**と**バックエンド（データ処理）**が完全に分離されており、開発中はそれぞれ独立して動くからです。`app.py` がないのは異常ではありません。

### 念のための動作確認方法

1.  **ダッシュボード（フロントエンド）の確認**
    これは従来通り、以下のコマンドで動作を確認できます。
    ```bash
    cd /workspaces/PBPE-Dashboard/dashboard
    npm run dev
    ```

2.  **データ処理（バックエンド）の確認**
    `app.py` のようなサーバーはなく、`models/` フォルダ内のPythonファイルを直接実行して計算ロジックを確認する設計です。
    ```bash
    cd /workspaces/PBPE-Dashboard
    python models/demo.py
    ```

### `app.py` がない理由
Reactで作られたダッシュボードは、`npm run dev` コマンドだけで内蔵の開発サーバーが起動します。また、気候変動や金融の計算は、バックエンドサーバーを介さずに、`models/` フォルダのPythonスクリプトを直接実行して検証する構成をとっているため、`app.py` は必要ありません。

まずは `cd dashboard` と `npm run dev` で、ダッシュボードが再び表示されるかをお試しください。

はい、**Streamlitでも表示できます！**

現在のダッシュボードはReactで作られていますが、PythonのStreamlitを使って同じものを実装することも可能です。

## Streamlit版のメリット

| 比較項目 | React版（現在） | Streamlit版 |
|---------|---------------|-------------|
| 開発言語 | TypeScript | Pythonのみ |
| 起動方法 | `npm run dev` | `streamlit run app.py` |
| デプロイ | Vercel/Netlify | Streamlit Cloud |
| データ連携 | API経由 | 直接Python処理 |
| 学習コスト | やや高い | 低い |

## Streamlit版の作成

もしStreamlit版を作成する場合、以下のような `app.py` をルートに作成するだけで動作します：

```python
import streamlit as st
import pandas as pd
import numpy as np
import sys
sys.path.append('./models')

from coffee_impact import PBPEImpactEngine, FarmMetrics
from carbon_sequestration import CarbonSequestrationEngine

st.set_page_config(
    page_title="PBPE Dashboard",
    page_icon="🌍",
    layout="wide"
)

# サイドバー
st.sidebar.title("🌍 PBPE Dashboard")
tab = st.sidebar.radio(
    "メニュー",
    ["Dashboard", "Carbon Ledger", "Impact Simulator", "Yield Predictor", "Finance Engine"]
)

# メイン表示
if tab == "Dashboard":
    st.title("PBPE Dashboard")
    
    col1, col2, col3, col4 = st.columns(4)
    with col1:
        st.metric("総炭素隔離量", "1.25M tCO₂e", "+12.5%")
    with col2:
        st.metric("アクティブ農家数", "50,000", "+8.3%")
    with col3:
        st.metric("総ロック価値", "$5.0B", "+15.2%")
    with col4:
        st.metric("農家ROI", "17.8x", "+23%")

elif tab == "Carbon Ledger":
    st.title("Carbon Ledger")
    # 炭素隔離データのグラフ表示
    chart_data = pd.DataFrame({
        'date': pd.date_range('2024-01-01', periods=30, freq='D'),
        'sequestration': np.random.normal(40000, 10000, 30).cumsum()
    })
    st.line_chart(chart_data.set_index('date'))

elif tab == "Impact Simulator":
    st.title("Impact Simulator")
    
    area = st.slider("農場面積 (ha)", 1, 100, 10)
    mbtt55 = st.checkbox("MBT55適用", True)
    
    if mbtt55:
        revenue = area * 4177
        st.metric("推定収益", f"${revenue:,.0f}", f"+{110}%")
    else:
        revenue = area * 1850
        st.metric("推定収益", f"${revenue:,.0f}", "基準値")
```
