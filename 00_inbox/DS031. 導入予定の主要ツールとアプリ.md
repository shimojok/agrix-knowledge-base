## 🧩 導入予定の主要ツールとアプリ

マルチAIエージェントシステムを構築するために、以下のツールを使用します。

### 1. LangGraph（ランググラフ）— エージェントの「司令塔」

**これが何か：**
AIエージェント（複数のAI）の**動作をグラフ（フローチャート）で設計・制御**するためのPythonライブラリです。複数のAIが「誰が、いつ、何をするか」を明確に管理できます。

**何ができるか：**
- 複数のAIエージェントの**状態（今どこにいるか）** を管理
- 処理の**分岐やループ**を設計可能
- **人間が途中で介入**できる仕組みを組み込める

**お金はかかるか：**
✅ **無料です**。MITライセンスのオープンソースライブラリで、商用利用も無料です。

---

### 2. LangChain（ラングチェーン）— LangGraphの「土台」

**これが何か：**
LLM（大規模言語モデル）を使ってアプリを作るための**基本フレームワーク**です。LangGraphはこの上に構築されています。

**LangGraphとの関係：**
- **LangChain** = 家を建てるための「基礎工事」や「材料」
- **LangGraph** = その材料を使って「設計図通りに部屋を配置する」作業

**お金はかかるか：**
✅ **無料**です。同じくオープンソースです。

---

### 3. LangSmith（ラングスミス）— エージェントの「監視カメラ」（※任意）

**これが何か：**
AIエージェントが**どう動いているかを可視化・監視・デバッグ**するサービスです。LangGraphと非常に相性が良いです。

**お金はかかるか：**
⚠️ **有料サービス**です（従量課金制）。ただし**必須ではありません**。まずは無料で始めて、後から必要に応じて導入を検討すれば十分です。

---

### 4. CrewAI / AutoGen — マルチAIエージェントの別の選択肢

**これらは何か：**
- **CrewAI**：役割（ロール）を決めたAIチームを作るフレームワーク
- **AutoGen**：Microsoftが開発した、複数AIが協調・対話するフレームワーク

**どれを選ぶか：**
今回のプロジェクトでは**LangGraphを選びます**。理由は：
- 状態管理が最も柔軟で複雑なワークフローに対応できる
- あなたのAGRIXシステムのように「多数のモジュールが連携する」ケースに最適

**お金はかかるか：**
✅ CrewAIもAutoGenも**オープンソースで無料**です。

## 💰 料金まとめ（シンプル版）

| ツール | 料金 | 必須か |
|---|---|---|
| **LangGraph** | ✅ **無料**（オープンソース） | **必須** |
| **LangChain** | ✅ **無料**（オープンソース） | **必須** |
| **LangSmith** | ⚠️ 有料（従量課金） | 任意（なくても可） |
| **CrewAI / AutoGen** | ✅ **無料**（オープンソース） | 今回は不使用 |

**ただし注意点**：
- LangGraph自体は無料ですが、**エージェントの「頭脳」となるLLM（ClaudeやGPTなど）のAPI利用料は別途かかります**。
- 今回は**あなたのアカウントでLLMのAPIキーを取得**して使用する形になります。

## 🛠️ 実際の導入方法（超簡易版）

LangGraphはPythonのライブラリなので、以下のコマンド一発でインストールできます：

```bash
pip install langgraph langchain
```

Pythonがインストールされていれば、これだけで使える状態になります。
