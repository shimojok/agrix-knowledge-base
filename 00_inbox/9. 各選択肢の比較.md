## 各選択肢の比較

```
                Vercel          GitHub Pages    Azure Static
──────────────────────────────────────────────────────────
セットアップ    5分             20分            15分
コスト          無料            無料            無料(一部)
カスタムドメイン ○              ○               ○
React対応       ◎ネイティブ     △ビルド設定必要  ○
Azure連携       △               △               ◎
将来のAPI追加   ◎               △               ◎
推奨            ★現段階         -               ★Azure移行時
```

**結論：今すぐ動かすならVercel、将来Azure統合するならAzure Static Web Apps**
