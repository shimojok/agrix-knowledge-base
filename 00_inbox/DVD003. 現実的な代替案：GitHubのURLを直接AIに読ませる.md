## Pineconeが自動でやってくれること

**「ベクトルの保存」と「類似ベクトルの高速検索」だけです。**

それ以外は、すべて外部から指示を与える必要があります。

| Pineconeがやること | Pineconeがやらないこと（＝私たちがコードで行う） |
|---|---|
| ベクトルデータの保存 | GitHubからのファイル収集 |
| クエリに対する類似ベクトルの高速検索 | テキストのチャンク分割 |
| 名前空間によるデータの論理分割 | OpenAI APIを使った埋め込み（ベクトル化） |
| | Pineconeへのデータ送信（アップサート） |
| | エラー処理・再試行 |

Pineconeは「検索エンジン付きの高性能なUSBメモリ」であり、そこにデータを出し入れする配管は自分で作る必要があります。

## 提案：Pineconeを「後回し」にする

本当に価値があるのは「Pineconeにデータを入れること」ではなく、「AIがあなたの設計書を正確に参照しながらコードを生成すること」です。

これは、Pineconeがなくても、**今この瞬間から実現できます。**

### 現実的な代替案：GitHubのURLを直接AIに読ませる

| 今までの問題 | 解決策 |
|---|---|
| AIが過去の会話を忘れる | 毎回、必要なリポジトリのURLを明示的に渡す |
| コンフリクトが起きる | 1つの会話で1つのリポジトリだけを扱う |
| 質が低下する | 設計書（BioNexus-Core）を毎回最初に読ませる |
| ハルシネーション | 回答の根拠をファイルの特定行で示すよう指示 |

## 具体的な進め方（今日からできること）

### まず、BioNexus-Coreを私に読ませてください

先ほどGitHubにプッシュした整理版を、私が直接読み、全体の設計意図を把握します。その上で：

1. **3システム（AGRIX, HEALTHBOOK, PBPE-MARKETPLACE）のうち、最も完成度が高いものを1つ選ぶ**
2. **そのリポジトリの設計書・コードを私が読み込む**
3. **必要な修正・追加機能を、設計書に基づいてブレずに提案する**
4. **生成したコードは、あなたがコピペして使い、動作確認する**
5. **動いたら次のシステムへ**

この方法なら：
- Pineconeのセットアップは不要
- 新しいコードやエラーは発生しない
- 1会話1テーマで、文脈が迷子にならない
- あなたの設計書が「憲法」として常に機能する
