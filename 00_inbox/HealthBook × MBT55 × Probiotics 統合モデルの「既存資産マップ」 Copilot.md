#### 3. 不足している「致命的パラメータ」一覧（再整理）

**3-1. MBT55 関連**

- **微生物群の具体種 or 機能分類（55内訳）**
    
    - 既存：CG1, CG30, 19. などで「機能的経路」としての抽象はある。
    - 不足：
        - 55の内訳を
            - 実在菌種（例：A. muciniphila など）
            - もしくは「機能クラス（酢酸産生群・酪酸産生群・乳酸産生群…）」  
                のどちらで定義するかを**固定したリスト**としてアップロードする必要がある。
- **分解対象ごとの実測速度**
    
    - デンプン・タンパク・脂質・セルロースなどについて、
        - ( v = k \cdot [substrate] ) 型でも
        - Michaelis-Menten 型でもよいので、  
            **MBT55 各クラスごとの分解速度パラメータ**が必要。
- **好気/嫌気のダイナミクスデータ**
    
    - 現状：好気/嫌気比率は概念的に語られているのみ。
    - 必要：
        - pO(_2)、還元状態、時間変化に応じた
            - 微生物群構成のシフト
            - 代謝産物（SCFA, lactate, ethanol など）の変化  
                を表す**ダイナミクス関数 or 実測テーブル**。
- **温度・pH応答カーブ**
    
    - 各 MBT55 クラスについて、
        - 最適温度・pH
        - 活性低下のカーブ（例：ガウス型、ロジスティック型）  
            を定義するパラメータセットが必要。

**3-2. HealthBook 関連**

- **137疾病マトリクスの「定量ロジック」**
    
    - JSON 自体はあるが、
        - 各疾病の「代謝ブロック」への重み
        - 代謝ブロック → リスクスコアへの変換式  
            を、**明示的な数式・係数として整理したドキュメント**が必要。
- **200問診 → パラメータ変換式**
    
    - 質問項目は JSON で存在。
    - 不足しているのは：
        - 各質問の回答（例：頻度・強度・有無）を
        - どの代謝パラメータ（炎症指数、インスリン抵抗性、腸透過性など）に  
            どの係数でマッピングするか、という**変換テーブル＋数式**。
- **腸内細菌と疾病の重み係数**
    
    - MBT55（または菌種）と 137疾病の間の
        - 正/負の影響方向
        - 重みの大きさ（例：-1.0〜+1.0）  
            を定義する**対応表**。
- **SCFA・代謝物と疾患リスクの関数形**
    
    - 酢酸・プロピオン酸・酪酸などの濃度と、
        - 2型糖尿病
        - NAFLD
        - 炎症性腸疾患  
            などのリスクの関係を、
        - ロジスティック回帰
        - スプライン  
            などの**関数形＋初期パラメータ**として定義。

**3-3. MBT Probiotics 関連**

- **菌株ごとの機能（SCFA生成、抗炎症など）**
    
    - 例：
        - A. muciniphila（既に個別ファイルあり）
        - Bifidobacterium spp.
        - Lactobacillus spp.  
            について、
    - 生成する SCFA プロファイル
    - 粘膜バリア・炎症マーカーへの影響  
        を**定量パラメータ（係数）として整理**。
- **投与量 → 効果の用量反応曲線**
    
    - 1日あたり CFU / g / 回数 と、
        - SCFA 濃度変化
        - 疾病リスクスコア変化  
            の関係を、
    - Emax モデル
    - Hill 関数  
        などで表現するための**初期パラメータセット**。

### 5. モデル統合後に可能になること（再定義）

アップロードが完了すると、このスレッド②で狙っていることが一気に現実になる：

- **パラメータ推定**
    
    - MBT55・SCFA・疾病リスクの関数形に対して
        - Bayesian / MLE によるフィットが可能
    - HealthBook の問診・疾病マトリクスを
        - 「実データに裏打ちされたスコアリングエンジン」に昇格できる。
- **個別最適化（Precision HealthBook）**
    
    - 個人の腸内細菌プロファイル＋問診＋血液データから
        - 最適な MBT Probiotics 処方
        - 食事・生活介入の優先順位  
            を数理的に提案できる。
- **PBPEとの直接接続（実数値IRR）**
    
    - 介入前後の
        - 疾病リスク低下
        - 医療費削減  
            を定量化し、
        - PBPE（Planetary Bio-Physical Economy）モデルに直接接続して  
            IRR を算出可能。
- **GHG削減の実測リンク**
    
    - AGRIX（農業・食料）× HealthBook（健康）× MBT Probiotics（介入）を  
        一つの数理フレームで結び、
        - 食環境改善 → 健康改善 → 医療・サプライチェーン由来 GHG 削減  
            を「実測＋モデル」でトレースできる。
