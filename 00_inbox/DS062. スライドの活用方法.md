スライドは、READMEに設置し、スライドはもちろん、ヘッダー画像としても使えませんか？

---

**はい、使えます。**

スライドをREADMEに設置し、ヘッダー画像としても活用する方法をいくつか提案します。

---

## ✅ スライドの活用方法

### 方法1：そのままPDFをREADMEにリンク

```markdown
# PBPE Marketplace

> Building the Operating System for Earth and Wellness.

[📄 ピッチ資料（PDF）](./docs/pitch-deck/PBPE_Marketplace_s.pdf)
```

---

### 方法2：スライドから抜粋した画像をヘッダーに設定

PDFの各ページを画像化して、以下のように配置：

```markdown
# PBPE Marketplace

![ヘッダー画像](./docs/images/header.png)

**ROI 344% | Payback 3.5 months | GHG Reduction 510 MtCO₂e**
```

---

### 方法3：GitHubの「Social Preview」画像として設定

GitHubリポジトリの共有時に表示されるサムネイル画像として、スライドの表紙を設定できます。

1. リポジトリの `Settings` → `Social preview`
2. スライド表紙の画像をアップロード

---

### 方法4：Markdown内で直接画像引用

```markdown
## グリーンプレミアム

![Green Premium](./docs/pitch-deck/images/slide4.png)

従来 ¥100 → MBT ¥140-160（+40-60%）
```

## ⚙️ PDFを画像に変換する方法

### 方法A：Notebook LMの機能
- Notebook LMでスライドを開き → 各ページを「画像として保存」

### 方法B：オンラインツール
- https://www.ilovepdf.com/pdf_to_jpg

### 方法C：Pythonスクリプト

```python
from pdf2image import convert_from_path

images = convert_from_path('PBPE_Marketplace_s.pdf')
for i, image in enumerate(images):
    image.save(f'slide{i+1}.png', 'PNG')
```
