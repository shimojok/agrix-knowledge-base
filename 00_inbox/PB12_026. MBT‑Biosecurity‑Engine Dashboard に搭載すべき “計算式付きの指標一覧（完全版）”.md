# 🧭 **MBT‑Biosecurity‑Engine Dashboard

計算式付き KPI（完全版）**

---

# 1️⃣ **Disease Loss Reduction Index（病害損失削減指数）**

### **定義**

MBT55 による病害抑制によって、どれだけ収量損失が減ったか。

### **計算式**

[ \text{Disease Loss Reduction Index} = \frac{L_{\text{before}} - L_{\text{after}}}{L_{\text{before}}} ]

- (L_{\text{before}})：MBT55 介入前の損失量
- (L_{\text{after}})：介入後の損失量

### **例**

病害損失 30% → 10%  
→ **66.7% 改善**

---

# 2️⃣ **Yield Gain (%)（収量増加率）**

### **計算式**

[ \text{Yield Gain} = \frac{Y_{\text{after}} - Y_{\text{before}}}{Y_{\text{before}}} ]

- (Y_{\text{before}})：介入前の収量
- (Y_{\text{after}})：介入後の収量

### **例**

1.0t → 1.4t  
→ **40% 増加**

---

# 3️⃣ **Quality Premium Score（品質プレミアム指数）**

### **構成要素**

- 糖度（Brix）
- 香気成分（Terpenes）
- ポリフェノール
- 欠点率（Defect Rate）

### **計算式（標準化スコア）**

[ Q = w_1 B + w_2 T + w_3 P - w_4 D ]

- (B)：糖度
- (T)：香気成分
- (P)：ポリフェノール
- (D)：欠点率
- (w_i)：作物別の重み

---

# 4️⃣ **Anti‑Spoilage Effect（腐敗抑制効果）**

### **計算式**

[ \text{Anti-Spoilage Effect} = \frac{S_{\text{before}} - S_{\text{after}}}{S_{\text{before}}} ]

- (S_{\text{before}})：腐敗率（例：40%）
- (S_{\text{after}})：MBT55 介入後（例：5%）

### **例**

40% → 5%  
→ **87.5% 改善**

---

# 5️⃣ **Food Loss Reduction (t/year)（食品ロス削減量）**

### **計算式**

[ \text{Food Loss Reduction} = Y_{\text{marketable, after}} - Y_{\text{marketable, before}} ]

市場に出荷可能な量の増加を直接算出。

---

# 6️⃣ **Cost Reduction Index（生産費削減指数）**

### **構成要素**

- 化学肥料削減
- 農薬削減
- 抗生物質削減
- 廃棄物処理コスト削減

### **計算式**

[ C = (F_{\text{saved}} + P_{\text{saved}} + A_{\text{saved}} + W_{\text{saved}}) ]

---

# 7️⃣ **Livestock Biosecurity Score（畜産バイオセキュリティ指数）**

### **構成要素**

- 感染率低下
- 殺処分回避数
- 抗生物質削減
- 腸内 SCFA 増加
- 糞尿分解速度（24h）

### **計算式（総合スコア）**

[ L = w_1 I + w_2 K + w_3 A + w_4 S + w_5 D ]

---

# 8️⃣ **Soil Carbon Sequestration (ΔC)（土壌炭素隔離量）**

### **計算式**

[ \Delta C = C_{\text{after}} - C_{\text{before}} ]

- SOC（Soil Organic Carbon）の増加量を表示
- PBPE Marketplace の **Carbon Credits** に直結

---

# 9️⃣ **GHG Reduction (CH₄, N₂O)（温室効果ガス削減量）**

### **計算式**

[ \text{GHG Reduction} = (\Delta CH_4 \times GWP_{CH_4}) + (\Delta N_2O \times GWP_{N_2O}) ]

- GWP：地球温暖化係数
- PBPE Marketplace の **Climate Credits** に直結

---

# 🔟 **Price Stability Index（価格安定指数）**

### **計算式**

[ \text{Price Stability Index} = 1 - \frac{\sigma_{\text{after}}}{\sigma_{\text{before}}} ]

- (\sigma)：価格変動の標準偏差

→ **MBT55 による供給安定化 → 価格安定化を数値化**

---

# 1️⃣1️⃣ **PBPE‑Biosecurity Value (USD)（価値化モデル）**

### **PBPE の中核式**

[ \text{PBPE Value} = L_{\text{reduction}}

- C_{\text{reduction}}
- Y_{\text{gain}}
- Q_{\text{premium}}
- F_{\text{loss reduction}}
- \text{Climate Credits} ]

MBT55 の科学的効果を **PBPE Marketplace の経済価値** に変換する。

---

# 1️⃣2️⃣ **Biosecurity ROI（投資利益率）**

### **計算式**

[ ROI = \frac{\text{PBPE Value} - \text{Cost of MBT55}}{\text{Cost of MBT55}} ]

→ 財団・投資家向けの最重要指標。
