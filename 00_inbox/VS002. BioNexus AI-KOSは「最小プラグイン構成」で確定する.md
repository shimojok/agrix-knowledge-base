# Architecture

## 結論：BioNexus AI-KOSは「最小プラグイン構成」で確定する

前回の **Smart Connections + Smart Chat + Dataview + Canvas + Excalibrain** の構成は、BioNexusには機能過多です。

**推奨は以下の2プラグインのみです。**

```text
Obsidian Core
    │
    ├── Smart Connections
    │       └── Semantic Search / Related Notes / AI Retrieval
    │
    └── Git
            └── Version Control / Governance / Backup
```

### 採用プラグイン

|Plugin|採用|役割|
|---|--:|---|
|**Smart Connections**|✅|AI意味検索・関連ノート発見|
|**Obsidian Git**|✅|GitHub同期・履歴・統治|
|Dataview|❌|Markdown標準＋GitHub側で代替|
|Canvas|❌|Mermaid / Markdown図で代替|
|Excalibrain|❌|Smart Connectionsの意味検索で代替|
|Smart Chat|❌|ChatGPT / API / GitHub側で代替|

Smart Connections v4は、ローカル埋め込みモデルを使用し、ノートを外部へ送信せずに意味検索を実行できる構成です。また、依存関係を抑えた軽量設計を採用しています。([Obsidian Community](https://community.obsidian.md/plugins/smart-connections?utm_source=chatgpt.com "Smart Connections - Obsidian Plugin"))

# Smart Connectionsの使い方

## 1. Inboxにすべて入れる

最初から分類しません。

```text
00_Inbox/
    │
    ├── 研究メモ
    ├── ChatGPT出力
    ├── アイデア
    ├── 会議メモ
    └── 未整理資料
```

Smart Connectionsが意味的な関連性を発見します。

```text
「土壌微生物」
        │
        ├── MBT55
        ├── AGRIX
        ├── N2O
        ├── GHG
        └── PBPE
```

**フォルダ分類を最初から完璧にしない**ことがポイントです。

---

## 2. 「関連ノート」を発見する

例えば、

```text
MBT55の農業利用
```

を開いた場合、

Smart Connectionsが意味的に近い

```text
AGRIX fertilizer reduction
Soil carbon
N2O reduction
PBPE Impact Asset
```

などを表示します。

つまり、Obsidianを

```text
Manual Wiki
```

ではなく、

```text
Semantic Knowledge Discovery System
```

として使います。

# Plugin Governance

## 採用基準

新しいプラグインは、以下の条件を満たさない限り追加しません。

```text
1. Obsidian Coreで代替できない
2. Smart Connectionsで代替できない
3. GitHubで代替できない
4. BioNexusの意思決定速度を上げる
5. 起動・検索性能への影響を測定できる
```

### 目標KPI

|KPI|Target|
|---|--:|
|Community Plugins|**2個以下**|
|Obsidian Startup|**3秒以内**|
|Semantic Search|**30秒以内**|
|Knowledge Retrieval|**60秒以内**|
|未整理Inbox|**100件以下**|
|正式決定のGitHub記録率|**100%**|

プラグイン数そのものより、各プラグインが独自インデックスやバックグラウンド処理を持つかが性能に影響します。そのため、最小構成を基本とし、Obsidianの起動時間計測機能で定期的に監査する方針が適切です。([Obsidian Forum](https://forum.obsidian.md/t/performance-on-large-vaults/114864?utm_source=chatgpt.com "Performance on large vaults - Help - Obsidian Forum"))
