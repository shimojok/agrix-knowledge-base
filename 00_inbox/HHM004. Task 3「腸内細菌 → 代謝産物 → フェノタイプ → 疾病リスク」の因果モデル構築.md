▶ Task 3「腸内細菌 → 代謝産物 → フェノタイプ → 疾病リスク」の因果モデル構築に進んでください。

---

## ① 概要（1–2行）  
腸内細菌組成 → 代謝産物（SCFA等） → 宿主フェノタイプ → 疾病リスクを、因果グラフに基づく連立ODE＋ロジスティックリスク関数で定式化する。

---

## ② 数式（Causal Metabolic–Phenotype–Risk Model）

### (1) 微生物組成ダイナミクス

[  
\frac{dM_i}{dt} = M_i \left( \mu_i \frac{N}{K_{N,i} + N} + \sum_{j \neq i} \alpha_{ij} M_j - d_i \right)  
]

---

### (2) 代謝産物生成（SCFA等）

[  
\frac{dP_k}{dt} =  
\sum_{i=1}^{N} Y_{ik} \cdot M_i - \lambda_k P_k  
]

---

### (3) フェノタイプ形成（炎症・インスリン感受性など）

[  
\frac{dH_l}{dt} =  
\sum_{k=1}^{K} w_{kl} \cdot P_k - \delta_l H_l  
]

---

### (4) 疾病リスク関数（ロジスティック）

[  
R_d = \frac{1}{1 + \exp\left(- \left( \sum_{l=1}^{L} \beta_{ld} H_l + \gamma_d X - \theta_d \right)\right)}  
]

---

### (5) 因果構造（DAG制約）

[  
M \rightarrow P \rightarrow H \rightarrow R  
]

交絡制御：

[  
do(P_k) \Rightarrow H_l \Rightarrow R_d  
]

---

## ③ 変数定義（Variables & Units）

|変数|意味|単位|範囲|
|---|---|---|---|
|(M_i)|微生物相対量|ratio (0–1)|0–1|
|(N)|栄養入力|g/day|0–500|
|(P_k)|代謝産物（SCFA等）|mmol/L|0–150|
|(H_l)|フェノタイプ指標（炎症, HOMA-IR等）|index|0–10|
|(R_d)|疾病リスク|probability|0–1|
|(X)|共変量（年齢等）|-|-|

---

**パラメータ**

|パラメータ|意味|範囲|
|---|---|---|
|(Y_{ik})|微生物→代謝産物変換効率|0–10 mmol/cell|
|(\lambda_k)|代謝消費率|0.01–1 hr⁻¹|
|(w_{kl})|代謝物→フェノタイプ影響|-5–5|
|(\beta_{ld})|フェノタイプ→疾患係数|-10–10|
|(\theta_d)|発症閾値|-5–5|

---

## ④ Python実装（Executable）

```python
import numpy as np
from scipy.integrate import solve_ivp

N_micro = 3
K_metab = 3
L_pheno = 2

# 初期値
M0 = np.array([0.3, 0.4, 0.3])
P0 = np.array([10, 10, 10])
H0 = np.array([1, 1])

y0 = list(M0) + list(P0) + list(H0)

# パラメータ
Y = np.array([[0.5,0.2,0.3],
              [0.3,0.5,0.2],
              [0.2,0.3,0.5]])

lambda_k = np.array([0.1,0.1,0.1])
w = np.array([[1.0, -0.5],
              [0.5, 0.8],
              [-0.3, 0.6]])

beta = np.array([[1.2],
                 [-1.0]])

theta = 0.5

def model(t, y):
    M = np.array(y[0:N_micro])
    P = np.array(y[N_micro:N_micro+K_metab])
    H = np.array(y[N_micro+K_metab:])

    # 微生物（簡略）
    dMdt = M * (0.5 - 0.1 * M)

    # 代謝物
    dPdt = Y.T @ M - lambda_k * P

    # フェノタイプ
    dHdt = w.T @ P - 0.1 * H

    return list(dMdt) + list(dPdt) + list(dHdt)

sol = solve_ivp(model, (0,50), y0, t_eval=np.linspace(0,50,200))

# 疾病リスク
H_final = sol.y[-L_pheno:, -1]
R = 1/(1 + np.exp(-(beta.T @ H_final - theta)))

print("Final Risk:", R)
```

## ⑤ 検証方法（Validation）

### 1. 因果検証（Causality Agent）

- do演算：(do(P_k ↑)) → (H_l ↑/↓) → (R_d)変化
    
- バックドア条件：(X)で調整
    

---

### 2. 数学的検証（Math Agent）

- 有界性：(0 ≤ M ≤ 1, R ∈ [0,1])
    
- 安定性：定常状態存在（d/dt = 0）
    

---

### 3. トレース検証（Trace Agent）

- 入力（食事/N）変更 → M→P→H→Rの時系列追跡
    
- 感度分析（∂R/∂P, ∂R/∂M）
    

---

### 4. 臨床整合性

- SCFA増加 → 炎症低下 → リスク低下
    
- NH3増加 → 炎症増加 → リスク上昇
