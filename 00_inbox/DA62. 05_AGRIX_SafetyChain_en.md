# Soil Dynamics ODE Model

## Overview

The core computational model of AGRIX-OS, extending the M3-Core-Engine MBT55 Hypercycle ODE with **real-time soil sensor data (pH, Eh, moisture).**

---

## State Variables (8 Variables)

| Variable | Definition | Unit |
|:---|:---|:---|
| S | Substrate concentration | g/L |
| X_A | Substrate-degrading microbial biomass | g/L |
| M | Metabolic intermediate | g/L |
| X_B | Metabolite-converting biomass | g/L |
| P | Functional product / Humic precursor | g/L |
| X_C | Hypercycle control biomass | g/L |
| C | Soil organic carbon | g/L |
| N | Available nitrogen | g/L |

---

## Sensor Integration

| Sensor | ODE Impact |
|:---|:---|
| **pH** | Modifies β_i (mortality/inhibition coefficients) |
| **Eh (Redox Potential)** | Selects aerobic vs. anaerobic pathway dominance |
| **Moisture (θ)** | Moisture-dependent oxygen availability (aerobic/anaerobic switch) |

---

## Aerobic Fraction Function

```python
def aerobic_fraction(Eh_mV, moisture_pct):
    f_Eh = 1.0 / (1.0 + np.exp(-0.02 * (Eh_mV - 50)))
    f_moisture = 1.0 - max(0.0, (moisture_pct - 70.0) / 30.0)
    return np.clip(f_Eh * f_moisture, 0.05, 0.95)
```

Reproduces MBT55 design specification: 55% aerobic / 45% anaerobic under reference conditions.


| **DIMINISHING_IMPROVEMENT** | Slowing improvement | Prepare next intervention |

## Overview

The Vitality Score (V-Score) is a metabolic vitality indicator (0–100) based on **post-harvest ATP decay rate.**

---

## ATP Decay Model

```
ATP_t = ATP_0 × exp(-k_atp × t)
```

### Correction Factors for Decay Constant k_atp

| Factor | Effect |
|:---|:---|
| SCFA Protection | Enhanced membrane integrity → Reduced k_atp |

| Storage Temperature (Q10≈2) | Lower temperature → Reduced k_atp |
