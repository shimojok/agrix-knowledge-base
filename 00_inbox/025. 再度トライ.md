- **Planetary Health Unified API (Full PBPE Model)**

Error rendering embedded code
Invalid PDF

---

GitHubのREADME.mdでPDFを「埋め込み表示（embed）」しようとしているのが原因です。

**GitHubのREADMEでは：**

|方法|結果|
|---|---|
|PDFファイルを直接クリック|✅ 表示される|
|`![](./docs/slides/xxx.pdf)` 画像埋め込み記法|❌ エラー|
|`[テキスト](./docs/slides/xxx.pdf)` リンク記法|✅ クリックで開ける|

---

**現在のREADMEの記述を確認したいのですが、`*` の前に `!` がついていませんか？**

```markdown
<!-- エラーになる（画像埋め込み記法） -->
![The PDF](./docs/slides/The_Planetary_Health_Unified_API_s.pdf)

<!-- 正しい（リンク記法） -->
[The_Planetary_Health_Unified_API_s.pdf](./docs/slides/The_Planetary_Health_Unified_API_s.pdf)
```
