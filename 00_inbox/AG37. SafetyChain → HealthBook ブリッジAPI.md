### 1. 全体アーキテクチャ

- **SafetyChain側:**
    
    - Certificate（V-Index, polyphenolDensity, metabolicLifeDays など）
        
- **HealthBook側:**
    
    - 食事ログ（何を・いつ・どれだけ食べたか）
        
    - 腸内代謝モデル（SCFA, 炎症スコア, 代謝年齢など）
        

接続の基本は：

> 「食べた食品のロットID → SafetyChain Certificate → 機能性・代謝寿命 → 腸内モデルに反映 → HealthBookに記録」

### 2. SafetyChain → HealthBook ブリッジAPI

#### 新API: `/api/healthbook/intake`

ts

```
// app/api/healthbook/intake/route.ts
import { NextRequest, NextResponse } from "next/server";

export async function POST(req: NextRequest) {
  const body = await req.json();

  const { lotId, amount_g, eatenAt } = body;

  // SafetyChain Certificate を取得
  const certRes = await fetch(`${process.env.NEXT_PUBLIC_BASE_URL}/api/safetychain/certificate/lookup`, {
    method: "POST",
    body: JSON.stringify({ lotId }),
  });
  const cert = await certRes.json();

  const poly = cert.certificate.quality.polyphenolDensity;
  const vIndex = cert.certificate.phenotyping.vIndex;
  const metabolicLife = cert.certificate.quality.metabolicLifeDays;

  // 腸内代謝モデルへの簡易変換（例）
  const scfaGain = poly * amount_g * 0.01;
  const inflammationDrop = vIndex * 0.02;
  const gutInertiaBoost = metabolicLife * 0.03;

  const intakeRecord = {
    eatenAt,
    lotId,
    amount_g,
    scfaGain,
    inflammationDrop,
    gutInertiaBoost,
  };

  // ここで HealthBook 側のストレージ or 外部APIに送る想定
  return NextResponse.json({
    intake: intakeRecord,
    sourceCertificate: cert.certificate,
  });
}
```

### 3. HealthBook 側の「食事ログ × SafetyChain」ビュー

#### 新ページ: `/healthbook/intake-log`

tsx

```
'use client';

import { useState } from 'react';

export default function IntakeLogPage() {
  const [entry, setEntry] = useState<any | null>(null);

  async function logIntake() {
    const res = await fetch('/api/healthbook/intake', {
      method: 'POST',
      body: JSON.stringify({
        lotId: 'LOT-20260709-001',
        amount_g: 150,
        eatenAt: new Date().toISOString(),
      }),
    });
    setEntry(await res.json());
  }

  return (
    <main className="p-8 space-y-6">
      <h1 className="text-2xl font-bold">HealthBook × SafetyChain Intake</h1>

      <button
        onClick={logIntake}
        className="px-4 py-2 bg-green-600 text-white rounded"
      >
        このロットの摂取を記録
      </button>

      {entry && (
        <div className="grid grid-cols-2 gap-6 mt-4">
          <div className="bg-white p-4 rounded shadow">
            <h2 className="font-semibold mb-2">摂取記録</h2>
            <p>ロットID: {entry.intake.lotId}</p>
            <p>摂取量: {entry.intake.amount_g} g</p>
            <p>SCFA増加: {entry.intake.scfaGain.toFixed(2)}</p>
            <p>炎症低下: {entry.intake.inflammationDrop.toFixed(3)}</p>
            <p>腸内慣性ブースト: {entry.intake.gutInertiaBoost.toFixed(3)}</p>
          </div>

          <div className="bg-white p-4 rounded shadow">
            <h2 className="font-semibold mb-2">SafetyChain Certificate</h2>
            <pre className="bg-gray-100 p-2 text-xs rounded">
              {JSON.stringify(entry.sourceCertificate, null, 2)}
            </pre>
          </div>
        </div>
      )}
    </main>
  );
}
```

### 4. これで成立する「腸内代謝ループ」

1. **土壌 → MBT55 → SafetyChain Certificate**
    
2. **Certificate → 食事ログ（lotId付き）**
    
3. **食事ログ → 腸内代謝モデル（SCFA, 炎症, 慣性）**
    
4. **HealthBook → 人の代謝履歴として蓄積**
    

つまり、**「土壌の代謝が、人の腸内代謝にどう影響したか」を追跡できる OS**になる。
