# 🟥 1. **Next.js が呼び出す API と、bonds.py の API が一致していない**

Next.js Dashboard v3 の Finance ページは、  
以下の API を呼び出す：

### ✔ **GET /finance/bonds**

しかし、あなたの bonds.py は：

### ❌ **GET /bonds**

（prefix が /finance なので → /finance/bonds）

これは一致しているように見えるが、  
**レスポンス形式が Next.js の期待と異なる。**

---

# 🟦 Next.js が期待するレスポンス形式

Next.js の Finance ページは、  
以下の形式を期待している：

```json
{
  "bonds": [
    {
      "id": "PBPE-GLOBAL-2035",
      "outstanding_usd": 1500000000,
      "coupon_percent": 4.2,
      "pbpe_floor": 400000000,
      "impact_floor": 300000000,
      "maturity_year": 2035
    }
  ]
}
```

---

# 🟥 しかし、あなたの bonds.py はこうなっている：

```python
Bond(
    bond_id="PBPE-GLOBAL-2035",
    currency="USD",
    notional=1_500_000_000,
    maturity_year=2035,
    base_coupon_percent=2.0,
    pbpe_floor=400_000_000,
    pbpe_target=600_000_000,
    impact_floor_tco2e=300_000_000,
    coupon_min_percent=1.0,
    coupon_max_percent=6.0,
)
```

### ❌ Next.js が期待するフィールド名と違う

- Next.js: `id`
    
- Backend: `bond_id`
    
- Next.js: `outstanding_usd`
    
- Backend: `notional`
    
- Next.js: `coupon_percent`
    
- Backend: `base_coupon_percent`
    
- Next.js: `impact_floor`
    
- Backend: `impact_floor_tco2e`
    

---

# 🟥 **つまり、フィールド名が完全に不一致。

Next.js はこのデータを読み取れない。**
