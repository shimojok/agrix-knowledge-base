### 🚀 デモを起動させるための手順（手動）

Codespacesの画面が開くと、下に黒い画面（**Terminal / ターミナル**）が表示されているはずです。そこに、以下のコマンドを一行ずつコピー＆ペーストして、Enterキーを押してください。

#### **ステップ1：必要なライブラリのインストール**

まず、ダッシュボードを動かすための「道具（Streamlitなど）」をインストールします。

Bash

```
pip install streamlit pandas numpy
```

#### **ステップ2：ダッシュボードの起動**

次に、メインプログラムを実行します。

Bash

```
streamlit run 04_Azure_Economic_Impact/dashboard/app.py
```

---

### 🌐 起動した後の操作

1. コマンドを打つと、画面右下に **「Your application running on port 8501 is available.」** というポップアップが出ます。
    
2. そこの **[Open in Browser]** という青いボタンをクリックしてください。
    
3. 新しいタブで、日英対応のダッシュボードが立ち上がります。

### 🛠️ 今後のための「完全自動化」設定
