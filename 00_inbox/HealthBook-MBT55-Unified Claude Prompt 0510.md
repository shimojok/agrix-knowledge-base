## 1. プロジェクトの全体像（完了すべき姿）

MBT55微生物群が「生薬・ポリフェノールなどの複合有機物を分解・代謝し、ヒトに有用な代謝産物を生成する」プロセスを**全代謝経路レベルでトレース**し、以下のシステムとして統合する。

### 1.1 最終目標
- **全代謝経路解析**（入力：生薬・食品成分 → 出力：ヒト有用代謝産物）
- **フェノタイピング**（PATH_01〜05の代謝経路活性スコアから個人の健康状態を評価）
- **MBT Probioticsスクリーニング**（特定の代謝経路を活性化する菌株・処方の同定）
- **HealthBook Demo System**（上記を統合した対話型デモ）
- **M3-BioSynergyとの連携**（微生物生態学モデルとの理論的整合性）

### 1.2 システム三層構造
Layer 3: 臨床応用層（HealthBook Demo） — 200項目問診 → フェノタイピング → 疾病リスク評価 → 漢方・ファイトケミカル推奨
Layer 2: 代謝解析層（全代謝経路 + MBT Probiotics） — 生薬・ポリフェノール → 微生物分解 → 活性代謝物 → PATH_01〜05の経路別活性化マップ
Layer 1: 微生物生態学基盤層（M3-BioSynergy） — 120菌種動態 / ハイパーサイクル / 栄養カスケード

### フェーズ2：フェノタイピングエンジン（最高優先度）

**v5.0との最大の差分です。** 現状は `activeRFs` というリスク因子の加算にとどまっていますが、これを PATH_01〜05 の定量スコアに変換します。

```python
# 問診項目 → PATH活性スコアの重み行列（例）
PHENOTYPING_WEIGHTS = {
    "Q2_breakfast_skip": {
        "PATH_03": -0.85,   # 糖代謝低下
        "PATH_05": -0.60,   # 腸内環境悪化
    },
    "Q55_no_exercise": {
        "PATH_03": -0.92,   # 脂質代謝低下
        "PATH_02": -0.70,   # ミネラル代謝低下
    },
    "Q9_high_salt": {
        "PATH_02": -0.90,   # ミネラル還元障害
    },
    # ... 200問 × 5経路の重み行列
}

def calculate_path_scores(answers: dict) -> dict:
    """問診回答 → PATH_01〜05の活性スコア（-1.0〜+1.0）"""
    scores = {f"PATH_0{i}": 0.0 for i in range(1,6)}
    for qid, ans in answers.items():
        intensity = 1.0 if ans == "よくある" else 0.6
        weights = PHENOTYPING_WEIGHTS.get(qid, {})
        for path, w in weights.items():
            scores[path] += w * intensity
    return {k: max(-1.0, min(1.0, v)) for k,v in scores.items()}
```

**完了基準：** 問診回答セット → 5つのPATHスコアが出力される。
