# Analysis Framework

## 1. Fact

実際に確認できる事実

```text
会話ログ
設計ノート
コード断片
GitHub構造
```

---

## 2. Assumption

CopilotまたはDeepSeekの推測

```text
仮定係数
未確認KPI
推定アーキテクチャ
```

---

## 3. Design Decision

設計判断

```text
Pages Router採用
App Router採用
API構造
Dashboard構造
```

---

## 4. Contradiction

矛盾

```text
Concept vs Code

Dashboard vs API

Governance vs Implementation
```

---

## 5. Action Item

今後必要な作業

```text
維持
修正
廃止
再設計
```
