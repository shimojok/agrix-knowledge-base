# 🟩【1】frontend/src/pages/index.tsx と login.tsx はどこに移動する？

## ✔ 結論：**frontend/pages/ に移動する**

理由：

- Next.js の Pages Router の正しいルートは **frontend/pages/**
- UI（画面）はすべて pages/ に統合する必要がある
- src/pages/ は Next.js に無視されるため UI を置く場所ではない

### 正しい移動先：

```
frontend/src/pages/index.tsx → frontend/pages/index.tsx
frontend/src/pages/login.tsx → frontend/pages/login.tsx
```

---

# 🟥【2】frontend/src/pages/index.tsx は pages/index.tsx と重複 → 削除か？

## ✔ 結論：**削除ではなく「どちらを採用するか」決めてから統合する**

理由：

- pages/index.tsx（既存）
- src/pages/index.tsx（新規）

この 2 つは **内容が異なる可能性が高い**  
（実際、あなたの GitHub では別々にコミットされている）

### 正しい手順：

1. **どちらを採用するか決める**
2. 採用した方を **frontend/pages/index.tsx** として残す
3. もう片方は削除する
4. 最終的に **frontend/src/pages/index.tsx は削除**

# 🟦【3】Bonds / Insurance を src/ に移動する場合、パス修正が必要か？

ここが最も重要なポイント。

## 🟩 結論：**Bonds と Insurance は src/ に移動してはいけない（確定）**

理由：

- Bonds と Insurance は **UI（画面）**
- UI は **pages/** に置くのが Next.js の正しい構造
- src/ は **UI 以外（API、components、i18n）** を置く場所
- src/Bonds や src/Insurance に移動すると Next.js がルーティングできない
- つまり **画面が消える**

### よって：

## ❌ frontend/src/Bonds/ に移動 → 間違い

## ❌ frontend/src/Insurance/ に移動 → 間違い

## ✔ 必要なら frontend/pages/bonds/ に移動

## ✔ 必要なら frontend/pages/insurance/ に移動

---

# 🟥【では、Bonds と Insurance は移動すべきか？】

結論：

## ✔ **移動しない（現状のまま src/pages にあるが、UI としては不要）**

理由：

- Dashboard の finance.tsx が **Bonds と Insurance の UI を統合している**
- つまり、Bonds と Insurance は **独立ページとして使われていない**
- PBPE Marketplace Dashboard v3 の設計では  
    **Finance ページが両方を包含する**

よって：

## ❌ Bonds/ を pages/ に移動しない

## ❌ Insurance/ を pages/ に移動しない

## ✔ src/pages/Bonds/ と src/pages/Insurance/ は最終的に削除対象
