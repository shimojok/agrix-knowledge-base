# ✅ **Q1. 「market.tsx → page.tsx にリネームするのか？」**

**はい。App Router では、すべてのルートのエントリポイントは `page.tsx` です。**

つまり：

```
frontend/pages/dashboard/market.tsx
→ frontend/app/dashboard/market/page.tsx
```

**ファイル名は必ず `page.tsx` に統一されます。**

App Router のルール：

- `app/**/page.tsx` がその URL のエントリポイント
- `market.tsx` のような任意の名前は使えない

---

App Router では：

```
app/dashboard/dashboard/page.tsx
```

が **/dashboard/dashboard** に対応します。
