## 🔥 **Step 2：Value → Currency → Bond の連動テスト（金融 OS の心臓部）**

これは Planetary OS の金融レイヤーが **一貫したロジックで動いているか**を確認する最重要テストです。

### ① PBPE Value Engine の結果を取得

テスト JSON：

json

```
{
  "project_id": "TEST-INTEGRATION",
  "domain": "agriculture",
  "country": "JP",
  "time_horizon_years": 10,
  "inputs": {
    "financial": { "capex": 1000000, "opex_per_year": 100000, "expected_cashflow_per_year": 200000, "discount_rate": 0.03 },

  },
  "weights": { "financial": 0.3, "social": 0.3, "ecological": 0.25, "governance": 0.15 }
}
```

期待値：

- `pbpe_score` が **0.6〜0.9** の範囲にあること （農業 × MBT × HealthBook の統合プロジェクトとして妥当）
    

### ② PBPE Value を PBPE Currency Model に渡す

PBPE Value の `pbpe_score` をそのまま `pbpe_value` として使用：

json

```
{
  "pbpe_value": 0.78,
  "reserve_ratio": 0.3
}
```

期待値：

- `issued_amount` が **0.5〜0.7**
    
- `reserve_amount` が **0.2〜0.3**
    

PBPE Value → PBPE Currency の連動が確認できる。

### ③ PBPE Value を PBPE Bond Engine に渡す

PBPE Value の `pbpe_score` を `pbpe_stability` として使用：

json

```
{
  "bond_id": "JP-PBPE-2035",
  "face_value": 1000,
  "coupon_rate": 0.03,
  "maturity_years": 10,
  "pbpe_backing": 200,
  "pbpe_stability": 0.78
}
```

期待値：

- `price` が **1200〜1400** の範囲
    
- `ytm` が **0.018〜0.025** の範囲
    

PBPE Value → PBPE Bond の連動が確認できる。
