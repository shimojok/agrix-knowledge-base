🧮 各エンジンの計算式（数式）

1. MBT55エンジン

① GHG削減量

```
total_CO2e = (CH4削減 × 28) + (N2O削減 × 265) + CO2削減
```

· CH4削減 = ベースラインCH4 × 0.94 × 廃棄物量
· N2O削減 = ベースラインN2O × 0.78 × 廃棄物量
· CO2削減 = ベースラインCO2 × 0.60 × 廃棄物量

② 炭素隔離量

```
total_sequestration = 310 tCO₂e/ha × 面積(ha) × (年数/10)
```

③ ハイパーサイクル安定度

```
MEI = 0.3 + 0.55 × (多様度/120)
安定度 = MEI × 温度係数
温度係数 = 1.0 - 0.007 × |温度 - 90|
```

---

2. AGRIXエンジン

① 収量予測

```
最終収量 = 基準収量 × MBT係数 × SOC係数
SOC係数 = 1.0 + (SOC増加量 / 100) × 0.15
```

② 栄養価スコア

```
栄養スコア = 各栄養素値 × MBT改善係数 (平均+31%)
```

③ 土壌健康指数 (SHE)

```
SHE = SOCスコア × 0.5 + 多様性スコア × 0.3 + pHスコア × 0.2
```

---

3. Scope3エンジン

① PBPE変換

```
PBPE = Scope3排出量(tCO₂e) × 1.0 (1:1換算)
```

② MBT削減効果適用

```
削減後排出 = 元排出 × (1 - 削減率)
削減率 = 0.82 (廃棄物) / 0.30 (輸送) / 0.40 (購入品)
```

---

4. HealthBookエンジン

① エストロボローム活性

```
活性スコア = 食物繊維(30) + 発酵食品(25) + 便通(20) - 加工食品(30) - ディスバイオシス(40)
```

② アセチルCoA生成能力

```
能力 = 糖(25%) + 脂質(20%) + タンパク質(15%) + SCFA(25%) + ミネラル(10%) - 冷え(15%) - ストレス(10%)
```

③ Health PBPE

```
Health PBPE = (健康スコア / 10) × 1000 × 人口 + (医療費削減 × 0.1) × 人口
```

---

5. PBPEエンジン

① 各コンポーネント

```
Carbon PBPE   = GHG削減(tCO₂e) × 1.0 + 炭素隔離(tCO₂e) × 0.5 + 廃棄物処理(ton) × 0.1
Soil PBPE     = SOC増加(tCO₂e) × 0.3 + 重金属無害化率(%) × 10000 + 多様性改善 × 50000
Water PBPE    = 節水量(m³) × 0.1 + 水質改善 × 10000 + 栄養塩流出削減(%) × 20000
Health PBPE   = 栄養改善 × 5000 + 収量増加(ton) × 100 + 品質スコア × 1000 + 医療費削減 × 0.1
```

② 総合PBPE

```
Total PBPE = Carbon × 1.0 + Soil × 0.8 + Water × 0.6 + Health × 1.2
```

③ 動的PBPE価格

```
価格 = 基準価格(10USD) × (1 + 0.5 × (需要/供給 - 1))
```

---

6. Registryエンジン

① 7桁コード生成

```
コード = プレフィックス(CRD/BND/RPT) + "-" + 7桁ランダム文字列
文字列 = A-Z (0,1,I,O除外) + 2-9
```

② 二重計上防止

```
IF KPI_ID IN 使用済みリスト → エラー
ELSE → 発行許可
```

🔄 MBT ON/OFF 切り替え時の挙動

モード データソース 表示値
MBT ON 各エンジンの計算結果 最大効果値 (例: GHG 510Mt)
MBT OFF 従来比ベースライン (固定値) ベースライン値 (例: GHG 150Mt)

現在の「従来比」値は仮定値です。
設計ノートを元に、実際のベースライン値に修正します。
