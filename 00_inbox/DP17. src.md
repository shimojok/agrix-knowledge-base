# 🟦【Next.js の公式構造（Pages Router）】

Next.js（Pages Router）の構造はこう定義されている：

```
pages/        ← UI（ルーティングされるページ）
src/          ← UI 以外のアプリケーションロジック
```

つまり：

- **pages/** → ルーティングされる UI（画面）
- **src/** → ルーティングされないロジック（API 呼び出し、コンポーネント、i18n、hooks、utils など）
