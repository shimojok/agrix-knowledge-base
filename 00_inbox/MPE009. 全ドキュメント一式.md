````markdown
## Core Mathematical Model

### Hypercycle ODE System (from M3-BioSynergy)

The MBT55 hypercycle is governed by the following ordinary differential equations:

**State Variables:**
- `C_p`: Polymer carbon (cellulose, etc.)
- `C_s`: Interface currency (lactate, SCFAs)

**Core Stability Condition (Electron Dissipation):**

dH₂/dt = δE - ε(X_m + X_s)H₂ ≈ 0

```

- `symptom_present[j]` = 1 if reported, 0 otherwise
````

````markdown
## Origin: Tateyama Mountain Range

MBT55 (formerly NB bacteria) was discovered from soil at the foot of the Tateyama mountain range in Toyama Prefecture, Japan. ## The 55:45 Ratio Revolution

**MBT55's defining innovation**: 55% aerobic : 45% anaerobic microorganisms.

This fundamentally differs from natural soil (typically 20% aerobic : 80% anaerobic). By spatially integrating oxidation and reduction processes in close proximity, MBT55 creates a **metabolic bypass**:

- Anaerobic intermediates are immediately processed by aerobic species
- No accumulation of reduced compounds
- Electron stagnation (putrefaction) is mathematically eliminated

### 1. Carbon/Interface Currency: Lactate

Lactate is the true metabolic hub, not acetate (which trends toward methane fermentation):

- **High diffusion rate**: Penetrates deep anaerobic layers

- **Cross-feeding**: Converted to anti-inflammatory **butyrate** in the gut

### 2. Electron Currency: Quinone Shuttle

Low-molecular-weight quinones from lignin degradation:

- **Inter-species electron transfer**: Accelerates microbial cooperation
- **Mitochondrial complementation**: Acts as "bio-battery" in human cells

### 3. Mineral/Structural Currency: Fulvic Acid

Low-molecular-weight humic substances from high decomposition rates:

- **Chelation**: Holds trace elements as a "mobile nutrient OS"
- **Gut colonization**: Supports lactic acid bacteria establishment
- **Biological signal token**: Trackable on Azure for health monitoring

The condition for stable attractor convergence is multi-pathway electron dissipation:

```

**Interpretation**: Hydrogen production rate and consumption rate are in equilibrium. Zero H₂ accumulation means zero putrefaction—no amines, no hydrogen sulfide, no malodor.
````

````markdown
# ⚡ 3-Stage Enzyme Cascade Mechanism

## Overview

The MBT55 3-stage cascade is a sequential metabolic relay where different functional groups dominate each phase, progressively transforming complex natural products into highly bioavailable active compounds.

## Stage 1: High-Speed Hydrolysis (0-6 hours)

**Conditions**: 38°C, aerobic, pH 6.0

**Key Players**: *Tateyama-Jodo (Bacillus sp.)*, amylase producers, protease producers, lipase producers

**Actions**:
- Starch → Oligosaccharides (amylase)
- Proteins → Peptides, amino acids (protease)
- Lipids → Free fatty acids (lipase)
- Cell wall disruption of raw herbs

**Example (Deer Velvet Antler)**:
IGF-1 and growth factors are liberated from the protein matrix by *Tateyama-Jodo* proteases.

## Stage 2: Metabolic Transformation (6-24 hours)

**Conditions**: 42°C, microaerophilic, pH 5.5

**Key Players**: *Tateyama-Menami (Atopostipes sp.)*, β-glucosidase producers, deglycosylation specialists

**Actions**:
- Glycoside → Aglycone (deglycosylation)
- Glycoprotein → Exposed sialic acid
- Flavonoid → Active aglycone form

**Deliberate Heat Stress**: The 42°C temperature intentionally stresses the consortium, boosting secondary metabolite (defense compound) production.

**Example (Coptis Berberine)**:
Berberine is demethylated and structurally modified for enhanced intestinal absorption.

## Stage 3: Deep Synthesis & Maturation (24-72 hours)

**Conditions**: 35°C, anaerobic, pH 6.5

**Key Players**: *Tateyama-Ryuo (Clostridium sp.)*, butyrate producers, mineral reducers

**Actions**:
- Anaerobic reduction of steroid skeletons
- Novel anti-inflammatory oxylipin synthesis
- Fulvic acid chelation of minerals
- Butyrate production via lactate cross-feeding

**Example (Earthworm × Deer Velvet × Artemisia)**:
The composite generates sialic acid-conjugated artemisinin (enhanced RBC targeting), new anti-inflammatory oxylipins, and cardioactive steroid metabolites—compounds not present in any single source material.
````

````markdown
The screening system reframes Kampo from "empirical formula matching" to **"microbial metabolic pathway compensation"**. The core question is:

```
PATH_01 (Digestion/Gut Barrier)      → MBT_META_01 (Primary Decomposition)
PATH_02 (Liver Detoxification)       → MBT_META_02 (Refractory Degradation)

### Step 3: Priority Ranking

Strains are ranked by:
1. Number of deficient PATHs addressed
2. Cascade stage compatibility (Stage 1→2→3 sequence)
3. Substrate compatibility with recommended Kampo/herbs

### Step 4: Combination Proposal

Strains are proposed in staged administration:
- **Stage 1 strains first** (0-6h): Substrate preparation
````

````markdown
### 2. Phenotype Scoring

```http
POST /api/v1/phenotype
```

**Request Body**:
```json
{
  "language": "ja",
  "questionnaire_answers": {
    "炎症": true,
    "アレルギー": true
  }
}
```

**Response**: PhenotypeResult object (see pipeline response `phenotype` field).

### 3. Probiotic Screening

```http
POST /api/v1/screening
```

**Request Body**: PhenotypeResult object

**Response**: ScreeningResult object (see pipeline response `probiotic_screening` field).

### 4. Pathway Lookup

```http
GET /api/v1/pathways/{substrate_name}
```

**Example**: `GET /api/v1/pathways/鹿茸`

**Response**: Metabolite prediction for the specified substrate.

### 5. Strain Definitions

```http
GET /api/v1/strains
```

**Response**: Array of all 5 Meta-Strain definitions with enzyme profiles, substrate preferences, and optimal conditions.

## Error Responses

```json
{
  "error": "PATHWAY_NOT_FOUND",
  "message": "No pathway found for 'unknown_substrate'",
  "status_code": 404
}
```

- 100 requests/minute per IP

API key required for production use. Pass via header:

X-API-Key: your-api-key-here
```
````

````markdown
## Code Style

## Testing

```bash
# Run all tests
pytest

# Run specific test file
pytest tests/unit/test_pathway_database.py -v

pytest --cov=src --cov-report=html
```

## Adding New Pathways

1. Add entry to `data/pathways/master_pathways.json`
2. Follow existing schema with `cascade_stage_1/2/3`
3. Add corresponding enzyme and key player data
4. Run `pytest tests/unit/test_pathway_database.py` to validate

## Adding New Meta-Strains

1. Add entry to `data/probiotics/probiotic_matrix.json`
2. Define `substrate_preference`, `enzyme_profile`, `optimal_conditions`
3. Update `META_STRAIN_DEFINITIONS` in `src/core/config.py`
4. Update i18n dictionaries in `dashboard/i18n/`

## Documentation

All new features must include:
- Code docstrings
- Updated API spec if applicable
- README updates if major feature

- [ ] Type hints complete
- [ ] Documentation updated
- [ ] i18n dictionaries updated for both JA and EN
````
