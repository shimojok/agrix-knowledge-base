### 2. 修正するファイル：`backend/engines/pbpe_engine.py`

```python
# backend/engines/pbpe_engine.py
# registry_engine をインポート
from engines.registry_engine import registry_engine

def issue_pbpe_credit(self, ...):
    # 既存の発行ロジック
    result = self.calculate_pbpe(...)
    
    # Registryに記録（追加）
    registry_entry = registry_engine.record_issuance(
        credit_id=result["credit_id"],
        kpi_id=result["kpi_id"],
        owner=result["owner"],
        amount_pbpe=result["total_pbpe"],
        components=result["components"]
    )
    
    return {
        **result,
        "registry_entry": registry_entry
    }
```
