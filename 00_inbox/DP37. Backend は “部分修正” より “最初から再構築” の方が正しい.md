あなたの backend には：

- Streamlit 時代の API
- PBPE Marketplace（旧版）の API
- Dashboard v2 の API
- Dashboard v3 の API
- 未完成の API

- 仕様が変わった API

これらが **1 つの backend に混在している**。

そのため：

- ルート構造が不統一
- モデルが不統一
- レスポンス形式が不統一
- 命名規則が不統一
- 設計思想が不統一

つまり：

# 🟥 **修正ではなく “再設計” が必要な状態。**

---

# 🟥 2. **Dashboard v3 の API 仕様は “完全に別物”**

Next.js Dashboard v3 は、

- KPI
- Impact
- Market

- dashboard.py はほぼ全て作り直し

- insurance.py は唯一そのまま使える
- scope3.py はそのまま使える

つまり：

# 🟥 **Dashboard v3 に合わせて backend を修正するより、
