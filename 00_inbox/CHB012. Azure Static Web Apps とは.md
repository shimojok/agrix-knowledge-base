## Azure Static Web Apps とは

一言で言うと、**「GitHubにpushするだけで世界中に公開されるWebホスティング」**です。サーバー管理が一切不要で、HealthBookのようなReactアプリに最適です。

---

## HealthBookに関係する主要機能

**① GitHub連携の自動デプロイ**
`main`ブランチにpushした瞬間、自動でビルド→世界配信まで完了します。手動操作は不要です。

**② グローバルCDN（コンテンツ配信網）**
静的ファイルを世界中のエッジサーバーに自動配置するため、東南アジア・アフリカからのアクセスも高速です。HealthBookのグローバル展開に直結します。

**③ Azure Functions との統合**
JavaScript、TypeScript、Python、C#でAzure Functionsを使ったサーバーレスAPIを構築でき [Microsoft Azure](https://azure.microsoft.com/en-us/products/app-service/static) ます。将来の**Pythonバックエンド**（推論エンジン本番版）をそのまま同じリポジトリに追加できます。

**④ プレビュー環境**
Pull Requestを作るたびに独立したプレビューURLが自動生成されます。本番に影響せずテストできます。

## 料金（2025年現在）

フリープランはカスタムドメイン2つ、ステージング環境3つ、250MB/環境のストレージを含みます。スタンダードプランは月9ドル/アプリで、カスタムドメイン5つ、ステージング環境10つ、500MB/環境のストレージを備えSLAが付きます。 [Azuredive](https://www.azuredive.net/2025/09/azure-static-web-apps-in-depth/)

```
フリープラン（現在のHealthBook開発段階）
  ✅ 完全無料
  ✅ カスタムドメイン 2つ
  ✅ SSL証明書 自動
  ✅ GitHub Actions 自動設定
  ✅ Azure Functions 月100万回まで無料
  ❌ SLA（稼働保証）なし

スタンダードプラン（本番・企業向け展開時）
  💰 月9ドル/アプリ
  ✅ SLA保証
  ✅ カスタム認証（生命保険・医療機関向けAPI）
  ✅ プライベートエンドポイント（VNet統合）
  ✅ エンタープライズCDN（Azure Front Door）
```

## 一点注意点

APIファンクションのリクエスト処理は最大45秒に制限されており、2025年はSWAのGitHubリポジトリの更新が少ない状況です。 [Azuredive](https://www.azuredive.net/2025/09/azure-static-web-apps-in-depth/) 将来、推論エンジンの処理が重くなった場合は、APIバックエンドだけ**Azure Container Apps**や**Azure App Service**に分離する設計が安全です。

ただしHealthBookのPOC段階では全く問題ありません。まずフリープランで公開し、本番移行時に構成を見直す形で進めましょう。
