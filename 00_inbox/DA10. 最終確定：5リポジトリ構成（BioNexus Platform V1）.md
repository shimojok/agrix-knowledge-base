### 2. 「コードによるエージェント化」の具体的実装方法

各リポジトリに **`AGENTS.md`** ファイルを配置し、そこでAIエージェントの振る舞いを定義します。これを **「リポジトリ埋め込み型エージェント指示書」** と呼びます。

#### 運用フロー例 (GitHub Issues + 手動トリガー)

```mermaid
graph LR
    User[あなた] -->|1. Issue作成| Repo[例: M3-Core-Engine]
    Repo -->|2. GitHub Actions 起動| Agent[AI Agent Script]
    Agent -->|3. AGENTS.md 読込 & コード生成| PR[Pull Request]
    PR -->|4. あなたがレビュー| Merge
```

#### 実装コード例 (`.github/workflows/ai-agent.yml`)

```yaml
name: AI Agent Responder

on:
  issues:
    types: [opened]

jobs:
  ai-response:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
    steps:
      - uses: actions/checkout@v4
      - name: Setup Python
        uses: actions/setup-python@v5
      - name: Run MBT55 Agent
        env:
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          ISSUE_TITLE: ${{ github.event.issue.title }}
          ISSUE_BODY: ${{ github.event.issue.body }}
        run: |
          # AGENTS.md の指示に従い、コードを自動生成するスクリプトを呼び出し
          python scripts/ai_code_generator.py
      - name: Create Pull Request
        uses: peter-evans/create-pull-request@v6
        with:
          commit-message: "AI: ${{ github.event.issue.title }}"
          branch: "ai/${{ github.event.issue.number }}"
```
