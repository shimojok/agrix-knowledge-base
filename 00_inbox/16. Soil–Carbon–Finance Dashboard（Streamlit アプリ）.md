## **Codespaces を削除して作り直す**

1. GitHub のリポジトリを開く
2. 緑の「Code」→ **Codespaces**
3. 今使っている Codespace の右側の **… → Delete**
4. **Create codespace on main** を押す
5. 新しい Codespaces が開いたら：

```
pip install streamlit pandas numpy
streamlit run app.py
```

これで **必ず右下に “Open in Browser” が出る**。
