# 🔍 **なぜ全部 `page.tsx` になるのか？（Next.js App Router の仕様）**

Next.js App Router では：

- **URL = フォルダ名**
- **ページ本体 = そのフォルダ内の `page.tsx`**

というルールになっています。

例：

|URL|App Router の構造|
|---|---|
|/dashboard/market|`app/dashboard/market/page.tsx`|
|/dashboard/finance|`app/dashboard/finance/page.tsx`|
|/dashboard/kpis|`app/dashboard/kpis/page.tsx`|

だから、**ファイル名は全部 `page.tsx` で正しい**のです。
