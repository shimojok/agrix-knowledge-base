Kazさん、このエラーは、`activate` スクリプトの実行方法に問題があります。正しいコマンドは、パスを **スペースで区切る** 必要があります。

---

## ✅ 正しいコマンド

```bash
venv\Scripts\activate
```

**※ `activate` の前にスペースが必要です。**

あなたが実行したコマンドは：

```bash
venv\Scripts\activatevenv\Scripts\activate
```

これは間違いです。`activate` が2回連続で書かれています。

---

## 🚀 正しい手順（再確認）

### Step 1: 仮想環境を有効化

```bash
cd C:\PBPE-Marketplace\backend
venv\Scripts\activate
```

成功すると、プロンプトの先頭に `(venv)` と表示されます。

---

### Step 2: バックエンドを起動

```bash
uvicorn main:app --reload --port 8000
```

---

## ⚠️ もし「venv」フォルダが存在しない場合

仮想環境が作成されていない可能性があります。その場合は：

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
