## STEP2：時間発展を追加

```python
def step(state, mbt55=True):
    M = 1.0 if mbt55 else 0.3
    
    D = state["disease"] * np.exp(-0.3 * M)
    N = state["nutrients"] + 0.5 * M
    
    Y = state["yield"] + 0.2*M + 0.3*N - 0.4*D
    C = state["carbon"] + 0.3*M
    
    return {
        "yield": Y,
        "carbon": C,
        "disease": D,
        "nutrients": N
    }
```

## STEP3：シミュレーション化

```python
def run_simulation(mbt55=True, steps=10):
    state = {
        "yield": 5.0,
        "carbon": 2.0,
        "disease": 0.4,
        "nutrients": 1.0
    }
    
    history = []
    
    for _ in range(steps):
        state = step(state, mbt55)
        history.append(state.copy())
    
    return history
```
