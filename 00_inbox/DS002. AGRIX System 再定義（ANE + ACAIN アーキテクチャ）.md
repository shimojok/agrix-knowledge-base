## 🤖 AgriWare AIエージェント（4つの完全数値化エンジン）

各エージェントはMBT55の特定領域を「数値（0-1スコア＋詳細メトリクス）」に変換します。

### Agent-1: ハイパーサイクル・アナライザー（土壌生態制御）
**入力**: pH, Eh, 水分, 温度, 有機炭素, 窒素, MBT55投入量  
**出力**:
- `cyclePhase`: 'ACCELERATING' | 'STABLE' | 'DECAYING'  
- `cycleEfficiency`: 0-1（炭素/窒素変換効率）  
- `humificationRate`: 0-1（腐植化達成率）  
- `resourceConversionRate`: 0-1（有機物→代謝産物変換率）

### Agent-2: バイオセキュリティ・モニター（病原菌制御）
**入力**: 病原菌カウント（Fusarium, Pythium等）, 有用菌比率, MBT55活性指数  
**出力**:
- `pathogenSuppressionIndex`: 0-1（病原菌抑制率）  
- `biomeResilienceScore`: 0-1（微生物叢の回復力）  
- `diseaseOutbreakRisk`: 0-1（病害発生リスク）  
- `biosecurityLevel`: 'HIGH' | 'MEDIUM' | 'LOW'

### Agent-3: バイオコントロール・オプティマイザー（生物的防除）
**入力**: 作物フェノタイピング（NDVI, PRI, 葉温）, 土壌酵素活性, SCFA量  
**出力**:
- `pestResistanceScore`: 0-1（害虫抵抗性）  
- `beneficialMicrobeRatio`: 0-1（有用菌/全菌比）  
- `biocontrolEfficacy`: 0-1（防除効果）  
- `recommendedAction`: string（次回推奨処方）

### Agent-4: リソース・カスケード・トラッカー（栄養・代謝フロー）
**入力**: 全栄養塩（N,P,K,Ca,Mg）, アミノ酸, SCFA, ポリフェノール前駆体  
**出力**:
- `nutrientUseEfficiency`: 0-1（肥料利用率）  
- `metaboliteCascadeIndex`: 0-1（代謝カスケードの完全性）  
- `polyphenolPrecursorPotential`: 0-1（機能性前駆体蓄積量）  
- `lossPreventionRate`: 0-1（養分ロス削減率）

### 統合オーケストレーションAPI（最重要エンドポイント）

```typescript
// app/api/agrix/orchestrate/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { runHypercycleAgent } from '@/lib/agrix/agents/hypercycle';
import { runBiosecurityAgent } from '@/lib/agrix/agents/biosecurity';
import { runBiocontrolAgent } from '@/lib/agrix/agents/biocontrol';
import { runResourceCascadeAgent } from '@/lib/agrix/agents/resourceCascade';

export async function POST(req: NextRequest) {
  const soilData = await req.json();

  // 4エージェントを並列実行
  const [hypercycle, biosecurity, biocontrol, cascade] = await Promise.all([
    runHypercycleAgent(soilData),
    runBiosecurityAgent(soilData),
    runBiocontrolAgent(soilData),
    runResourceCascadeAgent(soilData),
  ]);

  // AGRIX総合診断スコア（MBT55の全リソース数値化）
  const agrixHealthScore = (
    hypercycle.cycleEfficiency * 0.3 +
    biosecurity.biomeResilienceScore * 0.25 +
    biocontrol.biocontrolEfficacy * 0.25 +
    cascade.nutrientUseEfficiency * 0.2
  ) * 100;

  return NextResponse.json({
    timestamp: new Date().toISOString(),
    agrixHealthScore, // 0-100（MBT55生態系の総合健康度）
    agents: {
      hypercycle,
      biosecurity,
      biocontrol,
      resourceCascade: cascade,
    },
    // ACAINゲートウェイ出力（SafetyChain/PBPEが直接利用可能）
    acain: {
      safetyChain: {
        polyphenolPotential: cascade.polyphenolPrecursorPotential,
        functionalBaseScore: hypercycle.resourceConversionRate * 0.7 + cascade.metaboliteCascadeIndex * 0.3,
        biosecurityLevel: biosecurity.biosecurityLevel,
      },
      pbpe: {
        carbonSequestrationPotential: hypercycle.humificationRate * 2.5, // tCO2/ha/yr概算
        lossReductionValue: cascade.lossPreventionRate * 100, // ％
        yieldStabilityIndex: biocontrol.pestResistanceScore * 0.5 + hypercycle.cycleEfficiency * 0.5,
      }
    }
  });
}
```
