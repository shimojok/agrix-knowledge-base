土壌データとは、どのような項目が必要ですか？

---

結論から言うと、**AGRIXの「土壌ハイパーサイクル管理モジュール」で必要な土壌データ項目は、従来の農学データでは不十分**です。 あなたが構築しているのは **“土壌の代謝システム”を理解するプロダクト**なので、必要な項目は **生態学 × 微生物学 × 地球化学 × MBT55代謝**を統合した “新しい土壌データ標準” になります。

以下に、**MVPとして絶対に必要な項目**と、**ハイパーサイクル完全版で必要になる項目**を整理します。

# 🎯 **まず最初に必要な結論（MVP）**

**土壌ハイパーサイクルを動かすための最小データ項目は、以下の5カテゴリ・合計18項目です。**

1. **炭素代謝（SOC・腐植質）**
    
2. **微生物代謝（MBT55 × 土壌微生物）**
    
3. **栄養カスケード（NPK・ミネラル）**
    
4. **土壌物理性（構造・水分・通気性）**
    
5. **土壌毒性（農薬・重金属・化学物質）**
    

これらは、あなたが作る **AgriWare / SafetyChain / MBT55ハイパーサイクル** の “核” になります。

# 🧬 **1. 炭素代謝（SOC・腐植質）**

MBT55の代謝産物が腐植質へ変化するかどうかを判定するための必須項目です。

### **必須（MVP）**

- **SOC（有機炭素量） before / after**
    
- **腐植質量（Humus）**
    
- **フミン酸 / フルボ酸 / ヒューミン比率**
    
- **土壌有機物（SOM）**
    
- **土壌呼吸量（CO₂放出量）**
    

### **理由**

- MBT55代謝物が腐植質に変化しているか
    
- 長期炭素隔離が成立しているか
    
- 土壌の「代謝速度」がどれくらいか
    

を判定するため。

# 🦠 **2. 微生物代謝（MBT55 × 土壌微生物）**

MBT55が土壌の微生物ネットワークをどう変化させたかを測定する項目です。

### **必須（MVP）**

- **MBT55指数（before / after）** → MBT55の存在量・活性度
    
- **微生物多様性指数（Shannon / Simpson）**
    
- **好気性 / 嫌気性比率**
    
- **菌体量（CFU）**
    
- **酵素活性（セルラーゼ・リグニナーゼ・プロテアーゼ）**
    

### **理由**

MBT55は「分解者ギルドの再構築」を行うため、 土壌の微生物構造がどう変化したかを追跡する必要があります。

# 🧪 **3. 栄養カスケード（NPK・ミネラル・ポリフェノール）**

MBT55代謝物が「肥料として機能しているか」を判定する項目です。

### **必須（MVP）**

- **窒素（N）**
    
- **リン酸（P）**
    
- **カリウム（K）**
    
- **カルシウム（Ca）**
    
- **マグネシウム（Mg）**
    
- **鉄（Fe）**
    
- **マンガン（Mn）**
    
- **ポリフェノール含有量**
    
- **アミノ酸含有量（MBT55代謝物由来）**
    

### **理由**

MBT55代謝物はアミノ酸・ポリフェノール・ミネラルを含むため、 「肥料としての機能性」を評価する必要があります。

# 💧 **4. 土壌物理性（構造・水分・通気性）**

ハイパーサイクルが成立するための “環境条件” を測定します。

### **必須（MVP）**

- **土壌水分量**
    
- **pH**
    
- **EC（電気伝導度）**
    
- **CEC（陽イオン交換容量）**
    
- **土壌硬度**
    
- **土壌粒子構造（砂・シルト・粘土比）**
    
- **通気性（O₂拡散率）**
    

### **理由**

MBT55は好気性55%・嫌気性45%のため、 土壌の通気性・水分がハイパーサイクルの成立に直結します。

# ☣️ **5. 土壌毒性（農薬・重金属・化学物質）**

MBT55が「毒性物質を無害化したか」を判定する項目です。

### **必須（MVP）**

- **農薬残留量（主要成分）**
    
- **カドミウム（Cd）**
    
- **鉛（Pb）**
    
- **ヒ素（As）**
    
- **その他重金属（Cr, Hg, Ni）**
    

### **理由**

MBT55は農薬・重金属を分解するため、 「どれだけ無害化されたか」が重要な評価指標になります。

# 🧩 **まとめ：MVPで必要な土壌データ項目（18項目）**

|カテゴリ|項目|
|---|---|
|炭素代謝|SOC、腐植質、フミン酸/フルボ酸/ヒューミン、SOM、土壌呼吸|
|微生物代謝|MBT55指数、微生物多様性、好気/嫌気比、菌体量、酵素活性|
|栄養カスケード|NPK、Ca、Mg、Fe、Mn、ポリフェノール、アミノ酸|
|物理性|水分、pH、EC、CEC、硬度、粒子構造、通気性|
|毒性|農薬残留、Cd、Pb、As、その他重金属|
