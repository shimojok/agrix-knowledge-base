### 3. MBT55 ODE と AIエージェントの連結

**狙い:** 土壌側の MBT55 ハイパーサイクル出力を Microbe-Agent の入力に反映させる。

**流れ:**

1. `/api/mbt55/hypercycle` に土壌センサーデータを渡す
    
2. 返ってきた `C`（炭素）や `P`（腐植前駆体）を `SoilSignals` の一部として扱う
    
3. Phenotyping-Orchestrator 内で、
    
    - まず MBT55 ODE を呼ぶ
        
    - その結果を使って Microbe-Agent を呼ぶ
        

ts

```
// app/api/phenotyping/route.ts 内の先頭部分を拡張
const mbt = await fetch(`${base}/api/mbt55/hypercycle`, {
  method: "POST",
  body: JSON.stringify({
    eh_mV: body.soil.eh_mV,
    moisture_pct: body.soil.moisture_pct,
    S: 10,
  }),
}).then((r) => r.json());

// Microbe-Agent 呼び出し時に CO₂フラックスなどを MBT55出力から補正
const micro = await fetch(`${base}/api/agents/microbe`, {
  method: "POST",
  body: JSON.stringify({
    soil: {
      ...body.soil,
      co2_flux_mg_m2_h: mbt.C * 100, // 例：炭素固定量からCO₂フラックスを推定
    },
  }),
}).then((r) => r.json());
```

これで、

- **V-Index が SafetyChain UI に乗り、消費者の選択基準として提示される**
    
- **AIエージェント群の挙動が専用ダッシュボードで可視化される**
    
- **MBT55 ハイパーサイクル ODE が AIエージェントと連結し、「土壌 → 代謝 →機能性」の一連の流れが数理的に繋がる**
