# プロジェクト統括PMOへの指示プロンプト

## 【前提】あなたはPMOです。以下の全コンテキストを読み込み、HealthBook／MBT55／全代謝経路解析／MBT Probioticsスクリーニングの完了に向けた実行計画を立案・推進してください。


## 1. プロジェクトの全体像（完了すべき姿）

MBT55微生物群が「生薬・ポリフェノールなどの複合有機物を分解・代謝し、ヒトに有用な代謝産物を生成する」プロセスを**全代謝経路レベルでトレース**し、以下のシステムとして統合する。

### 1.1 最終目標
- **全代謝経路解析**（入力：生薬・食品成分 → 出力：ヒト有用代謝産物）
- **フェノタイピング**（代謝不全パターンから個人の健康状態を評価）
- **MBT Probioticsスクリーニング**（特定の代謝経路を活性化する菌株・処方の同定）
- **HealthBook Demo System**（上記を統合した対話型デモ）
- **M3-BioSynergyとの連携**（微生物生態学モデルとの理論的整合性）

### 1.2 システム三層構造
```
┌─────────────────────────────────────────────────────────────────┐
│ Layer 3: 臨床応用層（HealthBook Demo）                          │
│ - 200項目問診 → フェノタイピング                                │
│ - 疾病リスク評価 → 漢方・ファイトケミカル推奨                   │
├─────────────────────────────────────────────────────────────────┤
│ Layer 2: 代謝解析層（全代謝経路 + MBT Probiotics）             │
│ - 生薬・ポリフェノール → 微生物分解 → 活性代謝物               │
│ - PATH_01〜05 の経路別活性化マップ                             │
├─────────────────────────────────────────────────────────────────┤
│ Layer 1: 微生物生態学基盤層（M3-BioSynergy）                    │
│ - 120菌種動態 / ハイパーサイクル / 栄養カスケード              │
│ - Wilkinsonの7プロセス × MBT55                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 3. PMOが実行すべきタスク

### 3.1 フェーズ1：全代謝経路解析の実装（2週間）

**目的**：MBT55微生物群が生薬・ポリフェノールから「ヒト有用代謝産物」を生成する経路をデータベース化する。

**タスク**：
1. `MetabolicPathwayDatabase` クラスを実装（`src/mbt55/metabolomics/pathway_db.py`）
2. 以下の経路マッピングをデータ化：

| 基質（例） | 分解菌群 | 中間代謝物 | 最終活性代謝物 | ヒト効果 |
|-----------|---------|-----------|---------------|---------|
| 葛根（プエラリン） | 放線菌 | ダイゼイン | エクオール | 血流改善 |
| 黄連（ベルベリン） | 放線菌 | ジヒドロベルベリン | ベルベリン誘導体 | 抗炎症 |
| 大豆イソフラボン | 乳酸菌 | ダイゼイン | エクオール | ホルモン調整 |
| 緑茶カテキン | 放線菌 | 没食子酸 | ピロガロール | 抗酸化 |

3. `src/mbt55/metabolomics/predictor.py` で「入力成分 → 予測活性代謝物」を推定する関数を実装

### 3.2 フェーズ2：フェノタイピングエンジンの実装（1.5週間）

**目的**：200項目問診を PATH_01〜05 の各代謝経路活性スコアに変換する。

**タスク**：
1. `src/healthbook/phenotyping/engine.py` を新規作成
2. 問診項目 → 代謝ブロックの重み行列を定義（例：朝食欠食 → PATH_03糖代謝低下）
3. 以下のスコアリング関数を実装：
   ```python
   def calculate_pathway_score(responses: Dict[int, bool]) -> Dict[str, float]:
       """
       戻り値例：
       {
           "PATH_01": 0.65,  # 硫黄・解毒系
           "PATH_02": 0.42,  # ミネラル・還元系
           "PATH_03": 0.38,  # 脂質・糖代謝系
           "PATH_04": 0.71,  # 芳香族・神経系
           "PATH_05": 0.53   # 多糖・免疫系
       }
       """
   ```
4. フェノタイプと疾患リスクの相関を可視化

### 3.3 フェーズ3：MBT Probioticsスクリーニングエンジンの実装（2週間）

**目的**：「どの菌株が、どの基質から、どの活性代謝物を産生するか」をスコアリングする。

**タスク**：
1. `src/mbt55/screening/engine.py` を新規作成
2. スクリーニングスコア関数を実装：
   ```python
   def calculate_probiotic_score(
       strain_id: str,
       substrate: str,
       target_metabolite: str
   ) -> float:
       """0-1のスコア（1が最適）"""
   ```
3. 菌株 × 基質 × 代謝産物のマトリックスデータを `data/mbt55/screening_matrix.json` として作成
4. 処方（漢方・食事）から最適なMBT55菌株セットを提案する関数を実装

### 3.4 フェーズ4：統合デモシステムの完成（1週間）

**目的**：フェーズ1〜3を統合し、エンドツーエンドで動作するデモを完成させる。

**タスク**：
1. `examples/complete_demo.py` を作成し、以下のフローを実装：
   - 問診入力（サンプル）
   - フェノタイピング（PATH_01〜05スコア）
   - 疾病リスク評価
   - 不足している代謝経路の特定
   - 推奨漢方・ファイトケミカルの表示
   - MBT55菌株セットの提案
   - 予測される活性代謝物と期待効果の表示
2. `examples/mbt55_screening_demo.py` でスクリーニング単体のデモを実装
