## 1. Streamlit Cloud デプロイ手順

### M3-Core-Engine のデプロイ

Streamlit Cloudを使えば、GitHub上のコードをそのままWebアプリとして公開できます。

1. [Streamlit Cloud](https://streamlit.io/cloud) にアクセスし、GitHubアカウントでログイン
2. 右上の「**New app**」をクリック
3. 以下の設定を入力：
   - **Repository**: `shimojok/M3-Core-Engine`
   - **Branch**: `main`
   - **Main file path**: `notebooks/02_methane_abatement_calc.ipynb` → ただし`.ipynb`は直接デプロイできないため、まずは以下の簡易`streamlit_app.py`を作成して`dashboard/`に配置してください。

#### M3-Core-Engine用 Streamlitアプリ（新規作成）

`M3-Core-Engine/dashboard/app.py` として以下を設置：

```python
import streamlit as st
import json
import sys
from pathlib import Path

sys.path.append(str(Path(__file__).parent.parent))

st.set_page_config(page_title="M3-Core-Engine Dashboard", layout="wide")
st.title("🌍 MBT55 GHG Abatement Simulator")
st.markdown("**M3-Core-Engine | IPCC Tier 2 | 5.1億トン削減目標**")

# パラメータ読み込み
with open("src/parameters_optimized.json") as f:
    params = json.load(f)

# 基本数値（notebookから抽出）
GHG_PER_UNIT_YEAR = 9299  # tCO2e/unit/yr
TARGET_GHG = 510_000_000   # tCO2e/yr
DAC_LOW, DAC_HIGH = 300, 600
MBT55_COST = 2.90  # USD/tCO2e

# スライダー
col1, col2 = st.columns(2)
with col1:
    units = st.slider("MBT55発酵機台数", 0, 100000, 54850, step=100)
    ghg = units * GHG_PER_UNIT_YEAR / 1e6
    st.metric("年間GHG削減量 (Mt CO₂e)", f"{ghg:.1f}")
    st.metric("目標達成率", f"{ghg / (TARGET_GHG/1e6) * 100:.1f}%")

with col2:
    st.metric("MBT55 コスト ($/tCO₂e)", f"${MBT55_COST:.2f}")
    st.metric("DAC コスト ($/tCO₂e)", f"${DAC_LOW}〜${DAC_HIGH}")
    st.metric("MBT55の優位性", f"{DAC_LOW/MBT55_COST:.0f}x〜{DAC_HIGH/MBT55_COST:.0f}x 安価")

st.info(f"**パラメータ最適化**: Nelder-Mead + L-BFGS-B | H₂制約: {params['_metadata']['h2_constraint_satisfied']} | 分解率24h: {params['_metadata']['decomposition_rate_24h']*100:.0f}%")
```

4. ファイルをGitHubにプッシュ後、Streamlit Cloudで **Main file path** を `dashboard/app.py` に設定してデプロイ

## 3. M3-Quantitative-Basis 統合リポジトリについて

**結論：M3-Quantitative-Basisは「統合ランディングページ兼アーカイブ」として立ち上げます。**

先日の設計段階では、M3-Quantitative-Basisを独立したリポジトリとして構想しましたが、その後、各スレッドが独自のリポジトリ（M3-Core-Engine, HealthBook-AI, AGRIX-OS, PBPE-Finance）を持つ構成に進化しました。

**M3-Quantitative-Basisの新しい位置づけ：**
- 5つのリポジトリ全体の「統合ポータル」
- 理論ドキュメントのアーカイブ（`theory/`, `evidence/`）
- 共通スキーマ定義のマスターコピー（`schema/`）
- 5リポジトリへのリンクハブ
