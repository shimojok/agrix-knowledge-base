## 4. 日英統合の実装方針

### 4-1. i18nディレクトリ構成

```python
# dashboard/i18n/translator.py
class I18nManager:
    """日英統合翻訳マネージャー"""
    
    SUPPORTED_LANGUAGES = {
        "ja": "日本語",
        "en": "English"
    }
    
    def __init__(self, lang: str = "ja"):
        self.lang = lang
        self.translations = self._load_translations()
    
    def t(self, key: str) -> str:
        """翻訳キーから表示テキストを取得"""
        return self.translations.get(key, key)
    
    def _load_translations(self):
        """言語辞書を動的ロード"""
        if self.lang == "ja":
            from dashboard.i18n.ja import DICT
        else:
            from dashboard.i18n.en import DICT
        return DICT
```

```yaml
      - LANG=ja
    volumes:
      - ./data:/app/data
      
  healthbook-dashboard:
    build:
      context: ./dashboard
    ports:
      - "8501:8501"
    environment:
      - API_URL=http://healthbook-api:8000
    depends_on:
      - healthbook-api
```
