# Architecture｜Microbiome Functional Ontology v1.0 — 策定開始

HealthBook/MIOSの正式Ontologyとして、**Microbiome Functional Ontology v1.0（MFO v1.0）**の設計を開始します。

本Ontologyの中心命題は、

> **Microbiomeは「菌種の集合」ではなく、宿主の代謝能力を補完・拡張するFunctional Systemとしてモデル化する。**

です。

# 2. 最重要Entity｜Functional Capacity

今回のOntologyの中心Nodeを、

> **Microbial Functional Capacity**

とします。

```
Microbial Taxon
       │
       │ performs
       ▼
Microbial Function
       │
       │ contributes to
       ▼
Functional Capacity
       │
       │ transforms
       ▼
Substrate
       │
       ▼
Metabolite
       │
       │ influences
       ▼
Host Response
```

### 原則

```
Taxonomy ≠ Function
Function ≠ Capacity
Capacity ≠ Clinical Effect
```

これを明確に分離します。

---

# 3. Essential Microbial Functions

## Definition

> **Essential Microbial Functionとは、宿主の生理・代謝維持に重要な役割を担うことがEvidenceによって支持される微生物由来機能である。**

ただし、v1.0では**「Essential」というラベルを簡単には付与しません。**

```
Function
   ↓
Biological relevance
   ↓
Host dependence
   ↓
Evidence
   ↓
Essentiality assessment
```

したがって、

**「その菌がいないと駄目」**

ではなく、

**「その機能が宿主にとってどの程度代替不能なのか」**

を評価します。

---

# 4. Functional Capacityの分類

|Class|Definition|
|---|---|
|**Essential**|宿主に重要かつ代替性が限定される機能|
|**Beneficial**|健康関連の有益性が支持される機能|
|**Context-dependent**|食事・宿主・微生物環境によって作用が変化|
|**Unknown**|機能的重要性が十分評価されていない|
|**Potentially Harmful**|条件によって宿主に有害となり得る機能|

この分類により、単純な

**善玉菌 / 悪玉菌**

モデルを避けます。

# 5. Substrate Ontology

Microbiomeを「代謝主体」として扱うため、入力側も定義します。

```
Substrate
│
├── Nutrient
│    ├── Carbohydrate
│    ├── Protein / Amino Acid
│    ├── Lipid
│    └── Other
│
├── Phytochemical
│    ├── Isoflavone
│    ├── Ellagitannin / Ellagic Acid
│    ├── Polyphenol
│    ├── Flavonoid
│    └── Carotenoid
│
├── Host-derived
│
└── Xenobiotic
```

ここで、

**Amino Acid = Substrate**

であり、

**Microbiome = Biological Transformer**

という役割分担を明確にします。

# 7. Cross-feeding Ontology

今回特に重要なのがここです。

```
Microbe A
   │
   │ metabolite
   ▼
Intermediate
   │
   ▼
Microbe B
   │
   ▼
Final Metabolite
```

したがって、

> **Functional Capacityは単一菌株ではなくCommunity Levelで成立する場合がある。**

という構造をOntologyに組み込みます。

### Relationship

```
Taxon A
 ──produces──> Metabolite X

Metabolite X
 ──substrate_for──> Taxon B

Taxon B
 ──produces──> Metabolite Y
```

# 12. Evidence Layer

Ontology上のすべての重要RelationshipにEvidenceを接続します。

```
E0  Unknown
 ↓
E1  Hypothesis
 ↓
E2  Mechanistic Evidence
 ↓
E3  Human Observational
 ↓
E4  Clinical Evidence
 ↓
E5  Validated Intervention
```

### Governance Rule

**Evidence Levelを飛び越えて臨床的結論を生成しない。**

例えば、

```
「菌Xが存在する」
       ↓
「エクオール産生に関与する」
       ↓
「エクオールが産生される」
       ↓
「宿主シグナルが変化する」
       ↓
「更年期症状が改善する」
```

は、それぞれ別のEvidence Claimとして管理します。
