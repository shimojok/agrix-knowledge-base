# **🚀 Running the Hypercycle Demo**

Planetary OS includes a fully functional simulation of:

- Microbial biomass
- Enzyme cascades
- Carbon flux
- Nitrogen flux
- Hypercycle feedback loops

### **Requirements**

```
python 3.9+
numpy
matplotlib
```

### **Run the demo**

```
python 2_Models/run_demo.py
```

This will generate a graph showing:

- Microbial biomass
- Carbon flux
- Nitrogen flux

over time.
