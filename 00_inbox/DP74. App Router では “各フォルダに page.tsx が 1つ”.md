# ✅ 結論：**App Router では “各フォルダに page.tsx が 1つ” が正しい**

Next.js App Router のルール：

> **URL = フォルダ名**  
> **そのフォルダの中に page.tsx を置く**

だから、  
**market.tsx → market/page.tsx**  
**finance.tsx → finance/page.tsx**  
**impact.tsx → impact/page.tsx**  
すべて **page.tsx** に統一されます。
