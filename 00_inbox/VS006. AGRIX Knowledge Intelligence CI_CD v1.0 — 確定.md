# Governance Rules

## Rule 1 — GitHubが正本

```text
GitHub Documents
      ↓
Source of Truth
```

FAISSインデックスは**正本ではありません**。

インデックスを削除しても、

```text
GitHub Knowledge
      ↓
Rebuild
      ↓
FAISS Index
```

で完全復元可能にします。

---

## Rule 2 — Pull Request必須

```text
Knowledge Change
      ↓
Pull Request
      ↓
Automated Validation
      ↓
Review
      ↓
Merge
```

直接変更は禁止します。

---

## Rule 3 — Knowledge Domain必須

各知識は必ずドメインを持ちます。

```text
AGRIX
├── Soil
├── Crop
├── Microbiology
├── Fertilizer
├── Climate
└── Food Security
```

これにより、AGRIX AIが**「何の知識に基づいて回答したか」**を追跡可能になります。
