WTOなどの制度が人の健康を診るのではなく、唯一、代謝経路解析による代謝改善が人々の健康を維持できるのです。そのためには、栄養素や腸内環境などをはじめ代謝環境整備が必要となります。食材のクオリティは言うまでもありません。浜田先生の30年間にわたる30万人の症例、改善対策情報、栄養情報は、個々の代謝経路解析に役立ちます。加えて、代謝に有用なプロバイオティクスであるMBT55を導入し、腸内ハイパーサイクルの実現による代謝改善は、さらなるデータの蓄積になります。これらをAzure上で行なうのです。

## コアフィロソフィーの理解

```
従来医療：症状 → 診断 → 薬物投与
HealthBook：問診 → 代謝経路解析 → 代謝環境整備 → 自己回復
```

つまり「治療」ではなく**「代謝の最適化」**が本質ですね。これは規制上も重要な差異です。
