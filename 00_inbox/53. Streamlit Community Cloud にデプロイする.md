さて、このダッシュボードを**スマホで見る方法**ですが、GitHubアプリはあくまで「コードを見るためのもの」なので、ダッシュボード（Streamlit）を動かすことはできません。

スマホで見るには、以下の**2つの方法**があります。

---

### 1. 【最も簡単】Streamlit Community Cloud にデプロイする（無料）

GitHubと連携させるだけで、世界中のどこからでも（スマホのブラウザからでも）アクセスできる専用URL `https://azure-pmos.streamlit.app` のようなものが発行されます。

1. [Streamlit Cloud](https://share.streamlit.io/) にアクセス。
    
2. GitHubアカウントでサインイン。
    
3. 「Deploy a new app」をクリック。
    
4. 自分のリポジトリ `Azure-PMOS` と `final_demo.py` を選択して「Deploy」。
    
5. **数分でURLが発行されます。** そのURLをスマホのブラウザ（SafariやChrome）で開くだけです。
    

### 2. GitHub Codespaces のポート転送を使う（一時的な確認）

現在PCで Codespaces を動かしている場合、その環境をスマホで覗き見ることができます。

1. Codespaces の画面下にある **「Ports」** タブをクリック。
    
2. `8501` ポートの **「Visibility」** を `Private` から **`Public`** に変更。
    
3. 表示されている「Forwarded Address（URL）」をコピーして、スマホに送って開く。
    
    - _注意：PCのCodespacesを閉じるとアクセスできなくなります。_
        

---

### 💡 スマホで表示する際の「隠し技」

スマホで見ると、画面が狭いためサイドバーが自動的に隠れます。

ナデラ氏にスマホで見せる際は、**「スマホを横向きにする」**か、左上の **「>」マーク** をタップして言語選択（日英）を切り替えるよう伝えるとスムーズです。

**「常に誰でも見れる状態」**にしておきたい場合は、**方法1（Streamlit Cloud）**が圧倒的におすすめです。これなら、LinkedInの投稿にそのURLを貼るだけで、世界中の人があなたのデモをスマホで体験できるようになります。
