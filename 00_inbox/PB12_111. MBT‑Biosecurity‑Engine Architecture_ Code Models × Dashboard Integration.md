# 📦 **MBT‑Biosecurity‑Engine Architecture: Code Models × Dashboard Integration**

（README にそのまま貼り付け可能）

MBT‑Biosecurity‑Engine は、  
**「生態学的ハイパーサイクルを数理モデル化し、  
その結果を PBPE 経済モデルに接続する “生態学的 OS”」**  
として設計されている。

そのため、リポジトリは以下の 3 層構造で動作する：

---

# 🧬 **Layer 1 — Scientific Engine（Code Models）**

MBT55/HMT238 の生態学的プロセスを数理モデルとして実装する層。

```
09_Code_Models/
│
├── Disease_Risk_Model.py        # 病害リスク（CLR, Fusarium, Downy Mildew）
├── Microbial_Simulation.py      # 微生物ハイパーサイクル（P-M-Nモデル）
├── Soil_Carbon_Model.py         # 土壌炭素（SOC）とネクロマス形成
├── Price_Stability_Model.py     # 収量安定性 → 価格変動の数理モデル
└── OneHealth_Model.py           # 家畜・腸内・抗生物質・メタンの統合モデル
```

これらのモデルは、  
**MBT55 の生態学的効果を “数値として生成する” エンジン** であり、  
ダッシュボードや PBPE に渡す **KPI の計算源** となる。

---

# 📊 **Layer 2 — Data Layer（Data Model）**

科学モデルの出力を統合し、PBPE へ渡すためのデータ構造。

```
08_Dashboard/Data_Model.json
```

この JSON は、以下のデータを統合する：

- Crop performance（収量・病害・品質）
- Post-harvest（腐敗・食品ロス）
- Soil & Climate（SOC・CH₄・N₂O）
- Livestock（感染率・抗生物質・メタン）
- Economics（価格・コスト・所得）
- PBPE Credits（Biosecurity / Carbon / Food Loss / Quality）

**AGRIX → MBT55 → PBPE → Marketplace**  
のデータフローを統一する “共通データモデル” である。

---

# 📈 **Layer 3 — Dashboard Engine（Streamlit Prototype）**

```
08_Dashboard/Streamlit_Prototype.py
```

このダッシュボードは、  
**Code Models の出力 → Data Model → 可視化**  
という流れで動作する。

表示される KPI は：

- Disease Loss Reduction
- Yield Gain
- Anti‑Spoilage
- ΔC（土壌炭素）
- GHG Reduction（CH₄/N₂O）
- PBPE Value（USD）
- ROI
- Price Stability Index

これにより、MBT55 の生態学的効果が  
**“科学 → 経済 → 金融” の一連の流れで可視化される。**

---

# 🔗 **Layer 4 — PBPE Integration（Economic & Finance Layer）**

MBT‑Biosecurity‑Engine の出力は PBPE に渡され、  
以下の価値に変換される：

- PBPE‑Biosecurity Credits
- Carbon Credits
- Food Loss Credits
- Quality Credits
- PBPE Value（USD）
- Farmer Income Uplift
- Price Stability

PBPE‑Dashboard と PBPE‑Finance は、  
MBT‑Biosecurity‑Engine の “科学的アウトプット” を  
**経済価値・金融価値に変換するレイヤー** である。
