# 1. 「エクオール産生菌は自然界のどこにいるのか？」

現時点の研究から最も確実に言えるのは、

### 主な生態的ニッチは「哺乳類の腸管」

です。

```

   ↓
糞便
   ↓
エクオール産生菌を分離
```

実際、_Adlercreutzia equolifaciens_ はヒト糞便から分離されています。[PubMed](https://pubmed.ncbi.nlm.nih.gov/18450717/?utm_source=chatgpt.com)

また、_Eggerthella_ sp. YY7918も健康なヒトの糞便から分離され、ダイゼインからS-エクオールを生成することが確認されています。[PubMed](https://pubmed.ncbi.nlm.nih.gov/18838805/?utm_source=chatgpt.com)

さらに興味深いのは、**豚などの哺乳類の腸管にもダイゼイン→エクオール変換菌が存在する**ことです。豚糞便から _Eubacterium_ 属のエクオール産生菌が分離されています。[OUP Academic](https://academic.oup.com/femsle/article-pdf/282/1/73/19611018/282-1-73.pdf?utm_source=chatgpt.com)

したがって現段階では、

> **「エクオール産生菌は植物や土壌に普通に存在する菌」というより、「哺乳類の腸内に適応した微生物群」と考える方が妥当**

# 2. ここで非常に重要なこと

Kazさんの、

> 「その微生物が腸内にどのように入るのか？」

という問いは、実は非常に重要です。

腸内細菌は「生まれたときから完全に固定されている」わけではありません。

一般的な腸内細菌については、

```
母親・家族
   ↓
生活環境
   ↓
食事
   ↓
動物・他者との接触
   ↓
環境中の微生物
   ↓
腸内への曝露
   ↓
定着・維持
```

というダイナミックな獲得・交換が起こり得ます。腸内細菌の宿主間伝播については、糞便中への排出→環境中での生存→新しい宿主への摂取→腸内定着という経路が研究されています。[Nature](https://www.nature.com/articles/nrmicro.2017.50?utm_source=chatgpt.com)

ただし、**「エクオール産生菌が具体的に土壌・植物・水・食品からヒトへ移って定着した」という経路は、現在の研究では十分確立されていません。**

ここは仮説と確立知見を分ける必要があります。
