## 2. 目的

**浜田式問診（200項目）× 137疾病マトリックス × MBT漢方代謝ライブラリー（293方剤）を統合した、パーソナライズドヘルスケア推論プラットフォームの構築**

- 30年間・30万人以上の臨床データをデジタル化
- 代謝不全の特定 → 疾病リスク評価 → ファイトケミカル/漢方/プロバイオティクスの推奨
- 土壌健康（AGRIX）と腸内健康（MBT55）の統合（将来的な拡張）

## 3. 内容と特徴

### コアコンポーネント

| コンポーネント | 内容 | 規模 |
|--------------|------|------|
| 浜田式問診 | 症状・生活習慣・食習慣を評価 | 200項目 |
| 疾病マトリックス | 食生活パターンと疾病の相関 | 137疾病 × 40+パターン |
| 下條式ファイトケミカル分類 | ポリフェノール・カロテノイド・イオウ化合物 | 30+分類 |
| MBT漢方代謝ライブラリー | 生薬成分・代謝経路・MBT55最適化 | 293方剤 |

### 主要機能

| 機能 | 説明 |
|------|------|
| **代謝不全分析** | 問診回答から代謝問題を特定、PATH_01～05にマッピング |
| **疾病リスク予測** | 137疾病のリスクスコアを計算、ランキング表示 |
| **ファイトケミカル推奨** | 疾病リスクに応じた食品・栄養素の提案 |
| **漢方処方推奨** | 293方剤から適切な処方を推奨、MBT55最適化情報付き |
| **MBT55最適化** | プロバイオティクス菌株・発酵プロトコルの提案 |
| **言語切り替え** | 日本語/英語（フィールドレベルで対応） |

### 技術スタック

- Python 3.9+
- JSONデータ構造
- NumPy, Pandas（データ処理）
- Flask/FastAPI（API対応・オプション）

## 4. 可能なデモの内容

### デモ1: 統合健康分析（`healthbook_demo.py`）

```python
# 入力：問診回答（200項目から選択）
responses = {
    1: True,   # 食事時間が不定
    2: True,   # 朝食抜き
    9: True,   # 塩分偏好
    55: True,  # 運動不足
    60: True,  # ストレス
}

# 実行
result = engine.analyze(responses)

# 出力例
# - 総合リスクレベル（低/中/高/極高）
# - 上位疾病リスク（高血圧: 78%, 糖尿病: 65%...）
# - ファイトケミカル推奨（カテキン、セサミン...）
# - 漢方処方推奨（釣藤散、七物降下湯...）
# - MBT55最適化（MBT55-001, MBT55-003...）
```

### デモ2: 言語切り替え

```python
# 日本語モード
engine_ja = HealthBookEngine(language=Language.JAPANESE)
result_ja = engine_ja.analyze(responses)

# 英語モード
engine_en = HealthBookEngine(language=Language.ENGLISH)
result_en = engine_en.analyze(responses)
```

### デモ3: 漢方検索

```python
# 症状から検索
mapper.search_by_symptom("headache")  # 葛根湯、桂枝湯...

# 疾病から推奨
mapper.recommend_by_disease("hypertension")  # 釣藤散、七物降下湯...
```

### デモ4: MBT55連携（`mbt55_integration.py`）

```python
# 漢方処方に基づくプロバイオティクス処方
formula = kampo_mapper.get_formula("F001")  # 葛根湯
probiotic = mbt55.create_custom_probiotic(formula)
# 出力例: 推奨菌株（MBT55-001, MBT55-003）、発酵時間（24時間）
```
