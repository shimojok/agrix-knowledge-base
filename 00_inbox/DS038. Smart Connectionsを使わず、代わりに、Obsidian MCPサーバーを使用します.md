## ✅ Smart Connections プラグインは使いません

**代わりに、Obsidian MCPサーバーを使用します**。

理由は：
- **AIエージェント（Claude Codeなど）が直接Vaultを読み書き・検索できる**ようになるからです。
- プラグインはObsidianアプリが起動していることが前提ですが、MCPサーバーは**ファイルシステムに直接アクセス**するため、Obsidianが起動していなくても動作します。
- 42種類ものツール（ファイル操作、検索、グラフ分析など）が利用可能になります。

---

## 🟢 はい、**Pineconeを導入します**

今回のプロジェクトでは、**Pinecone MCPサーバー**を利用します。

その理由は：
1. **膨大なノート（5,000件）のセマンティック検索**を実現するには、専用のベクトルデータベースが最も効率的です。
2. MCP（Model Context Protocol）経由で、AIエージェントがPineconeの**インデックス管理・データのアップサート（挿入/更新）・セマンティック検索**を直接操作できるようになります。
3. 将来的に、Pinecone Assistant MCPサーバーを利用すれば、**アップロードしたファイル群を知識ソース**としてAIに参照させることも可能です。

---

## 🔧 導入ステップ（概要）

### 1. Obsidian MCPサーバーのセットアップ
```bash
# リポジトリをクローン
git clone https://github.com/quanticsoul4772/obsidian-mcp.git
cd obsidian-mcp
npm install
npm run build
```
設定後、Claude DesktopなどのMCPクライアントからVaultにアクセスできるようになります。

### 2. Pinecone MCPサーバーのセットアップ
Pinecone APIキーを取得し、MCPクライアントに以下のように設定します。
```json
{
  "mcpServers": {
    "pinecone": {
      "command": "npx",
      "args": ["-y", "@pinecone-database/mcp"],
      "env": {
        "PINECONE_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}
```

### 3. 知識ベース構築フロー
1. Obsidian MCPサーバーでVault内の.mdファイルをリストアップ/読み込み。
2. 読み込んだ内容を、Pinecone MCPサーバーの`upsert-records`ツールでPineconeインデックスに格納。
3. AIエージェントが、Pineconeの`search-records`ツールでセマンティック検索を実行し、関連ノートを取得。

## 📌 まとめ

| ツール | 役割 | 導入 |
|---|---|---|
| **Obsidian MCPサーバー** | Vaultへのファイル操作・検索 | **必須** |
| **Smart Connectionsプラグイン** | 同上（Obsidian起動が前提） | **不使用** |
| **Pinecone MCPサーバー** | 大規模ベクトル検索・RAG基盤 | **導入** |

**Pineconeは無料枠（例：1GBのストレージ）がありますが、利用量に応じて有料プランへの移行が必要になる可能性があります。**

まずは、上記のMCPサーバー2つをセットアップし、Obsidian Vaultの内容をPineconeに同期するパイプラインを構築するのが最初のステップです。
