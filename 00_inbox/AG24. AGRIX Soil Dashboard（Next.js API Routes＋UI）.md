### 1-1. API Route: `/api/soil`

**ファイルパス（Next.js App Router想定）**

- `app/api/soil/route.ts`
    

ts

```
import { NextResponse } from 'next/server';

export async function GET() {
  // 仮のセンサーデータ＋MBT55モデル出力
  const data = {
    timestamp: new Date().toISOString(),
    sensors: {
      ph: 7.3,
      eh_mV: 120,
      moisture_pct: 65,
      temperature_c: 24.5,
    },
    mbt55: {
      om_degradation_rate_24h: 0.86, // 有機物分解率
      aerobic_fraction: 0.55,        // 好気性画分
      carbon_seq_rate_tCO2_ha_year: 2.5,
    },
    she_score: {
      micro_score: 0.82,
      humic_score: 0.78,
      cn_score: 0.75,
      phys_score: 0.80,
      total: 0.40 * 0.82 + 0.25 * 0.78 + 0.20 * 0.75 + 0.15 * 0.80,
    },
  };

  return NextResponse.json(data);
}
```

> 「MBT55設計値：55%好気性 / 45%嫌気性を基準条件で再現。」

> 「SHE = 0.40 × micro_score + 0.25 × humic_score + 0.20 × cn_score + 0.15 × phys_score」

'use client';

type SoilResponse = {
  timestamp: string;
  sensors: {
    ph: number;
    eh_mV: number;
    moisture_pct: number;
    temperature_c: number;
  };

## 2. SafetyChain × AGRIX 統合フロー UI

ここでは、「土壌動態 → ポリフェノール生成 → 鮮度保持力（V-Score）→ SafetyChain機能性・価格」の流れを、API＋UIで一画面にまとめます。

### 2-1. API Route: `/api/safetychain`

**ファイルパス**

- `app/api/safetychain/route.ts`
    

ts

```
import { NextResponse } from 'next/server';

export async function GET() {
  const payload = {
    timestamp: new Date().toISOString(),
    soil: {
      ph: 7.3,
      eh_mV: 120,
      moisture_pct: 65,
      she_total: 0.80,
    },
    phenolics: {
      density_index: 1.45, // ポリフェノール密度（標準比）
      antioxidant_activity_dpph: 0.90,
    },
    vitality: {
      v_score: 0.88, // Platinumクラス
      metabolic_life_days: 12,
    },
    pricing: {
      p_market: 100,
      v_functionality: 18,
      l_loss_avoidance: 7,
      m_medical_savings: 12,
      c_carbon: 5,
    },
  };

  return NextResponse.json(payload);
}
```

> 「鮮度保持力（Metabolic Endurance）: 収穫後も細胞が『自己修復能力』を維持している時間」

> 「P_total = P_market + V + L + m + C」
