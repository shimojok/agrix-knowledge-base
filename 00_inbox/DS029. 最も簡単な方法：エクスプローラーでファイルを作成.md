## ✅ 最も簡単な方法：エクスプローラーでファイルを作成する

### Step 1: エクスプローラーを開く

`C:\Users\user\PBPE-Marketplace\backend\` フォルダを開いてください。

### Step 2: 右クリック → 新規作成 → テキスト ドキュメント

### Step 3: ファイル名を `requirements.txt` に変更する

**注意：** 拡張子が `.txt` であることを確認してください。`requirements.txt.txt` にならないように。

### Step 4: ファイルを右クリック → 「編集」または「メモ帳で開く」

### Step 5: 以下を貼り付ける

```
fastapi==0.104.1
uvicorn==0.24.0
pydantic==2.5.0
python-multipart==0.0.6
```

### Step 6: 保存する（`Ctrl + S`）

---

## 🚀 その後、コマンドプロンプトで実行

```bash
cd C:\Users\user\PBPE-Marketplace\backend
pip install -r requirements.txt
```

---

## ❓ ファイルが表示されない場合

エクスプローラーの「表示」タブ → 「ファイル名拡張子」にチェックを入れてください。これで `.txt` が見えるようになります。
