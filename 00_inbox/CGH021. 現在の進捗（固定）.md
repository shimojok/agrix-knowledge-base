# 私からの提案（正式採用）

ここで一つだけ、アーキテクチャ上の重要な提案があります。

これまでの成果物は「Book」が中心でしたが、国際的なソフトウェアアーキテクチャでは、仕様書の依存関係を明確にします。

私は、以下のような**ドキュメント階層**を正式仕様として固定することを提案します。

```
Level 0
MIOS Constitution
        │
        ▼
Level 1
MIOS White Paper
        │
        ▼
Level 2
MIOS Architecture Book
        │
        ▼
Level 3
MIOS Specification Suite
        │
        ▼
Level 4
Reference Architecture
        │
        ▼
Level 5
Reference Implementation
```

この階層により、

* White Paperは**「なぜ作るのか」**
* Architecture Bookは**「どう設計するのか」**
* Specification Suiteは**「何を標準とするのか」**
* Reference Architectureは**「どう適用するのか」**
* Reference Implementationは**「どう実装するのか」**

という役割が明確になります。
