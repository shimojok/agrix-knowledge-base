# 📘 **1. PBPE 7桁コード（PBPE‑UID）仕様書**

## **目的**

PBPE‑UID（7桁コード）は、 PBPE Marketplace のすべての資産・取引・企業・農場・金融商品を **世界共通の識別子として一意に管理するための標準ID**。

AI／AIエージェントが PBPE Marketplace にアクセスする際の **ユニバーサルアクセスキー**となる。

## **構造（7桁）**

コード

```
AAA‑1234
```

### **① Prefix（3文字）＝ Asset Type**

|Prefix|意味|
|---|---|
|**CRED**|PBPE Credits|
|**BOND**|PBPE Bonds|
|**INS**|PBPE Insurance|
|**FARM**|農場／生産者|
|**COF**|コーヒー産業|
|**HLT**|HealthBook（医療・健康）|
|**MBT**|MBT55／Biosecurity|
|**ORG**|企業／組織|
|**GOV**|政府／自治体|
|**PRD**|PBPE Products|

※ 実際には3文字に圧縮（例：CRD、BND、INS、FRM、COF）

### **② Sequence（4文字）＝ Base36（0–9, A–Z）**

- 1,679,616通り
    
- 衝突確率ほぼゼロ
    
- AIが扱いやすい
    
- 人間も読みやすい
    

## **PBPE‑UID の例**

コード

```
CRD‑A9F3   → PBPE Credit
BND‑X2K7   → PBPE Bond
FRM‑Q8L2   → 農場
ORG‑M4D9   → 企業
COF‑T1B8   → コーヒー産業プロジェクト
MBT‑H7C3   → MBT55バイオセキュリティ案件
```

## **PBPE‑UID の役割**

### ✔ **① PBPE Issuance の一意性保証**

二重発行を防止。

### ✔ **② PBPE Registry × Blockchain のキー**

- 二重計上ゼロ
    
- 改ざん不可
    
- 監査可能
    

### ✔ **③ AIエージェントのアクセスキー**

AIが PBPE Marketplace の資産を直接参照できる。

### ✔ **④ 金融商品・企業・政府との接続**

PBPE Bonds、PBPE Insurance、Scope3報告などを **7桁コードで統一管理**。

## **PBPE‑UID の社会的意義**

- 世界初の **Planetary Value Identifier（PVI）**
    
- カーボンクレジット市場の欠点（不透明・二重計上）を解決
