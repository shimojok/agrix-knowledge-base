# 🟩 **PBPE Marketplace Backend API 一覧（構造確定版）**

以下は、あなたの Dashboard v3 が依存している API を  
**機能別 × ルーター別**に完全整理したもの。

各 API 名は **Guided Link** で、  
次に解析すべき対象へそのまま進める。

---

# 🟦 **1. 認証（Auth）API**

ルーター：`routers/auth.py`

- **POST /auth/login**  
    JWT アクセストークンを返す
- **POST /auth/register**（存在する場合）
- **GET /auth/me**（存在する場合）

用途：

- Login ページ
- Dashboard の保護ルート
- axios の Authorization ヘッダー

---

# 🟦 **2. Dashboard（KPI / Impact / PBPE）API**

ルーター：`routers/dashboard.py`

### **GET /dashboard/kpis**

Dashboard のトップ指標

- total_credits
- total_enterprises
- total_impact_score
- market_volume  
    など

### **GET /dashboard/impact**

Impact Breakdown

- emissions_reduced
- water_saved
- biodiversity_score  
    など

### **GET /dashboard/pbpe**

PBPE Issuance

- issued
- retired
- pending  
    など

---

# 🟦 **3. PBPE Credits Market API**

ルーター：`routers/credits.py`

### **GET /credits/market**

マーケットデータ

- price
- volume
- bid/ask
- historical chart（存在する場合）

### **POST /credits/issue**（存在する場合）

### **POST /credits/retire**（存在する場合）

---

# 🟦 **4. Finance（Bonds & Insurance）API**

ルーター：`routers/finance.py` または `routers/bonds.py` / `routers/insurance.py`

### Bonds

- **GET /finance/bonds**  
    Bond 一覧
- **POST /finance/bonds/price**  
    Bond Pricing Simulator（Pricing.tsx が呼ぶ API）

### Insurance

- **GET /finance/insurance/products**
- **GET /finance/insurance/policies**
- **POST /finance/insurance/quote**

---

# 🟦 **5. Enterprise（Scope3）API**

ルーター：`routers/scope3.py`

### **POST /scope3/convert**

Scope3 → PBPE 変換  
Enterprise Dashboard が使用

### **GET /scope3/history**（存在する場合）

---

# 🟦 **6. Users / Identity API**

ルーター：`routers/users.py`

### **GET /users/me**

### **GET /users/{id}**

### **POST /users/update**

Dashboard のユーザー情報表示に使用される可能性あり。

---

# 🟦 **7. System / Healthcheck API**

ルーター：`routers/system.py`（存在する場合）

### **GET /health**

Render / Railway の稼働確認用
