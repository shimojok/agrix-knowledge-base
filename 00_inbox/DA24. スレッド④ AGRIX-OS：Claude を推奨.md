## 2. スレッド⑥ PBPE-Finance：ChatGPT の新規プロジェクト

HealthBook-AIとは**別の新規プロジェクト**を作成します。

### 理由
- 各プロジェクトのカスタム指示（AGENTS.md）が異なる
- ファイル知識ベースが混在するとAIが混乱する
- 独立した開発パイプラインとして管理するため

### 手順
1. ChatGPTの画面左「**New project**」→ プロジェクト名「**PBPE-Finance**」
2. カスタム指示欄に PBPE-Finance の AGENTS.md 全文を貼り付け
3. 新規チャットを開き、開始Promptを送信
4. 添付ファイル：`schema/mbt55_output.schema.json`、`■5.1億トン削減目標の実現性分析`、`■5.1億トンの温室効果ガス削減_アフリカ全土シミュレーション`
