# 2. Essential Microbial Functions

候補機能を以下のように分類します。

```
Essential Microbial Functions
│
├── Vitamin Synthesis
├── SCFA Production
├── Bile Acid Transformation
├── Amino Acid Metabolism
├── Phytochemical Transformation
│     └── Daidzein → Equol
│     └── Ellagic Acid → Urolithins
│
├── Xenobiotic Transformation
│
└── Other Host-Complementary Functions
```

**重要なGovernance Rule：**

> 「必須性」は原則として菌種ではなく、**微生物機能（Functional Capacity）単位**で評価する。

---

# 3. 栄養学の再定義

従来：

```
Nutrition
=
Human Nutrient Requirements
```

HealthBook/MIOS：

```
Nutrition
=
Human Nutrient Requirements
+
Microbial Functional Requirements
+
Microbial Metabolite Supply
```

つまり、

> **Human Nutrition → Human + Microbiome Nutrition**

へ拡張します。

---

# 4. エクオールを最初のモデルケースにする

```
Soy
 ↓
Daidzein
 ↓
Microbial Functional Capacity
 ↓
Equol
 ↓
ERβ / Host Signaling
 ↓
Menopausal Phenotype
```

ここで評価するのは単純な菌数ではなく、

- 産生機能の有無
- 関連菌群
- 代謝遺伝子・酵素
- 基質供給
- Cross-feeding
- 腸内生態系
- 実際の代謝物産生

です。
