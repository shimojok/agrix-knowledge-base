## 構造の階層

```
F271 全体
├── "id": "F271"
├── "name_ja": "伏龍肝湯"
├── "phytochemicals": [ ... ]  ← ここが閉じられている
└── }                          ← F271ここで閉じる
,                              ← カンマ（必須）
{                              ← F272ここから始まる
  "id": "F272",
  "name_ja": "大建中湯",
  ...
}
```

## 正しいルールの再確認

| あなたのコード | 正誤 | 理由 |

| `}` でF271を閉じる | ✅ | オブジェクトの終了 |
| `,` を付ける | ✅ | 次のオブジェクトとの区切り |
| `{` でF272を始める | ✅ | 新しいオブジェクトの開始 |
