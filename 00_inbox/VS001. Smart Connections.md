 Obsidianのコミュニティプラグインである Smart Connectionsの特徴、先端的な使い方をまとめてください。

---

# 結論

**Smart Connections** は、Obsidianを単なるリンク型ノートではなく、**AIによる意味検索（Semantic Search）を備えた「第二の脳（Second Brain）」へ進化させるコミュニティプラグイン**です。

特に、BioNexusのような大量の研究ノート・PMOドキュメント・設計資料を扱うプロジェクトとの相性が非常に高いです。([Obsidian Community](https://community.obsidian.md/plugins/smart-connections?utm_source=chatgpt.com "Smart Connections - Obsidian Plugin"))

---

```
Markdown Notes

        ▼

        │
        ▼
Vector Index

        ├── Similar Paragraphs
        ├── Semantic Search
        └── AI Context

```

を検索できます。([Obsidian Community](https://community.obsidian.md/plugins/smart-connections?utm_source=chatgpt.com "Smart Connections - Obsidian Plugin"))

# 先端的な使い方②

## Vault全体をRAG化

Smart Connectionsは

```
Vault
↓
Embedding
↓
Relevant Notes
↓
LLMへ渡す
```

というRAG（Retrieval-Augmented Generation）の仕組みを構築できます。

AIは質問に応じて関連ノートだけを参照するため、巨大なVaultでも効率的です。([Reddit](https://www.reddit.com/r/ObsidianMD/comments/1fzmkdk/just_wanted_to_mention_that_the_smart_connections/?utm_source=chatgpt.com "Just wanted to mention that the smart connections plugin is incredible."))
