# 🟩 **3. 署名・検証（Signature / Hash）**

QRコードで公開されるため、 **改ざん防止のための署名（Signature）**が必須。

### 署名方式（推奨）

- **SHA-256 ハッシュ**
    
- **ECDSA（楕円曲線署名）** → 軽量で QR に適する
    

### 署名対象

以下のフィールドを連結してハッシュ化：

コード

```
lotId + issuedAt + vIndex + polyphenolDensity + metabolicLifeDays + pTotal
```

### 署名例（Next.js API）

ts

```
import crypto from "crypto";

function signCertificate(cert: any) {
  const payload =
    cert.lotId +
    cert.issuedAt +
    cert.phenotyping.vIndex +
    cert.quality.polyphenolDensity +
    cert.quality.metabolicLifeDays +
    cert.pricing.pTotal;

  const hash = crypto.createHash("sha256").update(payload).digest("hex");

  return {
    hash,
    algorithm: "SHA-256"
  };
}
```

# 🟩 **4. SafetyChain Certificate API（正式版 v1.1.0）**

`app/api/safetychain/certificate/route.ts`

ts

```
import { NextRequest, NextResponse } from "next/server";
import QRCode from "qrcode";
import crypto from "crypto";

export async function POST(req: NextRequest) {
  const body = await req.json();

  const certificate = {
    certificateId: crypto.randomUUID(),
    lotId: body.lotId,
    issuedAt: new Date().toISOString(),
    version: "1.1.0",

    soil: body.soil,
    phenotyping: body.phenotyping,
    quality: body.quality,
    pricing: body.pricing
  };

  const payload =
    certificate.lotId +
    certificate.issuedAt +
    certificate.phenotyping.vIndex +
    certificate.quality.polyphenolDensity +
    certificate.quality.metabolicLifeDays +
    certificate.pricing.pTotal;

  certificate.signature = {
    hash: crypto.createHash("sha256").update(payload).digest("hex"),
    algorithm: "SHA-256"
  };

  const qrCode = await QRCode.toDataURL(JSON.stringify(certificate));

  return NextResponse.json({
    certificate,
    qrCode
  });
}
```
