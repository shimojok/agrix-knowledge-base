## 📌 補足：なぜロックが発生するのか？

PowerShellで**現在の作業ディレクトリ**にしているフォルダは、プロセスが終了するまでロックされます。  
先ほどのコマンドを実行する前に、以下のようにして**ルートディレクトリ（C:\ や E:\）** に移動しておくのが安全です：

```powershell
# 良い例
cd E:\
cd "E:\Documents\BioNexus Holdings\BioNexus_vault\GitHub"   # ここで作業するのはOK

# 悪い例（ロックが発生しやすい）
cd "E:\Documents\BioNexus Holdings\BioNexus_vault\GitHub\M3-BioSynergy"   # この状態でMove-Itemは失敗する
```

1. GitHub Desktopを終了

```powershell

cd "E:\Documents\BioNexus Holdings\BioNexus_vault\GitHub"
git clone https://github.com/shimojok/M3-BioSynergy.git M3-BioSynergy_new
```
