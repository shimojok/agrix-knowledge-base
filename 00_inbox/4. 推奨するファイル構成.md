はい、お願いします。日本語版は、別に保管しておきますか？

---

## ✅ **はい、日本語版は別に保管するのが良いです。**

---

## 📁 **推奨するファイル構成**

```
M3-BioSynergy/
├── data/
│   ├── questionnaire_full.json         ← 英語版（メイン）
│   └── questionnaire_full_ja.json      ← 日本語版（参照用）
├── data_ja/                            ← または別フォルダ
│   └── questionnaire_full.json
```

---

## 💡 **なぜ日本語版を残すのか**

| 理由 | 説明 |
|------|------|
| **国内展開** | 日本国内のパートナーや研究者向け |
| **バックアップ** | 翻訳の参考や検証用 |
| **GitHub Pages** | 日本語ドキュメントとの連携 |
| **将来の日本語版リポジトリ** | `M3-BioSynergy-JP` への移行が容易 |

---

## 📝 **具体的な配置方法**

### **方法A: 同じフォルダに別名保存（推奨）**
```
data/
├── questionnaire_full.json      # 英語版（メイン）
└── questionnaire_full_ja.json   # 日本語版（参照用）
```

### **方法B: 別フォルダに分ける**
```
data/
└── en/
    └── questionnaire_full.json   # 英語版
data_ja/
└── questionnaire_full.json       # 日本語版
```

---

## 🔧 **コードの修正（必要に応じて）**

日本語版を参照する場合は、パスを切り替えられるようにします：

```python
class QuestionnaireEngine:
    def __init__(self, language: str = 'en'):
        if language == 'en':
            data_path = "data/questionnaire_full.json"
        else:
            data_path = "data/questionnaire_full_ja.json"
```

---

## ✅ **おすすめ**

**方法A（同じフォルダに `_ja` を付けて保存）** がシンプルで良いです。

```
data/
├── questionnaire_full.json      # 英語版（メイン）
└── questionnaire_full_ja.json   # 日本語版（参照用）
```
