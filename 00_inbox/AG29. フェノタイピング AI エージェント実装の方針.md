### フェノタイピング AI エージェント実装の方針

まずは **4つのエージェントを「APIとして立てる」＋「オーケストレーション用APIを1つ作る」**ところまで一気に進めます。

- Microbe-Agent（ハイパーサイクル回転儀）
    
- Cascade-Agent（栄養カスケード）
    
- Stability-Agent（バイオセキュリティ）
    
- Inertia-Agent（鮮度保持力）
    
- Phenotyping-Orchestrator（4体をまとめて呼び出す統合API）

## 2. 共通型定義（代謝通貨スキーマ）

4エージェントは共通の「代謝通貨（乳酸、SCFA、電子）」を媒介に対話するので、 最低限の共通インターフェースを決めておきます。

## 3. Microbe-Agent（ハイパーサイクル回転儀）

ts

```
// app/api/agents/microbe/route.ts
import { NextRequest, NextResponse } from "next/server";
import { SoilSignals, MetabolicCurrency } from "../types";

export async function POST(req: NextRequest) {
  const body = (await req.json()) as { soil: SoilSignals };

  const { ph, eh_mV, moisture_pct, co2_flux_mg_m2_h } = body.soil;

  // 簡易モデル：EhとCO₂フラックスからハイパーサイクル回転速度を推定
  const aerobicFraction =
    1 / (1 + Math.exp(-0.02 * (eh_mV - 50))) *
    (1 - Math.max(0, (moisture_pct - 70) / 30));

  const omegaCycle = co2_flux_mg_m2_h * aerobicFraction; // 24h腐植化達成率の代理

  const currency: MetabolicCurrency = {
    lactate_mmol_l: 2.5 * aerobicFraction,
    scfa_pool_mmol_l: 5.0 * aerobicFraction,
    electron_balance_index: Math.tanh(eh_mV / 200),
  };

  return NextResponse.json({
    omegaCycle,
    metabolicCurrency: currency,
  });
}
```

## 4. Cascade-Agent（栄養カスケード）

ts

```
// app/api/agents/cascade/route.ts
import { NextRequest, NextResponse } from "next/server";
import { PlantSignals, MetabolicCurrency } from "../types";

export async function POST(req: NextRequest) {
  const body = (await req.json()) as {
    plant: PlantSignals;
    currency: MetabolicCurrency;
  };

  const { ndvi, pri, polyphenol_density_index } = body.plant;
  const { scfa_pool_mmol_l, electron_balance_index } = body.currency;

  // NDVI/PRIと代謝通貨から機能性変換効率を推定
  const functionalConversion =
    polyphenol_density_index *
    (0.6 * ndvi + 0.4 * pri) *
    (1 + 0.3 * electron_balance_index);

  const phiFunctional = functionalConversion * (1 + scfa_pool_mmol_l / 10);

  return NextResponse.json({
    phiFunctional,
  });
}
```

## 5. Stability-Agent（バイオセキュリティ）

ts

```
// app/api/agents/stability/route.ts
import { NextRequest, NextResponse } from "next/server";
import { PathogenSignals, MetabolicCurrency } from "../types";

export async function POST(req: NextRequest) {
  const body = (await req.json()) as {
    pathogen: PathogenSignals;
    currency: MetabolicCurrency;
  };

  const { pathogen_load_cfu_g, antioxidant_enzyme_activity } = body.pathogen;
  const { electron_balance_index } = body.currency;

  // 病原体負荷と抗酸化酵素活性からホメオスタシス強度を推定
  const pathogenPressure = Math.log10(pathogen_load_cfu_g + 1);
  const defensePower =
    antioxidant_enzyme_activity * (1 + 0.5 * electron_balance_index);

  const sigmaResilience = defensePower / (1 + pathogenPressure);

  return NextResponse.json({
    sigmaResilience,
  });
}
```

## 6. Inertia-Agent（鮮度保持力）

ts

```
// app/api/agents/inertia/route.ts
import { NextRequest, NextResponse } from "next/server";
import { PostHarvestSignals, MetabolicCurrency } from "../types";

export async function POST(req: NextRequest) {
  const body = (await req.json()) as {
    postharvest: PostHarvestSignals;
    currency: MetabolicCurrency;
  };

  const {
    atp_initial,
    atp_current,
    respiration_rate_mg_co2_kg_h,
    ethylene_ppm,
    elapsed_days,
  } = body.postharvest;

  const { scfa_pool_mmol_l } = body.currency;

  const atpRatio = atp_current / atp_initial;
  const stressFactor = respiration_rate_mg_co2_kg_h * (1 + ethylene_ppm / 10);

  const inertiaRaw =
    atpRatio * (1 + scfa_pool_mmol_l / 10) / (1 + stressFactor / 100);

  const tauInertiaDays = Math.max(0, inertiaRaw * 14 - elapsed_days); // 最大14日を仮定

  return NextResponse.json({
    vScore: inertiaRaw, // 0〜1スケール
    tauInertiaDays,
  });
}
```

## 7. Phenotyping-Orchestrator（4エージェント統合）

最後に、**4つのエージェントをまとめて呼び出し、SafetyChain 用の V-Index を返す API**を作ります。

ts

```
// app/api/phenotyping/route.ts
import { NextRequest, NextResponse } from "next/server";
import {
  SoilSignals,
  PlantSignals,
  PathogenSignals,
  PostHarvestSignals,
} from "../agents/types";

export async function POST(req: NextRequest) {
  const body = (await req.json()) as {
    soil: SoilSignals;
    plant: PlantSignals;
    pathogen: PathogenSignals;
    postharvest: PostHarvestSignals;
  };

  // 1. Microbe-Agent
  const microRes = await fetch(new URL("/api/agents/microbe", process.env.NEXT_PUBLIC_BASE_URL), {
    method: "POST",
    body: JSON.stringify({ soil: body.soil }),
  }).then((r) => r.json());

  // 2. Cascade-Agent
  const cascadeRes = await fetch(
    new URL("/api/agents/cascade", process.env.NEXT_PUBLIC_BASE_URL),
    {
      method: "POST",
      body: JSON.stringify({
        plant: body.plant,
        currency: microRes.metabolicCurrency,
      }),
    }
  ).then((r) => r.json());

  // 3. Stability-Agent
  const stabilityRes = await fetch(
    new URL("/api/agents/stability", process.env.NEXT_PUBLIC_BASE_URL),
    {
      method: "POST",
      body: JSON.stringify({
        pathogen: body.pathogen,
        currency: microRes.metabolicCurrency,
      }),
    }
  ).then((r) => r.json());

  // 4. Inertia-Agent
  const inertiaRes = await fetch(
    new URL("/api/agents/inertia", process.env.NEXT_PUBLIC_BASE_URL),
    {
      method: "POST",
      body: JSON.stringify({
        postharvest: body.postharvest,
        currency: microRes.metabolicCurrency,
      }),
    }
  ).then((r) => r.json());

  // SafetyChain V-Index統合スコア
  const functionality = cascadeRes.phiFunctional;
  const inertia = inertiaRes.vScore;
  const security = stabilityRes.sigmaResilience;

  const vTotal = Math.cbrt(functionality * inertia * security);

  return NextResponse.json({
    microbe: microRes,
    cascade: cascadeRes,
    stability: stabilityRes,
    inertia: inertiaRes,
    vIndex: vTotal,
  });
}
```

これで、

- 各エージェントが独立した API として存在し、
    
- Phenotyping-Orchestrator がそれらをまとめて呼び出し、
    
- SafetyChain™ が必要とする **V-Index（Functionality × Inertia × Security の立方根）** を返せる状態になった。
    

次の一手は、この Phenotyping-Orchestrator を **SafetyChain Flow UI に接続して、「代謝の動的フェノタイピング」を画面上で見える化すること**になるけど、そこもこの流れのまま続けていこう。
