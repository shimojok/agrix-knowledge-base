## 1. MBT55 ODE パラメータ最適化（実測値に寄せる）

### 目的

- 24時間で
    
    - 有機物分解率 ≧ 85%
        
    - C/N 比 40–60 → 15–18 を再現するように ODE の係数を調整する。
        

### 方針

- **S（基質）**は 24h で 10〜15% 残る程度まで減少させる
    
- **P（腐植前駆体）＋C（有機炭素）**が増加するように k4, k5, kC を強める
    
- **N（有効態窒素）**は X_A に比例して増えるように kN を調整
    

### 具体調整例（`app/api/mbt55/hypercycle/route.ts`）

ts

```
const params = {
  k1: 0.55,   // S → X_A（分解速度を上げる）
  k2: 0.35,   // X_A → M
  k3: 0.30,   // M → X_B
  k4: 0.26,   // X_B → P（腐植前駆体を増やす）
  k5: 0.20,   // P → X_C
  kC: 0.18,   // Carbon fixation（炭素隔離を強める）
  kN: 0.20,   // Nitrogen activation（有効態窒素増加を強める）
};
```

- 実際には、**S の初期値と 24h 後の S を見て「(1 − S24/S0) ≈ 0.85」になるように k1 を微調整**していく。
    
- C/N 比は、C と N の出力から CN=C/N を計算し、15〜18 に近づくよう kC, kN を調整。
    

## 2. SafetyChain Certificate の UI/UX デザイン

### 目的

- 消費者が QR を読み取った瞬間に **「この農産物は何がどれだけ優れているのか」** が一目で分かる画面にする。
    

### コンポーネント例（`app/agrrix/certificate/page.tsx`）

tsx

```
'use client';

import { useState } from 'react';

export default function CertificatePage() {
  const [cert, setCert] = useState<any | null>(null);

  async function generate() {
    const res = await fetch('/api/safetychain/certificate', {
      method: 'POST',
      body: JSON.stringify({
        lotId: 'LOT-20260709-001',
        vScore: 88,
        functionalityIndex: 91,
        metabolicLifeDays: 12,
        polyphenolDensity: 0.81,
      }),
    });
    setCert(await res.json());
  }

  return (
    <main className="min-h-screen p-8 bg-gray-100 space-y-6">
      <h1 className="text-2xl font-bold">SafetyChain™ Certificate Viewer</h1>

      <button
        onClick={generate}
        className="px-4 py-2 bg-purple-600 text-white rounded"
      >
        証明書を生成
      </button>

      {cert && (
        <div className="grid grid-cols-2 gap-6 mt-4">
          <div className="bg-white p-4 rounded shadow space-y-2">
            <h2 className="font-semibold">証明書概要</h2>
            <p>ロットID: {cert.certificate.lotId}</p>
            <p>V-Score: {cert.certificate.vScore}</p>
            <p>機能性インデックス: {cert.certificate.functionalityIndex}</p>
            <p>代謝寿命: {cert.certificate.metabolicLifeDays} 日</p>
            <p>
              ポリフェノール密度:{' '}
              {(cert.certificate.polyphenolDensity * 100).toFixed(1)}%
            </p>
          </div>

          <div className="bg-white p-4 rounded shadow flex flex-col items-center">
            <h2 className="font-semibold mb-2">QRコード</h2>
            <img src={cert.qrCode} alt="SafetyChain QR" className="w-48 h-48" />
            <p className="text-xs text-gray-500 mt-2">
              スマートフォンで読み取ると、この証明書データにアクセスできます。
            </p>
          </div>
        </div>
      )}
    </main>
  );
}
```

## 3. Planetary Metabolism OS 統合画面（AGRIX Soil + SafetyChain Flow）

### 目的

- **生産者と消費者の視点を一枚の画面に重ねる**
    
    - 左側：AGRIX Soil（SHE・MBT55 ODE）
        
    - 右側：SafetyChain（機能性・鮮度保持力・価格・証明書）
        

### ページ例（`app/planetary-os/dashboard/page.tsx`）

tsx

```
'use client';

import { useEffect, useState } from 'react';
import SoilSummaryCard from '../../agrrix/components/SoilSummaryCard';
import SoilTimeSeriesChart from '../../agrrix/components/SoilTimeSeriesChart';
import SafetyChainFlowCard from '../../agrrix/components/SafetyChainFlowCard';

export default function PlanetaryOSDashboard() {
  const [soil, setSoil] = useState<any | null>(null);
  const [safety, setSafety] = useState<any | null>(null);

  useEffect(() => {
    fetch('/api/soil').then((r) => r.json()).then(setSoil);
    fetch('/api/safetychain').then((r) => r.json()).then(setSafety);
  }, []);

  if (!soil || !safety) return <div>Loading Planetary Metabolism OS...</div>;

  const latest = soil.snapshots[soil.snapshots.length - 1];

  return (
    <main className="min-h-screen p-8 bg-gray-100 space-y-6">
      <h1 className="text-3xl font-bold">Planetary Metabolism OS</h1>
      <p className="text-gray-700">
        土壌生態（AGRIX）と機能性・鮮度保持力（SafetyChain™）を統合した代謝OSビュー。
      </p>

      <div className="grid grid-cols-2 gap-6">
        <div className="space-y-4">
          <h2 className="text-xl font-semibold">AGRIX Soil</h2>
          <SoilSummaryCard
            latestShe={latest.she_score}
            latestPhenotype={latest.eco_phenotype}
          />
          <SoilTimeSeriesChart snapshots={soil.snapshots} />
        </div>

        <div className="space-y-4">
          <h2 className="text-xl font-semibold">SafetyChain™ Flow</h2>
          <SafetyChainFlowCard data={safety} />
        </div>
      </div>
    </main>
  );
}
```

これで、

- MBT55 ODE は API に統合されていて、
    
- SafetyChain Certificate は QR で外部に開けていて、
    
- AGRIX Soil と SafetyChain が一枚の「Planetary Metabolism OS」画面でつながっている。
