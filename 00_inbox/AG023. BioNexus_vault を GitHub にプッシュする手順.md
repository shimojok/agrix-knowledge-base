## 🛠️ BioNexus_vault を GitHub にプッシュする手順

Gitを初めて使う場合、あるいは久しぶりに触る場合でも迷わないよう、最もシンプルで確実なコマンド手順です。

### 1. GitHub上で空のリポジトリを作る

1. ブラウザで [GitHub](https://github.com/) にログインします。
    
2. 画面右上または左上の **「New」** ボタンをクリックしてリポジトリ作成画面を開きます。
    
3. 以下のように設定します：
    
    - **Repository name:** `BioNexus_vault`（わかりやすい名前でOKです）
        
    - **Public/Private:** **「Private」** を選択（無料枠のままノートを世界中に完全非公開にできます）
        
    - **Initialize this repository with:** すべてチェックを外した状態（空のまま）にします。
        
4. 最下部の **「Create repository」** をクリックします。
    
5. 画面に表示される `[https://github.com/ユーザー名/BioNexus_vault.git](https://github.com/ユーザー名/BioNexus_vault.git)` という **リポジトリのURL** をコピーしておきます。
    

### 2. パソコンのターミナル（コマンドプロンプト）を開く

Obsidianのノートが保存されているフォルダ（`BioNexus_vault`）に移動します。

- **Macの場合:** 「ターミナル」アプリを開き、以下を入力してEnter。
    
- **Windowsの場合:** 「コマンドプロンプト」または「PowerShell」を開き、以下を入力してEnter。
    

Bash

```
cd /path/to/your/BioNexus_vault
```

_(※ `/path/to/your/` の部分は、実際のフォルダがあるパスに書き換えてください。フォルダをターミナル画面にドラッグ＆ドロップすると自動でパスが入力されます)_

### 3. Gitの初期化と初回のプッシュを実行する

フォルダ内に移動したら、以下のコマンドを1行ずつ順番に実行してください。

Bash

```
# 1. このフォルダをGit管理下に置く
git init

# 2. フォルダ内のすべてのノート（.mdやJSON）を送信対象に追加する
git add .

# 3. 最初の保存（コミット）を行う
git commit -m "Initial commit: Add BioNexus vault nodes"

# 4. メインのブランチ名を「main」に設定する
git branch -M main

# 5. 先ほどGitHubでコピーしたURLとローカルフォルダを紐付ける
# (※URL部分はご自身がコピーしたものに差し替えてください)
git remote add origin https://github.com/ユーザー名/BioNexus_vault.git

# 6. GitHubへデータをアップロード（プッシュ）する
git push -u origin main
```

> 💡 **認証を求められた場合**
> 
> 最後の `git push` を行った際、GitHubのユーザー名とパスワード（またはPersonal Access Token / SSH Key）を求められる場合があります。画面の指示に従ってログインを完了させてください。

## ✨ これで準備完了です！
