# 📌 **画像ファイル名について**

あなたが選ぶスライドを PNG/JPG に変換し、 GitHub リポジトリ内に以下のように配置してください：

コード

```
MBT-Biosecurity-Engine/
 ├── README.md
 ├── docs/
 │    └── images/
 │         └── pbpe-header-slide.png   ← ここに保存
```

ファイル名は自由ですが、 `pbpe-header-slide.png` が最もわかりやすく、 後から差し替えも簡単です。
