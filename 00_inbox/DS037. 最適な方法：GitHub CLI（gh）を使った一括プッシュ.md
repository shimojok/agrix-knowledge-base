## 🚀 最適な方法：GitHub CLI（gh）を使った一括プッシュ

ローカルにリポジトリがない環境でも、**GitHub CLI（コマンドラインツール）**を使えば、Obsidian Vault全体を一度にプッシュできます。

---

### ステップ1：GitHub CLIをインストール（まだの場合）

- **Windows**: [GitHub CLI公式ページ](https://cli.github.com/) からインストーラをダウンロード
- **macOS**: `brew install gh`
- **Linux**: パッケージマネージャーでインストール（例：`sudo apt install gh`）

### ステップ2：GitHubにログイン（認証）

```bash
gh auth login
```
対話式の指示に従い、ブラウザで認証を完了します。

### ステップ3：リポジトリをクローン（一時的にローカルに展開）

```bash
# リポジトリをクローン（例：デスクトップに一時フォルダを作成）
cd ~/Desktop
git clone https://github.com/shimojok/AGRIX-OS.git
cd AGRIX-OS
```

### ステップ4：Obsidian Vaultを知識ベースとしてコピー

```bash
# あなたのObsidian Vaultのパスを指定してコピー
cp -r /path/to/your/obsidian-vault/* docs/knowledge-base/

# （例）Obsidian Vaultが ~/Documents/Obsidian/AGRIX_Vault/ にある場合
cp -r ~/Documents/Obsidian/AGRIX_Vault/* docs/knowledge-base/
```

### ステップ5：不要なファイルを除外（`.gitignore` に追加）

```bash
# .gitignore にObsidian設定ファイルを追加
echo "docs/knowledge-base/.obsidian/" >> .gitignore
echo "docs/knowledge-base/workspace.json" >> .gitignore
echo "docs/knowledge-base/.trash/" >> .gitignore
```

### ステップ6：Gitに追加してプッシュ

```bash
git add docs/knowledge-base/
git commit -m "docs: KazのObsidian知識ベース（全5,000ノート）を追加"
git push origin main
```

### ステップ7：一時フォルダの削除（任意）

```bash
cd ~/Desktop
rm -rf AGRIX-OS
```

| **再現性** | 今後ノートを更新した場合も、同じ手順で簡単に同期可能 |
