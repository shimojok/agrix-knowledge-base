# Acceptance Criteria

Dashboard v4 is considered complete when:

- Executive Overview operational
    
- Eliminated Cost operational
    
- Climate Impact operational
    
- Biosecurity Impact operational
    
- Resource Transformation operational
    
- Agricultural Productivity operational
    
- Human Health operational
    
- Finance & Investment operational
    
- Impact Registry operational

No API returns:

- PBPE Price
    
- PBPE Supply
    
- PBPE Market Value
    
- Credit Retirement
    
- Token Metrics
