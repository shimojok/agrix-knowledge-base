## 🚀 VS Code / ターミナルを使った実行手順

### 前提条件
1. **Gitがインストール**されていること（`git --version` で確認）
2. **Python 3.9以上**がインストールされていること（`python --version` で確認）
3. **VS Code**（またはお好みのエディタ）がインストールされていること

### ステップ1：プロジェクト用の新しいフォルダを作成し、AGRIX-OSをクローン

```bash
# デスクトップなど作業用ディレクトリに移動
cd C:\Users\user\Desktop

# AGRIX-OSリポジトリをクローン（既にローカルにある場合はスキップ）
git clone https://github.com/shimojok/AGRIX-OS.git
cd AGRIX-OS
```

**補足**：すでにローカルにAGRIX-OSがある場合は、そのディレクトリに移動してください。

---

### ステップ2：`.env` ファイルを作成し、APIキーを設定

VS CodeでAGRIX-OSフォルダを開き、ルートに `.env` という名前の新規ファイルを作成し、以下の内容を記述します。

```env
# .env
PINECONE_API_KEY=あなたのPineconeAPIキー
PINECONE_INDEX_NAME=agrix-knowledge-base
OPENAI_API_KEY=あなたのOpenAIAPIキー
OBSIDIAN_VAULT_PATH=C:\Users\user\OneDrive\BioNexus_vault
```

---

### ステップ3：必要なPythonパッケージをインストール

ターミナル（VS Code内のターミナル、またはコマンドプロンプト）で以下を実行します。

```bash
# AGRIX-OSディレクトリにいることを確認
cd C:\Users\user\Desktop\AGRIX-OS

# 仮想環境（推奨）を作成して有効化
python -m venv venv
venv\Scripts\activate      # Windowsの場合

# パッケージをインストール
pip install -r requirements.txt
```

なお、`requirements.txt` は前回のメッセージでご提示した内容で作成してください。もしファイルがない場合は、以下のコマンドで直接インストールすることも可能です。

```bash
pip install pinecone-client openai langchain langchain-pinecone langchain-openai tiktoken PyGithub python-dotenv gitpython
```

---

### ステップ4：知識ベース取り込みスクリプトを `scripts/ingest_knowledge.py` として作成

VS Codeで `scripts` フォルダを作成し（`mkdir scripts`）、その中に `ingest_knowledge.py` という名前で前回のメッセージにある**完全なPythonスクリプト**をコピー＆ペーストして保存します。

---

### ステップ5：スクリプトを実行

ターミナルで以下を実行します。

```bash
python scripts/ingest_knowledge.py
```

実行が完了すると、指定したObsidian VaultとGitHubリポジトリ群の内容が**Pineconeにベクトル化されて格納**されます。

---

## 📂 Obsidian Vaultパスについての補足

ご提供いただいたパス構造を確認しました。スクリプト内の `OBSIDIAN_VAULT_PATH` には、**`.obsidian` フォルダを含まない、Vaultのルートパス**を指定する必要があります。

**正しい設定例**：
```
OBSIDIAN_VAULT_PATH=C:\Users\user\OneDrive\BioNexus_vault
```

スクリプトはこのルート以下にあるすべての `.md` ファイルを再帰的に処理しますので、ご指定のすべてのサブフォルダが自動的に対象となります。
