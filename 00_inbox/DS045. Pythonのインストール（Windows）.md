### ステップ2：スクリプトファイルを作成

1. **VS Code**（またはメモ帳）を開いてください。
2. 新規ファイルに、**以下のコードをすべてコピー＆ペースト**してください。

**以下が、あなたのための完全なスクリプトです。** （わからない部分はコメントアウトしてあります）

```python
import os
import glob
from pinecone import Pinecone
from openai import OpenAI

# ----- 1. 設定（ここをあなたの情報に書き換えてください）-----
VAULT_PATH = r"C:\Users\user\OneDrive\BioNexus_vault"  # ← あなたのObsidian Vaultのパス

# ここに、あなたのAPIキーを貼り付けてください
PINECONE_API_KEY = "あなたのPineconeAPIキー"   # ← Pineconeダッシュボードの「API Keys」からコピー
OPENAI_API_KEY = "あなたのOpenAI APIキー"      # ← platform.openai.com/api-keys からコピー
# ------------------------------------------------

# ----- 2. Pineconeに接続 -----
print("🔄 Pineconeに接続中...")
pc = Pinecone(api_key=PINECONE_API_KEY)
index = pc.Index("agrix-knowledge-base")  # あなたが作成したインデックス名
print("✅ Pineconeに接続しました！")

# ----- 3. OpenAIに接続（埋め込み生成用）-----
print("🔄 OpenAIに接続中...")
openai_client = OpenAI(api_key=OPENAI_API_KEY)
print("✅ OpenAIに接続しました！")

# ----- 4. Obsidian Vaultからファイルを読み込む -----
print(f"📁 Obsidian Vaultを読み込み中: {VAULT_PATH}")
md_files = glob.glob(os.path.join(VAULT_PATH, "**/*.md"), recursive=True)
print(f"✅ {len(md_files)} 個のMarkdownファイルが見つかりました。")

# ----- 5. アップロード処理 -----
print("📤 Pineconeへのアップロードを開始します（少し時間がかかります）...")

for i, file_path in enumerate(md_files):
    try:
        # ファイルを読む
        with open(file_path, 'r', encoding='utf-8') as f:
            content = f.read()
        
        # 空ファイルや短すぎるファイルはスキップ（50文字未満）
        if len(content.strip()) < 50:
            continue
        
        # OpenAIで埋め込みベクトルを生成
        response = openai_client.embeddings.create(
            model="text-embedding-3-small",
            input=content[:8000]  # 長いファイルは最初の8000文字だけにする
        )
        vector = response.data[0].embedding
        
        # メタデータ（検索時に表示される情報）
        file_name = os.path.basename(file_path)
        folder_name = os.path.basename(os.path.dirname(file_path))
        
        # Pineconeにアップロード（ID、ベクトル、メタデータをセットで）
        index.upsert(vectors=[(
            f"file_{i}",  # 一意なID
            vector,       # ベクトル
            {
                "filename": file_name,
                "folder": folder_name,
                "full_path": file_path,
                "content": content[:500]  # 検索結果の表示用
            }
        )])
        
        # 100ファイルごとに進捗を表示
        if (i + 1) % 100 == 0:
            print(f"   {i+1}/{len(md_files)} ファイルをアップロードしました。")
            
    except Exception as e:
        # エラーがあっても継続する
        print(f"   ⚠️ スキップ: {os.path.basename(file_path)} - {e}")

print("🎉 すべてのファイルのアップロードが完了しました！")
print(f"📊 Pineconeダッシュボードでレコード数を確認してください。")
```

### 🔑 APIキーの入手方法（ステップバイステップ）

まず、OpenAIの開発者プラットフォームにアクセスし、以下の手順でAPIキーを入手してください。

1.  **サイトへアクセス・ログイン**: [https://platform.openai.com/](https://platform.openai.com/) にアクセスし、アカウントでログインします（アカウントがない場合は「Sign Up」から新規登録してください）。
2.  **APIキー管理ページへ移動**: ログイン後、ページ右上の「Settings」（設定）アイコンをクリックし、左側のメニューから「**API Keys**」を選択します。
3.  **新しいシークレットキーを作成**: 「**Create new secret key**」ボタンをクリックします。
4.  **キーをコピーして安全に保存**: キーに名前を付けて「Create secret key」をクリックすると、**その場だけ**APIキー（英数字の長い文字列）が表示されます。必ずすぐにコピーし、**安全な場所に保存**してください。このページを離れると、再度表示することはできません。

### ⚠️ 注意：APIキーを取得する前に

*   **有料プランへの登録が必要**：無料アカウントを作成しただけでは、新しいキーを作成できない場合があります。多くの場合、ダッシュボードで支払い方法（クレジットカードなど）を登録し、有料プランにアップグレードする必要があります。
*   **電話番号認証**：アカウント作成時に電話番号での認証が必要になることがあります。
