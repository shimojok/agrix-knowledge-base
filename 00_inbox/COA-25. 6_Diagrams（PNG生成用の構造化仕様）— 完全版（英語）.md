# Diagram Specifications for PNG Generation

This folder contains structured specifications for generating PNG diagrams
using the Planetary OS visual architecture.

Each diagram is defined using:
1. Components (nodes)
2. Relationships (arrows)
3. Layout (top → bottom, left → right)
4. Labels and annotations
5. Color coding rules
6. Optional style notes

These specifications are optimized for AI-based image generation.
```

# Gaia–MBT55 Integration Diagram — Specification

## 1. Components
- Atmosphere
- Soil Layer
- Plant Biomass
- Microbial Consortium (MBT55)
- Enzyme Cascades
- Nitrogenase System
- Carbon Flux
- Water Cycle
- Gaia Feedback Loop

## 2. Relationships
- Atmosphere ↔ Soil (gas exchange)
- Soil → Plants (nutrient uptake)
- Plants → Soil (root exudates)
- MBT55 → Enzyme Cascades (activation)
- Enzyme Cascades → Carbon Flux (acceleration)
- Nitrogenase → Nitrogen Cycle (fixation)
- Water Cycle ↔ Soil (moisture regulation)
- Gaia Feedback Loop → All components (stabilization)

## 3. Layout
Top: Atmosphere  
Middle: Plants / Soil / MBT55  
Bottom: Enzyme Cascades / Carbon & Nitrogen Flux  
Surrounding: Gaia Feedback Loop

## 4. Color Coding
- Blue: Water cycle
- Green: Plants / biomass
- Brown: Soil
- Yellow: Enzymes
- Red: Nitrogenase
- White arrows: feedback loops

## 5. Style Notes
- Circular Gaia loop around entire diagram
- Soft gradients, scientific infographic style
```
