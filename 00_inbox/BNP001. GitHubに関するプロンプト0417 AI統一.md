１．AGRIX/HealthBook Project が、世界の食料・栄養問題改善、食料価格の低減・安定化、土壌の修復、有機質廃棄物の資源化、サステナブルな食料システム構築、炭素隔離と温室効果ガス削減を実現する論拠

２．MBT55/HMT238などが再現する生態学的ハイパーサイクル、栄養カスケードなど、代謝・代謝産物サイクルが、温室効果ガス削減を実現する地球の生態制御に重要である論拠、同じく、このメカニズムが、腸内細菌による代謝産物=代謝改善・健康維持に寄与する論拠。特に、ハイパーサイクルモデルと栄養カスケードモデルの数値化が重要です。

３．MBT55/HMT238のバイオコントロール機能、バイオセキュリティ機能が、農産物のあらゆる病気、コーヒーのさび病、シイタケの青カビ、養蜂のチョーク病、家畜の感染症などの防御と、生産性の向上に貢献する論拠。この２つの機能のメカニズム、数値・数式化が重要です。

４．MBT55/MBT Sustainable Cycleが、社会コスト、資源化コストの削減と資源化と言う価値を創出し、サステナブルな食料経済を実現する論拠。食品廃棄物、海産物残渣、家畜の排泄物、農業残渣、上下水道汚泥、流木を含めた森林廃棄物、アパレル廃棄物などのMBT Sustainable Cycle による資源化サイクル(24時間)の重要性を説きます。

５．AGRIX/HealthBook/MBT Probiotics Platformが、食料生産、グローバルヘルスにおける社会インフラとして機能すること。ハイパーサイクルの視点での土壌生態制御を司るAgriWare™の機能と土壌の動態を診るフェノミクス手法の重要性を説明。 同様に、対処療法、投薬依存の現在の医療から、全代謝経路解析による生活習慣病と疾病リスクの改善と健康維持を目指すHealthBook が必要であり、代謝の動態を診るフェノミクス手法が重要であり、さらに、これらがAIを含む技術革新に貢献すること。

６．AGRIX Platformが、食料システムの変革、食料安全保障の実現に貢献し、SafetyChain™が評価する農産物品質、鮮度保持力、食品ロス削減モデルが重要である論拠
