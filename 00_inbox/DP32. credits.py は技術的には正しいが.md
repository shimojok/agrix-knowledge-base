# 🟦 **Dashboard v3 が期待するマーケット API の仕様**

Next.js の Market ページは、

```json
{
  "credits": [
    {
      "type": "carbon",
      "volume_pbpe": 510000000,
      "price_usd": 10.0,
      "value_usd": 5100000000

  ]
```

これは **dashboard.py の `/dashboard/credits/market`** に存在している。

呼ぶのは：

# ✔ **GET /credits/market**
