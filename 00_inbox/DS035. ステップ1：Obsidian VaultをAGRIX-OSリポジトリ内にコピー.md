## 📌 なぜGitHubにプッシュするのか（理由）

| 理由 | 説明 |
|---|---|
| **全エージェントが常に最新を参照できる** | GitHub上のファイルは、AIエージェント（LangGraph）が直接読み取ることができる |
| **バージョン管理ができる** | 知識ベースの変更履歴がGitで追跡可能になる |
| **バックアップになる** | ローカルが消失してもGitHub上に残る |
| **コラボレーションが可能** | 複数のAIエージェント（実装AI・検証AI・文書化AI）が同時に参照できる |

## 🧠 AIエージェントはどうやって参照するのか？

オーケストレーターAI（LangGraph）は、以下のようにしてこの知識ベースを読み込みます：

```typescript
// lib/agents/knowledge-base/client.ts（提供予定）
import { readdirSync, readFileSync } from 'fs';
import { join } from 'path';

const KNOWLEDGE_BASE_PATH = 'docs/knowledge-base/';

export function loadAllKnowledge(): Record<string, string> {
  const files = readdirSync(KNOWLEDGE_BASE_PATH, { recursive: true });
  const knowledge: Record<string, string> = {};
  
  for (const file of files) {
    if (file.endsWith('.md')) {
      const content = readFileSync(join(KNOWLEDGE_BASE_PATH, file), 'utf-8');
      knowledge[file] = content;
    }
  }
  return knowledge;
}
```
