**uvicorn / fastapi / pydantic / sqlalchemy / prisma-client などが未インストール**です。

---

# 🟦 **STEP A：Python 仮想環境を作成**

プロジェクトのルートで：

```
python3 -m venv venv
```

---

# 🟦 **STEP B：仮想環境をアクティベート**

```
source venv/bin/activate
```

（PowerShell の場合は `.\venv\Scripts\activate`）

---

# 🟦 **STEP C：必要なパッケージをインストール**

backend/main.py を見る限り、必要なのは：

```
pip install fastapi uvicorn pydantic sqlalchemy python-multipart
```

もし prisma を使うなら：

```
pip install prisma-client
```

---

# 🟦 **STEP D：Backend を起動**

```
uvicorn backend.main:app --reload
```

これで：

```
http://localhost:8000/docs
```

が開けるようになります。
