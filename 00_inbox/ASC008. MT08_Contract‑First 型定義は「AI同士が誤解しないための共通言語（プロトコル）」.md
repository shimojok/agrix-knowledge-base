NotebookLM・Claude・Gemini・ChatGPT・Kimi が

あなたが悩んでいた「AIが勝手に項目名を変える」「数値がズレる」「構造が壊れる」

# 🟩 では、具体的にどう使うのか？  
## ① NotebookLM に「この型に従って出力しろ」と命令する  
NotebookLM向けプロンプトの中に、  
**Python Pydantic / TypeScript Interface の型定義をそのまま貼る**。

NotebookLMはそれを読み取り、  
**型に完全準拠した JSON を返す**。

つまり NotebookLM は：

- フィールド名を勝手に変えない  
- 構造を壊さない  
- 必ず同じ形式で返す

# 🟩 ② Claude に「この型のデータを受け取って処理しろ」と命令する  
Claude向けプロンプトにも同じ型定義を貼る。

すると Claude は：

- NotebookLMが返した JSON をそのまま読み込む  
- 型に従ってロジックを作る  
- ダッシュボードの構造もこの型に合わせる  

つまり **NotebookLM → Claude のデータ受け渡しが壊れなくなる**。

---

# 🟩 ③ Python計算エンジンで「この型をそのまま読み込む」  
あなたが作る Python コードは、NotebookLMが返した JSON を  
**そのまま Pydantic モデルとして読み込むだけ**。

```python
from methane_contract import MethaneReductionSummary

with open("notebooklm_output.json") as f:

```

これで：

- NotebookLMの出力  
- Claudeの出力  
- UIの入力  
- Azure Functionsの処理  

すべてが **同じ型で統一される**。
