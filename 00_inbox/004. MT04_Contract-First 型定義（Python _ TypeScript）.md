### 全体方針

今やりたいことは：

1. NotebookLM に対して「MBT55によるメタン削減シミュレーション用の構造化データ」を、**Contract-First**で引き出すプロンプトを作る。  
2. その構造化データを Claude に渡し、「削減ロジック＋ダッシュボード」を生成させるプロンプトを作る。  

なので、**① NotebookLM向けプロンプト＋型定義コード**と、**② Claude向けプロンプト**をセットで作ります。

### 1. Contract-First 型定義（Python / TypeScript）

#### Python（Pydantic）モデル

```python
from pydantic import BaseModel, Field
from typing import List, Optional

class MethaneReductionScene(BaseModel):
    """
    単一の削減シーン（発酵飼料、水田、食品廃棄物、流木災害など）ごとの
    メタン排出削減シミュレーション結果。
    """
    scene_id: str = Field(..., description="シーンの一意なID（例: 'livestock_feed', 'rice_paddy', 'food_waste', 'driftwood_disaster'）")
    scene_name: str = Field(..., description="シーン名（日本語）")
    description: str = Field(..., description="NotebookLMから抽出した、シーンの詳細説明")
    baseline_emission_ton_ch4_per_year: float = Field(..., description="MBT導入前の年間メタン排出量 [ton-CH4/year]")
    mbt_reduction_ton_ch4_per_year: float = Field(..., description="MBT発酵肥料・飼料導入後の年間メタン削減量 [ton-CH4/year]")
    reduction_rate_percent: float = Field(..., description="削減率 [%] = mbt_reduction / baseline_emission * 100")
    key_parameters: List[str] = Field(..., description="削減量算出に使った主要パラメータ（NotebookLMからの出典を含む）")
    data_source_notes: str = Field(..., description="NotebookLM内のどのドキュメント・セクションから抽出したかのメモ")

class MethaneReductionSummary(BaseModel):
    """
    全シーンを統合した、MBT55によるメタン削減シミュレーションの集計結果。
    """
    total_baseline_emission_ton_ch4_per_year: float = Field(..., description="全シーン合計のMBT導入前年間メタン排出量 [ton-CH4/year]")
    total_mbt_reduction_ton_ch4_per_year: float = Field(..., description="全シーン合計のMBT導入後年間メタン削減量 [ton-CH4/year]")
    total_reduction_rate_percent: float = Field(..., description="全体削減率 [%]")
    scenes: List[MethaneReductionScene] = Field(..., description="各シーンの詳細結果リスト")
    notes: Optional[str] = Field(None, description="前提条件・不確実性・補足説明など")
```

export interface MethaneReductionScene {

### 3. Claude向けプロンプト（MBT55削減ロジック＋ダッシュボード生成）

NotebookLM から得た `MethaneReductionSummary` JSON を、そのまま Claude に渡すときのプロンプトです。

```text
あなたは、MBT55 BioHubによるメタンガス排出削減ロジックを設計し、
経営者・投資家・政策決定者向けのダッシュボードを構築する専門家です。

以下に、NotebookLMから抽出した「MBT発酵肥料・発酵飼料・MBT廃棄物処理によるメタン削減シミュレーション」の
構造化データ（MethaneReductionSummary）が JSON 形式で与えられます。

【入力データ（Contract-First）】
- MethaneReductionSummary JSON
  - total_baseline_emission_ton_ch4_per_year
  - total_mbt_reduction_ton_ch4_per_year
  - total_reduction_rate_percent
  - scenes[]（各シーンの詳細）

【あなたのタスク】
1. **MBT55削減ロジックの明文化**
   - 各シーンごとに、
     - ベースライン排出量の算出ロジック
     - MBT導入後削減量の算出ロジック
     - 削減率 [%] の意味と前提条件
   を、数式と文章で明確に説明してください。
   - 可能であれば、CH₄ → CO₂e への換算も行い、
     - 「年間 CO₂e 削減量」として統合してください。

2. **ダッシュボード構成案の設計**
   - 既存の AGRIX Architecture Dashboard（index.html / ja.html / en.html / agrix_architecture_dashboard など）を参考に、
     - 以下のようなセクション構成を提案してください：
       - 全体削減量（CH₄ / CO₂e）のサマリー
       - シーン別削減量（家畜 / 水田 / 食品廃棄物 / 災害廃棄物 / その他）
       - 削減率 [%] と、MBT導入前後の比較グラフ
       - 投資額・運営コストと、削減量あたりのコスト指標（例：$/ton-CO₂e）
   - 各セクションについて、
     - どの指標を表示するか
     - どのグラフ（棒グラフ・折れ線・円グラフなど）を使うか
     を具体的に記述してください。

3. **実装に使えるレイアウト・コンポーネント案**
   - HTML/CSS/JavaScriptで実装することを想定し、
     - ページ構成（ヘッダー／メイン／サイドバー）
     - 主要コンポーネント（カード、チャート、テーブル）
     の構造を、擬似コードレベルで示してください。
   - 可能であれば、各チャートに対応するデータ構造（TypeScriptインターフェース）も提案してください。

【出力フォーマット】
- 1. MBT55削減ロジックの説明（数式＋文章）
- 2. ダッシュボード構成案（セクションごとの説明）
- 3. 実装向けレイアウト・コンポーネント案（擬似コード＋インターフェース）

【重要な前提】
- 入力 JSON の数値は「Canonical値」として扱い、勝手に変更しないでください。
- 不確実性やレンジがある場合は、ロジック内で明示し、
  「どの部分が仮定で、どの部分がNotebookLM由来の実測・推定値か」を区別してください。
```
