監査情報（アクセス権限の監査設定）をコピーしようとしてエラーが発生しています。これは管理者権限の問題です。

## 🔧 解決策：権限を落としてコピー

### 方法1：`/COPYALL` ではなく `/COPY:DAT` を使用（推奨）

```powershell
# 監査情報（U）を除外してコピー
robocopy "M3-BioSynergy" "M3-BioSynergy_backup_worktree" /E /COPY:DAT /R:0 /W:0
```

**説明：**
- `/COPY:DAT` = Data, Attributes, Timestamps（監査情報はコピーしない）
- `/COPYALL` = すべての情報をコピー（これが監査情報でエラーになる）

### 方法2：さらに簡易的に `/MIR` を使用

```powershell
# /MIR は /E /PURGE と同じ（ミラーリング、コピー先にないファイルは削除）
robocopy "M3-BioSynergy" "M3-BioSynergy_backup_worktree" /MIR /COPY:DAT /R:0 /W:0
```

### 方法3：最も簡単なバックアップ（xcopyを使用）

```powershell
# 昔ながらのxcopy（権限エラーが出にくい）
xcopy "M3-BioSynergy\*" "M3-BioSynergy_backup_worktree\" /E /I /H /Y
```

## ⚡ そもそもバックアップは本当に必要か？

**結論：多くの場合、バックアップは不要です。**

なぜなら：
1. **リモート（GitHub）** にすべてのコミット済み履歴がある
2. 未コミットの変更が**本当に重要なもの**（数時間かけた作業など）でない限り、最初からやり直せる
3. `git clone` すれば新鮮な状態が手に入る

### 未コミットの変更を確認する方法：
```powershell
cd "M3-BioSynergy"
git status
```

**もし「nothing to commit, working tree clean」と表示されたら：**
→ バックアップ不要。すぐにクローンし直してOK。

**もし未コミットの変更がある場合：**
→ そのファイル名をメモしてから、以下のコマンドで退避（stash）：
```powershell
git stash push -m "一時退避_$(Get-Date -Format 'yyyyMMdd_HHmmss')"
```
その後、新しいクローンで同じディレクトリ構造を作って復元。
