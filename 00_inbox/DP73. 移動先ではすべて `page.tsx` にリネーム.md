# 🎯 **結論：はい、移動先ではすべて `page.tsx` にリネームします。**

つまり：

```
frontend/pages/dashboard/market.tsx
→ frontend/app/dashboard/market/page.tsx
```

このとき **ファイル名は必ず `page.tsx` に変わります。**

---

# なぜすべて `page.tsx` にするのか？

これは **Next.js App Router の絶対ルール**です。

- Pages Router（旧方式）  
    → `market.tsx` のように自由なファイル名で OK
    
- App Router（新方式）  
    → **各ルートのエントリーポイントは必ず `page.tsx`**
    

つまり：

```
/dashboard/market
```

という URL を作りたい場合は、必ず：

```
app/dashboard/market/page.tsx
```

という構造になります。
