# 1. **PBPE の本質（Core Concept）**

PBPE は本来 **通貨ではなく「地球価値の測定モデル」**。

- CO₂削減
    
- 土壌炭素（SOC）
    
- 微生物代謝（MBT55）
    
- 生態系回復
    
- 健康改善
    
- 医療費削減
    

これらを **統一単位で測定する Planetary Value Model**。

しかし、PBPE を **交換可能な価値単位（通貨的扱い）** に拡張すると、 地球価値を “経済価値” に変換する新しい市場が生まれる。
