# 土壌動態ODEモデル

## 概要

M3-Core-EngineのMBT55ハイパーサイクルODEを**土壌センサーデータ（pH, Eh, 水分）**で拡張した、AGRIX-OSの中核演算モデル。

---

## 状態変数（8変数）

| 変数 | 定義 | 単位 |
|:---|:---|:---|
| S | 基質濃度 | g/L |
| X_A | 基質分解微生物バイオマス | g/L |
| M | 代謝中間体 | g/L |
| X_B | 代謝物変換バイオマス | g/L |
| P | 機能性産物/腐植前駆体 | g/L |
| X_C | ハイパーサイクル制御バイオマス | g/L |
| C | 土壌有機炭素 | g/L |
| N | 有効態窒素 | g/L |

---

## センサー連携

| センサー | ODEへの影響 |
|:---|:---|
| **pH** | β_i（死亡率・阻害係数）を修正 |
| **Eh（酸化還元電位）** | 好気/嫌気経路の優位性を選択 |
| **水分（θ）** | 水分依存的酸素可用性（好気/嫌気スイッチ） |

---

## 好気性画分関数

```python
def aerobic_fraction(Eh_mV, moisture_pct):
    f_Eh = 1.0 / (1.0 + np.exp(-0.02 * (Eh_mV - 50)))
    f_moisture = 1.0 - max(0.0, (moisture_pct - 70.0) / 30.0)
    return np.clip(f_Eh * f_moisture, 0.05, 0.95)


MBT55設計値：55%好気性 / 45%嫌気性を基準条件で再現。
```

carbon_seq_rate (tCO₂/ha/year) → PBPE Finance Engineへ供給

# AgriWare™ 診断・処方エンジン

## 概要

土壌のSHE™（Soil Health & Ecosystem）スコアの時系列から**速度と加速度**を計算し、5つのエコフェノタイプを診断。MBT55/HMT/NASARAの処方を自動生成する。

---

## 5つのエコフェノタイプ（EcoPhenotype）

| フェーズ | 状態 | 処方方針 |
|:---|:---|:---|
| **ACCELERATING_IMPROVEMENT** | 改善加速中 | 現状維持・最小介入 |
| **DIMINISHING_IMPROVEMENT** | 改善減速中 | 次の介入準備 |
| **STABLE** | 安定 | 維持投与 |
| **DIMINISHING_DEGRADATION** | 劣化減速中 | 介入効果発現中・監視 |
| **ACCELERATING_DEGRADATION** | 劣化加速中 | **緊急：MBT55即時投入** |

---

## SHE™スコア計算

```python
SHE = 0.40 × micro_score + 0.25 × humic_score + 0.20 × cn_score + 0.15 × phys_score
```

| 要素 | 重み | 内容 |
|:---|:---|:---|
| micro_score | 40% | 微生物バイオマス活性 |
| humic_score | 25% | 腐植産物（土壌構造の代理指標） |
| cn_score | 20% | 炭素・窒素バランス |
| phys_score | 15% | pH・Ehの物理化学的指標 |

---

## 処方例：ACCELERATING_DEGRADATION時

```
MBT55: 3.0-5.0 L/ha（緊急）
HMT: 1.0 L/ha（ミネラル補助）
監視間隔: 3時間
```

**AGENTS.md Rule #1厳守**：化学NPK推奨ゼロ。微生物管理パスのみ。

# V-Score：代謝寿命モデル

## 概要

Vitality Score（V-Score）は、収穫後の**ATP減少速度**に基づく代謝的活力指標（0-100）。

---

## ATP減衰モデル

ATP_t = ATP_0 × exp(-k_atp × t)


### 減衰定数 k_atp の補正因子

| 因子 | 影響 |
|:---|:---|
| SCFA保護効果 | 膜完全性強化 → k_atp低減 |
| 抗酸化密度 | 酸化的劣化遅延 → k_atp低減 |
| SHEスコア | 栄養負荷完全性 → k_atp低減 |
| 保存温度（Q10≈2） | 低温→k_atp低減 |

**MBT55作物：k_atpが従来比約30%低減**

---

## V-Scoreグレード

| グレード | V-Score範囲 | Freshness Score |
|:---|:---|:---|
| **Platinum** | ≥0.85 | 最高鮮度 |
| **Gold** | ≥0.70 | 高鮮度 |
| **Silver** | ≥0.55 | 標準以上 |
| **Standard** | <0.55 | 標準 |

# 食料価格下降モデル

## 概要

MBT55導入による**供給量増加→価格下降**のメカニズムを、価格弾力性モデルでシミュレーションする。

---

## 基本方程式

```python
def simulate_food_price(self, years=10, elasticity=-0.3):
    for t in range(years):
        supply_increase = (1 + dy)
        price *= (1 + elasticity * (supply_increase - 1))
```

| 変数 | 定義 | 数値例 |
|:---|:---|:---|
| dy | 収量増加率 | 0.20（+20%） |
| elasticity | 価格弾力性 | -0.3（供給1%増→価格0.3%下落） |

---

## 4レイヤー動的価格モデル

```
P_total = P_market + V_functionality + L_loss_avoidance + m_medical_savings + C_carbon
```

| レイヤー | 内容 | MBT55優位性 |
|:---|:---|:---|
| V（機能性） | ATP保持率 | +40%長い代謝寿命 |
| L（ロス削減） | 腐敗低減 | -20%収穫後ロス |
| m（医療費削減） | 疾患予防価値 | HealthBook連携 |
| C（炭素） | 隔離CO₂e/kg | 2.5 kgCO₂e/kg認証済 |

# フェノタイピングAIエージェント群

## 概要

SafetyChain™の動的フェノタイピングを駆動する**4つのAIエージェント**。

---

## AIエージェント定義

| エージェント | 役割 | 主要入力 | 主要出力 |
|:---|:---|:---|:---|
| **Microbe-Agent** | ハイパーサイクル回転儀 | 土壌Eh、温度、CO₂フラックス | ω_cycle（24時間腐植化達成率） |
| **Cascade-Agent** | 栄養変換エンジン | NDVI/PRI分光、土壌N/P/K | Φ_functional（ポリフェノール密度） |
| **Stability-Agent** | 免疫監視・防御 | 病原体シグナル、抗酸化酵素 | σ_resilience（ホメオスタシス強度） |
| **Inertia-Agent** | 鮮度減衰予測 | 収穫時ATP、呼吸速度、エチレン | τ_inertia（代謝寿命・日数） |

---

## エージェント間通信プロトコル

```
Microbe → Cascade → Inertia → SafetyChain™ (V-Index) → Health-Agent (m-ROI)
```

各エージェントは共通の「代謝通貨（乳酸、SCFA、電子）」を媒介にJSONスキーマで通信する。

---

## V-Index統合スコア

```
V_Total = ∛(Functionality × Inertia × Security)
```
