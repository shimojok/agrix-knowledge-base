## 📝 **より簡単な方法：一括作成スクリプト**

以下のスクリプトを `setup.sh`（Mac/Linux）または `setup.bat`（Windows）として保存し、実行するとすべて自動で作成されます：

### **Mac/Linux用 (`setup.sh`)**
```bash
#!/bin/bash

echo "Setting up M³-BioSynergy repository structure..."

# ディレクトリ作成
mkdir -p src/{core,azure/{digital_twins,iot_integration,ml_models},edge,analytics,utils}
mkdir -p docs/{theory,api,tutorials,whitepapers,images}
mkdir -p examples tests notebooks data/{samples,config,schemas}
mkdir -p deploy/{azure/{arm_templates,docker,kubernetes},scripts,monitoring}
mkdir -p config tools .github/workflows

# 基本ファイル作成
cat > README.md << 'EOF'
# 🌱 M³-BioSynergy: Microbial-Metabolic-Modular Theory
（ここに先ほどのREADME内容を貼り付け）
EOF

cat > LICENSE << 'EOF'
MIT License
（ここに先ほどのライセンス内容を貼り付け）
EOF

cat > requirements.txt << 'EOF'
numpy>=1.21.0
scipy>=1.7.0
（ここに先ほどのrequirements内容を貼り付け）
EOF

# コアファイル作成
cat > src/core/microbial_dynamics.py << 'EOF'
（ここに先ほどのmicrobial_dynamics.py内容を貼り付け）
EOF

cat > src/core/carbon_flow.py << 'EOF'
（ここに先ほどのcarbon_flow.py内容を貼り付け）
EOF

# 使用例作成
cat > examples/basic_simulation.py << 'EOF'
"""
Basic simulation example for M³-BioSynergy
"""
import numpy as np
from src.core.microbial_dynamics import MicrobialEcosystem
from src.core.carbon_flow import CarbonSequestrationModel

def main():
    print("M³-BioSynergy Basic Simulation")
    # 簡単な使用例
    ecosystem = MicrobialEcosystem(n_species=120)
    ecosystem.load_mbt55_configuration()
    
    results = ecosystem.simulate(
        initial_conditions={'population': np.ones(120), 'substrate': 100.0},
        duration_hours=24.0
    )
    
    print(f"Simulation completed: {results['metrics']['total_biomass']:.2f} total biomass")

if __name__ == "__main__":
    main()
EOF

echo "✅ Repository structure created successfully!"
```

### **実行方法（Mac/Linux）**
```bash
# スクリプトを保存
nano setup.sh
# 内容を貼り付け、Ctrl+X → Y → Enter

# 実行権限を付与
chmod +x setup.sh

# 実行
./setup.sh
```
