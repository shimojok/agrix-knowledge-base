### 🚀 方法1: GitHub Codespaces (最も簡単・おすすめ)

**所要時間:** 約3分 / **費用:** 無料枠あり (月60時間まで)

これは、リポジトリのコードをクラウド上の仮想マシンで動かすサービスです。ローカルのVS Codeと同じ操作感で使えます。

1.  **リポジトリを開く**: ブラウザであなたのリポジトリ `https://github.com/shimojok/M3-BioSynergy` にアクセスします。

    *   **Codespaces** タブを選択します。
    *   `Create codespace on main` ボタンをクリックします。
3.  **環境構築を待つ**: 数十秒～1分ほどで、ブラウザ上にVS Codeが起動します。この時点でPython環境は完了しています。

### ⚙️ 方法2: GitHub Actions (自動実行)

**所要時間:** 設定10分 / **費用:** 無料 (一定時間まで)

こちらは「コミットをプッシュしたら自動でシミュレーションを走らせる」といった自動化に向いています。結果はログで確認します。

1.  **ワークフローファイルを作成**: リポジトリに `.github/workflows/run_simulation.yml` ファイルを作成します。
2.  **コードを記述**: 以下のYAMLコードを貼り付けます。
    ```yaml
    name: Run Simulation

    on: [push, workflow_dispatch]  # プッシュ時または手動で実行

    jobs:
      run:
        runs-on: ubuntu-latest
        steps:
        - uses: actions/checkout@v4
        - name: Set up Python
          uses: actions/setup-python@v5
          with:
            python-version: '3.11'
        - name: Install dependencies
          run: |
            pip install numpy matplotlib scipy
        - name: Execute simulation
          run: python examples/basic_simulation.py
    ```
3.  **実行**: このファイルをコミットしてプッシュすると、自動でシミュレーションがスタートします。
4.  **結果確認**: リポジトリの「Actions」タブを開き、ワークフローをクリックすると、実行結果のログが表示されます。

### 📝 具体的な修正手順 (Codespaces上で直接)

以下のコードは、ハイパーサイクル計算を安定化させるための修正です。`src/core/hypercycle_engine.py` を開いて編集してください。

**現在のコード (問題のある部分):**
```python
# 例: hypercycle_engine.py の simulate_cycle メソッド内
next_state[i] = current[i] + (growth * (1 + coupling) - loss + external) * dt
```

**以下のように修正します (安定化):**
値を急激に変化させないために、以下の処理を追加します。

1.  **ネガティブチェック**: 値がマイナスにならないようにする (0でクリップ)
2.  **オーバーフローチェック**: 値が異常に大きくならないようにする (上限を設定)
3.  **数値安定化**: `nan` が発生した場合のフォールバック値を設定

```python
# 修正後の安定化コードの例
dt = 0.01 # タイムステップを小さくするなども有効

# ... (計算途中) ...

# 値の更新
new_value = current[i] + (growth * (1 + coupling) - loss + external) * dt

# 安定化処理
if np.isnan(new_value) or np.isinf(new_value):
    # 異常値が発生した場合は、現在の値を維持する (または小さな値を設定)
    next_state[i] = current[i]
else:
    # 値がマイナスにならないようにし、極端な値も制限する
    next_state[i] = max(0.0, min(new_value, 1e10)) # 上限を1e10に設定
```

より根本的には、`hypercycle_engine.py` の数値積分の方法を `odeint` などのより堅牢なソルバーに変更するのが良いのですが、まずは上記の簡易的な安定化処理で試してみてください。
