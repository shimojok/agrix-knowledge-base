## ① 概要（1–2行）  

食品・プロバイオティクス介入を外部入力として、腸内微生物→代謝→フェノタイプ→リスクへ伝播する制御系（control system）として定式化する。

---

## ② 数式（Intervention Control Model）

**(1) 介入入力（食品・プロバイオティクス）**

[  
U(t) = [F_a(t), Pro_i(t)]  
]

- (F_a)：栄養基質（食物繊維、脂質など）
    
- (Pro_i)：菌株投入量
    

---

**(2) 微生物ダイナミクス（介入項追加）**

[  
\frac{dM_i}{dt} =  
M_i \left( \mu_i \frac{N + \sum_a \phi_{ia} F_a}{K_{N,i} + N} + \sum_{j \neq i} \alpha_{ij} M_j - d_i \right)

- \kappa_i Pro_i  
    ]
    

---

**(3) 代謝産物制御**

[  
\frac{dP_k}{dt} =  
\sum_i Y_{ik} M_i + \sum_a \psi_{ak} F_a - \lambda_k P_k  
]

---

**(4) フェノタイプ応答**

[  
\frac{dH_l}{dt} =  
\sum_k w_{kl} P_k - \delta_l H_l  
]

---

**(5) 疾病リスク（制御対象）**

[  
R_d(t) =  
\frac{1}{1 + \exp\left(-\left(\sum_l \beta_{ld} H_l - \theta_d \right)\right)}  
]

---

**(6) 最適制御問題（Optimal Intervention）**

目的関数：

[  
\min_{U(t)} ; J = \int_0^T \left( R_d(t) + \rho |U(t)|^2 \right) dt  
]

制約：

- ODE系（上記）
    
- (0 \leq F_a, Pro_i \leq U_{max})
    

---

## ④ Python実装（Executable）

```python
import numpy as np
from scipy.integrate import solve_ivp

N = 3  # microbes
K = 3  # metabolites
L = 2  # phenotypes

# 初期値
M0 = np.array([0.3,0.4,0.3])
P0 = np.array([10,10,10])
H0 = np.array([1,1])

y0 = list(M0) + list(P0) + list(H0)

# 入力（例）
def intervention(t):
    F = np.array([20, 10])  # 食物繊維・脂質
    Pro = np.array([1e9, 0, 0])  # 1菌株投入
    return F, Pro

# パラメータ
phi = np.random.uniform(-1,1,(N,2))
kappa = np.array([0.1,0.05,0.02])
Y = np.random.uniform(0,1,(N,K))
psi = np.random.uniform(0,1,(2,K))
lambda_k = np.array([0.1,0.1,0.1])
w = np.random.uniform(-1,1,(K,L))

def model(t, y):
    M = np.array(y[:N])
    P = np.array(y[N:N+K])
    H = np.array(y[N+K:])

    F, Pro = intervention(t)

    # 微生物
    growth = 0.5 * (1 + phi @ F)
    dMdt = M * (growth - 0.1) + kappa * Pro / 1e9

    # 代謝物
    dPdt = Y.T @ M + psi.T @ F - lambda_k * P

    # フェノタイプ
    dHdt = w.T @ P - 0.1 * H

    return list(dMdt) + list(dPdt) + list(dHdt)

sol = solve_ivp(model, (0,50), y0, t_eval=np.linspace(0,50,200))

# リスク計算
beta = np.array([1.2, -1.0])
theta = 0.5

H_final = sol.y[-L:, -1]
R = 1/(1 + np.exp(-(beta @ H_final - theta)))

print("Risk:", R)
```
