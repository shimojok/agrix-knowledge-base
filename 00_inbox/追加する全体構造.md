# ■ ① Food Safety（品質・安全性スコア）追加

## ■ 追加コード（CALCULATIONS内）

```python
# =========================
# ■ Food Safety（品質）
# =========================

def calculate_food_safety(mbt_on):
    if mbt_on:
        contamination_risk = 0.1   # 低リスク
        traceability = 0.9         # 高トレーサビリティ
    else:
        contamination_risk = 0.3
        traceability = 0.6

    safety_score = (1 - contamination_risk) * 0.6 + traceability * 0.4
    return safety_score

food_safety_score = calculate_food_safety(mbt_on)
```
