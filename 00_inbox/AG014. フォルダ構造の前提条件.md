9,500もの膨大なノートから6,300まで削り込まれたのは大変な作業だったと拝察します！ただ、ここからはWeb記事の残骸や重複が多く、手動で減らすのは限界が来やすいフェーズです。

GitHub Actionsで動かすPythonスクリプトで、**「自動でフォルダ階層を解析し、適切なメタデータ（分類情報）を付与してPineconeに同期する」具体的な実装方法**を解説します。

### 1. フォルダ構造の前提条件

スクリプトが自動でメタデータを判別できるよう、Vault内のフォルダ名を以下のように整理しておきます。

Plaintext

```
BioNexus_vault/
├── 01_Executive_Summaries/  <-- 【総括・総合提言書】
│   └── bill_gates_proposal.md
├── 02_Individual_Issues/     <-- 【個別テーマ（1Prompt完結ノート）】
│   ├── AGRIX/
│   ├── HealthBook/
│   ├── PBPE-Marketplace/
│   └── MBT-Probiotics/
└── 04_Dev_Logs/              <-- 【実装のやり取り・チャット履歴】
```

### 2. 具体的なPythonスクリプト（`sync_to_pinecone.py`）

GitHub Actionsのサーバー上で実行するPythonスクリプトのコードです。ファイルパス（フォルダ名）を見て、**自動的にメタデータを判別して付与**します。

Python

```
import os
import glob
from pinecone import Pinecone
from openai import OpenAI

# APIキーの初期化（GitHub ActionsのSecretsから渡されます）
pc = Pinecone(api_key=os.environ["PINECONE_API_KEY"])
openai_client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])

# Pineconeのインデックスを指定
index = pc.Index("bionexus-vector-db")

def get_metadata_from_path(file_path):
    """ファイルパスから自動的にメタデータを生成する関数"""
    # Windows/Mac/Linuxのパス区切りをスラッシュに統一
    normalized_path = file_path.replace("\\", "/")
    parts = normalized_path.split("/")
    
    # デフォルトのメタデータ構造
    metadata = {
        "source_path": file_path,
        "doc_type": "unknown",
        "target_system": "general",
        "is_important": True
    }
    
    # 1. 総括・総合提言書フォルダの場合
    if "01_Executive_Summaries" in parts:
        metadata["doc_type"] = "executive_summary"
        metadata["target_system"] = "all"
        
    # 2. 個別テーマフォルダの場合
    elif "02_Individual_Issues" in parts:
        metadata["doc_type"] = "individual_issue"
        # どのシステム（AGRIX等）に属しているかをフォルダ名から自動取得
        # 例: 02_Individual_Issues/AGRIX/soil.md -> 'AGRIX'
        issue_index = parts.index("02_Individual_Issues")
        if len(parts) > issue_index + 1:
            metadata["target_system"] = parts[issue_index + 1]
            
    # 3. 実装のやり取り・ログフォルダの場合
    elif "04_Dev_Logs" in parts:
        metadata["doc_type"] = "dev_log"
        dev_index = parts.index("04_Dev_Logs")
        if len(parts) > dev_index + 1:
            metadata["target_system"] = parts[dev_index + 1]
            
    return metadata

def main():
    # Vault内のすべてのMarkdownファイルを再帰的に探索
    md_files = glob.glob("**/*.md", recursive=True)
    
    for file_path in md_files:
        # 【重要】もし6,300ノートの中に「未整理の古いメモ」が残っていても、
        # 指定した特定のフォルダ以外は完全にスキップ（無視）するフィルター
        if not any(x in file_path for x in ["01_Executive_Summaries", "02_Individual_Issues", "04_Dev_Logs"]):
            continue
            
        print(f"同期中: {file_path}")
        
        # メタデータの自動生成
        metadata = get_metadata_from_path(file_path)
        
        # ファイルの中身（テキスト）を読み込む
        with open(file_path, "r", encoding="utf-8") as f:
            content = f.read()
            
        if not content.strip():
            continue
            
        # OpenAIのAPIでテキストをベクトル（Embedding）に変換
        response = openai_client.embeddings.create(
            input=content,
            model="text-embedding-3-small"
        )
        vector = response.data[0].embedding
        
        # メタデータの中に、検索用として「実際のテキスト」も一緒に保存する
        metadata["text"] = content
        
        # PineconeへUpsert（送信）
        index.upsert(
            vectors=[{
                "id": file_path,       # ファイルパスをそのまま一意のIDにする
                "values": vector,      # ベクトルデータ
                "metadata": metadata   # 自動付与した分類情報
            }]
        )

if __name__ == "__main__":
    main()
```

### 3. GitHub Actions の設定（`.github/workflows/sync.yml`）

Obsidianでノートを編集し、GitHubに `git push` した瞬間に上記のPythonスクリプトを自動実行させる設定ファイルです。

YAML

```
name: Sync Vault to Pinecone

on:
  push:
    branches:
      - main # mainブランチにPushされた時に実行

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'

      - name: Install Dependencies
        run: |
          pip install pinecone-client openai

      - name: Run Sync Script
        env:
          # GitHubのリポジトリ設定（Secrets）にAPIキーを登録しておきます
          PINECONE_API_KEY: ${{ secrets.PINECONE_API_KEY }}
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: python sync_to_pinecone.py
```

### 💡 この自動化がもたらす最大のメリット

このスクリプトを導入すれば、6,300のノートを無理やりゼロになるまで削除しなくても、**「システム対象フォルダに入っている精鋭ノートだけ」がPineconeに自動抽出されて同期**されます。

さらに、実際にAI（RAG）がPineconeからデータを検索する際は、以下のように**メタデータフィルター**をかけてピンポイントで情報を引っ張れるようになります。

- **提言書を作りたいとき：** `{"doc_type": "executive_summary"}` で検索
    
- **AGRIXのバグを直したいとき：** `{"target_system": "AGRIX", "doc_type": "dev_log"}` で検索
    

手動での削除作業は一旦ここで区切りをつけて、この「システム側での自動フィルター制御」へシフトしてみてはいかがでしょうか？開発効率が圧倒的に向上します！
