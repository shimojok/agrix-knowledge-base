# Data Flow

**入力**

- Markdown（GitHubドキュメント）
    
- PDF（論文・特許）
    
- JSON（各種データセット）
    
- CSV（農業・環境・実験データ）
    

**処理**

1. ドキュメント読込
    
2. チャンク分割
    
3. 埋め込み（Embedding）生成
    
4. FAISSインデックス更新
    
5. SQLiteへメタデータ保存
    

**出力**

- セマンティック検索結果
    
- RAGコンテキスト
    
- AIエージェントへの知識供給
    
- 関連文書・根拠の提示

# Governance Rules

- **Repository:** `BioNexus-KnowledgeBase`
    
- **役割:** 全AIエージェント共通の知識基盤
    
- **検索方式:** セマンティック検索（FAISS）
    
- **メタデータ管理:** SQLite
    
- **ソース管理:** GitHub
    
- **更新フロー:** Pull Request → レビュー → インデックス再生成
    
- **知識の正本:** Markdown/JSON（Git管理対象）
    
- **FAISSインデックス:** ビルド成果物として再生成可能にする
