## ■ Python実証モデル（地域版）

```python
def regional_model(waste, adoption, carbon_price):
    ef_conv = 1.5
    ef_mbt = 0.5

    reduction = waste * (ef_conv - ef_mbt) * adoption
    carbon_value = reduction * carbon_price
    cost_saving = waste * 0.84

    return {
        "GHG": reduction,
        "CarbonValue": carbon_value,
        "CostSaving": cost_saving
    }

result = regional_model(1e6, 0.3, 50)
print(result)
```
