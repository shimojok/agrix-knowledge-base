## 🚀 GitHub Codespaces での体験方法

リポジトリが統合された後、以下の手順でデモを起動できます。

1. GitHubリポジトリの **[Code]** ボタンをクリック。
    
2. **[Codespaces]** タブから **[Create codespace on main]** を選択。
    
3. ターミナルが起動し、自動的に `Streamlit run app.py` が実行されます。
    
4. ブラウザに、日英対応の「Azure-PMOS 経営ダッシュボード」が表示されます。
