先にAGRIX Soil Dashboard を作成し、その後、SafetyChain × AGRIX 統合フロー UI を作成してください。

---

### 全体方針（Next.js × API Routes）

- **フレームワーク:** Next.js（Pages Router）
    
- **API層:** `pages/api/*` に AGRIX Soil と SafetyChain 用のエンドポイントを定義
    
- **UI層:** `pages/*` にダッシュボードと統合フローの画面を定義
    
- **思想:**
    
    - AGRIX Soil Dashboard → 「土壌動態＋SHE＋エコフェノタイプ」
        
    - SafetyChain × AGRIX 統合フロー → 「土壌 → ポリフェノール → 機能性・鮮度保持力 → V-Score / V-Index → 動的価格」

// pages/agrrix-soil-dashboard.tsx
import React, { useEffect, useState } from 'react';
import { SoilSummaryCard } from '../components/SoilSummaryCard';
import { SoilTimeSeriesChart } from '../components/SoilTimeSeriesChart';

type EcoPhenotype =
  | 'ACCELERATING_IMPROVEMENT'
  | 'DIMINISHING_IMPROVEMENT'
  | 'STABLE'
  | 'DIMINISHING_DEGRADATION'
  | 'ACCELERATING_DEGRADATION';

type SoilSnapshot = {
  timestamp: string;
  pH: number;
  eh_mV: number;
  moisture_pct: number;
  co2_flux_mg_m2_h: number;
  she_score: number;
  eco_phenotype: EcoPhenotype;
};

type SoilApiResponse = {
  fieldId: string;
  snapshots: SoilSnapshot[];
};

const AgrrixSoilDashboardPage: React.FC = () => {
  const [data, setData] = useState<SoilApiResponse | null>(null);

  useEffect(() => {
    const fetchSoil = async () => {
      const res = await fetch('/api/soil');
      const json: SoilApiResponse = await res.json();
      setData(json);
    };
    fetchSoil();
  }, []);

  if (!data) {
    return <div className="p-6">Loading AGRIX Soil Dashboard...</div>;
  }

  const latest = data.snapshots[data.snapshots.length - 1];

  return (
    <div className="min-h-screen bg-gray-100 p-6">
      <h1 className="text-2xl font-bold mb-4">AGRIX Soil Dashboard</h1>
      <p className="text-sm text-gray-700 mb-4">
        MBT55 ハイパーサイクルと土壌センサーから算出された
        「SHE™スコア」と「EcoPhenotype」に基づき、
        AgriWare™ の診断・処方エンジンの前段となる土壌動態を可視化します。
      </p>

      <SoilSummaryCard
        latestShe={latest.she_score}
        latestPhenotype={latest.eco_phenotype}
      />

      <SoilTimeSeriesChart snapshots={data.snapshots} />
    </div>
  );
};

export default AgrrixSoilDashboardPage;

### 2-2. API Route: `pages/api/safetychain.ts`

SafetyChain の「機能性・鮮度保持力・ポリフェノール・動的価格」を AGRIX 土壌データから派生させた形で返します。

ts

```
// pages/api/safetychain.ts
import type { NextApiRequest, NextApiResponse } from 'next';

type SafetyChainMetrics = {
  fieldId: string;
  cropName: string;
  vScore: number; // 代謝寿命モデル
  vIndex: number; // V_Total = ∛(Functionality × Inertia × Security)
  metabolicLifeDays: number;
  polyphenolDensityIndex: number;
  functionalityLayerValue: number;
  lossAvoidanceLayerValue: number;
  medicalSavingsLayerValue: number;
  carbonLayerValue: number;
  pTotal: number;
};

export default function handler(
  req: NextApiRequest,
  res: NextApiResponse<SafetyChainMetrics>
) {
  // 本来は AGRIX Soil + フェノタイピング結果から計算
  const vScore = 0.82;
  const vIndex = 1.45;
  const metabolicLifeDays = 10.5;
  const polyphenolDensityIndex = 1.3;

  const V = 120; // 機能性
  const L = 35;  // ロス削減
  const m = 80;  // 医療費削減
  const C = 25;  // 炭素隔離
  const pMarket = 300; // 従来市場価格（例）

  const pTotal = pMarket + V + L + m + C;

  const payload: SafetyChainMetrics = {
    fieldId: 'FIELD-AGRIX-001',
    cropName: 'MBT55 Tomato',
    vScore,
    vIndex,
    metabolicLifeDays,
    polyphenolDensityIndex,
    functionalityLayerValue: V,
    lossAvoidanceLayerValue: L,
    medicalSavingsLayerValue: m,
    carbonLayerValue: C,
    pTotal,
  };

  res.status(200).json(payload);
}
```
