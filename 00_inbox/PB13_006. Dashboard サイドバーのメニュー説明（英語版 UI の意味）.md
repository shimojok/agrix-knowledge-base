# 🌱 **MBT‑Biosecurity‑Engine（投資家向け）

サイドバーのメニュー説明（英語版 UI の意味）**

---

# 1️⃣ **Crop Type（作物）**

**何を意味する？**  
作物ごとの基準収量・価格・病害感受性が異なる。

**投資家にとっての意味**

- MBT55 の効果は作物によって変わる
- Coffee や Citrus は品質プレミアムが大きい
- Rice / Wheat / Maize は収量効果が大きい

---

# 2️⃣ **Region（地域）**

**何を意味する？**  
地域ごとに気候リスク・市場リスク・病害圧が異なる。

**投資家にとっての意味**

- Africa はリスク係数が高く、改善余地が大きい
- Asia は安定性が高い
- LATAM は中間

---

# 3️⃣ **Climate Scenario（気候シナリオ）**

**何を意味する？**  
気候条件が収量と病害に影響する。

**選択肢**

- Normal
- Drought（干ばつ）
- Wet（多湿）

**投資家にとっての意味**

- 干ばつ時の MBT55 効果は特に大きい
- 気候変動リスクに対する “レジリエンス価値” を示せる

---

# 4️⃣ **MBT55 Application Level（MBT55 投与レベル）**

**何を意味する？**  
MBT55 の投入量（None → High）

**投資家にとっての意味**

- 収量増加
- 病害損失の削減
- 品質向上
- 収穫後損失の削減
- 炭素固定量の増加
- GHG 削減量の増加
- PBPE Value の増加
- ROI の改善

**最重要パラメータ**  
投資家が “MBT55 の価値” を体験する中心。

---

# 5️⃣ **Disease Pressure（病害圧）**

**何を意味する？**  
その地域・作物の病害リスクの強さ。

**投資家にとっての意味**

- 病害圧が高いほど MBT55 の価値が跳ね上がる
- Disease Loss Reduction（病害損失削減）が大きく変動

---

# 6️⃣ **Soil Carbon Baseline (tC/ha)**

**何を意味する？**  
土壌炭素の初期値。

**投資家にとっての意味**

- ΔC（炭素固定量）の計算に影響
- Carbon Credits の価値に直結

---

# 7️⃣ **Post-Harvest Loss Baseline (%)**

**何を意味する？**  
収穫後の損失率（腐敗・劣化・輸送ロス）。

**投資家にとっての意味**

- MBT55 による Anti-Spoilage 効果が見える
- Food Loss Credits の価値が変動

---

# 8️⃣ **Market Volatility (0–1)**

**何を意味する？**  
市場価格の不安定さ。

**投資家にとっての意味**

- Price Stability Index に影響
- MBT55 の “価格安定化効果” を体験できる
- 企業の Scope 3 リスク管理に直結

---

# 9️⃣ **Area (ha)**

**何を意味する？**  
農地の面積。

**投資家にとっての意味**

- PBPE Value（USD）がスケールする
- Carbon / Food Loss / Biosecurity Credits が増える
- 投資規模のシミュレーションが可能

---

# 🔟 **Input Cost Baseline (USD/ha)**

**何を意味する？**  
肥料・農薬などの投入コスト。

**投資家にとっての意味**

- MBT55 による Cost Reduction が見える
- ROI の改善幅が変わる

---

# 🎯 **まとめ：サイドバーは “MBT55 の価値を動かす変数”**

投資家にとって、サイドバーは **MBT55 の価値を体験するためのコントロールパネル**。

- 収量
- 病害損失
- 品質
- 収穫後損失
- 炭素固定
- GHG 削減
- PBPE Value
- ROI
- PBPE Credits

これらが **リアルタイムで変化する**。
