## 🔧 **ステップ1: 依存関係のインストール**

### **VS Codeのターミナルで実行：**

```bash
# リポジトリのディレクトリに移動
cd E:\OneDrive\ドキュメント\GitHub\M3-BioSynergy

# 仮想環境を作成（初回のみ）
python -m venv venv

# 仮想環境を有効化
# Windowsの場合：
venv\Scripts\activate
# Mac/Linuxの場合：
source venv/bin/activate

# 必要なパッケージをインストール
pip install numpy scipy matplotlib
```

## 🏃 **ステップ2: 各ファイルの実行方法**

### **方法A: 統合シミュレーション（推奨）**

全ての機能を一度に実行する最も簡単な方法：

```bash
python examples/basic_simulation.py
```

**実行結果：**
- 微生物多様性シミュレーション（120菌種）
- ハイパーサイクル動態
- 栄養カスケード
- 炭素流動・隔離量計算
- GHG削減（9項目）
- 経済分析（炭素クレジット収益）
- 7つのグラフ（`mbt55_simulation_results.png`）
- JSONデータ出力（`simulation_output.json`）

---

### **方法B: 個別モジュールの実行**

#### **1. 炭素流動モデル（単独）**
```bash
python -c "from src.core.carbon_flow import CarbonFlowModel; m = CarbonFlowModel(use_mbt55=True); print(m.calculate_carbon_cycling_efficiency())"
```

#### **2. GHG削減計算（単独）**

```bash
python -c "from src.core.microbial_diversity import MicrobialDiversityEngine; e = MicrobialDiversityEngine(); print(e.get_emergent_metrics())"
```
