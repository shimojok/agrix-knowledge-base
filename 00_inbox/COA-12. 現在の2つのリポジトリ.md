# 🏷️ **3. 推奨される新しいリポジトリ名**

## **英語版（旧 M3-BioSynergy）**

### 推奨名：

```
M3-BioSynergy-Archive
```

または

```
M3-BioSynergy-Legacy
```

または

```
M3-BioSynergy-Materials
```

### 理由

- 「Archive」＝素材集
- 「Legacy」＝旧版
- 「Materials」＝資料集

どれも国際的に意味が明確で、誤解がありません。
