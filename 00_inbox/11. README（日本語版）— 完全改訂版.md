## 🌍 M3-BioSynergy-Core

**MBT55 × PBPE × Planetary OS Soil Module – 統合デモシステム**

本リポジトリは、MBT55（微生物バイオ触媒）を用いた  
**土壌炭素隔離・収量向上・微生物生態改善** を統合的に評価する  
**Soil–Carbon–Finance ダッシュボード（Streamlit）** の実装です。

Planetary OS（地球規模生態オペレーティングシステム）の  
**Soil Module（1.0）** と互換性を持つデータ構造を採用し、  
国際機関・企業・研究者がそのまま利用できる形式で出力します。

---

## 📁 フォルダ構成

```
/
├── app.py                # 日本語版ダッシュボード
├── app_en.py             # 英語版ダッシュボード
├── core_model.py         # 土壌炭素・微生物・収量モデル
├── mrv.py                # MRV（モデル vs 実測）比較モジュール
├── planetary_os_adapter.py # Planetary OS Soil Module Export
└── README.md
```

---

## 🧠 モデル概要（core_model.py）

- 土壌炭素ストック（SOC）
- 年次炭素隔離量（tCO₂e/ha/yr）
- 収量（t/ha）
- 微生物バイオマス
- 基質ダイナミクス
- 土壌安定性
- C/N サイクル

MBT55 の投入量（0–3）に応じて、  
**土壌生態・炭素隔離・収量が連動して変化する**ように設計。

---

## 📑 MRV（mrv.py）

アップロードされた実測データ（CSV/Excel）と  
モデル出力を比較し、以下を算出：

- RMSE（SOC / Flux / Yield）
- Bias
- R²
- MRV レポート（JSON）

---

## 🚀 Planetary OS Soil Module Export（planetary_os_adapter.py）

Planetary OS Soil Module（v1.0）と互換性のある JSON を生成：

- baseline
- project
- difference
- scenario
- area / years / initial SOC

国際プロジェクトでそのまま利用可能。

---

## 📊 ダッシュボード（app.py / app_en.py）

- Overview（隔離量・収益・グリーンプレミアム）
- Soil（SOC・微生物・基質・安定性）
- Carbon（年次隔離量）
- Finance（収量 × 価格、炭素クレジット）
- MRV（実測データ比較）
- Export（Planetary OS JSON）

## 🔬 **何ができるのか？**

### 1. **土壌炭素隔離のシミュレーション**

MBT55 の投入量に応じて、  
SOC（tC/ha）と年次隔離量（tCO₂e/ha/yr）を計算。

### 2. **収量向上の推定**

MBT55 による収量増加（10–55%）を反映。

### 3. **微生物生態の変化を可視化**

- 微生物バイオマス
- 基質ダイナミクス
- 土壌安定性

### 4. **MRV（モデル vs 実測）比較**

CSV/Excel をアップロードするだけで  
RMSE / Bias / R² を自動計算。

### 5. **Planetary OS Soil Module Export**

国際プロジェクトでそのまま使える JSON を生成。

---

## 💰 **グリーンプレミアムの算定**

- 追加炭素隔離量 × カーボンクレジット価格
- 収量向上 × 市場価格

これらを統合し、  
**農業の “気候価値” を数値化**します。
