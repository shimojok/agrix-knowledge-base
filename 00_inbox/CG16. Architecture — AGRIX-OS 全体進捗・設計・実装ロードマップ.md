# 18. Evidence Adjudication Model

Canonical Objectを以下の6階層に分類します。

```text
E0 — SOURCE
     原資料そのもの

E1 — OBSERVATION
     観察・実測・記録

E2 — VERIFIED EVIDENCE
     独立または規定手順で検証済み

E3 — MODEL-DERIVED
     数式・Simulation・推計による結果

E4 — CLAIM
     Repository / Documentに記載された主張

E5 — HYPOTHESIS / SCENARIO
     仮説・将来Scenario・未検証予測
```

---

# 19. Critical Rule

**E3 Model resultをE2 Evidenceへ昇格させない。**

**E4 ClaimをE2 Evidenceへ昇格させない。**

**E5 Scenarioを実績値として扱わない。**

これをAGRIX-OSの**Evidence Firewall**として固定します。

を固めることが、過去に発生した「AIのメモリ異常・ハルシネーション・重複定義」を構造的に防ぐポイントです。

そして、この方式ならNotebookLMを**Knowledge Source / Retrieval Layer**として使い、Gemini/GemやChatGPT等を**Reasoning / Architecture / Generation Layer**として分離することも可能になります。

```text
NotebookLM
   ↓
Retrieval / Source Grounding
   ↓
Canonical Knowledge
   ↓
AI Reasoning
   ↓
Architecture / Decision
   ↓
Human Governance
```

これは、現在検討している**PMOS Knowledge & AI Governance Architecture**とも整合します。
