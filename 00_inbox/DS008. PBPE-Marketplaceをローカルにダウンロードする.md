## 🎯 今やるべきことは「3つだけ」

### Step 1: PBPE-Marketplaceをローカルにダウンロードする

Cursorを開いたら、以下の手順をやってみてください：

1. **Cursorを開く**
2. **`Cmd + Shift + P`（Mac）または `Ctrl + Shift + P`（Windows）を押す**
3. 表示された入力欄に `Git: Clone` と入力してEnter
4. 以下のURLを貼り付けてEnter：
   ```
   https://github.com/shimojok/PBPE-Marketplace.git
   ```
5. 保存先を選ぶ（デスクトップなど、わかりやすい場所）

**これでGitHubのファイルがあなたのパソコンにダウンロードされます。**

---

### Step 2: ターミナルを開いて必要なものをインストールする

Cursorの下部に「ターミナル」というタブがあります。そこをクリックして、以下のコマンドを**1つずつ**実行してください：

```bash
cd frontend
npm install
npm run dev
```

**「エラーが出た」という場合は、そのエラーメッセージをここに貼ってください。**

---

### Step 3: ブラウザで確認する

ターミナルに `http://localhost:3000` のようなURLが表示されたら、そのURLをブラウザで開いてください。
