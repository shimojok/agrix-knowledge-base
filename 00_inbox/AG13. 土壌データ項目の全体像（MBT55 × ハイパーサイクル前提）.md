### 土壌データ項目の全体像（MBT55 × ハイパーサイクル前提）

| カテゴリ      | 項目例                                     | MBT55／ハイパーサイクルでの役割       |
| --------- | --------------------------------------- | ------------------------ |
| 物理性       | 土壌水分・温度・テクスチャ（砂・シルト・粘土）                 | 微生物活性・分解速度・根の伸長に直結       |
| 化学性（基礎）   | pH・EC・C/N比・塩分（Na⁺）・交換性塩基                | MBT55活性条件・塩害修復・肥料効率の基盤   |
| 炭素・有機物    | SOC（有機炭素量）・全有機物量・腐植質（フミン酸/フルボ酸比）        | ハイパーサイクルの「炭素ストック」と炭素隔離評価 |
| 栄養カスケード   | N・P・K・Ca・Mg・微量元素（Fe, Mn, Zn, Cu, B, Mo） | 作物栄養状態とMBT55代謝産物の肥料効果の評価 |
| MBT55関連動態 | MBT55投与量・分解率・温度推移・pH推移・C/N収束            | 「ハイパーサイクルが動いているか」の動的指標   |
| 代謝産物      | アミノ酸プロファイル・短鎖脂肪酸・ポリフェノール・腐植質指標          | 肥料価値・作物フェノタイプとのリンク       |
| バイオセキュリティ | 病原菌数・MBT55優占度・微生物多様性指数                  | バイオコントロール・土壌ヘルスの評価       |

### 1. アップロードドキュメントから読み取れる「必須項目」

**MBT55 実測値.md** には、土壌データ設計に直結するヒントがかなり入っています。

> 「センサーで取得した**土壌pH、塩分濃度、温度**などのデータを、MBT55の至適条件（pH 9-10, 塩分10%まで, 20-30°C）とリアルタイムで比較表示します。」

ここから、**最低限必要な動的項目**は：

- **pH**
    
- **温度**
    
- **EC（塩分・電気伝導度）**
    
- **有機物分解率（OM degradation）**
    
- **C/N比**
    
- **Na⁺関連指標（ESP・塩害レベル）**
    
- **病原菌数・抑制率**
    

同じドキュメントで、

> 「有機物分解率（OM Degradation Rate）：≥85% / 24h」「ピーク温度：55℃〜68℃」「C/N比…24時間後15〜18」

と書かれているので、**MBT55ハイパーサイクルを評価するための「コア土壌テレメトリ」**はここから設計できます。

### 2. 腐植質・炭素・栄養カスケード系の項目

**MBT55代謝産物と腐植質.md** では、土壌側で見るべき炭素・栄養項目が明示されています。

> 「摂取栄養チェック＝土壌中のミネラル・SOC(有機炭素量）・ポリフェノール含有量など」

ここから追加すべき項目は：

- **SOC（有機炭素量）**
    
- **ミネラル（N, P, K, Ca, Mg, 微量元素）**
    
- **ポリフェノール含有量**
    
- **腐植質指標（フミン酸／フルボ酸比、ヒューミン）**
    

さらに同ドキュメントで、

> 「MBT代謝物は、腐植質と非常に近い性質を有し、土壌中で腐植質へと進化する可能性を持つ"人工的腐植質生成物"とみなすことができます。」

とあるので、**腐植質量・腐植質タイプ**は、炭素隔離と肥料機能の両方の評価軸として必須になります。

### 3. ハイパーサイクル理論から見た「動態項目」

**MBTハイパーサイクルの理論的優位性と体系化.md** では、炭素動態の数理モデルが出てきます。

> 「短期（24時間）：微生物分解ダイナミクス」「中期（10年）：腐植質形成・炭素安定化」

ここから、土壌データとして追うべき「時間軸付き項目」は：

- **24時間スケール：**
    
    - MBT55投与量
        
    - 分解率
        
    - 温度・pH・ECの時間変化
        
- **年〜10年スケール：**
    
    - SOC増加率
        
    - 腐植質量の推移
        
    - メタン・N₂O排出量（可能なら）
        

### 4. 「アップロードドキュメントは参考にならない？」への答え

正直に言うと——

- **「土壌データ項目の一覧表」としては、確かに直接は書かれていません。**
    
- ただし、
    
    - MBT55の分解・発酵動態
        
    - 腐植質・SOC・栄養カスケード
        
    - 塩害・重金属・病原菌制御
        
    
    という**「何を測ればハイパーサイクルが見えるか」**のヒントは、かなり濃く入っています。
    

なので、

- 「AGRIXの土壌スキーマをゼロから設計する」には不足
    
- 「MBT55ハイパーサイクル用の必須パラメータを抽出する」には十分
    

という感じです。

### 5. いま決めてしまえる「AGRIX土壌データのMVP項目」

**A案：本物のプロダクト**として最初に実装するなら、MVPとしてはこのくらいに絞るのが現実的です。

1. **物理・環境**
    
    - **温度**
        
    - **水分**
        
    - **pH**
        
    - **EC（塩分）**
        
2. **炭素・有機物**
    
    - **SOC**
        
    - **全有機物量**
        
    - **C/N比**
        
3. **栄養カスケード**
    
    - **N・P・K**
        
    - **Ca・Mg**
        
    - **主要微量元素（Fe, Mn, Zn, Cu）**
        
4. **MBT55動態**
    
    - **MBT55投与量**
        
    - **24h分解率**
        
    - **温度・pH・ECのタイムシリーズ**
        
5. **バイオセキュリティ**
    
    - **病原菌数（簡易指標で可）**
        
    - **MBT55優占度（後からでも良いが設計だけは入れておく）**
        

もしよければ、次のステップで：

- この項目セットを**Next.jsフロントの「土壌ハイパーサイクル管理画面」のフォーム項目**に落とし込みます。
    
- その上で、**API Routesのスキーマ（TypeScript型）をフルファイルで定義**していきましょう。
