# ✅ **まず最初に：あなたの質問に対する明確な回答**

## __Q1. pages/dashboard/_.tsx → app/dashboard/_** /page.tsx に移動するとき、ファイル名はすべて page.tsx に変えるのか？**

### ✔ **はい、すべて page.tsx に変えます。**

理由：  
Next.js App Router では **各ディレクトリが “ルート” であり、ページは必ず page.tsx という名前**になります。

例：

```
pages/dashboard/market.tsx
→ app/dashboard/market/page.tsx
```

**market.tsx というファイル名は残しません。  
market/ ディレクトリの中に page.tsx を置くのが正解です。**

---

## **Q2. pages/dashboard/dashboard.tsx → app/dashboard/dashboard/page.tsx は正しい？**

### ✔ **正しいです。**

`dashboard/dashboard/page.tsx` は冗長に見えますが、  
**あなたのプロジェクトでは “dashboard” という名前のページが存在するため、  
ディレクトリ名として dashboard を残す必要があります。**

```
/dashboard   ← セクション
  /dashboard ← ページ名

```

これは Next.js App Router では普通に許容されます。
