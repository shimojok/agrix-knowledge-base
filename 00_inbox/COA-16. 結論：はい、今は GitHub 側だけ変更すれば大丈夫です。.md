# 🧭 **1. GitHub 側だけ名前を変更しても問題ない理由**

GitHub のリポジトリ名変更は、  
**リモート（GitHub上のURL）が変わるだけ** です。

ローカルのフォルダは `.git` の中でリモートURLを記録しているため、  
フォルダ名が変わっても Git は気にしません。

つまり：

- GitHub → 名前変更
- ローカル → そのままでもOK
- `git pull` / `git push` → そのまま動く

という状態になります。

# 🧩 **2. ローカルフォルダ名を “変えたほうが良い” ケース**

### ✔ 新しい正式版リポジトリ（Core）を作る予定がある

→ 旧フォルダは「Archive」として名前を揃えたほうが管理しやすい

### ✔ ローカルに複数の M3-BioSynergy 関連フォルダを置く予定

### ✔ GitHub とローカルの名前を一致させたい
