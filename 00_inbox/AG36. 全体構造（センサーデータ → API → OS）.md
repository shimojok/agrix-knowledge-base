# 🟦 **1. CSV 形式のセンサーデータ投入スクリプト**

CSV例（圃場から送られる形式）：

コード

```
timestamp,ph,eh_mV,moisture_pct,temperature_c,co2_flux_mg_m2_h
2026-07-09T10:00:00Z,6.8,180,58,24.5,310
2026-07-09T11:00:00Z,6.9,185,57,24.7,315
```

## 📌 Node.js投入スクリプト（`ingest-csv.js`）

js

```
import fs from "fs";
import csv from "csv-parser";
import fetch from "node-fetch";

const results = [];

fs.createReadStream("soil_data.csv")
  .pipe(csv())
  .on("data", (row) => results.push(row))
  .on("end", async () => {
    const payload = {
      lotId: "LOT-20260709-001",
      snapshots: results.map((r) => ({
        timestamp: r.timestamp,
        ph: parseFloat(r.ph),
        eh_mV: parseFloat(r.eh_mV),
        moisture_pct: parseFloat(r.moisture_pct),
        temperature_c: parseFloat(r.temperature_c),
        co2_flux_mg_m2_h: parseFloat(r.co2_flux_mg_m2_h),
      })),
    };

    const res = await fetch("https://your-domain/api/soil", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });

    console.log(await res.json());
  });
```

# 🟦 **3. MQTT形式のセンサーデータ投入スクリプト**

MQTTは圃場センサーで最も一般的。 トピック例：

コード

```
agrrix/soil/LOT-20260709-001
```

ペイロード例：

json

```
{
  "timestamp": "2026-07-09T10:00:00Z",
  "ph": 6.8,
  "eh_mV": 180,
  "moisture_pct": 58,
  "temperature_c": 24.5,
  "co2_flux_mg_m2_h": 310
}
```

## 📌 Node.js MQTT投入スクリプト（`ingest-mqtt.js`）

js

```
import mqtt from "mqtt";
import fetch from "node-fetch";

const client = mqtt.connect("mqtt://your-broker-ip");

client.on("connect", () => {
  client.subscribe("agrrix/soil/LOT-20260709-001");
});

client.on("message", async (topic, message) => {
  const payload = {
    lotId: "LOT-20260709-001",
    snapshots: [JSON.parse(message.toString())],
  };

  const res = await fetch("https://your-domain/api/soil", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload),
  });

  console.log(await res.json());
});
```
