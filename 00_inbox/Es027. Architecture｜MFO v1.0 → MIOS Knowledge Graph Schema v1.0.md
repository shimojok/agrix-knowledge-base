# 2. Node Schema

MIOS KG v1.0では、**13 Core Node Types**を定義します。

|Node|Purpose|Required ID|
|---|---|---|
|`Food`|食品|`food_id`|
|`Nutrient`|栄養素|`nutrient_id`|
|`Phytochemical`|植物由来化合物|`phytochemical_id`|
|`MicrobialTaxon`|微生物分類群|`taxon_id`|
|`MicrobialCommunity`|微生物群集|`community_id`|
|`MicrobialFunction`|微生物機能|`function_id`|
|`FunctionalCapacity`|宿主に提供可能な機能|`capacity_id`|
|`Transformation`|代謝変換|`transformation_id`|
|`Metabolite`|代謝物|`metabolite_id`|
|`HostTarget`|宿主標的|`target_id`|
|`HostResponse`|宿主応答|`response_id`|
|`Phenotype`|表現型・症状|`phenotype_id`|
|`Evidence`|根拠|`evidence_id`|

# 13. Evidence Graph

```
                  ┌──────────────┐
                  │   Evidence   │
                  └──────┬───────┘
                         │ SUPPORTS
                         ▼
                ┌──────────────────┐
                │ KG Relationship  │
                └──────────────────┘
```

Evidence Level：

```
E0 Unknown
E1 Hypothesis
E2 Mechanistic
E3 Human Observational
E4 Clinical
E5 Validated Intervention
```

### Critical Rule

```
Evidence Level
      ↓
Confidence
      ↓
AI Reasoning
```

AIがEvidence Levelを無視して、

```
Mechanism
   ↓
Clinical Recommendation
```

と飛躍することを禁止します。

# 17. Governance｜Schema Freeze Rules

MIOS KGでは以下を固定します。

### Rule 1

**Nodeを追加する前にOntology上の意味を定義する。**

### Rule 2

**RelationshipにはEvidenceを紐付ける。**

### Rule 3

**TaxonomyからFunctionを推論しない。**

### Rule 4

**FunctionからClinical Effectを直接推論しない。**

### Rule 5

**Functional Capacityと実測Functional Activityを区別する。**

### Rule 6

**UnknownをUnknownとして保持する。**
