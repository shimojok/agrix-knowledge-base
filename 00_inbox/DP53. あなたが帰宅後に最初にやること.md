# 🟩 **STEP 4：Backend の動作確認（あなたが帰宅後に最初にやること）**

ここは **5 分で終わるチェックリスト**にします。

---

## ✅ **4-1. Backend を起動**

ターミナルで：

```
uvicorn backend.main:app --reload
```

起動ログにエラーが出なければ OK。

---

## ✅ **4-2. API ドキュメントを開く**

ブラウザで：

```
http://localhost:8000/docs
```

ここで確認するポイントは 3 つだけ：

### **① /registry/** が表示されている

- `/registry/record`
- `/registry/{rpt_id}`
- `/registry/by-subject/{subject_id}`
- `/registry/chain/status`

これらが見えていれば **Registry × Blockchain が FastAPI に統合済み**。

---

### **② /credits/** が表示されている

- `/credits/issue`
- `/credits/retire`
- `/credits/{crd_id}`

これが見えていれば **PBPE Credits API が正しくロードされている**。

---

### **③ /registry/chain/status を実行してみる**

レスポンス例：

```json
{
  "length": 1,
  "is_valid": true
}
```

- length = 1 → Genesis ブロックのみ
- is_valid = true → チェーン整合性 OK

これで **Blockchain が正常に動作している**ことが確認できる。

# 🟩 **STEP 5：Frontend と Backend の接続確認（Dashboard 動作確認）**

ここからは **Dashboard が Backend と正しく通信できるか**を確認するフェーズ。

---

## ✅ **5-1. Dashboard を起動**

```
npm run dev
```

または

```
pnpm dev
```

---

## ✅ **5-2. .env の API URL を確認**

`.env.local` に以下があること：

```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

これがないと Dashboard が Backend に接続できない。

---

## ✅ **5-3. Dashboard にログイン（JWT 認証）**

- ログイン画面が表示される
- 正しい認証フローでトークンが発行される
- トークンが localStorage または cookie に保存される

ここで確認するのは：

### **axios の interceptor が動いているか**

- API 呼び出し時に Authorization: Bearer <token> が付いている
- トークンが切れたら自動でログアウト or リフレッシュされる


---

## ✅ **5-4. Dashboard の各ページがデータを取得できるか**

### **① /dashboard/market（PBPE Credits 一覧）**

- Credits API からデータが取得できる
- CRD-ID が表示される
- 発行したクレジットが一覧に出る

---

### **② /dashboard/registry（Registry Explorer）**

- Registry API からデータが取得できる
- Chain length が表示される
- Entries テーブルが表示される

---

### **③ /dashboard/finance（Bonds）**

- Bond API が動いていればデータが表示される
- まだ空でも OK（後で接続する）

---

## ✅ **5-5. 実際に PBPE Credit を発行してみる**

Swagger で：

```
POST /credits/issue
```

入力例：

- kpi_id: KPI-TEST123
- amount_pbpe: 10
- owner: TEST_CORP

レスポンス例：

```json
{
  "crd_id": "CRD-4F9A2C1",
  "registry_entry": "RPT-7C1A9F2",
  "chain_hash": "0000abcd..."
}
```

これが出たら **PBPE Credits → Registry → Blockchain が完全に連動している**。

---

## ✅ **5-6. Dashboard で Registry を確認**

`/dashboard/registry` を開くと：

- 今発行した CRD-ID の履歴が表示される
- Chain Hash が ✔ で表示される
- Timestamp が正しい

これで **Backend と Frontend の完全接続が確認できる**。
