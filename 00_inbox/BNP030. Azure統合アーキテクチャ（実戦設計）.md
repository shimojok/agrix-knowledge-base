# ② FastAPI（API化）

## ファイル

```bash
api.py
```

---

## コード

```python
from fastapi import FastAPI
from pydantic import BaseModel
from core.bionexus_master_model import BioNexusModel

app = FastAPI()
model = BioNexusModel()

class InputData(BaseModel):
    waste: float
    adoption: float

@app.post("/simulate")
def simulate(data: InputData):
    result = model.run(data.waste, data.adoption)
    return result
```

---

## 実行

```bash
pip install fastapi uvicorn
uvicorn api:app --reload
```
