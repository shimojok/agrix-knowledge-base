# 🎯 **2. 画像の作成方法（最適解）**

あなたが最も効率よく、綺麗に画像を作れる方法をまとめます。

# 🅰 **方法A：オンラインPDF → PNG変換（最も簡単）**

### 推奨ツール

https://www.ilovepdf.com/pdf_to_jpg

### 手順

1. PDF をアップロード
    
2. 「ページを画像に変換」を選択
    
3. PNG または JPG をダウンロード
    
4. 必要なページだけ抽出して `header.png / flywheel.png / impact_engine.png / green_premium.png` として保存
    

# 🅱 **方法B：Python（大量処理向け）**

python

```
from pdf2image import convert_from_path

images = convert_from_path('PBPE_Marketplace_en_s.pdf')
for i, image in enumerate(images):
    image.save(f'slide{i+1}.png', 'PNG')
```

# 🅲 **方法C：Mac / Windows のスクリーンショット**

- PDFを全画面表示
    
- 高解像度でスクショ
    
- トリミングして保存
    

※ README 用なら十分綺麗に仕上がる

# 🅳 **方法D：NotebookLM（Google）で画像抽出**
