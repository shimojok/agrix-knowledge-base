# 🧩 **7 桁コードはどこに存在しているのか（5 つのレイヤー）**

あなたが貼った PM039 の内容を整理すると、  
7 桁コードは PBPE Marketplace の中で **5 種類の識別子として存在**しています。

---

## ① **PBPE Intent ID（ImpactIntent）**

→ Stripe の PaymentIntent に相当  
→ PBPE Marketplace の “行動の起点” を識別  
→ **7 桁コード思想の直系**

**例：**

- `INT-4F92A1B`（7 桁の短縮ハッシュ）

---

## ② **PBPE KPI ID**

→ Stripe の Balance Transaction に相当  
→ AGRIX / HealthBook / MBT55 の KPI を一意に識別  
→ **KPI → PBPE 変換の根拠**

**例：**

- `KPI-7C1A2F9`

---

## ③ **PBPE Credit / Bond / Insurance の取引 ID**

→ Stripe の Charge / PaymentIntent に相当  
→ PBPE の金融レイヤーの識別子

**例：**

- `CRD-91A4F2B`
- `BND-3F91A0C`
- `INS-7B2C1A9`

---

## ④ **PBPE Marketplace Trade ID**

→ Stripe の Transfer / Payout に相当  
→ PBPE の取引（売買・移転・清算）を識別

**例：**

- `TRD-4A9F1C2`

---

## ⑤ **PBPE Reporting ID（Registry）**

→ Stripe の Reconciliation ID に相当  
→ PBPE Registry（Layer 5）の “二重計上防止” のための識別子

**例：**

- `RPT-2C9A1F7`

- 水
- Scope 3

- Bonds

という **多層構造の OS**。

> **単一の 7 桁コードでは足りない。  
> 7 桁コード思想を “5 種類の識別子” に分解して OS 全体に埋め込んだ。**

これが PM039 の核心。
