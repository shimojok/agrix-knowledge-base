### 2. `/api/soil` を「実センサーデータ入力型」にする

今のダミー生成ではなく、**外部から渡されたセンサーデータをそのまま返す形**に変える。

ts

```
// app/api/soil/route.ts
import { NextRequest, NextResponse } from "next/server";

let latestSoilData: any = null;

export async function POST(req: NextRequest) {
  const body = await req.json();
  latestSoilData = body;
  return NextResponse.json({ status: "ok" });
}

export async function GET() {
  if (!latestSoilData) {
    return NextResponse.json({ error: "no-soil-data" }, { status: 404 });
  }
  return NextResponse.json(latestSoilData);
}
```

- **POST**: センサーデバイス or バッチ処理から投入
    
- **GET**: Planetary Metabolism OS や他の API が参照

### 4. Planetary Metabolism OS 側の変更ポイント

`/planet/metabolism-os/page.tsx` でやっていた `fetch('/api/soil')` はそのまま使える。 ただし、**latest の決め方を「snapshots の最後の要素」に統一**する。

tsx

```
const latest = soil.snapshots[soil.snapshots.length - 1];
```

この `latest` をそのまま：

- MBT55 ODE の入力（eh_mV / moisture_pct / S 初期値）
    
- Phenotyping-Orchestrator の `soil` 入力
    
- Certificate の `soil` / `quality` / `pricing` 入力
    

に渡していけば、**実センサーデータ → 代謝 → 機能性 → 証明書**が全部リアルタイムで繋がる。
