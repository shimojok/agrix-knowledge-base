## 💰 すべて「完全無料」で運用するプラン

- **GitHub / GitHub Actions**
    
    - **費用:** **0円**
        
    - パブリックリポジトリであれば完全無料。プライベート（非公開）リポジトリでも、GitHub Actionsは毎月2,000分まで無料で動かせます。5,000ノートの同期であれば、数分で終わるため余裕で無料枠に収まります。
        
- **Pinecone (ベクトルデータベース)**
    
    - **費用:** **0円**
        
    - 「Free Tier（スタータープラン）」が用意されています。1つのインデックス（データベース）が無料で作成でき、数万件のチャンクまで余裕で保存可能です。5,000ノート規模であれば、この無料枠にすっぽり収まります。
        
- **OpenAI API (Embeddingモデル)**
    
    - **注意点:** 通常のOpenAI APIは従量課金（チャージ制）ですが、初期の無料クレジットが残っているか、あるいは完全無料にこだわるなら、Pythonスクリプト側を「Hugging Faceの無料オープンソースモデル（`all-MiniLM-L6-v2` など）」に差し替えることで、ベクトル化の計算コストも完全無料（0円）にできます。
        

> 💡 **完全無料化のためのチューニング**
> 
> ベクトル化を行うAIモデルをOpenAIから「オープンソースの無料モデル」に切り替えてスクリプトを記述します。これにより、完全にクレジットカード登録不要、または一切課金されない仕組みを実現します。
