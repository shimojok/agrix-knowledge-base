# BioNexus-Enterprise: Evidence Vault 構築企画案

## 基本方針

1. **分野別に6つのセクションに分割**し、既存の全リポジトリから最も強力なドキュメント・コード・データを集約する
2. **日本語版と英語版を並列構築**（`ja/` `en/` のディレクトリ構造）
3. **一挙構築ではなく、優先度の高いセクションから順次充実**
4. 各セクションは「理論→証拠→数値→コード」の4層で構成
