# 5. Evidence Governance

特に重要なのは、**「獲得経路」と「定着」をまだ確立事項として扱わないこと**です。

|Layer|現時点の扱い|
|---|---|
|エクオール産生菌の存在|Evidence|
|ヒト腸管からの分離|Evidence|
|ダイゼイン→エクオール変換|Evidence|
|複数菌による代謝協調|Evidence / Emerging|
|食事による維持・機能発現|Hypothesis / Emerging|
|母子・家族からの獲得|Hypothesis|
|食物・環境からの直接獲得|Hypothesis|
|特定食品による定着誘導|未確立|
|産生能を意図的に形成する介入|Research|

これにより、HealthBook/MIOSで**科学的事実・機序仮説・未検証仮説を混同しない**構造になります。
