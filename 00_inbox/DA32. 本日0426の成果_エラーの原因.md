HealthBook-AIダッシュボードの不具合の原因は下記の通りです。

両ファイルを修正しました。2つのバグが原因でした：

バグ① from src.inference_engine → from inference_engine（L17〜20） sys.path.append(BASE_DIR / "src") で既に src をパスに追加しているので、インポート時に src. をつけると Python が src/src/inference_engine.py を探してしまいます。StreamlitはこのImportErrorを内部でJSONDecodeErrorとして隠蔽して表示していたため、わかりにくくなっていました。

バグ② encoding="utf-8" → encoding="utf-8-sig"（L44） inference_engine.py は utf-8-sig（BOM対応）で読んでいるのに、app.py は utf-8 のままでした。エンコーディングを統一します。

この2ファイルをGitHubにプッシュして、Streamlit Cloudで再デプロイしてください。また、disease_matrix_137.json と kampo_metabolic_library.json の末尾 ] の修正も忘れずにプッシュしてください。

## [① PMO] 根本原因と教訓

| 問題 | 内容 |
|:---|:---|
| **バグ①** | `from src.inference_engine` → `from inference_engine`。`sys.path.append`済みなのに`src.`を付けていた |
| **バグ②** | `utf-8` → `utf-8-sig`。BOM対応の不一致 |
| **隠蔽** | Streamlitが`ImportError`を`JSONDecodeError`として表示し、全AIがJSONファイルの破損と誤診断 |

**教訓：Streamlit Cloudはエラーをマスクするため、インポートエラーがJSONエラーに見えることがある。**
