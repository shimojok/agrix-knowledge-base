# ✅ **ローカルフォルダ名の変更について**

### **結論：手動でフォルダ名を変更して大丈夫です。**

ただし、状況によって “やるべき操作” が少し変わります。

---

# 🧭 **ケース別：どうするのが正しいか**

## **ケース①：ローカルフォルダは GitHub と同期していない（ただのフォルダ）**

→ **そのまま名前変更してOK**

例：

```
M3-BioSynergy → M3-BioSynergy-Archive
```

何も問題ありません。

---

## **ケース②：ローカルフォルダは GitHub リポジトリを clone したもの**

→ **フォルダ名を変更してもOK（Gitはフォルダ名を気にしない）**

Gitは内部の `.git` フォルダで管理しているため、  
フォルダ名を変えてもリポジトリとして機能します。

例：

```
M3-BioSynergy → M3-BioSynergy-Archive
```

そのまま `git pull` や `git push` も動きます。

---

## **ケース③：今後 “Core” リポジトリを新規作成して clone する予定**

→ **ローカルの旧フォルダはアーカイブとして残すだけでOK**

つまり：

- 旧フォルダ → 名前変更して素材集として保存
- 新フォルダ → GitHubの新リポジトリ（Core）を clone して作成

という2フォルダ体制になります。
