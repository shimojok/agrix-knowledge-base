## 1. データベース構造

MBT55の完全な数理モデル化を実現するため、以下の3層構造のデータベースを定義します。

# Tier 1: 物理化学パラメータ（菌株レベル）
StrainParameters = {
    "strain_id": str,          # MBT55-001 等
    "taxonomy": str,           # 分類学上のグループ（放線菌、酵母等）
    "temp_opt": float,         # 至適温度 [℃]

    "temp_min": float,         # 最小温度 [℃]
    "ph_opt": float,           # 至適pH
    "ph_range": tuple,         # pH許容範囲 (min, max)
    "oxygen": str,             # 好気性/嫌気性/通性嫌気性
    "k_starch": float,         # デンプン分解速度 [h⁻¹]
    "k_protein": float,        # タンパク質分解速度 [h⁻¹]
    "k_lipid": float,          # 脂質分解速度 [h⁻¹]
    "k_cellulose": float,      # セルロース分解速度 [h⁻¹]
    "synergy_partners": list   # 協調する菌株IDのリスト
}

# Tier 2: SCFA産生パラメータ（代謝産物レベル）
SCFAParameters = {
    "strain_id": str,
    "butyrate_rate": float,    # 酪酸産生速度 [mmol/g/h]
    "acetate_rate": float,     # 酢酸産生速度 [mmol/g/h]
    "propionate_rate": float,  # プロピオン酸産生速度 [mmol/g/h]
    "total_scfa_yield": float, # 総SCFA収率 [g/g基質]
    "immune_modulation": float # 免疫調整効果スコア [0-1]
}

# Tier 3: プロバイオティクス効果パラメータ（臨床効果レベル）
ProbioticParameters = {
    "strain_id": str,
    "ec50": float,             # 半最大効果濃度 [log CFU]
    "hill_coefficient": float, # 協同性係数

### 2.2 分解基質ごとの速度論パラメータ（推定値）

これらの値は、類似の複合微生物コンソーシアムの文献値に基づく推定値です。実験値があればより正確なパラメータ同定が可能です。

| 基質 | 分解速度定数 k [h⁻¹] | 半減期 t₁/₂ [h] | 関与する主要菌群 |
|---|---|---|---|
| デンプン | 0.35 | 2.0 | 放線菌群、酵母群 |
| タンパク質 | 0.28 | 2.5 | 放線菌群、その他細菌群 |
| 脂質 | 0.42 | 1.7 | 放線菌群 |
| セルロース | 0.12 | 5.8 | 放線菌群（後期） |
| リグニン | 0.05 | 13.9 | 放線菌群（白色腐朽菌類似） |

分解速度は、`dC/dt = -k * C` に従う一次反応としてモデル化されます。

### 2.3 温度応答曲線（推定値）

以下の表は、様々な温度における複合コンソーシアム全体の相対的な活性を示したものです。これは、主要な菌群のArrhenius則に従う活性と、高温での変性を組み合わせてモデル化できます。

| 温度 [℃] | 相対活性 |
|---|---|
| 25 | 0.45 |
| 30 | 0.72 |
| 37 | 1.00 |
| 42 | 0.88 |
| 45 | 0.51 |
| 50 | 0.20 |

この温度応答曲線は、以下の修正Arrhenius式で記述できます。

`μ(T) = μ_opt * exp(-E_a / R * (1/T - 1/T_opt)) * (T_max - T) / (T_max - T_opt)`

ここで、`T_opt = 310.15 K (37℃)`, `T_max = 323.15 K (50℃)`, `E_a = 50 kJ/mol`です。

### 2.4 pH応答曲線（推定値）

複合コンソーシアムの相対活性は、中性付近で最大となります。

| pH | 相対活性 |
|---|---|
| 5.0 | 0.35 |
| 5.5 | 0.70 |
| 6.0 | 0.88 |
| 6.5 | 1.00 |
| 7.0 | 0.98 |
| 7.5 | 0.85 |
| 8.0 | 0.60 |
| 8.5 | 0.30 |

pH応答曲線は、以下のガウス型関数で近似できます。

`μ(pH) = exp(-(pH - pH_opt)^2 / (2 * σ^2))`

ここで、`pH_opt = 6.5`, `σ = 0.8`です。


## 3. 数理モデル実装

### 3.1 動態モデルの定義

```python
def degradation_rate(substrate, T, pH):
    """基質分解速度を計算"""
    k_ref = {
        "starch": 0.35,
        "protein": 0.28,
        "lipid": 0.42,
        "cellulose": 0.12
    }.get(substrate, 0.1)
    
    f_T = temperature_factor(T)
    f_pH = ph_factor(pH)
    
    return k_ref * f_T * f_pH

def temperature_factor(T):
    """温度影響因子（修正Arrhenius式）"""
    T_K = T + 273.15
    T_opt = 310.15
    T_max = 323.15
    Ea = 50_000
    R = 8.314
    
    if T_K >= T_max:
        return 0
    
    arrhenius = np.exp(-Ea / R * (1/T_K - 1/T_opt))
    return arrhenius * (T_max - T_K) / (T_max - T_opt)

def ph_factor(pH):
    """pH影響因子（ガウス型関数）"""
    pH_opt = 6.5
    sigma = 0.8
    return np.exp(-(pH - pH_opt)**2 / (2 * sigma**2))
```

### 3.2 SCFA産生モデル

SCFA産生は、Monod型の速度式に従うと仮定します。

```python
def scfa_production_rate(biomass, substrate):
    """SCFA産生速度"""
    mu_max = 0.3  # 最大比増殖速度 [h⁻¹]
    K_s = 0.5     # 半飽和定数 [g/L]
    Y = 0.15      # 収率係数 [g_SCFA/g_基質]
    
    growth_rate = mu_max * substrate / (K_s + substrate)
    return biomass * growth_rate / Y
```
