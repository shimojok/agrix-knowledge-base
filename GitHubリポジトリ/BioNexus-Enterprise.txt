# MBT55 Core Metabolites: The Triple-Currency System

## Overview

At the core of the MBT55 Ecological Hypercycle lies not a single molecule, but a **functionally hierarchical "Triple Currency"** system.

Integrated analysis by four AIs (DeepSeek, Copilot, Gemini, ChatGPT) identified the following three metabolic currencies.

---

## 1. Carbon Currency: Lactate → Short-Chain Fatty Acids (Acetate, Butyrate)

- **Lactate** is the universal electron carrier penetrating the aerobic/anaerobic interface
- In the gut, lactate is converted to **butyrate** via cross-feeding
- Butyrate serves as the primary energy source for colonocytes (70% of ATP), mediates epigenetic regulation through HDAC inhibition, and induces Treg cells

## 2. Electron Currency: Hydrogen (H₂) and Quinone Shuttles

- MBT55 maintains **near-zero hydrogen partial pressure**
- Methanotrophs and sulfate-reducing bacteria consume H₂ instantly
- This is the physicochemical basis for **zero odor**, preventing H₂S and CH₄ accumulation
- Low-molecular-weight quinone compounds generated during lignin degradation function as "electron shuttles"

## 3. Mineral Currency: Fulvic Acid and Chelated Minerals

- Complete lignin degradation produces low-molecular-weight fulvic acid
- Fulvic acid chelates Fe²⁺, Mn²⁺, Zn²⁺, delivering them in bioavailable form to plants and gut microbiota

---

## Conclusion

The MBT55 Hypercycle is defined by the continuous, non-equilibrium flux of **lactate, hydrogen, and fulvic acid.**

> *"MBT55 is not just a decomposer. It is a non-equilibrium thermodynamic engine that stabilizes the soil metabolome."*

# The Electron Shuttle: Why MBT55 Never Putrefies

## DeepSeek Analysis (Backed by Video Evidence)

### Conventional Composting

In conventional anaerobic composting:
- H₂ accumulates → Sulfate-reducing bacteria produce H₂S (rotten egg odor)
- Methanogenic archaea produce CH₄
- Electron stagnation is the root cause of putrefaction

### MBT55 Electron Dissipation Mechanism

MBT55's 55% aerobic fraction provides **oxygen micro-niches**:

Electrons flow from fermentation (NADH) to diverse acceptors:
- **O₂** (aerobic respiration)
- **NO₃⁻** (denitrification → N₂)
- **Fe³⁺** (iron reduction)
- **Mn⁴⁺** (manganese reduction)

This **diverse electron sink capacity** maintains the redox potential (Eh) in a narrow band (-100 to +200 mV).
A delicate balance — **too low for putrefaction, too high for methanogenesis.**

---

## Key ODE Equation

dH₂/dt = δ·E - ε·(X_methanotroph + X_sulfate_reducer)·H₂

In the MBT55 consortium, ε is extremely high → **H₂ → 0**

---

# MBT55 コア代謝産物：三重通貨システム

## 概要

MBT55生態学的ハイパーサイクルの中核をなすのは、**単一分子ではなく、機能的に階層化された「三重通貨」** である。

DeepSeek, Copilot, Gemini, ChatGPTの4つのAIによる統合分析の結果、以下の3つの代謝通貨が特定された。

---

## 1. 炭素通貨：乳酸 → 短鎖脂肪酸（酢酸・酪酸）

- **乳酸**は好気/嫌気界面を貫通する普遍的な電子キャリア
- 腸内では、乳酸はクロスフィーディングにより**酪酸**へ変換される
- 酪酸は大腸上皮細胞の主要エネルギー源（ATP 70%）であり、HDAC阻害によるエピジェネティクス制御、Treg誘導を担う

## 2. 電子通貨：水素（H₂）とキノンシャトル

- MBT55は**ほぼゼロの水素分圧**を維持する
- メタン酸化菌・硫酸還元菌がH₂を即座に消費するため
- これがH₂SやCH₄の蓄積を防ぎ、**悪臭ゼロ**の物理化学的根拠となる
- リグニン分解過程で生じる低分子キノン化合物が「電子シャトル」として機能

## 3. ミネラル通貨：フルボ酸とキレートミネラル

- 完全なリグニン分解により低分子フルボ酸が生成される
- フルボ酸はFe²⁺, Mn²⁺, Zn²⁺をキレートし、植物と腸内細菌叢にバイオアベイラブルな形で供給する

---

## 結論

MBT55ハイパーサイクルは、**乳酸、水素、フルボ酸**の継続的な非平衡フラックスによって定義される。

> *「MBT55は単なる分解者ではない。土壌メタボロームを安定化させる非平衡熱力学エンジンである。」*

## 1. Yaraの現状と構造的課題

Yara Internationalは、グローバル窒素肥料市場におけるリーディングカンパニーとして、Haber-Bosch法を中核とする化学肥料事業により高い市場支配力を維持している。一方で、以下の構造的課題に直面している。

### ■ Scope 3排出の巨大性
- 窒素肥料の使用に伴うN₂O排出は、CO₂の約300倍の温室効果を持つ
- 農業セクターにおけるScope 3排出の中核を構成
- 顧客側（農家）由来排出のため、企業単独での削減が困難

### ■ Haber-Bosch法のエネルギー依存性
- 高温・高圧プロセスにより天然ガス依存度が高い
- エネルギー価格変動に対する脆弱性
- グリーンアンモニア移行の進展はあるが、コストが依然高い

### ■ 土壌劣化への批判

# Physics Validation
# ---------------------------------------------------------------------------
def validate_h2_constraint(solution, threshold: float = H2_ACCUMULATION_THRESHOLD):
    """Check that dH2/dt ≈ 0 throughout the simulation.
    
    AGENTS.md Sacred Principle 3: If H2 accumulates, the model is broken.
    
    Args:
        solution: solve_ivp result object
        threshold: max permissible dH2/dt (default 0.05 mmol/L/h)
    
    Raises:
        PhysicsViolationError: if H2 accumulation detected
    """
    H2 = solution.y[4]
    dH2 = np.diff(H2) / np.diff(solution.t)
    max_dH2 = np.max(np.abs(dH2))
    if max_dH2 > threshold:
        raise PhysicsViolationError(
            f"H2 ACCUMULATION DETECTED: max |dH2/dt| = {max_dH2:.4f} > threshold {threshold}.\n"
            "Model integrity violated. Review epsilon parameter (H2 consumption rate) "
            "or methanotroph/sulfur bacteria abundance proxy.\n"
            "Evidence ref: DeepSeek M1 — 'H2 at detection limit in MBT55 soil'."
        )
    return max_dH2


# ---------------------------------------------------------------------------
# Simulation Runner
# ---------------------------------------------------------------------------
def run_simulation(
    initial_conditions: Optional[dict] = None,
    t_span: tuple = (0, 24),
    n_points: int = 240,
    param_path: str = PARAM_FILE,
    validate_physics: bool = True,
) -> dict:
    """Run the MBT55 Hypercycle simulation.
    
    Args:
        initial_conditions: dict with keys matching STATE_LABELS.
                            Defaults to standard 24h fermentation starting conditions
                            derived from evidence/fermentation_24h/observed_data.csv
        t_span: (t_start, t_end) in hours. Default (0, 24) matches video evidence.
        n_points: number of time evaluation points
        param_path: path to parameters.json
        validate_physics: if True, raises PhysicsViolationError on H2 accumulation
    
    Returns:
        dict with keys: t, state (dict of arrays), max_dH2, params_used
    """
    params = load_parameters(param_path)

    # Default initial conditions — consistent with evidence/fermentation_24h/observed_data.csv
    # (t=0: ambient organic substrate, pH 6.8, 25°C)
    defaults = {
        "Cp": 10.0,   # g/L — cellulose-rich organic input
        "Cm":  2.0,   # g/L — initial soluble sugars/AAs
        "Cs":  0.5,   # g/L — trace SCFAs/lactate at start
        "E":   1.0,   # mmol/L — initial NADH
        "H2":  0.1,   # mmol/L — trace dissolved H2
        "Na":  1.0,   # mmol/L — ammonium from protein
        "No":  0.5,   # mmol/L — background nitrate
        "Sr":  1.0,   # mmol/L — sulfate
        "Xf":  0.5,   # g/L   — fermenter inoculum
    }
    if initial_conditions:
        defaults.update(initial_conditions)

    y0 = [defaults[label] for label in STATE_LABELS]
    t_eval = np.linspace(t_span[0], t_span[1], n_points)

    sol = solve_ivp(
        mbt55_ode,
        t_span,
        y0,
        args=(params,),
        t_eval=t_eval,
        method="RK45",
        rtol=1e-6,
        atol=1e-8,
    )

    if not sol.success:
        raise RuntimeError(f"ODE solver failed: {sol.message}")

    max_dH2 = None
    if validate_physics:
        max_dH2 = validate_h2_constraint(sol)

    return {
        "t": sol.t,
        "state": {label: sol.y[i] for i, label in enumerate(STATE_LABELS)},
        "max_dH2": max_dH2,
        "params_used": params,
        "solver_status": sol.status,
    }


# ---------------------------------------------------------------------------
# GHG Output — IPCC Tier 2 interface for PBPE-Finance
# ---------------------------------------------------------------------------
def compute_ghg_output(
    result: dict,
    schema_path: str = os.path.join(os.path.dirname(__file__), "..", "schema", "mbt55_output.schema.json"),
) -> dict:
    """Compute GHG reduction metrics from simulation results.
    
    Output conforms to schema/mbt55_output.schema.json for downstream
    consumption by PBPE-Finance and HealthBook-AI agents.
    
    IPCC Tier 2 references:
      - N2O from managed soils: Chapter 11
      - Enteric CH4: Chapter 10
      - CO2 from avoided transport: Chapter 5

    Args:
        result: output from run_simulation()
        schema_path: path to mbt55_output.schema.json
    
    Returns:
        dict conforming to mbt55_output.schema.json
    """
    with open(schema_path, "r") as f:
        schema = json.load(f)

    state = result["state"]
    t = result["t"]

    # Integral of Cs (SCFA/lactate) over 24h — proxy for humification quality
    cs_integral = np.trapezoid(state["Cs"], t) if hasattr(np, "trapezoid") else np.trapz(state["Cs"], t)

    # Final decomposition proxy: (Cp_initial - Cp_final) / Cp_initial
    decomposition_rate = (state["Cp"][0] - state["Cp"][-1]) / state["Cp"][0]

    # H2 constraint confirmation
    h2_final = state["H2"][-1]

    output = {
        "soil_n2o_suppression_factor": schema["properties"]["soil_n2o_suppression_factor"]["default"],
        "enteric_ch4_reduction_factor": schema["properties"]["enteric_ch4_reduction_factor"]["default"],
        "fermentation_time_to_humus": 24.0,
        "butyrate_yield_in_gut": schema["properties"]["butyrate_yield_in_gut"]["default"],
        "computed_decomposition_rate": round(decomposition_rate, 4),
        "cs_integral_24h": round(cs_integral, 4),
        "h2_final_mmol_L": round(h2_final, 6),
        "h2_constraint_satisfied": h2_final < H2_ACCUMULATION_THRESHOLD,
        "ipcc_tier": 2,
        "_warning": (
            "N2O and CH4 factors are schema defaults (PENDING evidence fit). "
            "Do not use in PBPE-Finance calculations until evidence/field_data.csv is loaded "
            "and parameters_optimized.json is generated via scipy.optimize."
        ),
    }
    return output
