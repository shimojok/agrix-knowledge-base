### 代謝・内臓脂肪・エストロン変換の因果モデル

#### 1. ベースとなるホルモン・代謝軸

- **卵巣エストロゲン低下 → 代謝セットポイントの変化**  
  \(\downarrow\) エストロゲン  
  → インスリン感受性低下・脂質代謝悪化  
  → 内臓脂肪増加・脂肪細胞からの炎症性サイトカイン増加   [PubMed](https://pubmed.ncbi.nlm.nih.gov/41903028/)  

- **内臓脂肪増加 → アロマターゼ活性上昇 → エストロン（E1）増加**  
  内臓脂肪・皮下脂肪・皮膚にはアロマターゼが存在し、  
  アンドロステンジオン → エストロン（E1）への変換が増える。  
  ただし、E1は卵巣由来E2より弱く、代謝リスクはむしろ上がりやすい。   [PubMed](https://pubmed.ncbi.nlm.nih.gov/41903028/)  

- **副腎アンドロゲン（DHEA・アンドロステンジオン） → 末梢でE1へ**  
  閉経後は副腎が主要な前駆ホルモン源となり、  
  その行き先が「脂肪組織のアロマターゼ」に大きく依存する。   [PubMed](https://pubmed.ncbi.nlm.nih.gov/41903028/)  

#### 2. 腸内細菌・エストロゲン代謝（エストロボローム）

- **エストロボローム**  
  エストロゲン代謝に関与する腸内細菌群（β-グルクロニダーゼ産生菌）  
  → 肝臓で抱合されたエストロゲンを腸内で再活性化し、再吸収させる。  
  → 腸内細菌叢の多様性低下で、この再活性化が弱まり、循環エストロゲンがさらに低下。   [symgram.symbiosis-solutions.co.jp](https://symgram.symbiosis-solutions.co.jp/column/0052)  

- **閉経 → 腸内細菌叢の多様性低下・SCFA産生菌減少**  
  → 腸管バリア低下・慢性炎症・インスリン抵抗性  
  → 内臓脂肪増加をさらに促進  
  → 内臓脂肪からのアロマターゼ依存E1産生にシフト、という負のループ。   [symgram.symbiosis-solutions.co.jp](https://symgram.symbiosis-solutions.co.jp/column/0052)  [academia.carenet.com](https://academia.carenet.com/share/news/b3ee96c0-1c7e-4c72-8d33-82c549f91b07)  

#### 3. エクオール・フィトエストロゲン軸

- **大豆イソフラボン（ダイゼイン） → 腸内細菌 → エクオール**  
  特定の「エクオール産生菌コンソーシアム」が存在する人のみ、  
  ダイゼイン → S-エクオールに変換され、弱いエストロゲン様作用を発揮。   [kagayaki-cl.jp](https://kagayaki-cl.jp/column/%e6%9b%b4%e5%b9%b4%e6%9c%9f%e5%af%be%e7%ad%96%e3%81%ae%e6%96%b0%e7%99%ba%e8%a6%8b%ef%bc%81%e4%bd%93%e3%81%ae%e4%b8%ad%e3%81%a7%e4%bd%9c%e3%82%89%e3%82%8c%e3%82%8b%e3%80%8c%e3%82%a8%e3%82%af%e3%82%aa/)  [おうち病院](https://anamne.com/menopause-supplement/)  

- **エクオールの機能性**  
  - エストロゲン受容体への結合（E2より弱いが選択的）  
  - ホットフラッシュ軽減・骨密度保護・LDL低下・血管柔軟性維持  
  → 「卵巣由来E2の欠落」を部分的に補うポストバイオティクス。   [kagayaki-cl.jp](https://kagayaki-cl.jp/column/%e6%9b%b4%e5%b9%b4%e6%9c%9f%e5%af%be%e7%ad%96%e3%81%ae%e6%96%b0%e7%99%ba%e8%a6%8b%ef%bc%81%e4%bd%93%e3%81%ae%e4%b8%ad%e3%81%a7%e4%bd%9c%e3%82%89%e3%82%8c%e3%82%8b%e3%80%8c%e3%82%a8%e3%82%af%e3%82%aa/)  [おうち病院](https://anamne.com/menopause-supplement/)

### 腸内細菌コンソーシアム（機能性視点）

#### 1. 閉経後に重要な機能モジュール

- **エストロゲン代謝モジュール（エストロボローム）**  
  - β-グルクロニダーゼ産生菌群  
  - 役割：抱合エストロゲンの再活性化・再吸収  
  - 乱れ：循環エストロゲン低下を加速し、更年期症状・骨・血管リスク増大。   [symgram.symbiosis-solutions.co.jp](https://symgram.symbiosis-solutions.co.jp/column/0052)  

- **エクオール産生コンソーシアム**  
  - ダイゼイン → S-エクオール変換菌群  
  - 役割：弱いエストロゲン様作用による症状緩和・代謝保護  
  - 日本人でも産生能は約50%程度。   [kagayaki-cl.jp](https://kagayaki-cl.jp/column/%e6%9b%b4%e5%b9%b4%e6%9c%9f%e5%af%be%e7%ad%96%e3%81%ae%e6%96%b0%e7%99%ba%e8%a6%8b%ef%bc%81%e4%bd%93%e3%81%ae%e4%b8%ad%e3%81%a7%e4%bd%9c%e3%82%89%e3%82%8c%e3%82%8b%e3%80%8c%e3%82%a8%e3%82%af%e3%82%aa/)  [おうち病院](https://anamne.com/menopause-supplement/)  

- **短鎖脂肪酸（SCFA）産生コンソーシアム**  
  - 酪酸・プロピオン酸・酢酸産生菌  
  - 役割：腸管バリア維持・炎症抑制・インスリン感受性改善  
  - 閉経後女性ではSCFA産生菌が減少しやすく、肥満・乳がんリスク因子と関連。   [symgram.symbiosis-solutions.co.jp](https://symgram.symbiosis-solutions.co.jp/column/0052)  [academia.carenet.com](https://academia.carenet.com/share/news/b3ee96c0-1c7e-4c72-8d33-82c549f91b07)

### MBT55を腸内細菌に取り入れた場合の代謝産物モデル（仮想設計）

MBT55はKazのプラットフォーム由来の「設計可能な代謝モジュール」として扱い、  
**腸内細菌コンソーシアムに組み込んだときの機能性を、因果モデルとして整理します。**

#### 1. MBT55の設計ターゲット（提案）

- **ターゲットA：SCFA産生強化モジュール**  
  - 腸内細菌に取り込まれ、酪酸・プロピオン酸産生経路を増幅するよう設計  
  - 期待効果：  
    - 腸管バリア強化 → LPS漏出抑制 → 慢性炎症低下  
    - インスリン感受性改善 → 内臓脂肪蓄積抑制  
    - 結果として「アロマターゼ依存E1過剰シフト」を抑える  

- **ターゲットB：エストロボローム調整モジュール**  
  - β-グルクロニダーゼ活性を「過剰でも不足でもない」レンジに調整する設計  
  - 期待効果：  
    - 抱合エストロゲンの再活性化を適度に維持  
    - 極端なエストロゲン低下を防ぎつつ、乳がんリスクを上げないバランスを狙う  

- **ターゲットC：エクオール産生支援モジュール**  
  - ダイゼイン代謝経路の補助因子として働き、既存エクオール産生菌の効率を上げる  
  - 期待効果：  
    - S-エクオール産生量増加 → 更年期症状緩和・骨・血管保護  
    - 「産生能はあるが産生量が低い」人の機能補完

#### 2. MBT55導入後の因果フロー（簡易モデル）

1. **MBT55導入 → SCFA産生増加**  
   \(\uparrow\) 酪酸・プロピオン酸  
   → 腸管バリア強化・炎症低下  
   → インスリン感受性改善  
   → 内臓脂肪減少  
   → アロマターゼ依存E1産生の過剰シフト抑制  

2. **MBT55導入 → エストロボローム機能の安定化**  
   \(\rightarrow\) 抱合エストロゲン再活性化の適正化  
   → 循環エストロゲン低下の“底抜け”を防ぐ  
   → 骨・血管・自律神経への急激な負荷を軽減  

3. **MBT55導入 → エクオール産生効率向上**  
   \(\uparrow\) S-エクオール  
   → エストロゲン受容体への穏やかな刺激  
   → ホットフラッシュ・血管運動症状・骨密度低下の緩和
