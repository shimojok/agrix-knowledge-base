# 📘 **HealthBook‑MI‑Probiome‑OS**

**Metabolic Intelligence × Estrobolome × MBT Probiotics × AI Agents**

## 🧬 **概要（Overview）**

**HealthBook‑MI‑Probiome‑OS** は、 人間の **代謝・内分泌・腸内環境・免疫・炎症・漢方・疾病リスク** を 統合的に解析する **次世代ヘルスケア OS（Metabolic OS）** です。

このプラットフォームは以下の 4 つの中核技術で構成されています：

- **MI（Metabolic Intelligence）**
    
- **Estrobolome（腸内ホルモン代謝）**
    
- **MBT Probiotics（MBT55 × 生薬 × 代謝産物）**
    
- **AI Agents（医療・保険・診療支援）**
    

Planetary Metabolism OS の思想を継承し、 医療機関・生命保険会社・研究機関・PBPE‑Marketplace と連携可能な **統合型ヘルスケアプラットフォーム**です。

## 🧠 **MI Core Engines（代謝OSの中核エンジン）**

## 🧪 **使用例（Usage Example）**

python

```
from platform.orchestrator.snapshot_builder import SnapshotBuilder
from platform.orchestrator.engine_orchestrator import EngineOrchestrator
from platform.pipelines.medical_pipeline import MedicalPipeline

snapshot_builder = SnapshotBuilder(
    "data/questionnaire/questionnaire_200_jp.json"
)

orchestrator = EngineOrchestrator({
    "phenotyping": PhenotypingEngine("data/questionnaire/questionnaire_200_jp.json"),
    "estrobolome": EstrobolomeEngine(),
    "acetylcoa": AcetylCoAEngine(),
    "inflammation": InflammationEngine()
})

pipeline = MedicalPipeline(snapshot_builder, orchestrator)

result = pipeline.run(
    responses={ "1": 1, "2": 0, ... },
    nutrition={ "carb": 70, "fat": 55, "protein": 60 },
    mbt_data={ "scfa": 65, "bile_acid": 40 },
    estro_data={ "beta_glucuronidase": 30 },
    mito_data={ "oxidative_stress": 45 },
    lifestyle={ "sleep_quality": 60, "stress": 70 }
)
```
