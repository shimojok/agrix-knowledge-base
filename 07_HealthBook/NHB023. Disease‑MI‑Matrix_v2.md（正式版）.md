## 1. 概要（Overview）

**Disease‑MI Matrix v2** は、HealthBook‑MI v2 の OS における  
**「疾患 × 代謝偏位 × MIエンジン × 介入」** を統合した辞書（Dictionary Layer）です。

この辞書は以下の目的で使用されます：

- MI Core Engines の推論結果と疾患を結びつける
- Deviation Codes（D000〜D550）を疾患にマッピング
- Dashboard の可視化に利用
- AIエージェント（Metabolic Intelligence Agent）の診断・提案の基盤
- PBPE‑Marketplace / MBT‑Biosecurity との共通データレイヤー

---

## 2. データ構造（Data Structure）

Disease‑MI Matrix v2 は **137件の疾患エントリを含む JSON 配列**です。

```json
[
  { ... D001 ... },
  { ... D002 ... },
  ...
  { ... D137 ... }
]
```

各エントリは **Disease Entry v2** と呼ばれ、  
以下の 6 レイヤーで構成されます：

1. **基本情報（ID・名称・カテゴリ）**
2. **疾患の説明（description）**
3. **Core Pathways（AcetylCoA / Estrobolome / Mito / MBT55 / Inflammation）**
4. **Deviation Codes（D000〜D550）**
5. **Snapshot Markers（症状・栄養・腸内・ホルモン・筋膜）**
6. **Intervention Focus（食事・生活・漢方・筋膜）**

---

## 3. Disease Entry v2 — フィールド仕様

### 3.1 基本情報

|フィールド|型|説明|
|---|---|---|
|`disease_id`|string|`"D001"` の形式|
|`name`|string|日本語名|
|`name_en`|string|英語名|
|`category`|string|Neuro / Metabolism / Gut / Hormone / Musculo‑Fascial / Oriental / Multi-System|

---

### 3.2 description

疾患の簡潔な説明（1〜3行）。

---

### 3.3 core_pathways

代謝の中心5軸を **low / normal / high** で表現。

```json
"core_pathways": {
  "acetylcoa": "low",
  "estrobolome": "normal",
  "mitochondria": "low",
  "mbt55": "normal",
  "inflammation": "high"
}
```

---

### 3.4 deviation_codes

疾患に関連する **Deviation Codes（D000〜D550）** の配列。

例：

```json
"deviation_codes": ["D121", "D141", "D212"]
```

---

### 3.5 snapshot_markers

Metabolic Snapshot v1 のどの項目が  
その疾患と関連するかを示す。

```json
"snapshot_markers": {
  "nutrition": ["fiber_low", "omega3_low"],
  "gut_status": ["bloating"],
  "hormone_state": ["sleep_low"],
  "microbiome": ["scfa_low"],
  "musculo_fascial": ["forearm_tension"],
  "symptoms": ["fatigue", "thumb_pain"]
}
```

---

### 3.6 related_mi_engines

疾患に関係する MI Core Engines。

例：

```json
"related_mi_engines": [
  "MI-AcetylCoA",
  "MI-Mitochondria",
  "MI-Inflammation"
]
```

---

### 3.7 intervention_focus

介入の方向性（食事・生活・漢方・筋膜）。

```json
"intervention_focus": {
  "diet": ["fiber", "omega3"],
  "lifestyle": ["sleep", "stress_management"],
  "kampo": ["F203"],
  "musculo_fascial": ["shoulder_release"]
}
```
