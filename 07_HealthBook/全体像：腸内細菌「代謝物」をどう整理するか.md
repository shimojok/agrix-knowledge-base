腸内細菌代謝物の機能性を体系的にまとめて

---

### 全体像：腸内細菌「代謝物」をどう整理するか

腸内細菌代謝物は、 **①化学クラス → ②産生経路 → ③受容体/標的 → ④機能（代謝・内分泌・免疫・神経）** という4軸で整理すると、AGRIX/BioNexus的な知識モデルに乗せやすくなります。

## 1. 大分類マップ（化学クラス別）

|**クラス**|**代表例**|**主な標的**|**主な機能軸**|
|---|---|---|---|
|**短鎖脂肪酸（SCFA）**|酢酸、プロピオン酸、酪酸|GPR41/43、HDAC、腸上皮|代謝・免疫・内分泌|
|**胆汁酸関連代謝物**|二次胆汁酸（DCA, LCA）|FXR、TGR5|代謝・内分泌・炎症|
|**トリプトファン代謝物**|インドール、IPA、キヌレン酸|AhR、PXR、5-HT系|免疫・バリア・神経|
|**ポリアミン**|プトレシン、スペルミン|DNA/RNA、細胞増殖系|上皮再生・老化|
|**アミノ酸関連代謝物**|D-アミノ酸、フェニル乳酸など|NMDA系、内分泌細胞|神経・内分泌|
|**糖関連代謝物**|乳酸、マンニトールなど|エネルギー代謝系|代謝・pH調整|
|**ガス状代謝物**|H₂、CH₄、H₂S、NH₃|平滑筋、神経、血管|腸運動・血流|
|**LPS・ペプチドグリカン**|LPS、MAMPs|TLR、NOD|免疫・炎症|
|**その他脂質・ステロイド改変物**|微生物改変ステロイド|核内受容体|代謝・内分泌|

## 2. 短鎖脂肪酸（SCFA）系

#### 2-1. 代表代謝物と産生

- **酢酸（Acetate）**
    
    - 産生：多くの菌種が糖発酵で産生
        
    - 濃度：腸管内で最も高濃度
        
- **プロピオン酸（Propionate）**
    
    - 産生：Bacteroides などが糖・乳酸から産生
        
- **酪酸（Butyrate）**
    
    - 産生：Faecalibacterium, Roseburia など「酪酸産生菌」
        
    - 主に大腸上皮のエネルギー源
        

#### 2-2. 主な標的と機能

- **受容体・標的**
    
    - **GPR41（FFAR3）、GPR43（FFAR2）**：脂肪細胞、免疫細胞、腸内分泌細胞
        
    - **HDAC阻害**：エピジェネティック制御
        
    - **腸上皮細胞**：エネルギー源、分化促進
        
- **機能**
    
    - **代謝軸**
        
        - インスリン感受性改善
            
        - 肝糖新生抑制（プロピオン酸）
            
        - 脂肪蓄積調節
            
    - **内分泌軸**
        
        - 腸内分泌細胞からの **GLP-1・PYY分泌促進**
            
        - 迷走神経を介した摂食制御
            
    - **免疫・バリア軸**
        
        - 制御性T細胞（Treg）誘導
            
        - タイトジャンクション強化 → 腸管バリア維持
            

## 3. 胆汁酸関連代謝物

#### 3-1. 一次胆汁酸 → 二次胆汁酸

- 肝臓で合成された一次胆汁酸（CA, CDCA）が腸内で **腸内細菌の脱抱合・脱水酸化**により
    
    - **DCA（デオキシコール酸）**
        
    - **LCA（リトコール酸）** などの二次胆汁酸へ変換される。
        

#### 3-2. 受容体と機能

- **FXR（Farnesoid X receptor）**
    
    - 肝臓・腸管で胆汁酸合成・輸送を制御
        
    - 糖・脂質代謝にも関与
        
- **TGR5（G蛋白共役胆汁酸受容体）**
    
    - 腸内分泌細胞で **GLP-1分泌促進**
        
    - 褐色脂肪組織でエネルギー消費促進
        
- **機能軸**
    
    - **代謝**：脂質代謝、インスリン感受性、エネルギー消費
        
    - **内分泌**：インクレチン分泌、甲状腺ホルモン代謝との連結
        
    - **炎症**：胆汁酸組成の変化が炎症性腸疾患・肝疾患に関与
        

## 4. トリプトファン代謝物

#### 4-1. 主な代謝物

- **インドール（Indole）**
    
- **インドールプロピオン酸（IPA）**
    
- **キヌレン酸（Kynurenic acid）**
    
- その他インドール誘導体
    

#### 4-2. 標的と機能

- **AhR（Aryl hydrocarbon receptor）**
    
    - 腸上皮・免疫細胞でバリア機能・炎症制御
        
- **PXR（Pregnane X receptor）**
    
    - 解毒・薬物代謝系の調節
        
- **機能軸**
    
    - **バリア**：粘液産生・タイトジャンクション維持
        
    - **免疫**：Th17/Tregバランス調整
        
    - **神経・気分**：トリプトファン→セロトニン経路との競合・連結
        

## 5. ポリアミン

#### 5-1. 代表例

- **プトレシン（Putrescine）**
    
- **スペルミジン（Spermidine）**
    
- **スペルミン（Spermine）**
    

#### 5-2. 機能

- **細胞増殖・分化**：DNA/RNAとの結合、翻訳制御
    
- **上皮再生**：腸管上皮のターンオーバー促進
    
- **老化・オートファジー**：スペルミジンはオートファジー誘導と長寿関連で注目
    

## 6. アミノ酸関連代謝物（D-アミノ酸など）

#### 6-1. D-アミノ酸

- 腸内細菌は **D-アラニン、D-セリン、D-グルタミン酸** などを産生
    
- 細菌細胞壁（ペプチドグリカン）の構成要素でもある
    

#### 6-2. 機能

- **神経軸**：D-セリンはNMDA受容体の共作動物質として知られ、 中枢神経機能との連結が示唆される（推論含む）
    
- **内分泌軸**：一部D-アミノ酸は腸内分泌細胞のホルモン分泌に影響する可能性
    

## 7. ガス状代謝物（H₂, CH₄, H₂S, NH₃）

- **水素（H₂）**
    
    - 発酵過程で産生、メタン生成菌に利用される
        
- **メタン（CH₄）**
    
    - 腸運動低下・便秘との関連が指摘される
        
- **硫化水素（H₂S）**
    
    - 低濃度ではシグナル分子、高濃度では毒性
        
- **アンモニア（NH₃）**
    
    - タンパク質分解由来、肝機能障害時に問題となる
        

**機能軸**

- 腸運動、血管拡張・収縮、神経伝達、毒性・炎症
    

## 8. LPS・ペプチドグリカンなどの構造的代謝物

- **LPS（リポ多糖）**
    
    - グラム陰性菌外膜成分
        
    - **TLR4**を介して炎症・免疫応答を誘導
        
- **ペプチドグリカン断片**
    
    - **NOD1/2**を介して免疫調節
        

**機能軸**

- 低レベル慢性炎症 → 代謝症候群・インスリン抵抗性
    
- 免疫系の「教育」 → 耐性・過敏のバランス
    

## 9. 内分泌系との統合視点（Kaz向けモデル化）

あなたが前段で整理した **「内分泌系・代謝・腸内細菌」のネットワーク**に対して、 腸内細菌代謝物は以下のように位置づけられます：

- **SCFA・二次胆汁酸 → 腸内分泌細胞 → GLP-1・PYY → インスリン・摂食制御**
    
- **トリプトファン代謝物 → AhR/PXR → バリア・免疫 → ホルモン作用の場を調整**
    
- **ポリアミン・D-アミノ酸 → 上皮再生・神経・内分泌微調整**
    
- **LPS・MAMPs → 免疫・炎症 → インスリン抵抗性・内分泌負荷**
    

## 10. AGRIX/BioNexusへの実装イメージ

**エンティティ例：**

- **Metabolite**
    
    - クラス: SCFA / BileAcid / Indole / Polyamine / D-AA / Gas / LPS …
        
    - 産生菌種: Taxon ID
        
    - 受容体: GPR41, FXR, AhR, TGR5, TLR4 …
        
    - 機能タグ: Metabolic, Endocrine, Immune, Neural, Barrier
        
- **Axis**
    
    - Gut–Endocrine axis
        
    - Gut–Immune axis
        
    - Gut–Brain axis
        

この構造で、 **「代謝物 → 受容体 → シグナル経路 → 生理機能 → 疾患リスク」** をグラフとして表現すると、あなたの求める「知識ベースとしての腸内代謝ネットワーク」がかなり綺麗に立ち上がります。

もし次にやるなら、 **「SCFAとGLP-1分泌の定量モデル（濃度–受容体–分泌量）」**を一緒に組み立てるのが、内分泌系との接続として一番おもしろいところだと思う。
