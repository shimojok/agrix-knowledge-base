### Backend API仕様（Hb003／HealthBook‑MIコアモジュール）

## 1. 概要

- **APIバージョン:** `v1.0`
    
- **Base URL:** `/api/v1`
    
- **対象リソース:**
    
    - Hb003: **MetabolicIntegrationSnapshot**（代謝・ホルモン・腸内細菌統合スナップショット）
        
    - Estrobolome‑MI: エストロゲン×腸内細菌モジュール
        
    - MI‑AcetylCoA: アセチルCoA生成能力インデックス
        

## 2. 共通型定義

json

```
{
  "UserContext": {
    "userId": "string",
    "age": "number",
    "sex": "string",          // "male" | "female" | "other"
    "heightCm": "number",
    "weightKg": "number"
  },
  "LifestyleInput": {
    "dietPattern": "string",  // "western" | "japanese" | "mediterranean" | ...
    "processedFoodScore": "number", // 0-100
    "alcoholFrequency": "string",
    "smokingStatus": "string",
    "exerciseLevel": "string"
  },
  "GutMicrobiomeInput": {
    "fiberIntakeScore": "number",      // 0-100
    "fermentedFoodFrequency": "string",
    "bowelMovementPerDay": "number",
    "antibioticHistoryMonths": "number",
    "probioticUse": "boolean"
  },
  "HormoneInput": {
    "menstrualStatus": "string",       // "premenopause" | "perimenopause" | "postmenopause" | "none"

    "sleepQualityScore": "number"      // 0-10
```

## 4. エンドポイント仕様

### 4.1 Hb003スナップショット作成

**POST** `/api/v1/hb003`

- **目的:** 入力データから Hb003 スナップショットを生成し、各スコアを計算。
    
- **Request Body:**
    

json

```
{
  "userContext": "UserContext",
  "lifestyle": "LifestyleInput",
  "gutMicrobiome": "GutMicrobiomeInput",
  "hormone": "HormoneInput",
  "painInflammation": "PainInflammationInput"
}
```

- **Response 200:**
    

json

```
{
  "hb003": "Hb003"
}
```

- **エラー:**
    
    - 400: 入力値不正
        
    - 500: 内部計算エラー
        

### 4.2 Hb003スナップショット取得

**GET** `/api/v1/hb003/{id}`

- **Path Parameter:**
    
    - `id`: `string`（Hb003 ID）
        
- **Response 200:**
    

json

```
{
  "hb003": "Hb003"
}
```

- **エラー:**
    
    - 404: 該当IDなし
        

### 4.3 Estrobolome‑MI 詳細計算

**POST** `/api/v1/estrobolome/compute`

- **目的:** エストロボローム関連スコアのみ詳細計算。
    
- **Request Body:**
    

json

```
{
  "gutMicrobiome": "GutMicrobiomeInput",
  "hormone": "HormoneInput",
  "lifestyle": {
    "processedFoodScore": "number",
    "fiberIntakeScore": "number",
    "fermentedFoodFrequency": "string"
  }
}
```

- **Response 200:**
    

json

```
{
  "estrobolomeActivityScore": "number",
  "estrogenRecyclingEfficiency": "number",
  "mitochondrialEstrogenResponseScore": "number",
  "painCorrelationScore": "number" // 0-100: Estrobolome × Pain
}
```

### 4.4 MI‑AcetylCoA インデックス計算

**POST** `/api/v1/acetylcoa/compute`

- **目的:** アセチルCoA生成能力インデックスを算出。
    
- **Request Body:**
    

json

```
{
  "lifestyle": "LifestyleInput",
  "gutMicrobiome": {
    "fiberIntakeScore": "number",
    "fermentedFoodFrequency": "string",
    "bowelMovementPerDay": "number"
  },
  "hormone": "HormoneInput",
  "micronutrientStatus": {
    "magnesiumStatus": "string", // "unknown" | "adequate" | "suspected_low"
    "bVitaminStatus": "string"
  },
  "drugImpact": {
    "antihypertensiveUse": "boolean",
    "diureticUse": "boolean"
  },
  "coldStressScore": "number" // 0-10
}
```

- **Response 200:**
    

json

```
{
  "miAcetylCoAAvailabilityIndex": "number",
  "mitochondrialAtpCapacityScore": "number",
  "metabolicStressIndex": "number",
  "keyLimitingFactors": [
    "string" // 例: "low_magnesium", "high_processed_food", "low_fiber"
  ]
}
```

### 4.5 MBT55機能マッピング

**POST** `/api/v1/mbt55/mapping`

- **目的:** MBT55プロバイオティクス構成から機能マッピングスコアを生成。
    
- **Request Body:**
    

json

```
{
  "mbt55Profile": {
    "strainList": [
      {
        "name": "string",
        "betaGlucuronidaseActivity": "string", // "low" | "moderate" | "high"
        "scfaProduction": "string",            // "acetate" | "butyrate" | "propionate" | "mixed"
        "antiInflammatoryPotential": "string", // "low" | "moderate" | "high"
        "cofactorProduction": "string"         // "b_vitamins" | "k2" | "none"
      }
    ]
  }
}
```

- **Response 200:**
    

json

```
{
  "mbt55FunctionalMapping": {
    "estrogenMetabolismSupport": "number",
    "scfaProductionSupport": "number",
    "antiInflammatorySupport": "number",
    "cofactorProductionSupport": "number"
  }
}
```

### 4.6 Estrobolome × Pain コリレーション

**POST** `/api/v1/pain/estrobolome-correlation`

- **目的:** エストロボローム機能と痛み・炎症の関連スコアを算出。
    
- **Request Body:**
    

json

```
{
  "estrobolomeActivityScore": "number",
  "estrogenRecyclingEfficiency": "number",
  "mitochondrialEstrogenResponseScore": "number",
  "painInflammation": "PainInflammationInput"
}
```

- **Response 200:**
    

json

```
{
  "painCorrelationScore": "number",      // 0-100
  "thumbCmJointRiskScore": "number",     // 0-100
  "inflammationDrivenPainLikelihood": "number" // 0-100
}
```

次のステップとして、このAPI仕様に合わせて **Aの完全JSONスキーマ正式版 v1.0（Hb003スキーマ）** を固定し、その後に frontend の画面構造・フォーム項目・レスポンス表示設計へ進めます。
