# 🧬 **HealthBook‑MI：Metabolic Snapshot Schema v2（正式版）**

## 🎯 **目的（Why）**

Metabolic Snapshot Schema v2 は、 **個体の代謝状態を 1 JSON に完全表現するための標準フォーマット**。

これにより：

- MI‑AcetylCoA Index
    
- Estrobolome Score
    
- MBT55 Compatibility
    
- Neuro‑Endocrine Pattern
    
- Inflammation Load
    
- 137疾病リスク
    
- 漢方・経絡パターン
    
- MBT Probiotics スクリーニング入力
    

すべてのエンジンが **同じ入力** から動く。

# 🧩 **Metabolic Snapshot Schema v2：トップレベル構造**

以下が **HealthBook‑MI の“代謝OSカーネル”** となる構造。

コード

```
MetabolicSnapshotV2
├── profile                # 個体情報
├── lifestyle              # 生活習慣・環境
├── nutrition              # 栄養摂取・ミネラル・脂質
├── gut_microbiome        # 腸内細菌・MBT55・Estrobolome
├── hormones              # ホルモン・内分泌
├── labs                  # 血液検査・代謝指標
├── symptoms              # 症状・痛み・機能低下
├── questionnaire         # 浜田式200問診
├── deviation_codes       # 自動生成された代謝偏位コード
├── disease_risk          # 137疾病リスク
├── engines_input         # 各エンジンへの入力構造
├── mbt_probiotics        # 生薬×MBT55スクリーニング入力
└── summary               # ダッシュボード用の要約
```
