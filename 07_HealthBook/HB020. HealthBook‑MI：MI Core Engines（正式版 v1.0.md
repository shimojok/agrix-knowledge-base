# 🔥 **1. MI‑AcetylCoA Engine（代謝ハブ）**

### 役割

- 糖・脂質・タンパク質・SCFA（腸内）からの **アセチルCoA生成能力を統合スコア化**
    
- 代謝OSの中心指標 **MI‑AcetylCoA Index** を出力
    

### 入力

- 栄養
    
- MBT55（SCFA）
    
- エストロボローム（ホルモン）
    
- ミトコンドリア（ATP）
    
- 生活習慣（冷え・ストレス）
    

### 出力

- `mi_acetylcoa_index`
    
- 基質別スコア（糖・脂質・タンパク・SCFA）
    
- ボトルネック（Mg不足、低SCFA、ホルモン低下など）
    

# 🌸 **2. MI‑Estrobolome Engine（ホルモン代謝）**

### 役割

- 腸内細菌によるエストロゲン代謝（β-グルクロニダーゼ）
    
- ホルモンバランス → ミトコンドリア効率 → ATP
    
- 痛み・炎症・代謝低下の上流原因を推定
    

### 入力

- MBT55（SCFA・胆汁酸）
    
- 栄養（B群・Mg）
    
- 生活習慣（ストレス・睡眠）
    

### 出力

- `estrobolome_score`
    
- `beta_glucuronidase_risk`
    
- `hormone_balance_pattern`
    

# 🦠 **3. MI‑MBT55 Engine（微生物代謝）**

### 役割

- SCFA生成
    
- 胆汁酸変換
    
- 芳香族アミノ酸代謝
    
- 生薬 × MBT55 の代謝相性
    
- 137疾病パスウェイへの作用予測
    

### 入力

- MBT55プロファイル
    
- 生薬（植物・動物）
    
- ファイトケミカル
    
- 食物繊維・発酵食品
    
- PPI/NSAIDs（腸内破壊）
    

### 出力

- `mbt55_activity_score`
    
- `scfa_score`
    
- `bile_acid_score`
    
- `aromatic_aa_score`
    
- 生薬シナジー
    
- 疾病ターゲット
    

# 🔋 **4. MI‑Mitochondria Engine（ATP生成）**

### 役割

- ATP生成能力
    
- 酸化ストレス
    
- 冷え・ストレスの影響
    
- ホルモン（エストロゲン）との連動
    

### 入力

- AcetylCoA Engine
    
- Estrobolome Engine
    
- 栄養（Mg・B群）
    
- 生活習慣（冷え・睡眠）
    

### 出力

- `baseline_atp_score`
    
- `oxidative_stress_load`
    

# 🔥 **5. MI‑Inflammation Engine（炎症・免疫）**

### 役割

### 入力

- MBT55 Engine
    
- Estrobolome Engine
    
- Mitochondria Engine

### 出力

- `inflammation_load`
    
- `immune_pattern`
    
- 感染症リスク（マラリア含む）
