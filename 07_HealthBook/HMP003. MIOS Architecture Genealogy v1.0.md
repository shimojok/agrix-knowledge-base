# 5. 今回の重要な発見

Phase 0-Bで、今後のCanonicalizationにおいて特に注意すべき点が明確になりました。

### ① Architectureが一本ではない

初期のHealthBook-MI、MI-Probiome、MIOS Reference Architecture、8月のMIOS Architecture Specificationなどが存在します。

したがって、

**「最新文書＝全ての過去設計を自動的に無効化」**

とはできません。

---

### ② 「正式固定」と「科学的Canonical」は別

例えば、

```text
Architectureとして正式固定
        ≠
Scientific Evidenceとして検証済み
```

です。

この原則をGenealogyにも明記しました。

---

### ③ ReconciliationそのものがArchitectureの一部になっている

後半では、

**Source → Evidence → Canonical Decision → Data Model → KG → Implementation**

というGovernance architectureが形成されています。

これは今後のMIOSにとって非常に重要です。
