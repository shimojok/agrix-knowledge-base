# 🟦 **HealthBook‑MI Backend API Specification v1.0 — Endpoint Details**

# 1. **POST /api/metabolic/core**

### **目的**

Hb003A Metabolic Core JSON（v1.0）を受け取り、統合代謝スコアを生成する。

## **Request Body（Hb003A JSON v1.0）**

json

```
{
  "user_id": "string",
  "input_layer": {
    "nutrition": { ... },
    "gut_microbiome": { ... },
    "hormones": { ... },
    "medications": { ... },
    "lifestyle": { ... }
  },
  "core_layer": {
    "acetylcoa": { ... },
    "estrobolome": { ... },
    "mitochondria": { ... },
    "inflammation": { ... },
    "musculo_fascial": { ... }
  }
}
```

## **Response Body**

json

```
{
  "user_id": "string",
  "metabolic_age_score": 0,
  "mi_acetylcoa_availability_index": 0,
  "estrobolome_activity_score": 0,
  "mitochondrial_atp_generation_score": 0,
  "global_inflammation_score": 0,
  "pain_burden_score": 0,
  "recommendations": {
    "primary": ["string"],
    "secondary": ["string"]
  }
}
```

## **型定義（TypeScript）**

ts

```
export interface MetabolicCoreResponse {
  user_id: string;
  metabolic_age_score: number;
  mi_acetylcoa_availability_index: number;
  estrobolome_activity_score: number;
  mitochondrial_atp_generation_score: number;
  global_inflammation_score: number;
  pain_burden_score: number;
  recommendations: {
    primary: string[];
    secondary: string[];
  };
}
```

json

```
{
  "user_id": "string",
  "gut_microbiome": {
    "beta_glucuronidase_activity": "low | medium | high",
    "scfa_levels": {
      "acetate": number,
      "propionate": number,
      "butyrate": number
    },
    "diversity_index": number
  },
  "diet": {
    "fiber_grams": number,
    "fermented_foods": number,
    "processed_food_score": number
  },
  "bowel_movement": {
    "frequency": number,
    "form": number
  }
}
```

## **Response Body**

json

```
{
  "estrobolome_activity_score": 0,
  "estrogen_recycling_efficiency": 0,
  "mitochondrial_estrogen_response": 0,
  "pain_sensitivity_correlation": 0
```

ts

```
export interface EstrobolomeResponse {
```
