### ステップ1：Metabolic Snapshot Schema v2 の「骨」

ここではまだ**JSON全文ではなく、“構造とセクション”を確定**します。後でそのまま `schemas/metabolic_snapshot_v2.schema.json` に落とせる形にします。

#### 1. トップレベル構造

- `patient`
    
    - `id` / `age` / `sex` / `bmi` / `menopausal_status` など
        
- `snapshot_meta`
    
    - `timestamp` / `version` / `source`（問診／ウェアラブル／検査など）
        
- `inputs`（ここが v2 の中核）
    
    - `lifestyle`
        
    - `nutrition`
        
    - `medications`
        
    - `symptoms`
        
    - `labs`
        
    - `microbiome_mbt55`
        
    - `hormones`
        
    - `musculo_fascial`
        
    - `infection_immunity`
        
- `computed`（MIエンジンが埋める領域）
    
    - `mi_indices`
        
    - `deviation_codes`
        
    - `risk_scores`
        

#### 2. `inputs` の詳細ブロック

**(1)** `lifestyle`**（生活習慣）**

- `sleep_hours`
    
- `sleep_quality`
    
- `stress_level`
    
- `physical_activity_level`
    
- `cold_exposure`（冷え）
    
- `posture_pattern`（長時間座位／前傾など）
    

**(2)** `nutrition`**（栄養・食事）**

- `carb_intake_pattern`（精製糖／全粒）
    
- `fat_intake_pattern`（ω3／ω6／トランス）
    
- `protein_intake_level`
    
- `fiber_intake_level`
    
- `processed_food_frequency`
    
- `fermented_food_frequency`
    
- `mg_intake_estimate` / `zn_intake_estimate` など
    

**(3)** `medications`**（薬剤・サプリ）**

- `antihypertensives`（利尿薬など Mg 喪失系）
    
- `nsaids_use`
    
- `ppi_use`
    
- `supplements`（Mg／VitD／オメガ3 等）
    

**(4)** `symptoms`**（浜田式200問診と接続）**

- `fatigue_pattern`
    
- `pain_locations`（肩／頸／顎／膝…）
    
- `cold_intolerance`
    
- `sleep_disturbance`
    
- `hormonal_symptoms`（PMS／更年期）
    
- `gi_symptoms`（便通／膨満／ガス）
    
- → ここは **浜田式200問診の質問IDと紐付く** `questionnaire_responses` を持たせる
    

**(5)** `labs`**（検査値）**

- `glucose_fasting` / `hba1c`
    
- `lipid_panel`（LDL/HDL/TG）
    
- `liver_enzymes`
    
- `crp` / `il6`（炎症）
    
- `vitamin_d` / `ferritin` / `mg_serum` など
    

**(6)** `microbiome_mbt55`**（腸内細菌・MBT55・エストロボローム）**

- `scfa_profile`（酢酸／プロピオン酸／酪酸 推定 or 実測）
    
- `bile_acid_profile`
    
- `aromatic_aa_metabolites`
    
- `estrobolome_activity_score`（β-グルクロニダーゼ推定）
    
- `mbt55_presence`（MBT55 投与有無／期間）
    
- `mbt_probiotics_protocol_id`（MBTスクリーニング結果とのリンク）
    

**(7)** `hormones`**（ホルモン）**

- `estradiol` / `progesterone` / `testosterone`（実測 or 推定）
    
- `thyroid_panel`
    
- `cortisol_pattern`
    
- `menstrual_cycle_phase`
    

**(8)** `musculo_fascial`**（筋膜・姿勢）**

- `muscle_tension_map`（部位別スコア）
    
- `tmj_symptoms`（顎関節）
    
- `posture_assessment`
    

**(9)** `infection_immunity`**（感染症・免疫）**

- `infection_history`（マラリア／COVID／その他）
    
- `vaccination_status`
    
- `allergy_history`
    
- `autoimmune_markers`
    

#### 3. `computed` ブロック

ここは **MIエンジンの出力専用領域** として固定します。

- `mi_indices`
    
    - `acetylcoa_index`
        
    - `mitochondria_score`
        
    - `estrobolome_score`
        
    - `inflammation_load`
        
    - `musculo_fascial_load`
        
- `deviation_codes`
    
    - `core_metabolism`（D101–D150）
        
    - `microbiome_gut`（D201–D250）
        
    - `hormone_endocrine`（D301–D350）
        
    - `musculo_fascial`（D401–D450）
        
    - `oriental_medicine`（D501–D550）
        
- `risk_scores`
    
    - `disease_risks_137`（D001–D137 へのマッピング結果）
        

ここまでが **Metabolic Snapshot Schema v2 の「論理構造」** です。

次の一手としては：

- この構造をそのまま `metabolic_snapshot_v2.schema.json` **の完全ファイル** に落とし込む
    
- 並行して、**各** `mi_indices` **がどの** `inputs` **をどう読むか（数式・ロジック）** を定義する
    

ので、次のターンで **スキーマの実ファイル（フルJSON）** を一気に書き切ります。 そのあと、MI‑AcetylCoA Index から順に、エンジンの定義に入っていきましょう。
