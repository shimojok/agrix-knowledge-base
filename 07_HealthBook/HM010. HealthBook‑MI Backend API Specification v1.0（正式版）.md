# 🟦 **2. API エンドポイント一覧（正式版）**

## **2.1 Metabolic Core API（Hb003A JSON を扱う中核）**

### **POST /api/metabolic/core**

**目的:** Hb003A Metabolic Core JSON を受け取り、解析し、スコアを返す **入力:** Hb003A JSON（v1.0） **出力:** 統合スコア（代謝年齢、エストロボローム活性、アセチルCoA指数など）

### **GET /api/metabolic/core/:userId**

**目的:** 最新の Metabolic Core データを返す **出力:** Hb003A JSON（v1.0）

### **POST /api/metabolic/core/compute**

**目的:** 入力レイヤー（食事・腸内細菌・ホルモン・薬剤）から **Estrobolome / AcetylCoA / ATP / Pain / Inflammation** を自動計算 **出力:** Hb003A JSON（v1.0）

## **2.2 Estrobolome‑MI API**

### **POST /api/estrobolome/analyze**

**目的:** β-グルクロニダーゼ活性、腸内細菌多様性、便通、加工食品から **Estrobolome Activity Score** を算出 **出力:**

- estrobolome_activity_score
    
- estrogen_recycling_efficiency_score
    
- mitochondrial_estrogen_response_score
    
- pain_sensitivity_correlation_score
    

## **2.3 AcetylCoA / ATP API**

### **POST /api/acetylcoa/compute**

**目的:** 糖・脂質・タンパク質・短鎖脂肪酸・ミネラルから **MI‑AcetylCoA Availability Index** を算出

### **POST /api/mitochondria/compute**

**目的:** Mg/Mn、エストロゲン、冷え、ストレスから **ATP生成能力スコア** を算出

## **2.4 MBT55 Functional Mapping API**

### **POST /api/mbt55/map**

**目的:** MBT55菌群の機能（β-グルクロニダーゼ、SCFA、抗炎症）を Estrobolome と AcetylCoA にマッピング **出力:**

- mbt55_cluster_map
    
- estimated_impact_on_acetylcoa_score
    
- estimated_impact_on_estrobolome_score
    

## **2.5 Pain / Inflammation API**

### **POST /api/pain/analyze**

**目的:** CM関節症・筋膜負荷・炎症負荷から痛みスコアを算出 **出力:**

- pain_burden_score
    
- cm_joint_pain_score
    
- estrobolome_pain_correlation_index
    

### **POST /api/inflammation/analyze**

**目的:** 加工食品・腸内環境・ストレス・睡眠から炎症負荷を算出 **出力:**

- global_inflammation_score
    
- acetylcoa_inflammation_correlation_index

# 🟦 **8. 重要：既存の Python/JSON コードは修正が必要か？**

### ✔ 結論：

**はい、修正が必要です。**

理由は明確です：

### 1. Hb003A JSON が「新しい代謝OSの中核」になった

→ 既存の disease_matrix, kampo_library, MBT55 mapping を **この新しい構造に合わせて拡張する必要がある**

### 2. Python エンジン（snapshot_builder, medical_pipeline, kampo_engine）

→ Hb003A の

- Estrobolome
    
- AcetylCoA
    
- ATP
    
- MBT55 mapping を計算できるようにアップデートが必要
    

### 3. JSON ライブラリー（生薬・動物性・MBT55）

→ Hb003A の各スコアに対応するフィールドを追加する必要がある
