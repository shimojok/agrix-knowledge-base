### 1. HealthBook‑MI は「個体の代謝OS（Metabolic Operating System）」である

→人間の代謝・ホルモン・腸内細菌・ミトコンドリア・炎症・痛みを統合的に扱う OS**。

### 2. 症状ではなく「代謝の因果構造」を扱う

→痛み・疲労・ホルモン低下・炎症といった“結果”ではなく、  **代謝の上流にある原因（因果構造）を解析する。**

因果構造の例：
- 腸内細菌 → エストロゲン代謝 → ミトコンドリア効率 → ATP生成 → 炎症 → 痛み  
- Mg不足 → ATP生成低下 → 筋緊張 → 関節痛  
- 加工食品 → 腸内細菌破壊 → SCFA低下 → アセチルCoA不足 → 代謝低下  

HealthBook‑MI は、  
**代謝の“詰まり（bottleneck）”を特定するシステム**。

### 3. アセチルCoAを中心にした「代謝ハブモデル」

アセチルCoAは、  **糖・脂質・タンパク質・腸内細菌・ホルモン・ミトコンドリア**  すべてを統合する生命の中心。

HealthBook‑MI は、  **アセチルCoA生成能力（MI‑AcetylCoA Index）**  を代謝の中心指標として扱う。

これにより：

- エネルギー生成  
- ホルモン合成  
- エピジェネティクス  
- 免疫  
- 炎症  
- 痛み  

すべてを一つのモデルで扱える。

### 4. エストロボローム（Estrobolome）を代謝モデルに統合

エストロボロームは、  **腸内細菌がエストロゲン代謝を制御する遺伝子群**。

これは：

- ホルモン生成  
- ミトコンドリア効率  
- ATP生成  
- 免疫  
- 炎症  
- 痛み  

すべてに影響する。

HealthBook‑MI は、  **腸内細菌 → ホルモン → ミトコンドリア → ATP → 痛み**  という因果を扱う唯一のシステムになる。


### 5. MBT55（Microbial‑Metabolic‑Modular Theory 55）を中核にする

MBT55 の 3本柱：

- SCFA（短鎖脂肪酸）  
- Bile Acid（胆汁酸）  
- Aromatic AA（芳香族アミノ酸）  

これらは、  
**神経・免疫・内分泌・代謝の共通言語**。

HealthBook‑MI は、  
**MBT55 → 代謝偏位 → 症状**  
という流れで解析する。
