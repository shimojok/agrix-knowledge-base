# 22. Evidence Level

Evidence Levelは、Repository由来のDataを無理に「臨床Evidence」に格上げしないため、次の5段階とします。

|Level|定義|
|---|---|
|**E0**|Concept / Hypothesis|
|**E1**|Internal Data / Source|
|**E2**|Model / Computational Evidence|
|**E3**|External Published / Observational Evidence|
|**E4**|Experimental / Clinical Validation|

重要なのは、

**E4 > E3 > E2 > E1 > E0**

という単純な「科学的優劣」だけでなく、**Claimの種類に適したEvidenceかどうか**を別途見ることです。
