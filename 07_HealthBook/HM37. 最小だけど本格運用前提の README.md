# HealthBook-MI-Probiome-OS

A metabolic operating system integrating:
- Questionnaire-based metabolic snapshot (Snapshot v2)
- Metabolic engines (Phenotype, Estrobolome, Acetyl-CoA, ATP, Inflammation)
- Disease MI Matrix v2
- Kampo metabolic library
- Probiotics screening (MBT55 × herbal substrates)
- Causal map (MBT55 → Estrobolome → Acetyl-CoA → ATP → Inflammation → Disease)
- PBPE-Marketplace integration (Registry + KPIs)
- Explainability Engine (Clinical + Underwriting)

---

## Project structure

- `backend/` — FastAPI backend (engines, pipelines, AI agents, PBPE integration)
- `frontend/` — Next.js frontend (Dashboard, Medical, Probiotics, User, PBPE HealthBook tab)
- `tests/` — Integration tests (UI ↔ API ↔ Engine)
- `docs/` — Architecture and API documentation
- `docker/` — Dockerfiles and `docker-compose.yml`
- `.github/workflows/` — CI/CD pipeline

---

## Prerequisites

- Docker + Docker Compose
- Node.js (if you run frontend without Docker)
- Python 3.11+ (if you run backend without Docker)

---

## Quick start (recommended: Docker)

From the project root:

```bash
docker-compose up --build
````

This will start:

- FastAPI backend on `http://localhost:8000`
    
- Next.js frontend on `http://localhost:3000`
    

## Core endpoints (backend)

- `POST /snapshot/process` — Build Snapshot v2 from questionnaire + lifestyle + MBT55 + estrobolome + mitochondria
    
- `POST /engine/run` — Run metabolic engines (phenotype, estrobolome, acetyl-CoA, ATP, inflammation)
    
- `POST /causal/run` — Build causal map (MBT55 → Estrobolome → Acetyl-CoA → ATP → Inflammation → Disease)
    
- `POST /disease/risk` — Compute disease risk using Disease MI Matrix v2
    
- `POST /kampo/recommend` — Recommend Kampo formulas based on disease risk
    
- `POST /probiotics/screen` — Screen MBT55 strains × herbal substrates × pathways
    
- `POST /explainability/run` — Generate clinical + underwriting explanations
    
- `POST /pbpe/registry/save` — Save snapshot + engine + causal to PBPE registry
    
- `GET /pbpe/kpis/{user_id}` — Return PBPE KPIs for a user
    

## Frontend routes (Next.js)

- `/ui/dashboard` — HealthBook MI Dashboard
    
- `/ui/medical` — Medical evaluation UI
    
- `/ui/probiotics` — Probiotics screening UI
    
- `/ui/user` — User-facing metabolic health UI
    
- `/pbpe/healthbook` — PBPE-Marketplace HealthBook MI tab
