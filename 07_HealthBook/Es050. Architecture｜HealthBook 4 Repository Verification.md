# 5. 重要な方針

今回の4 Repositoryについては、

**まだ統合しません。**

例えば、

```
Repo A
 └── disease_matrix_137.json

Repo B
 └── disease_matrix_137.json

Repo C
 └── disease_matrix_137.json
```

があった場合、

「同じものだから一つにする」

とはしません。

まず、

```
Version
Schema
Content
Dependency
Implementation
Authority
```

を比較して、**どれをCanonical Sourceとするかを決定**します。

これは後のGitHub Governanceで非常に重要です。
