# Architecture｜正式固定

承認しました。

## HealthBook / MIOS 更年期Metabolic Map

**基本アーキテクチャを正式に固定します。**

```
Food
  │
  │ Nutrients / Phytochemicals
  ▼
Microbiome
  │
  │ Biotransformation
  ▼
Metabolite
  │
  │ Equol / Urolithins / SCFAs / etc.
  ▼
Host Response
  │
  ├── Endocrine
  ├── Immune / Inflammation
  ├── Mitochondria
  ├── Vascular
  ├── Bone
  ├── Muscle / Connective Tissue
  └── Neuro-metabolic
          │
          ▼
      Phenotype / Symptoms
```

## 固定する原則

> **Phytochemicals are not merely antioxidants; they are substrates and precursors of microbiome-derived metabolites that can modulate host signaling.**

### 代表的な代謝軸

|Food|Microbiome|Metabolite|Host Response|
|---|---|---|---|
|大豆|腸内細菌|ダイゼイン → **エクオール**|ERβ / 内分泌・骨・血管・更年期症状|
|ザクロ・ベリー等|腸内細菌|エラグ酸 → **ウロリチン類**|ミトコンドリア・筋代謝等|
|食物繊維|腸内細菌|**SCFA**|腸管・免疫・代謝|
|ポリフェノール|腸内細菌|多様な低分子代謝物|炎症・血管・免疫・代謝|
