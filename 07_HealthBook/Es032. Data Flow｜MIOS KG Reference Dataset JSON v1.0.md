# 7. SCFAの重要な違い

SCFAでは、

```
Microbe A
    ↓
Intermediate
    ↓
Microbe B
    ↓
SCFA
```

という**Cross-feeding**を正式に表現できます。

したがって、

```
MicrobialTaxon
       ↓
MicrobialCommunity
       ↓
Community Functional Capacity
       ↓
SCFA Production
```

を検証するReference Caseとなります。

これはEquolのような比較的特定のbiotransformationだけでは検証できない、**community metabolism**のモデルです。

# 9. Claim Layer

```
{
  "id": "CLAIM-EQUOL-001",
  "entity_type": "Claim",
  "subject_id": "PHY-DAIDZEIN-001",
  "predicate": "SUBSTRATE_FOR",
  "object_id": "FUNC-EQUOL-001",
  "evidence_ids": [
    "EVID-EQUOL-001"
  ],
  "confidence": "high",
  "status": "approved"
}
```

これにより、

```
Graph Edge
    +
Evidence
    +
Confidence
```

を一体管理できます。

```
✓ JSON Schema valid
✓ Entity IDs unique
✓ Relationship domain valid
✓ Relationship range valid
✓ Claim → Evidence traceable
✓ Essential Microbial Function present
✓ Functional Capacity present
✓ Transformation present
✓ Host layer separated
✓ Unknown ≠ False
✓ Association ≠ Causation
✓ Taxon ≠ Function
✓ Capacity ≠ Activity
```
