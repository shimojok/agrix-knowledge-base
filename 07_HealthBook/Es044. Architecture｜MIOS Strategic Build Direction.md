# Governance｜今後の原則

今後は、**「新しい概念を思いつくたびにLayerを増やす」ことを禁止**します。

新しい機能は必ず、

```
既存Architecture
      ↓
既存Layerに配置可能か？
      │
   Yes ─────→ 既存Layerへ統合
      │
     No
      ↓
Architecture Change Request
      ↓
PMO Review
      ↓
必要性を確認
      ↓
承認された場合のみLayer追加
```

とします。

これで設計が発散しません。
