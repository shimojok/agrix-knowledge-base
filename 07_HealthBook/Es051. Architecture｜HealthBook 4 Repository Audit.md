# Audit Rule

4つを単純に「最新版」を選ぶ形にはしません。

```
Repo A ─┐
Repo B ─┼─→ Entity / Schema / Logic比較
Repo C ─┤
Repo D ─┘
              ↓
       Canonical Authority
```

そして各資産を、

**RETAIN / REFACTOR / MERGE / DEPRECATE / BUILD**

に分類します。

特に同じ `200Q` や `137 Disease` が複数Repositoryに存在する場合は、**内容・Version・依存関係・実装ロジックまで確認してCanonical Sourceを決定**します。
