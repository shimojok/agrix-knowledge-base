# 2. Evidence Validation Rule

ここは特に厳格にします。

現在の200Q Mappingは、

> **Source-derived normalization**

です。つまり、MIOS Domain/FunctionはCanonical normalizationとして追加されていますが、まだ臨床的因果関係がValidation済みという意味ではありません。MIOS_200Q_Function_Mapping_v1.0.jsonJSON

したがってA.6では、各Functionを以下に分類します。

|Evidence Status|意味|
|---|---|
|`SOURCE_SUPPORTED`|Sourceに直接記載|
|`NORMALIZED_SUPPORTED`|Source内容をCanonical terminologyへ正規化|
|`LITERATURE_SUPPORTED`|外部科学文献等で支持|
|`MECHANISTIC_HYPOTHESIS`|MIOS仮説として保持|
|`EVIDENCE_PENDING`|根拠不足|
|`REJECTED_UNSUPPORTED`|採用不可|

**重要：HypothesisをEvidenceに昇格させません。**

# 5. Duplicate Decision Tree

```
Duplicate Question
        │
        ▼
Question text identical?
        │
       YES
        │
        ▼
Risk Factor identical?
        │
       YES
        │
        ▼
Metabolic Impact identical?
        │
       YES
        │
        ▼
Related Disease identical?
        │
       YES
        │
        ▼
Canonical Duplicate
```

一方、

```
Question text identical
        ↓
Metabolic Impact different
        ↓
NOT TRUE DUPLICATE
        ↓
Distinct Phenotype Context
```

とします。

これが重要です。

**「文章が同じ」＝「データとして同じ」ではありません。**

# 11. EvidenceとHypothesisを分離

今回、非常に重要なGovernance Ruleを固定します。

```
                         MIOS KG
                            │
             ┌──────────────┴──────────────┐
             ▼                             ▼
        Evidence Graph               Hypothesis Graph
             │                             │
       Validated claims              Research candidates
             │                             │
       Clinical use                  R&D / Experiment
```

例えば、

```
「Q129 → Hormonal Function」
```

と

```
「Q129 → Equol deficiency」
```

は同じ扱いにしません。

後者には追加Evidenceが必要です。
