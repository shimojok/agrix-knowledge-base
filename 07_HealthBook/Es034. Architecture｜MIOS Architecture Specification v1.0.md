# 1. MIOS Definition

## 1.1 System Definition

**MIOS = Metabolic Intelligence Operating System**

MIOSは、人間の健康状態を、

```
Food
 ↓
Phytochemical / Nutrient
 ↓
Microbiome
 ↓
Microbial Function
 ↓
Metabolite
 ↓
Host Signaling
 ↓
Metabolism / Hormone / ATP
 ↓
Phenotype
 ↓
Risk
 ↓
Intervention
```

という**統合代謝モデル**で解釈するKnowledge-Driven Intelligence Platformと定義します。

---

# 2. Core Architecture Principle

MIOSの最上位原則を以下に固定します。

> **Microbiome is not a nutrient.  
> Microbiome is a biological system that extends host metabolic capacity.**

したがって、栄養学の対象を、

```
従来

Nutrients
    ↓
Human Metabolism
```

から、

```
MIOS

Nutrients / Phytochemicals
          ↓
Microbial Functional Layer
          ↓
Microbial Metabolism
          ↓
Metabolites
          ↓
Host Metabolism
          ↓
Host Signaling
```

へ拡張します。
