# 🔷 **トップレベル構造（全体像）**

コード

```
MetabolicSnapshotV2 {
  profile
  snapshot_meta
  inputs {
    lifestyle
    nutrition
    medications
    symptoms
    labs
    microbiome_mbt55
    hormones
    musculo_fascial
    infection_immunity
    questionnaire
  }
  computed {
    mi_indices
    deviation_codes
    disease_risk
  }
  mbt_probiotics
  summary
}
```
