# 3. V02｜Entity Integrity

## ID Integrity

```
Entity ID
   ↓
Unique?
   ↓
YES → PASS

```

禁止：

```
同一ID
↓
異なるEntity

```

entity_type = EssentialMicrobialFunction

```

```

ならReject。

すべてのReference Pathwayに少なくとも1つのMicrobial Functionを定義。

Microbial FunctionとEssential Microbial Functionを同一Entityとして扱わない。

Functional Capacityと実測Activityを同一視しない。
