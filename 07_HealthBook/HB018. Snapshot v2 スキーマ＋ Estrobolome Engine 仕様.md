### 2. Estrobolome Engine v1 設計仕様

#### 2.1 役割

> 腸内細菌・生活習慣・MBT55・栄養から **エストロボローム機能（ホルモン代謝能力）**を推定し、 `estrobolome_score` とリスク・パターンを出力する。

#### 2.2 入力（MetabolicSnapshotV2 から使用するフィールド）

- `nutrition.micronutrients`（特に B群・Mg）
    
- `microbiome_mbt55.scfa_potential`
    
- `microbiome_mbt55.bile_acid_modulation`
    
- `microbiome_mbt55.aromatic_aa_flux`
    
- `microbiome_mbt55.mbt55_pattern`
    
- `lifestyle.sleep_quality`
    
- `lifestyle.stress_load`
    
- `meds.ppi`, `meds.nsaids`（腸内環境悪化要因）
    

#### 2.3 出力仕様

ts

```
type EstrobolomeEngineOutput = {
  estrobolome_score: number,          // 0–100 総合機能スコア
  beta_glucuronidase_risk: number,    // 0–100 再活性化リスク
  hormone_balance_pattern: string,    // "low_estrogen" | "estrogen_dominance" | "balanced" など
  limiting_factors: string[],         // ["low_scfa", "high_stress", "ppi_use", ...]
  mbt55_synergy_score: number         // 0–100（MBT55との協調度）
}
```

#### 2.4 スコアリングロジック（概念）

- **ベース機能スコア（base）**
    
    - SCFAポテンシャル
        
    - Bile acid modulation
        
    - Aromatic AA flux を重み付きで統合。
        
- **制限因子**
    
    - PPI/NSAIDs → 腸内環境悪化
        
    - 高ストレス・低睡眠 → ホルモン軸抑制
        
    - ミネラル・B群不足 → ホルモン合成低下
        
- **beta_glucuronidase_risk**
    
    - `mbt55_pattern` が「高脱糖活性」系＋加工食品・低食物繊維（将来追加）で上昇。
        
- **hormone_balance_pattern**
    
    - estrobolome_score と beta_glucuronidase_risk、 さらに年齢・性別（将来 Snapshot に追加）から判定。
        

この2つ（Snapshot v2 スキーマ＋ Estrobolome Engine 仕様）をベースに、 次は **MBT55 Engine の仕様 → Disease‑MI Matrix v2 への接続**へ進めていけます。
