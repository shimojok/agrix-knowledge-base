# 🧬 **HealthBook‑MI v2 — MI Core Engines v1**

**Metabolic Intelligence OS – Core Computational Engines**

本ドキュメントは、HealthBook‑MI v2 の中心となる **8つの MI Core Engines** の仕様を定義する。  
各エンジンは **Metabolic Snapshot v1** を入力とし、  
**Deviation Codes（D001〜D150）** と **Derived Indices** を出力する。

---

# 0. **全体構造（Overview）**

MI Core Engines は以下の 8 モジュールで構成される：

1. **MI‑AcetylCoA Engine**（代謝ハブ）
2. **MI‑Estrobolome Engine**（腸内ホルモン代謝）
3. **MI‑Mitochondria Engine**（ATP生成）
4. **MI‑MBT55 Engine**（腸内代謝モジュール）
5. **MI‑Inflammation Engine**（炎症負荷）
6. **MI‑Neuro‑Endocrine Engine**（神経・内分泌統合）
7. **MI‑Musculo‑Fascial Engine**（筋膜ライン）
8. **MI‑Oriental Medicine Engine**（漢方・経絡）

これらは **独立した関数モジュール**として実装され、  
HealthBook‑MI の **Inference Layer（因果推論層）** に統合される。

---

# 1. **MI‑AcetylCoA Engine**

**AcetylCoA Availability Estimation Engine**

### ■ 役割

代謝の中心ハブである **アセチルCoA生成能力** を推定する。  
HealthBook‑MI v2 の最重要エンジン。

### ■ 入力（Metabolic Snapshot v1 より）

- 栄養：  
    `protein_grams`, `fat_quality_score`, `omega3_score`, `fiber_grams`
- ミネラル：  
    `magnesium_sources`, `manganese_sources`
- 腸内細菌：  
    `scfa_score`
- 代謝阻害：  
    `processed_food_score`, `antihypertensive_taken`
- ホルモン：  
    `menopausal_stage`
- 代謝環境：  
    `cold_sensitivity_score`, `postprandial_sleepiness_score`

### ■ 内部ロジック（概念）

- 糖・脂質・タンパク質・SCFA → AcetylCoA供給ポテンシャル
- Mg/Mn/B群不足 → TCA回路の制限
- エストロゲン低下 → ミトコンドリア効率低下
- 冷え → 酵素活性低下
- UPF・薬剤 → 代謝阻害

### ■ 出力

- `mi_acetylcoa_index`（0–100）
- Deviation Codes：
    - **D101：AcetylCoA生成低下（軽度）**
    - **D102：AcetylCoA生成低下（中等度〜重度）**

---

# 2. **MI‑Estrobolome Engine**

**Gut‑Hormone Metabolism Engine**

### ■ 役割

腸内細菌による **エストロゲン再活性化（Estrobolome）** の機能を推定。

### ■ 入力

- `fiber_grams`, `fermented_food_servings`
- `processed_food_score`
- `bowel_movement_count`, `stool_form_score`
- `dysbiosis_score`

### ■ 内部ロジック

- 食物繊維・発酵食品 → Estrobolome 活性↑
- UPF・dysbiosis → 活性↓
- 便通・ブリストルスコア → 腸内環境の健全性

### ■ 出力

- `mi_estrobolome_score`（0–100）
- `estrobolome_activity_score`（β-グルクロニダーゼ推定）
- Deviation Codes：
    - **D111：Estrobolome 活性低下**
    - **D112：Estrobolome 過剰活性／不均衡**

---

# 3. **MI‑Mitochondria Engine**

**ATP Production Capacity Engine**

### ■ 役割

ミトコンドリアの **ATP生成能力** を推定。

### ■ 入力

- `magnesium_sources`, `manganese_sources`
- `cold_sensitivity_score`
- `sleep_quality_score`
- `stress_level_score`
- `antihypertensive_taken`
- `fatigue_score`, `brain_fog_score`

### ■ 内部ロジック

- Mg/Mn → 電子伝達系の必須因子
- 冷え → 酵素活性低下
- 睡眠・ストレス → ATP生成効率
- 薬剤（利尿薬） → Mg喪失 → ATP低下

### ■ 出力

- `mi_mitochondria_score`（0–100）
- Deviation Codes：
    - **D121：ミトコンドリア ATP 生成低下**
    - **D122：薬剤性ミトコンドリア負荷**

---

# 4. **MI‑MBT55 Engine**

**Microbial‑Metabolic Modular Engine**

### ■ 役割

MBT55（SCFA / Bile Acid / Aromatic AA）の機能モジュールを推定。

### ■ 入力

- `scfa_score`, `bile_acid_score`, `aromatic_aa_score`
- `fiber_grams`, `fermented_food_servings`
- `processed_food_score`

### ■ 内部ロジック

- SCFA → 抗炎症・AcetylCoA供給
- Bile Acid → 脂質吸収・ホルモン合成
- Aromatic AA → 神経伝達物質前駆体
- UPF → 腸内代謝阻害

### ■ 出力

- MBT55 Pathway Map
- Deviation Codes：
    - **D131：SCFA フラックス低下**
    - **D132：胆汁酸代謝異常**

---

# 5. **MI‑Inflammation Engine**

**Chronic Inflammation Load Engine**

### ■ 役割

「炎症が燃えやすい環境」の総量を推定。

### ■ 入力

- `processed_food_score`
- `stool_form_score`
- `sleep_quality_score`
- `stress_level_score`
- `cold_sensitivity_score`
- `dysbiosis_score`
- `crp`（任意）

### ■ 内部ロジック

- UPF・腸内環境悪化 → 炎症↑
- 睡眠不足・ストレス → 免疫調整低下
- 冷え → 血流低下 → 炎症遷延

### ■ 出力

- `mi_inflammation_load`（0–100）
- Deviation Codes：
    - **D141：慢性炎症負荷高値**

---

# 6. **MI‑Neuro‑Endocrine Engine**

**Neuro‑Hormonal Integration Engine**

### ■ 役割

神経・ホルモン・代謝の統合パターンを解析し、  
既存の **Neuro‑Metabolic Deviation Codes（D001〜D090）** を生成。

### ■ 入力

- `hormone_state.*`
- `symptoms.*`
- `questionnaire.*`
- `mi_acetylcoa_index`
- `mi_mitochondria_score`
- `mi_estrobolome_score`

### ■ 出力

- D001〜D090（既存の神経系偏位コード）

---

# 7. **MI‑Musculo‑Fascial Engine**

**Musculo‑Fascial Load Estimation Engine**

### ■ 役割

筋膜ライン（肩→腕→前腕→手）の負荷を推定し、痛みとの関係を評価。

### ■ 入力

- `shoulder_stiffness_score`
- `forearm_tension_score`
- `hand_palm_tension_score`
- `range_of_motion_limit`
- `thumb_pain_score`
- `morning_stiffness_minutes`

### ■ 出力

- `musculo_fascial_load`
- Deviation Codes：
    - **D151：筋膜ライン過負荷**

---

# 8. **MI‑Oriental Medicine Engine**

**Oriental Pattern Mapping Engine**

### ■ 役割

漢方・経絡のパターンを代謝偏位にマッピングし、Fコードを返す。

### ■ 入力

- `questionnaire.*`
- `symptoms.*`
- `hormone_state.*`
- `gut_status.*`

### ■ 出力

- Fコード候補
- Deviation Codes：
    - **D161：気虚**
    - **D162：瘀血**
    - **D163：痰湿**
    - **D164：気滞**
