# 1️⃣ **FastAPI 本番デプロイ（バックエンド）**

FastAPI は本番では **Gunicorn + Uvicorn Worker + Nginx** が最適構成です。

### 🧩 **本番構成図**

コード

```
Nginx (SSL termination)
    ↓
Gunicorn (process manager)
    ↓
Uvicorn Worker (ASGI)
    ↓
FastAPI (HealthBook-MI-Probiome-OS)
```

### 🧩 **Gunicorn 本番起動コマンド（固定）**

bash

```
gunicorn main:app \
  --workers 4 \
  --worker-class uvicorn.workers.UvicornWorker \
  --bind 0.0.0.0:8000
```

### 🧩 **Nginx の役割**

- SSL（Let's Encrypt）
    
- リバースプロキシ
    
- `/api/*` を FastAPI にルーティング
    
- `/` を Next.js にルーティング
    
- CORS 制御
    
- PBPE Marketplace の既存ルーティングと統合
