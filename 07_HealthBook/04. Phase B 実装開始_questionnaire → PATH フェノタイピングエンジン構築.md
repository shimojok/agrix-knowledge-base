# 4. PATHスコアリングモデル

単純合計は不十分。

---

# 推奨式

PATHScore_i=\sum_{k=1}^{n}(QuestionWeight_{k,i}\times Answer_k)+Modifier_i

---

# Modifier項目

|Modifier|内容|
|---|---|
|microbiome_modifier|腸内細菌|
|age_modifier|年齢|
|circadian_modifier|睡眠|
|inflammation_modifier|CRP等|
|intervention_modifier|MBT介入|
