# Architecture｜MIOS KG Reference Dataset & Validation Suite v1.0

進めます。  
今回の工程では、**MIOS KG JSON Schema v1.0が実際に正しく機能することを検証するためのReference DatasetとValidation Suite**を定義します。

最初のReference Caseは、これまで固定してきた**Equol metabolic pathway**とします。

> 重要：ここでは「エクオールが症状を改善する」といった臨床結論をDatasetに埋め込まず、**代謝経路・機能・Evidenceを分離して検証可能にする**ことを優先します。

# 4. Microbiome Functional Layer

ここをValidation Suiteの**最重要テスト対象**にします。

```
MicrobialTaxon
       │
       │ performs
       ▼
MicrobialFunction
       │
       │ contributes_to
       ▼
EssentialMicrobialFunction
       │
       │ defines
       ▼
FunctionalCapacity
```

### 検証する原則

```
Taxon presence
      ≠
Functional capacity
      ≠
Functional activity
      ≠
Metabolite concentration
      ≠
Clinical outcome
```

この5段階を混同しないことを、Validation Ruleとして固定します。

```
{

  "entity_type": "FunctionalCapacity",
  "name": "Equol production capacity",

  ],
  "community_level": true,
  "activity_status": "unknown",
  "substrate_dependency": true,
  "redundancy_level": "unknown",
  "evidence_ids": [],
  "status": "approved"
}
```

とします。

ここで意図的に、

```
activity_status = unknown
```

を許容します。

つまり、

> 「エクオール産生機能が存在する可能性」

と

> 「この個人が現在エクオールを産生している」

を分離します。

# 6. Essential Microbial Function Test

`EMF-EQUOL-001`について、

```
{
  "id": "EMF-EQUOL-001",
  "entity_type": "EssentialMicrobialFunction",
  "function_id": "FUNC-EQUOL-001",
  "essentiality_class": "context_dependent",
  "host_domains": [
    "endocrine"
  ],
  "dependency_type": "microbiome_dependent",
  "redundancy_level": "unknown",
  "evidence_ids": [],
  "status": "approved"
}
```

とします。

### なぜ `context_dependent` なのか

「エクオール産生が人間にとって必須」という意味ではないためです。

ここでは、

> **Essential Microbial FunctionsというOntology上の枠組みを使いながら、個々の機能のEssentialityについてはEvidenceに基づいて評価する**

というGovernanceを守ります。

# 20. Architecture Freeze

今回、以下を**MIOS KG v1.0のValidation Governanceとして固定**します。

```
                    MIOS
                     │
              Food / Nutrient
                     │
               Phytochemical
                     │
                  Microbiome
                     │
        ┌────────────┴────────────┐
        │                         │
Microbial Taxonomy      Essential Microbial
        │                    Functions
        │                         │
        └──────────┬──────────────┘
                   ▼
          Functional Capacity
                   │
                   ▼
          Microbial Transformation
                   │
                   ▼
               Metabolite
                   │
                   ▼
             Host Signaling
                   │
                   ▼
               Phenotype
                   │
                   ▼
                Evidence
```

### 最重要原則

> **MIOSは「何の菌がいるか」だけを評価するシステムではない。  
> 「そのMicrobiomeが、宿主に対して何を代謝できるのか」を評価するシステムである。**

そして、

> **Essential Microbial Functionsは、その「宿主の代謝能力を補完する微生物機能」を表現する正式なFunctional Layerである。**
