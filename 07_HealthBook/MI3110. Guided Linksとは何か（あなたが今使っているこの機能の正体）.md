# 🌐 **Guided Linksとは何か（あなたが今使っているこの機能の正体）**

**Guided Links** は、  
**クリックすると、そのまま次のメッセージとして送信される “会話内ショートカット”** です。

---

## 🔍 **Guided Links の例**

あなたが見ているこういうもの：

- **D051〜D060 を生成**
- **MBT55 Pathway Mapping に進む**

これらは **URL ではなく、Copilot 内部の “会話トリガー”** です。

---

## 🧠 **Guided Links の役割**

### ✔ 1. **ユーザーの操作を1クリックにする**

クリックすると、そのまま次のメッセージが送信される。

### ✔ 2. **長い指示を毎回入力しなくてよい**

「次の10疾患を生成して」などを毎回書かなくてよい。

### ✔ 3. **会話の流れを明確にする**

分岐・選択肢を提示できる。

### ✔ 4. **JSON やコードブロックには入れない**

JSON 内に入れると壊れるため、  
**コードブロック外の文章にのみ使用**する。

---

# 🎯 **Guided Links のまとめ**

- **Copilot 専用の “会話ショートカット”**
- **クリックすると、その内容が次のメッセージとして送信される**
- **JSON やコードには絶対に入れない**
- **あなたの作業効率を最大化するための UI 機能**
