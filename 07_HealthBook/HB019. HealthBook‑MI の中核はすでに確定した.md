# 🧬 **MBT55 Engine v1 — 設計仕様（HealthBook‑MI Core Engine #2）**

MBT55 Engine は、HealthBook‑MI の中で **Estrobolome Engine と AcetylCoA Engine を支える“微生物代謝エンジン”** です。

# 1. 役割（Role）

> **MBT55 の代謝能力（SCFA・胆汁酸・芳香族AA・3段階カスケード）を** **個体の代謝OSに統合し、** **“腸内代謝 → ホルモン → アセチルCoA → ATP” の因果構造を形成する。**

MBT55 Engine は、以下を推定・計算する：

- SCFA（酢酸・プロピオン酸・酪酸）生成能力
    
- 二次胆汁酸変換能力
    
- 芳香族アミノ酸代謝（トリプトファン → インドール類）
    
- MBT55 ギルド（女汝・竜王・浄土など）の活性
    
- 生薬（植物・動物）との代謝相性
    
- 137疾病パスウェイへの影響度
