# Risk Factor Engine

## Overview

The **Risk Factor Engine** ingests a `Metabolic Snapshot` and infers structured risk factors across lifestyle, microbiome, metabolic, hormone, and sleep domains.

It bridges:

- Questionnaire / lifestyle data  
- Clinical biomarkers  
- Microbiome functional capacity  
- Sleep / stress metrics  

into a unified **risk factor vector** used by downstream MI engines.

---

## Objectives

- **Standardize** risk factor representation across 137+ lifestyle-related diseases.
- **Auto-generate** risk factors from `metabolic_snapshot.schema.json`.
- Provide **inputs** for Threshold, Progression, Pathway, and Intervention engines.

---

## Inputs

- `schemas/metabolic_snapshot.schema.json`
- Optional:
  - Questionnaire responses
  - Device-derived sleep / activity data
  - Lab panels (glucose, lipids, inflammation, hormones)

---

## Outputs

- `risk_factors.json` (per snapshot):

  ```json
  {
    "snapshot_id": "UUID",

      "sleep_short": 0.64,

      }
    }
    ```
    

---

## Core Logic

- Map snapshot fields → canonical risk factor IDs.
- Normalize each factor to `[0, 1]` using governance rules.
- Aggregate multi-source signals (questionnaire + biomarkers + devices).
- Maintain **traceability** back to raw inputs.

## API Sketch
