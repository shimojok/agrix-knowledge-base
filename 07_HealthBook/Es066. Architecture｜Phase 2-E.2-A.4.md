## 2. 今回の重要な変更

Phase 2-E.2-A.3では、

> **どのFunctional Domainに属するか**

を定義しました。

A.4ではさらに一段下げ、

> **そのDomainの中で、何の機能を表しているのか**

を定義します。

つまり、

```
Domain ≠ Function
```

です。

例えば、

```
D08 Mitochondrial & ATP Energy
        │
        ├── ATP Production
        ├── Cellular Energy Availability
        ├── Energy Utilization
        └── Mitochondrial Metabolic Capacity
```

という階層にします。

# 4. Functionの定義原則

MIOS Functionは疾病名ではありません。

### ❌ Disease-first

```
Q071
 ↓
糖尿病
```

### ❌ Symptom-first

```
Q071
 ↓
疲労
```

### ✅ Function-first

```
Q071
 ↓
PHENO-FATIGUE
 ↓
RF-REDUCED-METABOLISM
 ↓
MET-REDUCED-ATP-PRODUCTION
 ↓
D08
 ↓
MIOS-FUNC-ATP-PRODUCTION
```

既存SourceにはQ071について、chronic fatigue、reduced metabolism、Reduced ATP productionという情報が存在します。したがって、ここまではSource-derived mappingとして扱えます。

---

# 5. 重要なEvidence Rule

A.4では、**Sourceに存在しないFunctionを勝手に追加しません。**

例えば、

```
Q071
Reduced ATP production
```

から、

```
NADH dysfunction
Electron transport chain failure
Mitochondrial membrane potential decline
```

などを自動生成しません。

それらを採用するには、別途Evidenceが必要です。

したがってFunctionは、

```
SOURCE_DEFINED
```

と

```
MIOS_CANONICAL_INFERRED
```

を明確に区別します。

---

# 6. Function Classification

各Functionに以下のStatusを付与します。

|Status|意味|
|---|---|
|`SOURCE_DEFINED`|元Datasetに明記|
|`NORMALIZED`|表記揺れをCanonical化|
|`DOMAIN_MAPPED`|MIOS Domainへ接続|
|`FUNCTION_MAPPED`|MIOS Functionへ接続|
|`EVIDENCE_PENDING`|Evidence確認待ち|
|`EVIDENCE_VALIDATED`|Evidence確認済み|
|`CLINICAL_VALIDATED`|Clinical validation済み|

# 8. Primary / Secondary Function

1問につきFunctionを1つだけに固定しません。

```

 │

 │
 └── Supporting Function
```

とします。

```

 │
 ├── Secondary

```

ただし、Sourceに裏付けられない関係は`CANDIDATE`とします。

# 24. 現時点のArchitecture Freeze

今回、次の原則を正式に固定します。

### Rule 1

**200QはPhenotype Sensor Layerである。**

### Rule 2

**MIOS Functional DomainはDisease Categoryではない。**

### Rule 3

**MIOS FunctionはPhenotypeの背後にある機能単位である。**

### Rule 4

**Microbiome FunctionはHuman Functional Requirementの補完Layerとして扱う。**

### Rule 5

**MetaboliteはFunctionとHost Responseを接続する中間Layerである。**

### Rule 6

**200Qから特定菌種・特定代謝物・ホルモン濃度等を根拠なく推定しない。**

### Rule 7

**Legacy PATHは保持し、MIOS Canonical Function ArchitectureへTranslationする。**
