# なぜJSONを先に見るのか

今までの議論では概念Architectureがかなり進んでいます。

```
Food
 ↓
Phytochemical
 ↓
Microbiome Function
 ↓
Metabolite
 ↓
Host Signaling
 ↓
Phenotype
 ↓
Risk
 ↓
Intervention
```

しかし、実際のHealthBookがどこまでこの構造を既に持っているかは、**JSON Schemaを見るのが最も早い**です。

例えば、

```
{
  "question_id": "...",
  "domain": "...",
  "phenotype": "...",
  "metabolic_axis": "...",
  "risk": "..."
}
```

のような構造が既に存在するなら、MIOS側で作り直す必要はありません。

逆に、

```
Question → Disease
```

程度なら、MIOS Canonical ModelへのMigration設計が必要になります。
