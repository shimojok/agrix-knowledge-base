# Backend API specification v1.0（Hb003 Estrobolome‑MI / AcetylCoA‑MI 中心）

まず「A＝Hb003 完全JSONスキーマ」を前提にした Backend API の各エンドポイント仕様を整理します。

## 共通仕様

- **Base URL:** `/api/v1`
    
- **Format:** JSON
    
- **Auth:** Bearer Token（`Authorization: Bearer <token>`）
    
- **Encoding:** UTF‑8
    

## 共通型定義（Core Types）

### UserContext

- **説明:** 個人の基本コンテキスト
    
- **型:**
    

json

```
{
  "userId": "string",
  "sex": "string",              // "male" | "female" | "other"
  "age": "number",              // years
  "heightCm": "number",
  "weightKg": "number"
}
```

### LifestyleInput

- **説明:** 生活習慣・食事・便通など、Estrobolome/代謝に関わる入力
    
- **型:**
    

json

```
{
  "dietPattern": "string",          // e.g. "high_fiber", "high_processed", "balanced"
  "fiberIntakeLevel": "string",     // "low" | "medium" | "high"
  "fermentedFoodFrequency": "string", // "rare" | "sometimes" | "daily"
  "processedFoodScore": "number",   // 0–100 (高いほど加工食品多い)
  "bowelMovementFrequencyPerDay": "number",
  "physicalActivityLevel": "string", // "low" | "medium" | "high"
  "sleepQualityScore": "number"     // 0–100
}
```

### MicrobiomeInput

- **説明:** 腸内細菌・MBT55関連入力
    
- **型:**
    

json

```
{
  "scfaProductionScore": "number",      // 短鎖脂肪酸産生推定 0–100
  "mbt55Composition": [
    {
      "groupId": "string",
      "name": "string",
      "relativeAbundance": "number",    // %
      "betaGlucuronidaseActivity": "string", // "low" | "medium" | "high"
      "antiInflammatoryPotential": "string", // "low" | "medium" | "high"
      "estrogenMetabolismRole": "string"     // "none" | "support" | "core"
    }
  ]
}
```

### HormoneInput

- **説明:** ホルモン・エストロゲン関連
    
- **型:**
    

json

```
{
  "estrogenStatus": "string",          // "unknown" | "normal" | "low" | "high"
  "menstrualStatus": "string",         // "premenopause" | "perimenopause" | "postmenopause" | "none"
  "hormoneTherapy": "boolean",
  "hormoneTherapyType": "string"       // 任意
}
```

### MedicationAndStressInput

- **説明:** 薬剤・ストレス・冷え
    
- **型:**
    

json

```
{
  "antihypertensiveUse": "boolean",
  "magnesiumDepletingDrugs": "boolean",
  "chronicStressLevel": "string",      // "low" | "medium" | "high"
  "coldSensitivity": "string"          // "low" | "medium" | "high"
}
```

## エンドポイント仕様

### 1. Estrobolome‑MI 評価（Hb003）

#### **POST** `/api/v1/mi/estrobolome/evaluate`

- **目的:** エストロボローム活性、エストロゲン再循環効率、ミトコンドリア応答、痛みとの関連を統合評価。
    
- **Request Body:**
    

json

```
{
  "userContext": { /* UserContext */ },
  "lifestyle": { /* LifestyleInput */ },
  "microbiome": { /* MicrobiomeInput */ },
  "hormones": { /* HormoneInput */ },
  "medicationAndStress": { /* MedicationAndStressInput */ }
}
```

- **Response 200:**
    

json

```
{
  "timestamp": "string",                 // ISO8601
  "userId": "string",
  "estrobolomeMi": { /* EstrobolomeMIResult */ }
}
```

### 2. MI‑AcetylCoA Availability Index 評価

#### **POST** `/api/v1/mi/acetyl-coa/evaluate`

- **目的:** アセチルCoA生成能力・ミトコンドリアATP生成能力・代謝ストレスを統合評価。
    
- **Request Body:**
    

json

```
{
  "userContext": { /* UserContext */ },
  "lifestyle": { /* LifestyleInput */ },
  "microbiome": { /* MicrobiomeInput */ },
  "hormones": { /* HormoneInput */ },
  "medicationAndStress": { /* MedicationAndStressInput */ }
}
```

- **Response 200:**
    

json

```
{
  "timestamp": "string",
  "userId": "string",
  "acetylCoaMi": { /* AcetylCoAMIResult */ }
}
```

### 3. MBT55 機能マッピング（Estrobolome 拡張モデル）

#### **POST** `/api/v1/mi/mbt55/mapping`

- **目的:** MBT55 の菌群を、エストロゲン代謝・短鎖脂肪酸・抗炎症・補酵素生成にマッピング。
    
- **Request Body:**
    

json

```
{
  "userContext": { /* UserContext */ },
  "microbiome": { /* MicrobiomeInput */ }
}
```

- **Response 200:**
    

json

```
{
  "timestamp": "string",
  "userId": "string",
  "mbt55Mapping": { /* MBT55FunctionalMappingResult */ }
}
```

### 4. 統合 Metabolic OS 評価（Estrobolome × AcetylCoA × Pain）

#### **POST** `/api/v1/mi/metabolic-os/summary`

- **目的:** Estrobolome‑MI、AcetylCoA‑MI、MBT55マッピングを統合し、痛み・炎症・代謝年齢を要約。
    
- **Request Body:**
    

json

```
{
  "userContext": { /* UserContext */ },
  "lifestyle": { /* LifestyleInput */ },
  "microbiome": { /* MicrobiomeInput */ },
  "hormones": { /* HormoneInput */ },
  "medicationAndStress": { /* MedicationAndStressInput */ },
  "painProfile": {
    "thumbCmJointPainScore": "number",   // 0–10
    "otherChronicPainScore": "number"    // 0–10
  }
}
```

- **Response 200:**
    

json

```
{
  "timestamp": "string",
  "userId": "string",
  "estrobolomeMi": { /* EstrobolomeMIResult */ },
  "acetylCoaMi": { /* AcetylCoAMIResult */ },
  "mbt55Mapping": { /* MBT55FunctionalMappingResult */ },
  "summary": {
    "metabolicAge": "number",           // 推定代謝年齢
    "inflammationLevel": "number",      // 0–100
    "painMetabolicCorrelationScore": "number", // 0–100
    "keyInsights": [
      "string"                          // e.g. "Estrogen recycling is impaired and SCFA supply is low."
    ]
  }
}
```

### 5. テンプレート取得（フロントエンド用）

#### **GET** `/api/v1/mi/templates/estrobolome`

- **目的:** フロントエンドが入力フォームを構築するための Hb003 スキーマテンプレート取得。
    
- **Response 200:**
    

json

```
{
  "schemaVersion": "string",           // "1.0.0"
  "inputSchema": { /* Hb003 JSON Schema A */ }
}
```

次のステップとして、

- Hb003「A 完全JSONスキーマ正式版 v1.0」をこの API 型定義に完全一致させる
