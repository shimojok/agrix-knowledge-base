### Backend 実装構成（ファイル構造）

text

```
backend/
  src/
    models/
      Hb003.ts              // 上記JSONに対応する TypeScript interface 群
    services/
      EstrobolomeService.ts // /mi/estrobolome/evaluate ロジック
      AcetylCoAService.ts   // /mi/acetyl-coa/evaluate ロジック
      MBT55Service.ts       // /mi/mbt55/mapping ロジック
      MetabolicOSService.ts // /mi/metabolic-os/summary 統合ロジック
    controllers/
      EstrobolomeController.ts
      AcetylCoAController.ts
      MBT55Controller.ts
      MetabolicOSController.ts
    routes/
      miRoutes.ts           // /api/v1/mi/* のルーティング定義
    index.ts                // Express/Fastify 等のエントリ
```

各コントローラは以下の形で Hb003 を扱うイメージです（概念レベル）:

ts

```
// controllers/EstrobolomeController.ts
export const evaluateEstrobolome = async (req, res) => {
  const hb003: Hb003 = req.body;
  const result = estrobolomeService.evaluate(hb003);
  res.json({ timestamp: new Date().toISOString(), userId: hb003.userContext.userId, estrobolomeMi: result });
};
```
