# 6. Equol Metabotype

MIOSでは、

```
Equol Producer
Equol Non-Producer
```

を単純なtaxonomy classifierにしません。

```
Dietary Exposure
       +
Microbial Functional Capacity
       +
Microbial Activity
       +
Measured Metabolite
       ↓
Equol Metabotype
```

とします。

現在の研究でもequol producer statusは、soy/isoflavone challenge後の尿・血中equolなどによって operationally 定義されることが多く、研究間で基準が完全には統一されていません。したがってMIOSでは**producer status = inference result**として管理します。[MDPI](https://www.mdpi.com/2072-6643/18/14/2396?utm_source=chatgpt.com)
