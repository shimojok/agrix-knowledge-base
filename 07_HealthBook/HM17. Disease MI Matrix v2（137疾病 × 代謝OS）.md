### 1. Disease MI Matrix v2（137疾病 × 代謝OS）

#### フォルダ構成

text

```
data/
  disease/
    disease_mi_matrix_v2.json
    index/
      by_system.json      # 循環器系・内分泌系など
      by_risk_level.json  # low / medium / high
      by_pathway.json     # PATH_01〜PATH_05
```

#### `disease_mi_matrix_v2.json` の基本構造

json

```
{
  "version": "2.0",

```

### 2. Kampo Metabolic Library 分割

#### フォルダ構成

text

```
data/
  kampo/
    kampo_metabolic_library/
      formulas/
        K001.json
        K002.json
        ...
      herbs/
        H001.json
        H002.json
        ...
      index/
        formulas_index.json
        herbs_index.json
```

#### `formulas/K001.json` の例

json

```
{
  "id": "K001",
  "name": "Kakkonto",
  "category": "cold/flu",
  "metabolic_profile": {
    "acetylcoa_support": 0.3,
    "estrobolome_support": 0.2,
    "mbt55_support": 0.4,
    "inflammation_modulation": 0.5
  },
  "herbs": ["H001", "H005", "H010"]
}
```

#### `herbs/H001.json` の例

json

```
{
  "id": "H001",
  "name": "Puerariae Radix",
  "metabolic_actions": {
    "scfa_production": 0.4,
    "bile_acid_modulation": 0.3,
    "beta_glucuronidase_inhibition": 0.2
  }
}
```

### 3. これをどうエンジン側で使うか

- **DiseaseMatrixEngine**
    
    - `disease_mi_matrix_v2.json` を読み込み
        
    - `disease_risk_causal` と `phenotype_score` を使ってリスクマッチング
        
- **KampoEngine**
    
    - `formulas/` と `herbs/` を読み込み
        
    - 疾病ID → 推奨方剤 → 代謝プロファイルを返す
        

### 4. 次の具体ステップ

1. `data/disease/disease_mi_matrix_v2.json` をこの構造で作る
    
2. `data/kampo/kampo_metabolic_library/` を分割フォルダで作る
    
3. それに合わせて `KampoEngine` と `DiseaseMatrixEngine` を少し拡張する
    

ここまで終われば、「代謝OS × 疾病 × 漢方」がデータ層からきれいに繋がります。
