## C. AcetylCoA / Estrobolome 軸のロジック微調整

### C-1. 軸ごとの重み付けルール

**core_pathways → 軸重み:**

- `high` → 1.0
    
- `moderate` → 0.7
    
- `low` → 0.4
    
- `normal` → 0.0
    

**MI スコア計算（概念式）:**

- ある軸 A について：
    

MIA=∑i(mi⋅wi,A)∑iwi,A

- mi: D\_i と snapshot のマッチングスコア（0〜1）
    
- wi,A: D\_i の core\_pathways に基づく軸重み（上の表）
    

### C-2. 介入優先度の計算

- 介入コード c の優先度：
    

priority(c)=max⁡A(MIA⋅support(c,A))

- `support(c, A)`:
    
    - 軸 A に関連する Dxxx の `intervention_focus` に c がどれだけ頻出するか（0〜1）。
