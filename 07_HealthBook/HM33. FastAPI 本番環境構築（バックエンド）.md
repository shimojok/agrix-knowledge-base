### **本番構成（最適解）**

コード

```
Nginx (SSL termination)
    ↓
Gunicorn (process manager)
    ↓
Uvicorn Worker (ASGI)
    ↓
FastAPI (HealthBook-MI-Probiome-OS)
```

### **本番起動コマンド（PMOレベルで固定）**

コード

```
gunicorn main:app \
  --workers 4 \
  --worker-class uvicorn.workers.UvicornWorker \
  --bind 0.0.0.0:8000
```

- SSL（Let's Encrypt）
    
- リバースプロキシ

- CORS 制御
