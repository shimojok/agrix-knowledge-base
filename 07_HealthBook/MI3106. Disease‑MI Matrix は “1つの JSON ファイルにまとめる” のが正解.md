# ❌ **バラバラの JSON ファイルを置く構成は推奨されない**

もちろん技術的には：

```
disease_mi_matrix_001_010.json
disease_mi_matrix_011_020.json
...
```

のように分割しても動くが、以下の問題が出る：

- 読み込み時に **複数ファイルをマージする処理が必要**
- GitHub の diff が散らばる
- API 仕様が複雑になる
- 将来の自動生成パイプラインが面倒になる

**HealthBook‑MI の設計思想は「単一の巨大 JSON 配列」**です。

# 🛠 **実装手順（最も安全な方法）**

1. `disease_mi_matrix.json` を作る
2. 最初の行に `[` を書く
3. 各疾病 JSON を貼る
4. 各オブジェクトの間に **カンマ** を入れる
5. 最後の行に `]` を書く
6. JSONLint で検証
7. GitHub に push
