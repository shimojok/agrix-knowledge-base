# 1. System Architecture v0.1

MIOS HealthBookを**8層Architecture**として固定します。

|Layer|名称|役割|
|---|---|---|
|L1|Assessment Layer|200問|
|L2|Phenotype Layer|症状・身体機能・生活情報|
|L3|Biological Context Layer|栄養・ホルモン・エネルギー|
|L4|Microbiome Functional Layer|Essential Microbial Functions|
|L5|Metabolic Layer|metabolite / pathway|
|L6|Signaling Layer|host signaling|
|L7|Risk & Intervention Layer|137疾病・漢方|
|L8|Knowledge / Evidence Layer|MIOS KG|

---

# 2. L1｜Assessment Layer

既存の**200問問診**を入口として維持します。

```
200Q
 ↓
Question ID
 ↓
Answer
 ↓
Normalized Answer
 ↓
Phenotype Feature
```

### 原則

200問を直接Disease判定へ接続しません。

```
200Q
 ↓
Phenotype
 ↓
Biological Interpretation
 ↓
Risk
```

とします。

例：

```
肩こり
 ↓

疲労
 ↓
PHENOTYPE:FATIGUE

睡眠問題
 ↓
PHENOTYPE:SLEEP_DISTURBANCE
```

さらに、

```
Severity
Frequency
Duration
Context
```

を属性として持たせます。

---

# 4. L3｜Biological Context Layer

ここに新しい解析領域を統合します。

```
Biological Context
│
├── Nutrition
│
├── Hormone
│
├── Mineral
│
├── Energy / ATP
│
└── Lifestyle / Exposure
```

これにより従来の「症状→疾病」という構造から、

```
Phenotype
   ↓
Biological Context
   ↓
Metabolic Interpretation
```

へ移行します。

---

# 5. L4｜Microbiome Functional Layer

ここは今回のMIOSで**正式なCore Layer**です。

### 固定原則

> **Microbiomeは栄養素ではなく、宿主の代謝能力を拡張する生物学的システムである。**

したがって、

```
Microbial Taxonomy
        ↓
Microbial Function
        ↓
Functional Capacity
        ↓
Functional Activity
        ↓
Metabolite
```

を分離します。

---

# 6. Essential Microbial Functions

MIOSでは「必須腸内細菌」という名称よりも、正式なOntologyとして、

**Essential Microbial Functions**

を使用します。

理由は、

```
特定菌種が必須
```

ではなく、

```
特定の代謝機能が宿主に必要
```

という考え方だからです。

例えば、

```
Daidzein Transformation Function
        ↓
Equol Production Capacity
```

です。

---

# 7. L5｜Metabolic Layer

MIOSの中心です。

```
Food
 ↓
Phytochemical / Nutrient
 ↓
Microbial Transformation
 ↓
Metabolite
```

Reference Pathway：

```
RP001 Equol
RP002 Urolithin A
RP003 SCFA
```

を正式採用します。

---

# 8. L6｜Host Signaling Layer

Metaboliteから宿主側へ接続します。

```
Metabolite
 ↓
Receptor / Signaling
 ↓
Cellular Response
 ↓
Tissue Response
 ↓
Phenotype
```

例えばEquolでは、

```
Daidzein
 ↓
Microbial Transformation
 ↓
S-equol
 ↓
Estrogen-related Signaling
 ↓
Host Response
```

という形です。

**「Equolを摂れば症状が改善する」という直接因果モデルにはしません。**

---

# 9. Hormone Architecture

更年期・女性代謝については、

```
Hormone Context
      │
      ├── Estrogen
      ├── Estrogen Signaling
      └── Menopausal Context
              │
              ▼
       Phytochemical
              │
              ▼
          Microbiome
              │
              ▼
          Metabolite
              │
              ▼
        Host Signaling
```

としてMIOS KGと接続します。

重要なのは、

**Hormone → Microbiome**

だけでなく、

**Microbiome → Metabolite → Host Signaling**

という双方向的な生物学的Contextを保持できることです。

# 10. Energy / ATP Architecture

```

```

したがって、

```

≠

```

を明確にします。

MIOSでは**Energy Phenotype**として扱います。

# 25. Governance Rules

### Rule 01

**200Qは診断器ではなくAssessment Layer。**

### Rule 02

**Microbiome TaxonomyとMicrobial Functionを分離。**

### Rule 03

**Function CapacityとActual Activityを分離。**

### Rule 04

**AssociationとCausationを分離。**

### Rule 05

**Metabolite生成とHost Responseを分離。**

### Rule 06

**RiskとDiagnosisを分離。**

### Rule 07

**Kampo CandidateとMedical Prescriptionを分離。**

### Rule 08

**すべての重要なKnowledge ClaimはEvidenceへTrace可能にする。**
