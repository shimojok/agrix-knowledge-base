## 1. Hms022〜024 のPromptはどこに貼るか

はい、基本的には、

> 各担当スレッドの冒頭に、そのスレッド専用の Custom Prompt を貼る

という運用で問題ありません。

ただし重要なのは、**Promptとスレッドの責務を1対1で対応させること**です。

現在確定しているAgent Promptは、

|Prompt|Agent|主目的|
|---|---|---|
|Hms022|`[01] Reconstruction Agent`|既存資料の再構築|
|Hms023|`[02] Architecture Genealogy Agent`|Architectureの系譜・変遷|
|Hms024|`[03] Evidence & Reconciliation Agent`|Evidence・矛盾・重複・Statusの統合|

です。

したがって、

**Hms022 → Reconstruction担当スレッド**  
**Hms023 → Architecture Genealogy担当スレッド**  
**Hms024 → Evidence & Reconciliation担当スレッド**

に貼ります。

# 3. 「System Architecture」に何を貼るべきか

### 結論

現在の **[01] System Architecture** に貼るべきなのは、Hms023をそのまま貼る、ではありません。

理由は、Hms023は、

> **Architecture Genealogy Agent**

だからです。

現在の[01]は、

> **System Architecture / Architecture Genealogy / Canonical Architecture**

まで担当しています。

したがって、このスレッドには今後、

### `System Architecture Agent — Custom Prompt Specification v1.0`

を**別途作成する必要があります。**

ただし、ここで重要なのは、**新しいAgent体系を再設計する必要はありません。**

既に確定している：

```text
HealthBook-MIOS
│
├── 01 System Architecture
├── 02 MBT Kampo Library
├── 03 MBT Probiotics
├── 04 Evidence & Reconciliation
├── 05 Data / Schema
└── 06 Implementation
```

をそのまま維持し、

```text
Agent Governance Contract
        │
        ├── System Architecture Agent
        ├── Reconstruction Agent
        ├── Architecture Genealogy Agent
        ├── Evidence & Reconciliation Agent
        ├── Data / Schema Agent
        └── Implementation Agent
```

という**役割の対応関係**を作ります。

# 4. 特に重要な点

今回の混乱は、

**「Agent番号」と「Thread番号」を同一視してしまったこと**

が原因です。

これは今後、明確に分離しましょう。

### Thread ID

```text
HMS-T01  System Architecture
HMS-T02  MBT Kampo Library
HMS-T03  MBT Probiotics
HMS-T04  Evidence & Reconciliation
HMS-T05  Data / Schema
HMS-T06  Implementation
```

### Agent Role

```text
BNX-HBMIOS-00  PMO / Chief Architect
BNX-HBMIOS-01  Reconstruction
BNX-HBMIOS-02  Architecture Genealogy
BNX-HBMIOS-03  Evidence & Reconciliation
BNX-HBMIOS-04  Data / Schema
BNX-HBMIOS-05  Implementation
```

この2つは**別レイヤー**として扱います。

これなら、例えば、

```text
HMS-T01 System Architecture
        │
        ├── System Architecture責務
        └── Architecture Genealogy責務
                ↑
                └── BNX-HBMIOS-02
```

とできます。

# 6. 第一スレッドで次に行う作業

ご指定どおり、**第一スレッド＝[01] System Architecture**で作業を進めるのが適切です。

そこで次に実施するのは、

## `Hms025. System Architecture Agent — Custom Prompt Specification v1.0`

です。

このPromptでは、[01]の本来の責務である、

```text
MIOS System Boundary
        ↓
System Architecture
        ↓
Architecture Layers
        ↓
Architecture Genealogyとの接続
        ↓
Canonical Architecture
        ↓
Interface / Dependency
        ↓
Agent / Data / Evidence Flow
        ↓
Decision Gate
        ↓
Implementation Handoff
```

を定義します。

そして **Hms023 Architecture Genealogy Agent** との責務境界を明確化します。

### 責務境界

```text
[01] System Architecture
        │
        │ 「現在どういうArchitectureなのか」
        ↓
Current / Target Architecture

[02] Architecture Genealogy Agent
        │
        │ 「なぜ・いつ・何から変化したのか」
        ↓
Architecture History / Transition / Supersession

[03] Evidence & Reconciliation
        │
        │ 「各主張・資料・決定をどう整合させるか」
        ↓
Reconciliation / Evidence Status
```

この分離により、以前問題になった**Architecture GenealogyとCanonical Architectureの混線**を防げます。
