# Governance Rule｜ここからの原則

### Rule 1

**Source ≠ Canonical**

### Rule 2

**Memory ≠ Source of Truth**

### Rule 3

**旧設計を自動的に新設計へ昇格させない**

### Rule 4

**EvidenceとHypothesisを分離する**

### Rule 5

**Microbiomeは栄養素ではなく、宿主代謝能力を拡張するFunctional Layerとして扱う**

### Rule 6

基本代謝経路を、

```text
Food
 ↓
Microbiome
 ↓
Metabolite
 ↓
Host Response
```

および

```text
Phytochemical
 ↓
Microbiome
 ↓
Metabolite
 ↓
Host Signaling
```

として保持する。

### Rule 7

さらに、

```text
Metabolite
 ↓
Endocrine / Hormone
 ↓
Mitochondria / ATP
 ↓
Cellular Response
 ↓
Phenotype
```

をMIOSのHost Response側へ統合する。
