## 全体アーキテクチャ（Hb003〜005を統合したMI-OS）

|レイヤ|役割|主な要素|
|---|---|---|
|Core Metabolism|代謝OSの中核|AcetylCoA, TCA, ミトコンドリア|
|Microbiome‑MI|腸内細菌・MBT55|Estrobolome, SCFA, 炎症制御|
|Hormone‑MI|ホルモン代謝|エストロゲン、ステロイド合成|
|Symptom‑MI|痛み・炎症・疲労|母指CM関節症などの症状モデル|

この上に「APIレイヤ」として Hb003〜005 を載せます。

## 1. リソース設計（JSONスキーマの方向性）

### 1-1. ユーザー代謝プロファイル `MetabolicProfile`

- **ID:** `profile_id: string`
    
- **ユーザー:** `user_id: string`
    
- **入力群:**
    
    - `nutrition`: 糖質・脂質・タンパク質・ミネラル摂取
        
    - `microbiome`: 腸内環境（推定SCFA産生、MBT55関連スコア）
        
    - `hormone`: エストロゲン関連指標（年齢・性別・症状から推定）
        
    - `medication`: 薬剤（血圧降下剤など）
        
    - `lifestyle`: 冷え・ストレス・睡眠
        
- **中核指標:**
    
    - `mi_acetylcoa_index: number`
        
    - `mitochondria_atp_capacity: number`
        
    - `estrobolome_activity_score: number`
        
- **出力群:**
    
    - `inflammation_level: number`
        
    - `pain_sensitivity_index: number`
        
    - `metabolic_age: number`
        

### 1-2. Estrobolome‑MI モジュール `EstrobolomeModule`

- **ID:** `estro_id: string`
    
- **リンク:** `profile_id: string`
    
- **指標:**
    
    - `beta_glucuronidase_activity_score: number`
        
    - `estrogen_recycling_efficiency: number`
        
    - `mitochondrial_estrogen_response: number`
        
- **MBT55マッピング:**
    
    - `mbt55_clusters: Array<{ name: string, role: "estrogen_metabolism" | "scfa" | "anti_inflammatory" | "cofactor_generation", weight: number }>`
        
- **痛み関連:**
    
    - `estrobolome_pain_correlation_index: number`
        

### 1-3. AcetylCoA‑MI モジュール `AcetylCoAModule`

- **ID:** `acetyl_id: string`
    
- **リンク:** `profile_id: string`
    
- **入力寄与:**
    
    - `from_glucose: number`
        
    - `from_fatty_acids: number`
        
    - `from_amino_acids: number`
        
    - `from_scfa_microbiome: number`
        
- **阻害因子:**
    
    - `processing_food_block_score: number`
        
    - `mineral_deficiency_score: number`
        
    - `drug_induced_magnesium_loss_score: number`
        
- **総合指標:**
    
    - `acetylcoa_availability_index: number`
        

## 2. API仕様（第一版）

### 2-1. プロファイル生成

**POST** `/api/mi/profile`

- **Body:**
    
    - `user_id`
        
    - 栄養・生活習慣・薬剤・簡易腸内環境アンケート
        
- **処理:**
    
    - MI‑AcetylCoA Index 算出
        
    - Estrobolome Activity Score 算出
        
    - 出力指標（炎症・痛み・代謝年齢）を生成
        
- **Response:**
    
    - `MetabolicProfile` JSON（上記スキーマ）
        

### 2-2. Estrobolome‑MI 詳細取得

**GET** `/api/mi/estrobolome/{profile_id}`

- **Response:**
    
    - `EstrobolomeModule` JSON
        

### 2-3. AcetylCoA‑MI 詳細取得

**GET** `/api/mi/acetylcoa/{profile_id}`

- **Response:**
    
    - `AcetylCoAModule` JSON
        

### 2-4. 痛み・炎症レポート

**GET** `/api/mi/report/pain-inflammation/{profile_id}`

- **Response:**
    
    - `{ profile_id, pain_sensitivity_index, inflammation_level, estrobolome_pain_correlation_index, explanatory_text: string }`
        

## 3. これまでのPython/JSONコードとの関係

結論から言うと：

- **はい、これまでのPython/JSONコードは「修正・拡張」することになります。**
    
    - Hb003〜005で定義する新しいスキーマ（上記のような構造）に合わせて、
        
    - 既存の計算ロジック（スコア算出）を「MI‑AcetylCoA」「Estrobolome‑MI」へ再マッピングする形になります。
        
- ただし、
    
    - 既存コードは「捨てる」のではなく、
        
    - **ロジックの断片（栄養スコア、炎症スコアなど）を新しいOS構造の中に再配置する**イメージです。
