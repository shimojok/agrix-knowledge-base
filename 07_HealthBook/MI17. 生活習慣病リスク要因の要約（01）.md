### ３つのリスク要因レイヤーの関係

|レイヤー|主な内容|位置づけ|
|---|---|---|
|生活習慣病リスク|食事・運動・睡眠・ストレス・環境など|一次ドライバー（行動・環境）|
|代謝異常リスク|インスリン抵抗性・ミトコンドリア・炎症|中核病態（metabolic engine）|
|腸内細菌リスク|Dysbiosis・SCFA・バリア・TMAOなど|代謝ネットワークの「外部臓器」|

---

### 1. 生活習慣病リスク要因の要約（01）

**コア構造**

> 「生活環境 → 食事・運動・睡眠・ストレス → 腸内細菌叢変化 → 慢性炎症 / 酸化ストレス → 代謝異常 → インスリン抵抗性 → 生活習慣病」

**主なリスク階層**

- **行動リスク（Layer 1）**  
    **食事・運動・睡眠・ストレス・嗜好品**が一次ドライバー。  
    例：超加工食品・高GI・食物繊維不足・座位時間増加・睡眠不足・慢性ストレス・喫煙など。
    
- **生物学的リスク（Layer 2）**  
    **腸内細菌異常・慢性炎症・酸化ストレス・インスリン抵抗性**が共通病態。
    
- **環境・社会構造リスク（Layer 3–4）**  
    PM2.5・農薬・土壌劣化・貧困・教育格差・食品アクセスなどが上流に存在。
    

**HealthBook実装イメージ**

- `schemas/lifestyle.schema.json`
- `engines/risk_score_engine/`
- `data/lifestyle_risk/`  
    → 行動・環境リスクを「modifiable risk」としてスコア化。

---

### 2. 代謝異常リスク要因の要約（02）

**コアコンセプト**

> 「エネルギー過剰 + 代謝柔軟性低下 + 慢性炎症 + 腸内細菌異常 ↓ 代謝恒常性崩壊」

**主なレイヤー**

- **栄養・食事リスク（Layer 1）**  
    高糖質・UPF・脂質異常食・微量栄養素不足 → 血糖変動・脂肪蓄積・酵素活性低下。
    
- **腸内細菌リスク（Layer 2）**  
    酪酸菌減少・多様性低下・LPS菌増加 → 「腸管バリア低下 → LPS流入 → 慢性炎症 → インスリン抵抗性」。
    
- **ミトコンドリア・炎症・ホルモン（Layer 3–5）**  
    ATP低下・ROS・Meta-inflammation・インスリン/レプチン/コルチゾール異常。
    
- **睡眠・活動・環境・加齢（Layer 6–9）**  
    概日リズム破綻・運動不足・環境毒性・NAD+低下などが代謝柔軟性をさらに低下。
    

**HealthBook実装イメージ**

- `metabolic_engine/`（insulin_resistance / mitochondrial / inflammation / microbiome / circadian）
- `schemas/metabolic.schema.json`
- `scoring/homa_ir_score.py`, `metabolic_age.py`  
    → 「代謝異常」を生活習慣病の中核ノードとして扱う。

### 3. 腸内細菌（Gut Microbiome）リスク要因の要約（03）

**本質定義**

> 「腸内細菌 = 代謝制御器官 + 免疫調節器官 + 神経内分泌器官」

**主要機能（Layer 1）**

- **SCFA生成（酪酸・酢酸・プロピオン酸）**  
    「食物繊維 → 腸内発酵 → SCFA生成 → 炎症抑制 + 腸管修復 + 代謝改善」
- **腸管バリア維持**（Tight Junction・粘液層・病原菌排除）  
    破綻すると「Leaky Gut → LPS流入 → 慢性炎症 → インスリン抵抗性」。
- **免疫調節・Gut-Brain Axis**  
    Treg誘導・IgA調整・GABA/セロトニン前駆体生成 → うつ・ASD・認知症とも接続。

**Dysbiosisと疾患接続（Layer 2–3）**

- 多様性低下・酪酸菌減少・LPS菌増加・真菌増殖。
- 代謝疾患（糖尿病・肥満・NAFLD）、心血管（TMAO）、癌、神経疾患と接続。

**HealthBook実装イメージ**

- `microbiome/`（taxa_database / metabolite_engine / dysbiosis_scoring / gut_brain_axis）
- `schemas/microbiome.schema.json`, `scfa.schema.json`
- `dashboards/gut_health_score/`  
    → 腸内細菌を「外部代謝臓器」として、代謝エンジンと直結させる。

### 4. 05–07の「本質」もGitHubに埋め込みたいポイント

これが、ただの「リスク一覧」から **HealthBookらしさ** に変わる部分だと思います。

**共通の再定義**

- 「疾患 = 代謝産物ネットワーク異常」
- 「健康 = 代謝機能が安定稼働している状態」
- 「問題の本質 = 代謝産物の絶対量不足ではなく、代謝経路ネットワークの偏り」

**そこから出てくる３つのエンジン**

1. **Functional Metabolism Engine（07）**
    
    - `functional_metabolism/pathway_activity/`, `flux_capacity/`, `cross_feeding/`, `redundancy/`, `resilience/`
    - KPI：Pathway Activity Score, Functional Redundancy, Metabolic Resilience など。
2. **Metabolic Flux / Pathway Bias Engine（06）**
    
    - `flux_engine/acetate_flux/`, `butyrate_flux/`, `amino_acid_flux/`
    - `pathway_balance/pathway_bias/`, `resilience_index/`
    - KPI：Acetate/Butyrate Ratio, Protein Fermentation Index, Flux Diversity Index。
3. **Microbiome → Protein/Hormone → Phenotype Engine（05）**
    
    - `metabolic_network/microbial_metabolism/`, `amino_acid_pathways/`, `neuroendocrine/`
    - `phenotype_engine/sleep_disruption/`, `inflammation_resultant/`, `hormonal_state/`

### 5. HealthBook-AI リポジトリへの具体的な活かし方（最初の一手）

**最初にやると良さそうな３つ：**

1. **共通スキーマの中核に「代謝ネットワーク」を置く**
    
    - `disease` を「診断名」ではなく  
        **`metabolic_state` + `microbiome_state` + `pattern_type`** で表現する。
2. **リスク因子を「Fluxに効くレバー」として整理する**
    
    - lifestyle / metabolic / microbiome の各リスクを  
        「どの Pathway Activity / Flux / Redundancy に効くか」でマッピングする。
3. **Pattern Engine と直結させる**
    
    - `phenotype_engine/metabolic_type/` などのパターンスコアを  
        `functional_metabolism/` と `flux_engine/` の出力から計算する設計にする。
