# ❗ **重要ポイント（JSON結合のルール）**

### ① **各オブジェクトの間にカンマが必要**

```json
{ ... },
{ ... },
{ ... }
```

### ② **最後のオブジェクトの後ろにはカンマを置かない**

```json
{ ... }   ← 最後はカンマなし
```

### ③ **全体を [ ] で囲む**

これが **配列（Array）** の構造。

### ④ **ファイル名は例えば：**

```
disease_mi_matrix.json
```
