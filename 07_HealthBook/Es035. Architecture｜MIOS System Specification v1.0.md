# 1. System Definition

### System Name

**MIOS — Metabolic Intelligence Operating System**

### System Objective

```
200問問診
   ↓
Phenotype
   ↓
Human Metabolism
   ↕
Microbiome Functional Layer
   ↓
Metabolite
   ↓
Host Signaling
   ↓
Hormone / ATP / Cellular Response
   ↓
137 Disease Risk
   ↓
Kampo / Nutrition / Lifestyle
   ↓
Personalized Intervention
   ↓
Outcome Monitoring
```

MIOSは「疾病診断システム」ではなく、

> **個人のPhenotype・Human Metabolism・Microbial Functional Capacity・Metabolites・Host Signalingを統合し、Evidenceに基づくRisk StratificationとIntervention Intelligenceを提供するシステム**

として定義します。
