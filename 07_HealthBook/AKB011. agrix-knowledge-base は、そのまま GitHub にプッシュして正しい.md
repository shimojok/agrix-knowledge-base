# 🟦 プッシュ後に行うこと（PMOとしての指示）

## ✔ ① Repomixでパッキング

GitHub にプッシュした後、ローカルで以下を実行：

コード

```
npx repomix --remote https://github.com/あなた/agrix-knowledge-base --output agrix_kb.xml
```

## ✔ ② XML → txt に変換

コード

```
agrix_kb.xml → agrix_kb.txt
```

## ✔ ③ NotebookLM に txt を読み込ませる

→ NotebookLM が AGRIX Knowledge Base を理解する

## ✔ ④ ローカルRAG の /txt に入れる

コード

```
/txt/agrix_kb.txt
```
