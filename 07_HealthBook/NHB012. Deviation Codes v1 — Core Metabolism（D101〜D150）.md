# 🧬 **D1xx：Core Metabolism Deviation Codes（代謝系）**

---

# **D101 — AcetylCoA 生成能力低下（Mild）**

**カテゴリ:** AcetylCoA Engine  
**概要:**  
アセチルCoA供給が軽度に低下している状態。  
代謝の“初期疲労”段階。

**判定条件（例）:**

- `mi_acetylcoa_index` 60–75
- 軽度の Mg/Mn 不足
- 軽度の SCFA 不足

**臨床的意味:**

- 疲労が抜けにくい
- 組織修復が遅い
- ホルモン合成がやや低下

---

# **D102 — AcetylCoA 生成能力低下（Moderate–Severe）**

**カテゴリ:** AcetylCoA Engine  
**概要:**  
アセチルCoA供給が中等度〜重度に低下。  
代謝の“根本的な詰まり”。

**判定条件:**

- `mi_acetylcoa_index` < 60
- Mg/Mn/B群不足
- SCFA 低値
- UPF 高値

**臨床的意味:**

- 慢性疲労
- 痛みの遷延
- ホルモン低下
- 炎症の持続

---

# **D111 — Estrobolome 活性低下**

**カテゴリ:** Estrobolome Engine  
**概要:**  
腸内細菌によるエストロゲン再活性化が低下。

**判定条件:**

- `mi_estrobolome_score` < 70
- 食物繊維不足
- 発酵食品不足
- dysbiosis 高値

**臨床的意味:**

- エストロゲン不足
- ミトコンドリア効率低下
- 痛覚過敏
- 更年期症状の悪化

---

# **D112 — Estrobolome 過剰活性／不均衡**

**カテゴリ:** Estrobolome Engine  
**概要:**  
β-グルクロニダーゼ活性が過剰、または偏在。

**判定条件:**

- `estrobolome_activity_score` 高値
- dysbiosis 高値

**臨床的意味:**

- エストロゲン過剰
- 子宮内膜症・腫瘍リスク背景
- ホルモンバランスの不均衡

---

# **D121 — ミトコンドリア ATP 生成低下**

**カテゴリ:** Mitochondria Engine  
**概要:**  
ATP生成能力が低下している状態。

**判定条件:**

- `mi_mitochondria_score` < 70
- 冷え・睡眠不足・ストレス
- Mg/Mn 不足

**臨床的意味:**

- 疲労
- ブレインフォグ
- 筋力低下
- 代謝の“燃焼効率”低下

---

# **D122 — 薬剤性ミトコンドリア負荷**

**カテゴリ:** Mitochondria Engine  
**概要:**  
薬剤（特に利尿薬系）による Mg 喪失 → ATP生成阻害。

**判定条件:**

- `antihypertensive_taken = true`
- ＋ Mg不足

**臨床的意味:**

- 薬剤性疲労
- 冷え
- 筋肉痛
- 代謝低下

---

# **D131 — SCFA フラックス低下**

**カテゴリ:** MBT55 Engine  
**概要:**  
短鎖脂肪酸（酢酸・酪酸）生成が低下。

**判定条件:**

- `scfa_score` 低値
- 食物繊維不足
- 発酵食品不足

**臨床的意味:**

- 抗炎症力低下
- 免疫調整不全
- AcetylCoA供給低下

---

# **D132 — 胆汁酸代謝異常**

**カテゴリ:** MBT55 Engine  
**概要:**  
胆汁酸の生成・循環・腸内代謝が異常。

**判定条件:**

- `bile_acid_score` 異常（高 or 低）

**臨床的意味:**

- 脂質吸収不良
- 脂溶性ビタミン不足
- ホルモン合成低下

---

# **D133 — Aromatic AA 代謝異常**

**カテゴリ:** MBT55 Engine  
**概要:**  
芳香族アミノ酸（トリプトファン等）の代謝異常。

**判定条件:**

- `aromatic_aa_score` 異常
- dysbiosis 高値

**臨床的意味:**

- セロトニン低下
- 睡眠障害
- 気分変動

---

# **D141 — 慢性炎症負荷高値**

**カテゴリ:** Inflammation Engine  
**概要:**  
炎症が燃えやすい環境が持続。

**判定条件:**

- `mi_inflammation_load` > 70
- UPF 高値
- 睡眠不足
- 腸内環境悪化

**臨床的意味:**

- 痛み
- 動脈硬化
- 自己免疫
- 神経変性

---

# **D142 — 低体温性炎症遷延**

**カテゴリ:** Inflammation Engine  
**概要:**  
冷えによる血流低下 → 炎症が治らない。

**判定条件:**

- `cold_sensitivity_score` 高値
- ＋ `mi_inflammation_load` 中等度以上

**臨床的意味:**

- 関節痛
- 筋膜痛
- 組織修復遅延

---

# **D150 — 代謝総合低下（Metabolic Downshift）**

**カテゴリ:** Core Metabolism（総合）  
**概要:**  
AcetylCoA・Mito・Estrobolome・MBT55 の複合低下。

**判定条件:**

- `mi_acetylcoa_index` < 60
- `mi_mitochondria_score` < 60
- `mi_estrobolome_score` < 70
- `mi_inflammation_load` > 60  
    （上記のうち 3つ以上）

**臨床的意味:**

- 代謝の“総合的な落ち込み”
- 痛み・疲労・ホルモン低下・炎症の複合状態
- 生活習慣病の前段階
