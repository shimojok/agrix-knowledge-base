## 1. 全体像：HealthBook‑MI プラットフォーム構造

**3レイヤー × 3ドメイン**で整理すると、迷いが減ります。

- **レイヤー軸**
    
    - **L1: Interface 層** … Next.js App Router フロントエンド
        
    - **L2: Intelligence 層** … MI Core Engines（代謝・ホルモン・MBT55・Estrobolome・AcetylCoA）
        
    - **L3: Data & Knowledge 層** … JSONスキーマ、ライブラリ、Disease‑MI Matrix、MBTライブラリ
        
- **ドメイン軸**
    
    - **D1: 個体代謝OS（HealthBook‑MI 本体）**
        
    - **D2: MBT Probiotics & 動物生薬スクリーニング**
        
    - **D3: 公衆衛生・ゲイツ財団向けインパクトモデル（マラリア等）**

## 3. バックエンド & MI Core Engines 構成

**モノリポ内の「エンジン層」を明確に分離**します。

```

  /services
    /phenotyping/          # 浜田式200問診 → Deviation Codes 生成
    /risk-scoring/         # 137疾病リスクスコア計算
    /mbt-screening/        # MBT × 生薬 × Disease-MI Matrix 照合
    /malaria-simulation/   # 地龍×鹿茸×青蒿 × MBT55 カスケード
  /api
    # Next.js の route handlers から呼ばれる層
```

### 3.1 MI Core Engines の役割

- **Metabolic Engine**
    
    - TCA回路、AcetylCoAフラックス、ミトコンドリア機能
        
- **Neuro-Endocrine Engine**
    
    - ホルモン（エストロゲン、コルチゾール等）＋神経パターン
        
- **Microbiome‑MBT55 Engine**
    
    - MBT55群、SCFA、Bile Acid、Aromatic AA
        
- **Estrobolome Engine**
    
    - 腸内エストロゲン代謝、β-グルクロニダーゼ、ホルモン再循環
        
- **AcetylCoA Engine**
    
    - MI‑AcetylCoA Index 算出（糖・脂質・タンパク・腸内由来）
        
- **Inflammation Engine**
    
    - TNF‑α, IL‑6, CRP, サイトカインストームリスク
        
- **Oriental Medicine Engine**
    
    - 経絡・方剤・証 → 代謝偏位コードへのマッピング

## 5. AIエージェント & フェノタイピング

ここは「どう使わせるか」の層。

### 5.1 AIエージェントの役割

- **Phenotyping Agent**
    
    - 浜田式200問診＋検査値から「代謝偏位プロファイル」を生成
        
- **Causal Inference Agent**
    
    - Estrobolome × AcetylCoA × MBT55 × ホルモンの因果グラフ推論
        
- **Formulation Agent（MBT Probiotics）**
    
    - 137疾病リスク × MBT55 × 植物/動物生薬 → 最適発酵レシピ提案
        
- **Global Health Agent（Gates向け）**
    
    - マラリア・感染症・栄養状態 × MBT55 × 発酵プロトコル → 介入シナリオ生成
        

### 5.2 フェノタイピング手法

- **入力:** 浜田式200問診＋血液検査＋腸内細菌＋ホルモン＋生活習慣
    
- **中間表現:** Deviation Codes v1（D101〜D550）＋ MI Snapshot Vector
    
- **出力:**
    
    - MI‑AcetylCoA Index
        
    - Estrobolome Activity Score
        
    - MBT55 Compatibility Score
        
    - Disease‑MI Risk Profile（137疾病）
