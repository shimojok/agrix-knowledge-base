````markdown
# Neuroendocrine Engine  
### HealthBook‑MI / BioNexus Holdings

The Neuroendocrine Engine models **hormone generation capacity**,  
based on metabolism, microbiome, mitochondrial function, inflammation,  
nutrient availability, and circadian state.

This engine implements the principle:

> **Hormones are not causes.  
> They are metabolic output signals.**

---

## Objectives

- Infer **hormone generation capacity**, not just hormone levels.
- Connect **microbiome → metabolites → gene expression → protein synthesis → hormones**.
- Detect **hormone generation failure modes**:
  - precursor deficiency  
  - mitochondrial ATP shortage  
  - dysbiosis  
  - inflammation  
  - micronutrient deficiency  
  - circadian disruption  
- Provide inputs to:
  - Pattern Engine (Type E: Neuroendocrine / Stress)
  - Sleep Engine
  - Intervention Engine (tryptophan flux, melatonin rhythm, GLP‑1 response)

---

## Inputs

- `Metabolic Snapshot` (v1.1+)
- Microbiome functional capacity:
  - SCFA capacity
  - Tryptophan flux capacity
  - Bile acid conversion
- Metabolic markers:
  - ATP proxy (VO2max, lactate)
  - Inflammation (CRP, IL‑6)
  - Redox markers (MDA, 8‑OHdG)
- Nutrient status:
  - B6, Mg, Zn, Fe (if available)
- Circadian context:
  - sleep timing
  - light exposure (optional)

---
````


## Core Logic

### 1. Peptide/Protein Hormones

(Insulin, GLP‑1, Leptin, GH)

Depends on:

- amino acids
- ATP
- Mg/Zn
- inflammation
- mitochondrial function

### 2. Amino Acid–Derived Hormones

(Serotonin, Melatonin, Dopamine)

Depends on:

- tryptophan flux
- microbiome metabolism
- B6, Mg, Fe
- inflammation (kynurenine shift)
- circadian state

### 3. Steroid Hormones

(Cortisol, Estrogen, Testosterone)

Depends on:

- cholesterol
- mitochondrial pregnenolone pathway
- vitamin C, B5, Mg
- inflammation
