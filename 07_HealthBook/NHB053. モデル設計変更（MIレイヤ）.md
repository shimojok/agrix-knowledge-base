### 目的と前提

- **目的:**
    - エストロボローム（Estrobolome）とアセチルCoA（AcetylCoA）を、HealthBook の **MI エンジンの一次軸**として正式導入する。
    - 既存の **Disease‑MI Matrix v2（Dxxx）** と **HealthBook MI 推論ロジック**を破綻させずに拡張する。
- **前提:**
    - `core_pathways` に `estrobolome` / `acetylcoa` がすでに導入されている。
    - `MI-Estrobolome`, `MI-AcetylCoA` というエンジン名を標準化して使う。

---

### 1. モデル設計変更（MIレイヤ）

**1-1. MI エンジンセットの再定義**

- **Core MI Engines:**
    - **MI-AcetylCoA:** エネルギー代謝・脂質代謝・胆汁・高脂肪食応答の中核。
    - **MI-Estrobolome:** 腸内細菌×エストロゲン代謝・SCFA・発酵パターン。
    - **MI-MBT55 / MI-Mitochondria / MI-Inflammation / MI-Neuro-Endocrine** は既存通り。
- **役割分担:**
    - **AcetylCoA 軸:**
        - 高脂肪食、胆汁異常、脂肪便、脂質異常、エネルギー低下（疲労）を束ねるメタ軸。
    - **Estrobolome 軸:**
        - SCFA 低下、発酵異常、便色・ガス・臭い・粘液など「腸内発酵シグネチャ」を束ねるメタ軸。

**1-2. MI スコア構造**

- 各ユーザーに対して：
    - (\text{MI_AcetylCoA} \in [0, 1])
    - (\text{MI_Estrobolome} \in [0, 1])
- 他 MI（MBT55, Mitochondria, Inflammation, Neuro-Endocrine）と同一スケールで扱う。

---

### 2. Disease‑MI Matrix v2 への反映

**2-1. `core_pathways` の意味づけ固定**

- `core_pathways.acetylcoa`:
    - **high:** 高脂肪食・胆汁異常・脂肪便・脂質異常・エネルギー過負荷／枯渇が中心因子。
    - **low:** エネルギー不足・胆汁分泌低下・便秘傾向。
- `core_pathways.estrobolome`:
    - **low:** SCFA 低下・発酵異常・dysbiosis・便色/臭/ガス/粘液の異常。
    - **high:** （将来拡張）エストロゲン再循環過剰など。

**2-2. `related_mi_engines` のルール**

- **原則:**
    - `core_pathways.acetylcoa != "normal"` → `MI-AcetylCoA` を `related_mi_engines` に含める。
    - `core_pathways.estrobolome != "normal"` → `MI-Estrobolome` を含める。
- 既存 Dxxx のうち、このルールから外れているものがあれば **一括修正**（スクリプトで検出）。

---

### 3. HealthBook MI 推論ロジックの変更

**3-1. スナップショット → MI スコア計算**

- 入力：
    - **Disease‑MI Matrix v2**（Dxxx）
    - ユーザーの **snapshot_markers**（nutrition, gut_status, hormone_state, microbiome, musculo_fascial, symptoms）
- 手順（概略）：
    1. **マッチング:**
        - ユーザーのマーカーと Dxxx の `snapshot_markers` の一致度を計算（0〜1）。
    2. **Dxxx 重み:**
        - 一致度 × `core_pathways` の強度（high > moderate > low > normal）で Dxxx の寄与重みを算出。
    3. **MI 軸ごとの集約:**
        - `core_pathways.acetylcoa` の重みを集約 → **MI-AcetylCoA スコア**
        - `core_pathways.estrobolome` の重みを集約 → **MI-Estrobolome スコア**
        - 他 MI 軸も同様に集約。
    4. 正規化して 0〜1 にマッピング。

**3-2. 介入提案ロジック**

- **MI-AcetylCoA 高値:**
    - Diet: `low_fat`, `anti_inflammatory_diet`
    - Lifestyle: `movement`, `hydration`
    - Kampo: `F203` 系を優先候補。
- **MI-Estrobolome 高値（≒異常）:**
    - Diet: `fiber`, `fermented_food`, `low_sugar`, `low_fodmap`
    - Lifestyle: `stress_management`
    - Kampo: `F203` をベースに、将来 SCFA/発酵特化処方を追加。

### 4. HealthBook UI / API 設計変更

**4-1. MI ダッシュボード**

- 新しい MI 軸を明示：
    - **「エネルギー・脂質代謝（AcetylCoA）」**
    - **「腸内エストロボローム（Estrobolome）」**
- 各軸ごとに：
    - **スコアバー**（0〜1）
    - **主なトリガー Dxxx**（例: D222, D231, D232…）
    - **推奨介入（食事・生活・漢方）** を 3〜5 個に集約表示。

### 5. マイグレーションと検証計画

**5-1. マイグレーション手順**

1. **Schema Freeze:**
    - 現行 `disease_mi_matrix_v2.json` をタグ付け（v2.0）。
2. **Consistency Check:**
    - `core_pathways.acetylcoa/estrobolome` と `related_mi_engines` の不整合をスクリプトで検出・修正。
3. **MI Engine 実装更新:**
    - 新しい集約ロジック（3-1）を実装し、旧ロジックと並行で A/B 比較。
4. **Backtest:**
    - 既存テストユーザーのスナップショットで、
        - 旧 MI スコア vs 新 MI スコア
        - 介入提案の一貫性・説明可能性を確認。
5. **リリース:**
    - v2.1 として MI エンジンを切り替え。
    - UI に AcetylCoA / Estrobolome 軸を追加。

**5-2. 検証観点**

- **一貫性:**
    - 胆汁・脂肪便系 Dxxx が **AcetylCoA 高値**に反映されているか。
    - SCFA 低下・発酵異常・便色/臭/ガス系 Dxxx が **Estrobolome 高値**に反映されているか。
- **解釈性:**
    - 「なぜこの介入が出ているか」を Dxxx レベルでトレース可能か。
