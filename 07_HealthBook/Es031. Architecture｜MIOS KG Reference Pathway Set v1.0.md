# Architecture｜MIOS KG Reference Pathway Set v1.0

**正式確定します。**

MIOS Knowledge Graph v1.0のReference Pathwayとして、以下の3経路を**Canonical Reference Pathway Set v1.0**に固定します。

```
MIOS KG Reference Pathway Set v1.0
│
├── RP-001｜Equol Pathway
│
├── RP-002｜Urolithin A Pathway
│
└── RP-003｜SCFA Pathway
```

この3経路によって、MIOSの核心である

> **Food → Microbiome → Metabolite → Host Signaling**

を異なる代謝パターンで検証できます。

---

# 1. RP-001｜Equol Pathway

### Purpose

**Phytochemical → Microbial Biotransformation → Endocrine Signaling**

```
Soy
 ↓
Isoflavone
 ↓
Daidzein
 ↓
Microbial Functional Capacity
 ↓
Daidzein Biotransformation
 ↓
S-Equol
 ↓
Estrogen Receptor Signaling
 ↓
Host Response
 ↓
Menopause-related Phenotype
```

### MIOSで検証する機能

```
Food
  ↓
Phytochemical
  ↓
Essential Microbial Function
  ↓
Functional Capacity
  ↓
Metabolite
  ↓
Endocrine
```

### Primary Domain

**Endocrine / Menopause / Phytochemical Metabolism**

---

# 2. RP-002｜Urolithin A Pathway

### Purpose

**Polyphenol → Microbial Conversion → Mitochondrial-related Host Signaling**

```
Ellagitannin / Ellagic Acid
 ↓
Gut Microbiome
 ↓
Microbial Transformation
 ↓
Urolithin Precursors
 ↓
Urolithin A
 ↓
Host Signaling
 ↓
Mitochondrial / Cellular Response
 ↓
Phenotype
```

ここでは特に、

```
Ellagitannin
      ↓
Microbial conversion capacity
      ↓

```

という**個人差のあるMicrobial Functional Capacity**を検証対象とします。

### Primary Domain

**Polyphenol / Microbiome / Mitochondrial Biology**

---

# 3. RP-003｜SCFA Pathway

SCFAはEquol/Urolithin Aとは異なるタイプのReference Pathwayとして採用します。

### Purpose

**Dietary substrate → Community metabolism → SCFA → Host metabolic/signaling response**

```
Dietary Fiber
 ↓
Microbial Community
 ↓
Fermentation
 ↓
SCFA
 ├── Acetate
 ├── Propionate
 └── Butyrate
       ↓
Host Targets / Signaling
       ↓
Metabolic / Immune / Intestinal Response
       ↓
Phenotype
```

### 特に重要なConcept

SCFAでは、

```
Single Microbe
     ↓
     ×
Community Metabolism
     ↓
Cross-feeding
     ↓
SCFA Production
```

という**Community Functional Architecture**を検証できます。

### Primary Domain

**Fiber / Microbial Ecology / Metabolic Signaling**

---

# 4. 3経路の比較

|Reference|Input|Microbial Function|Metabolite|主Host Domain|
|---|---|---|---|---|
|**Equol**|Daidzein|Specific biotransformation|S-Equol|Endocrine|
|**Urolithin A**|Ellagitannins|Polyphenol transformation|Urolithin A|Mitochondrial / Cellular|
|**SCFA**|Dietary fiber|Community fermentation|Acetate / Propionate / Butyrate|Metabolic / Immune / Intestinal|

この組み合わせは非常に重要です。

# 5. 3種類のMicrobiome Function Model

```
                    Microbiome Functional Layer
                              │
             ┌────────────────┼────────────────┐
             │                │                │
             ▼                ▼                ▼
          Equol          Urolithin A          SCFA
             │                │                │
        Specific/         Community /      Community
        pathway            pathway          metabolism
        transformation     transformation   fermentation
             │                │                │
             ▼                ▼                ▼
        Endocrine         Mitochondrial     Metabolic/
        signaling         signaling        Immune signaling
```

つまり3経路によって、

**「特定代謝産物を作る能力」**

と

**「Communityとして代謝機能を発現する能力」**

の両方を検証できます。

# 6. Essential Microbial Functionsとの接続

3経路すべてに正式に接続します。

```
Microbial Function
        ↓
Essential Microbial Function
        ↓
Functional Capacity
        ↓
Metabolic Output
```

ただし、各経路でEssentialityの評価はEvidence依存です。

```
Equol
→ Context-dependent Functional Capacity

Urolithin A
→ Context-dependent Functional Capacity

SCFA
→ Context-dependent / potentially broader
   community metabolic function
```

**「Essential」という名称から自動的に“必須”と判定しない**ことを固定します。

# 9. MIOS Reasoning Engineへの意味

この3経路は単なるサンプルではありません。

将来のReasoning Engineでは、

```
Patient / User
      ↓
Dietary Exposure
      ↓
Available Substrate
      ↓
Microbial Functional Capacity
      ↓
Predicted / Observed Activity
      ↓
Metabolite
      ↓
Host Signaling
      ↓
Phenotype
```

という推論テンプレートを使用します。

例えば、

```
Daidzein
   ↓
Equol capacity?
```

だけでなく、

```
Ellagitannin
   ↓
Urolithin capacity?
```

さらに、

```
Fiber
   ↓
SCFA functional capacity?
```

まで同一Engineで扱えます。
