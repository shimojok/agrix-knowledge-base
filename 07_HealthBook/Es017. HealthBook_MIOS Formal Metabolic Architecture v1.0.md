- **Polyphenols → Microbial Metabolites → Vascular / Immune / Cellular Signaling**

## Governance Rule

今後、HealthBook/MIOSでは、

> **Phytochemical = Antioxidant**

という単純モデルを正式に廃し、

> **Phytochemical = Substrate / Precursor → Microbial Biotransformation → Bioactive Metabolite → Host Signaling**

を基本モデルとします。

また、各経路には**Evidence Level**を付与し、機序研究・関連研究・臨床エビデンス・介入エビデンスを混同しない構造にします。
