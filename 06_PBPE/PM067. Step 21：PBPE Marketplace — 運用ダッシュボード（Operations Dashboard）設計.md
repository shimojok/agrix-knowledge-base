# 🌍 **Step 21：PBPE Marketplace — 運用ダッシュボード（Operations Dashboard）設計**

運用ダッシュボードは、次の 6 つの領域で構成される。

- **システム稼働状況（Status）**
- **API 使用量・負荷監視**
- **PBPE Issuance の推移**
- **企業利用状況（Scope 3 → PBPE）**
- **PBPE Finance（Credits/Bonds/Insurance）の稼働状況**
- **アラート & 通知システム**

これらは **あなた専用の “運営者向けダッシュボード”** であり、  
一般ユーザーには公開しない内部ツール。

---

# 1️⃣ システム稼働状況（Status）

運用ダッシュボードのトップに表示する項目：

- **Frontend（Vercel）稼働状況**  
- **Backend（Railway）稼働状況**  
- **Database（PostgreSQL）接続状況**  
- **API 応答速度（ms）**  
- **エラー率（%）**  
- **過去24時間の稼働率（%）**

これにより、PBPE Marketplace が **正常に動いているか一目で分かる**。

---

# 2️⃣ API 使用量・負荷監視

以下の API の使用量をリアルタイムで可視化：

- `/credits/price`  
- `/bonds/pricing`  
- `/insurance/premium`  
- `/scope3/convert`  
- `/pbpe/issuance`  
- `/dashboard/global`  

表示する指標：

- リクエスト数（1分 / 1時間 / 1日）  
- 平均応答時間  
- エラー率  
- トップユーザー（企業）  
- トップ API（最も使われている機能）

これにより、**どの機能が最も使われているか**が分かる。

---

# 3️⃣ PBPE Issuance の推移

PBPE Marketplace の根幹データである **PBPE 発行量**を追跡：

- 年度別 PBPE 発行量  
- カテゴリ別（Carbon / Soil / Water / Health）  
- 国別 / 地域別  
- AGRIX / HealthBook / MBT55 の貢献度  
- PBPE Value Flywheel の成長指標  

これにより、**PBPE の成長が可視化される**。

---

# 4️⃣ 企業利用状況（Scope 3 → PBPE）

企業向けの利用状況を追跡：

- Scope 3 データ提出企業数  
- PBPE Conversion 実行回数  
- PBPE 変換量（tCO₂e → PBPE）  
- 企業別の PBPE ポートフォリオ  
- 改善効果（AGRIX / HealthBook / MBT55）

これにより、**企業導入の進捗が分かる**。

---

# 5️⃣ PBPE Finance（Credits/Bonds/Insurance）の稼働状況

金融モジュールの利用状況：

- PBPE Credits の取引量  
- PBPE Bonds の発行量  
- PBPE Insurance の契約数  
- 価格モデルの安定性  
- 市場流動性（Liquidity）  
- 価格変動（Volatility）

これにより、**PBPE 経済圏の健全性が分かる**。

---

# 6️⃣ アラート & 通知システム

以下の条件でアラートを発生：

- API エラー率 > 5%  
- 応答速度 > 500ms  
- PBPE Issuance が異常値  
- Credits Market の急変動  
- Scope 3 Conversion の失敗  
- DB 接続エラー  

通知先：

- あなた（Kaz）  
- BioNexus 運用チーム  
- 必要なら政府・企業向けの自動通知も可能
