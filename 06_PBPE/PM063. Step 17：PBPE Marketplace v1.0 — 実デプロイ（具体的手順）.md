# 🟦 1. フロントエンド（Dashboard v3）を Vercel にデプロイ

### ✔ 必要なもの  
- GitHub アカウント（あなたは既に持っている）  
- PBPE Marketplace の frontend リポジトリ（既にある）

---

## 🔵 **手順（実際の操作）**

### **① Vercel にアクセスして GitHub でログイン**
[https://vercel.com](https://vercel.com)

→ 「Continue with GitHub」をクリック  
→ GitHub 認証を許可

---

### **② “Add New Project” をクリック**

Vercel があなたの GitHub リポジトリ一覧を読み込む。

---

### **③ PBPE Marketplace の frontend リポジトリを選択**

例：  
`bionexus-holdings/pbpe-marketplace-frontend`

---

### **④ 設定は触らず、そのまま “Deploy” をクリック**

Vercel が自動で：

- React / Vite を検出  
- ビルド  
- デプロイ  
- https URL を発行  

すべて自動で完了する。

---

### **⑤ 公開 URL が発行される**

例：  
```
https://pbpe-marketplace-frontend.vercel.app
```

これが **Dashboard v3 の公開 URL**。

# 🟣 2. バックエンド（PBPE API）を Railway にデプロイ

### ✔ 必要なもの  
- GitHub アカウント  
- PBPE Marketplace の backend リポジトリ  

---

## 🟣 **手順（実際の操作）**

### **① Railway にアクセスして GitHub でログイン**
[https://railway.app](https://railway.app)

---

### **② “New Project” → “Deploy from GitHub Repo”**

Railway が GitHub リポジトリ一覧を読み込む。

---

### **③ PBPE Marketplace の backend リポジトリを選択**

例：  
`bionexus-holdings/pbpe-marketplace-backend`

---

### **④ Railway が自動で Node.js を検出 → “Deploy”**

Railway が自動で：

- Node.js を検出  
- Express サーバーを起動  
- ポートを自動設定  
- 公開 URL を発行  

すべて自動で完了する。

---

### **⑤ 公開 API URL が発行される**

例：  
```
https://pbpe-backend-production.up.railway.app
```

これが **PBPE API の公開 URL**。

# 🔗 3. フロントエンドとバックエンドを接続する

Vercel → Project → Settings → Environment Variables

保存 → “Redeploy” をクリック。
