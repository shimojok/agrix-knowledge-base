Impact Simulator-Baeline, MBT55, Comparison のいすれも数値が変わりません。

ダッシュボードのボタンが機能していない問題を修正します。

## 問題の原因

これらのボタンは**表示切替のみ**で、実際のデータ更新ロジックが実装されていない可能性があります。

## 修正方法

### 1. Carbon Ledger の修正

`dashboard/src/components/CarbonLedger.tsx` を開き、`timeRange` の変更時にデータを再生成するように修正します。

以下のような `useEffect` を追加または修正：

```typescript
// timeRange が変更されたときにデータを再生成
useEffect(() => {
  const generateData = () => {
    const data: CarbonData[] = [];
    const now = new Date();
    let cumulative = 1250000;
    
    // timeRange に応じてデータ点数を変更
    const days = timeRange === '7d' ? 7 : 
                 timeRange === '30d' ? 30 : 
                 timeRange === '90d' ? 90 : 365;
    
    for (let i = days; i >= 0; i--) {
      const date = new Date(now);
      date.setDate(date.getDate() - i);
      
      const sequestration = 40000 + Math.random() * 10000;
      cumulative += sequestration;
      
      data.push({
        date: date.toISOString().split('T')[0],
        sequestration: Math.round(sequestration),
        cumulative: Math.round(cumulative),
        credits: Math.round(sequestration * 0.8),
      });
    }
    
    setCarbonData(data);
  };
  
  generateData();
}, [timeRange]); // timeRange が変わるたびに実行
```

### 2. Impact Simulator の修正

`dashboard/src/components/ImpactSimulator.tsx` では、`activeScenario` に応じてパラメータを切り替える処理が必要です。

```typescript
// activeScenario が変更されたときの処理
useEffect(() => {
  if (activeScenario === 'baseline') {
    setParams(prev => ({ ...prev, mbtt55Applied: false }));
  } else if (activeScenario === 'mbtt55') {
    setParams(prev => ({ ...prev, mbtt55Applied: true }));
  }
  // comparison の場合は現在のパラメータのまま
}, [activeScenario]);
```
