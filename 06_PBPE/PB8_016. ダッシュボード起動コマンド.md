## ダッシュボード起動コマンド

```bash
cd /workspaces/PBPE-Dashboard/dashboard
npm run dev
```

起動後、表示されるURL（`http://localhost:3000`）を開くか、Codespacesの右下の「Open in Browser」ボタンをクリックしてください。

## テストの内容説明

リポジトリには以下のテスト関連ファイルが含まれています：

| ファイル | 種類 | 内容 |
|---------|------|------|
| `models/demo.py` | Pythonデモ | 全モデルの計算結果を対話的に表示 |
| `models/test_coffee_impact.py` | Pythonテスト | 収益計算・炭素隔離の単体テスト |
| `contracts/test/*.test.js` | Solidityテスト | スマートコントラクトの動作検証 |
| `azure/functions/test/*.js` | APIテスト | SafelyChain検証APIのテスト |

### 各テストの実行方法と確認内容

#### 1. Pythonデモ（計算ロジック確認）

```bash
cd /workspaces/PBPE-Dashboard
python models/demo.py
```

**確認できること：**
- 農家収益計算（$1,850 → $3,892/ha）
- 炭素隔離量（2.5 tCO₂e/ha/年）
- システム乗数（94.1倍）
- 投資収益率（187%）

#### 2. スマートコントラクトテスト

```bash
cd /workspaces/PBPE-Dashboard/contracts
npm install
npx hardhat test
```

**確認できること：**
- トークン発行・償還の正常動作
- 炭素クレジットの二重計上防止
- 収量連動トークンの決済ロジック
