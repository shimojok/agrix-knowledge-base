# 🟥 なぜ react-router-dom が使えないのか？

Next.js は React とは違い、  
**独自のルーティングシステム（pages/ または app/）を持っている**ため、

- BrowserRouter
- Routes
- Route
- Link（react-router-dom）

これらは **すべて使えません**。

Next.js で使うのは：

```ts
import Link from "next/link";
```

これだけ。
