# 🔥 なぜ小文字が正しいのか（国際標準の理由）

### 1. **GitHub の推奨規約**

GitHub はリポジトリ名に **小文字・ハイフン**を推奨しています。

- 読みやすい
    
- URL として扱いやすい
    
- OS や CLI でトラブルが起きない
    

### 2. **npm / Node.js / Next.js の慣習**

JavaScript の世界では **小文字＋ハイフン**が完全に標準。

例：

- react
    
- nextjs
    
- fastapi
    
- planetary-os
    
- pbpe-marketplace-platform
    

### 3. **Python パッケージの慣習**

Python のパッケージ名も **小文字＋ハイフン**が標準。

### 4. **Docker / Kubernetes の命名規則**

Docker イメージ名や K8s のリソース名は **小文字のみ**が許可される。

### 5. **国際機関に提出する場合の可読性**

IMF / 世界銀行 / UN の技術担当者は 「lowercase + hyphen」構造を最も読みやすいと判断する。
