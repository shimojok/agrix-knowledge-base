# 🎯 **3. Sidebar / Header が正しく表示されるか確認する方法**

## ✔ 方法①：ローカルで確認（最も確実）

1. Codespaces またはローカルでフロントエンドを起動
    
    ```
    npm run dev
    ```
    
2. ブラウザで
    
    ```
    http://localhost:3000/dashboard
    ```
    
    を開く。
    
3. 以下を確認：
    

### 🔍 **チェックポイント（Sidebar）**

- 左側に **縦長のメニュー（Sidebar）** が表示されている
- メニュー項目（Dashboard / KPIs / Impact / Finance / Enterprise など）が並んでいる
- クリックするとページ遷移する
- スクロールしても Sidebar が固定されている（position: fixed）

### 🔍 **チェックポイント（Header）**

- 画面上部に **横長のバー（Header）** が表示されている
- ロゴ or タイトルが表示されている
- 右側に言語切替やユーザーアイコンがある
- スクロールしても Header が固定されている

---

あなたの Vercel URL（例）：

```
https://pbpe-marketplace-frontend.vercel.app/dashboard
```

# 🎯 **4. KPI / チャートが動くか確認する方法**

KPI とチャートは **バックエンド API が動いているか**で決まる。

確認方法は以下。

---

## ✔ 方法①：Dashboard を開いて実際に表示されるか確認

### 🔍 **KPI カードのチェック**

- “GHG Reduction”
- “PBPE Issued”
- “Market Value”

などのカードが **数字入りで表示されているか**。

**NG の例：**

- “undefined”
- “NaN”
- “0 のまま”
- “Loading…” のまま

### 🔍 **チャートのチェック**

- GHGStackedBar が表示されているか
- 棒グラフが描画されているか
- データが入っているか

---

## ✔ 方法②：ブラウザの DevTools で API を確認

1. Dashboard ページを開く
2. 右クリック → **検証（Inspect）**
3. Network タブを開く
4. `dashboard-summary` や `ghg-breakdown` の API が呼ばれているか確認

### 🔍 正常な例

- Status: **200**
- Response に JSON が入っている
    
    ```
    { "ghg_reduction_tco2e_per_year": 123, ... }
    ```
    

### ❌ エラー例

- Status: **404** → API の URL が間違い
- Status: **500** → バックエンドのエラー
- CORS error → Railway 側の CORS 設定が必要

---

## ✔ 方法③：バックエンド API を直接叩いて確認

Railway の API URL（例）：

```
https://pbpe-backend-production.up.railway.app/api/dashboard/summary
```

ブラウザで開いて、JSON が返るか確認。

### 🔍 正常な例

```
{
  "ghg_reduction_tco2e_per_year": 123,
  "pbpe_issued_per_year": 456,
  "pbpe_market_value_usd_per_year": 789
}
```

### ❌ エラー例

- “Application Error”
- “CORS policy”
- “Cannot GET /api/dashboard/summary”
