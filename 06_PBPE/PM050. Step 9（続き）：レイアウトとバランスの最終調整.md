# 🧩 まずは「完成形レイアウトの原則」を固める  
PBPE Marketplace の UI は、以下の 3 原則で統一する。

## ① **3カラム構造（情報密度の最適化）**

- 1行目：PBPE / GHG / Soil  
- 2行目：Biosecurity / Health / Stability  

視線誘導が最も自然になる。

---

## ③ **チャートは “上：全体 / 下：内訳” の2段構成**  
- 上段：全体の傾向（GHG / PBPE Issuance）  
- 下段：カテゴリ別（Scope 3 Breakdown / PBPE Components）
