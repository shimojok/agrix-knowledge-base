## 1. 「現状 vs MBT55 導入後」の差分を見せる構造

### 1-1. シナリオ設計

**共通パラメータ：**

- **Soil / climate / crop 条件**
    - soil_type, climate_zone, crop_type, initial_SOC, initial_SON, etc.
- **マネジメント条件**
    - tillage, residue, fertilizer, irrigation, etc.

**シナリオ A（Baseline）**

- `mbt_dose = 0.0`

**シナリオ B（MBT55 導入後）**

- `mbt_dose = user_selected_value`（例：1.0〜3.0）

```python
baseline_params = {**common_params, "mbt_dose": 0.0}
project_params  = {**common_params, "mbt_dose": mbt_dose}

baseline = run_soil_carbon_model(baseline_params)
project  = run_soil_carbon_model(project_params)

df_baseline = pd.DataFrame(baseline)
df_project  = pd.DataFrame(project)

df_diff["sequestration_diff"] = df_project["sequestration"] - df_baseline["sequestration"]
df_diff["yield_diff"]         = df_project["yield"] - df_baseline["yield"]
```

## 2. C. MRV + 実データ対応 + Planetary OS 統合で「何がどう変わるか」

ここは **アーキテクチャのレイヤーを分けて** 考えると整理しやすいです。

---

### 2-1. レイヤー構造

1. **Model Layer（土壌・炭素・MBT55 モデル）**
    - 今の `run_soil_carbon_model` を拡張
2. **MRV Layer（測定・報告・検証）**
    - 実測データ取り込み・比較・不確実性評価
3. **Finance Layer（Green Premium / Article 6）**
    - クレジット量・価格・収益計算
4. **Planetary OS Integration Layer**
    - Planetary OS の他モジュールとの I/O

### 2-4. Planetary OS モジュールとして統合すると変わること

ここが一番 “Kaz らしさ” が出るところ。

#### 新しいファイル：`planetary_os_adapter.py`

```python
def export_soil_module_state(model_output: dict) -> dict:
    """
    Planetary OS に渡すための標準化された状態表現
    """
    return {
        "module": "soil_carbon",
        "version": "0.1.0",
        "spatial_unit": "ha",
        "time_unit": "year",
        "timeseries": {
            "year": model_output["year"],
            "soc": model_output["soc"],
            "sequestration": model_output["sequestration"],
            "n2o": model_output.get("n2o", []),
        },
        "finance": model_output.get("finance", {}),
        "mrv": model_output.get("mrv", {}),
    }
```

#### 変わるポイント

- **単独のダッシュボード → Planetary OS の 1 モジュール** になる
- 他モジュール（例：
    - 気候モジュール（気温・降水）
    - 水循環モジュール
    - 経済モジュール  
        とデータ連携できる
- “MBT55 の土壌効果” が  
    **地球規模の炭素循環・気候・水・食料・経済** に波及する構造を作れる
