```Python
# 地球と健康の価値をミリ秒単位で決済・資産化するPH-API
impact = PHAPI.ImpactIntent.create(
    co2_reduction = 12.5,        # CO2削減量 (kg)[cite: 10]
    soil_regeneration = 3.2,     # 土壌再生面積 (m2)[cite: 10]

```
