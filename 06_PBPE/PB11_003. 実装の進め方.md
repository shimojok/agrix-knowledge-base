## 次に：「1〜5」が何を意味しているかを、超シンプルに言い換えます

### 1. 初期コミット一式

- フォルダ：`docs/`, `api/`, `engine/`, `ledger/`, `ui/`, `examples/` など

### 2. README に貼る SVG 図

→ **トップページに載せる「PBPE Marketplace の1枚図」**

- README から `![PBPE Marketplace Architecture](docs/architecture/pbpe-architecture.svg)` とリンクする
- GitHub 上で README を開くと、図が表示される

---

### 3. GitHub Pages 用 Web ドキュメント

→ **GitHub 上でそのまま “ドキュメントサイト” を公開する仕組み**

- `docs/` フォルダの中に `index.md` などを置く

### 4. OpenAPI 3.1

→ **「PBPE Marketplace の API 仕様書」を機械可読な形で書いたもの**

### 5. TypeScript SDK

→ **開発者が PBPE Marketplace を簡単に叩ける “クライアントライブラリ”**
