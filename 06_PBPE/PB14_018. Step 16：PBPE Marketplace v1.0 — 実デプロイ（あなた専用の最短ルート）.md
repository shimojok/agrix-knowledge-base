# 🟦 **1. フロントエンド（Dashboard v3）を Vercel に公開**





### ✔ 必要なのは GitHub アカウントだけ  
Vercel は GitHub と完全連携している。

### ✔ 手順（3クリック）

1. **Vercel にログイン**（GitHub でログイン）
2. **“Add New Project” → PBPE Marketplace の frontend リポジトリを選択**
3. **Deploy をクリック**

これだけで：

- 自動ビルド  
- 自動デプロイ  
- 自動 https  
- 自動 URL 発行  
- GitHub push → 自動更新  

すべて完了する。

---

# 🟣 **2. バックエンド（PBPE API）を Railway に公開**





### ✔ Railway は Streamlit と同じ “ワンクリック公開” の世界  
あなたのバックエンド（Node.js / Express）は Railway が自動認識する。

### ✔ 手順（3クリック）

1. **Railway にログイン（GitHub でログイン）**
2. **“New Project” → “Deploy from GitHub Repo”**
3. **PBPE Marketplace の backend リポジトリを選択 → Deploy**

これだけで：

- 自動で Node.js を検出  
- 自動でサーバー起動  
- 自動で URL 発行  
- 自動でログ管理  
- 自動で再デプロイ  

が完了する。

### ✔ PostgreSQL もワンクリックで追加できる  
Railway の “Add Database” → PostgreSQL を選ぶだけ。

---

# 🔗 **3. フロントエンドとバックエンドを接続する**

```
NEXT_PUBLIC_API_URL=https://your-railway-backend-url
```

これで Dashboard v3 が **リアルタイムで PBPE API と接続**される。
