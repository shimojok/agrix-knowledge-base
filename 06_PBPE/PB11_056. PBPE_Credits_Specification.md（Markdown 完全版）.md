# PBPE Credits Specification  
**Version 1.0 — PBPE Marketplace / PBPE OS Layer 4**

PBPE Credits は、PBPE Marketplace における価値単位であり、  
**Carbon / Biosecurity / Food Loss / Quality** の 4 種類で構成される。

PBPE は、MBT‑Biosecurity‑Engine（Layer 1〜2）および AGRIX（Layer 3）から  
提供されるインパクトデータを基礎として発行される。

---

# 1. PBPE Credits Overview

| Credit Type     | Impact Domain                     | Unit Basis                     | Primary Data Source |
|-----------------|-----------------------------------|--------------------------------|----------------------|
| Carbon PBPE     | 温室効果ガス削減                   | 1 PBPE = 1 tCO₂e               | MBT55 / AGRIX / MRV |
| Biosecurity PBPE| 微生物・病原体リスク低減           | Biosecurity Index × Area × Time| MBT‑Biosecurity‑Engine |
| Food Loss PBPE  | 食品ロス削減                       | Food Loss Avoided × β          | Retail / Logistics / MBT55 |
| Quality PBPE    | 栄養価・鮮度・品質向上             | Nutrition Index Improvement     | AGRIX / MBT Nutrition Index |

---

# 2. 共通仕様

## 2.1 Metadata

```json
{
  "credit_id": "string",
  "type": "carbon | biosecurity | food_loss | quality",
  "project_id": "string",
  "vintage_year": 2026,
  "amount_pbpe": 1000000,
  "methodology_id": "PBPE-METH-001",
  "mrv_reference": "MBT-Biosecurity-Engine v1.2"
}
````

## 2.2 発行プロセス（共通）

1. **Impact Measurement**
    
    - MBT‑Biosecurity‑Engine / AGRIX / Field Sensors からデータ取得
2. **Impact Verification (MRV)**
    
    - 自動 MRV（ImpactWebhook）
    - 第三者検証（任意）
3. **PBPE Calculation**
    
    - 各クレジットの計算式に基づき PBPE を算出
4. **Issuance**
    
    - PBPE Ledger に記録
    - Marketplace に上場

---

# 3. Carbon PBPE

## 3.1 対象インパクト

- 廃棄物処理回避
- 食品ロス削減
- 土壌炭素隔離
- 化学肥料削減
- 家畜メタン削減
- 稲作メタン削減
- バイオマス増加

## 3.2 計算式

[ \text{Carbon PBPE} = \text{Verified GHG Reduction (tCO₂e)} ]

## 3.3 データソース

- MBT55 発酵データ
- AGRIX 生産性データ
- Soil Carbon Model
- Food Loss Model

---

# 4. Biosecurity PBPE

## 4.1 対象インパクト

- 微生物リスク低減
- 病原体抑制
- 生態系安定性向上

## 4.2 計算式（例）

[ \text{Biosecurity PBPE} = \text{Risk Reduction Index} \times \text{Coverage Area (ha)} \times \text{Duration (years)} ]

## 4.3 データソース

- MBT‑Biosecurity‑Engine（Hypercycle Stability / Risk Index）

---

# 5. Food Loss PBPE

## 5.1 対象インパクト

- 小売・流通の食品ロス削減
- MBT55 による鮮度保持

## 5.2 計算式

[ \text{Food Loss PBPE} = \text{Food Loss Avoided (t)} \times \beta ]

（β = tCO₂e 換算係数 + 食料安全保障係数）

---

# 6. Quality PBPE

## 6.1 対象インパクト

- 栄養価向上（リコピン・ポリフェノール・ミネラル）
- 抗酸化能向上
- 鮮度保持力向上

## 6.2 計算式

[ \text{Quality PBPE} = \text{Nutrition Index Improvement} \times \text{Volume (t)} ]

## 6.3 データソース

- MBT Nutrition Index（AGRIX × MBT55）

---

# 7. PBPE Ledger（発行記録）

- Blockchain optional
- JSON-based immutable ledger
- 企業・政府・投資家向けに透明性を提供

---

# 8. PBPE Marketplace での扱い

- PBPE Credits は Marketplace 上で売買可能
- PBPE Price は市場需給で決定
- PBPE‑backed Bond の原資産として利用可能

---

# 9. PBPE Dashboard との連携

- `/dashboard/pbpe`

- `/dashboard/flywheel`

これらの API により、PBPE の発行量・価値・市場動態をリアルタイム表示する。

# 10. 今後の拡張
