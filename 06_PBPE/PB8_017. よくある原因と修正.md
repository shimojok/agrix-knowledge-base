`Finance Engine` の Market Data タブでエラーが発生しています。原因を特定して修正しましょう。

## エラー確認

ブラウザで **F12** キーを押して開発者コンソールを開き、Market Dataをクリックした時に表示される**赤いエラーメッセージ**を確認してください。

## よくある原因と修正

### 原因1：`Cell` コンポーネントのインポート不足

`FinanceEngine.tsx` ファイルを開き、インポート部分を確認・修正します。

```bash
cd /workspaces/PBPE-Dashboard/dashboard
```

`src/components/FinanceEngine.tsx` の先頭付近を以下のように修正：

**修正前：**
```typescript
import {
  LineChart,
  Line,
  BarChart,
  Bar,
  XAxis,
  YAxis,
  CartesianGrid,
  Tooltip,
  Legend,
  ResponsiveContainer,
  PieChart,
  Pie,
} from 'recharts';
```

**修正後（`Cell` を追加）：**
```typescript
import {
  LineChart,
  Line,
  BarChart,
  Bar,
  XAxis,
  YAxis,
  CartesianGrid,
  Tooltip,
  Legend,
  ResponsiveContainer,
  PieChart,
  Pie,
  Cell,  // ← 追加
} from 'recharts';
```

### 原因2：`COLORS` 配列が未定義

ファイル内に以下の定義があるか確認してください（PieChartの近く）：

```typescript
const COLORS = ['#2e7d32', '#1565c0', '#ff6f00', '#6a1b9a', '#90a4ae'];
```

ない場合は追加してください。

### 修正後の確認

1. **Ctrl + S** で保存
2. ブラウザのプレビュー画面が自動更新される
3. Market Dataタブをクリックして表示されるか確認
