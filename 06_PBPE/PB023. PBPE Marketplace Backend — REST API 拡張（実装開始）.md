## 🔥 Step 4 — ファイルにコードを貼り付け

python

```
from fastapi import APIRouter
from pbpe_core.value_engine.engine import PBPEValueEngine

router = APIRouter()
engine = PBPEValueEngine()

@router.post("/pbpe/value/calc")
def calc_pbpe_value(payload: dict):
    result = engine.evaluate(payload)
    return {
        "project_id": result.project_id,
        "pbpe_score": result.pbpe_score,
        "financial": result.financial_score,
        "social": result.social_score,
        "ecological": result.ecological_score,
        "governance": result.governance_score
    }
```

## 🔥 Step 5 — main.py にルーターを追加

### 📁 `marketplace/backend/src/main.py` を編集

python

```
from fastapi import FastAPI
from marketplace_api.rest.routes_pbpe_value_engine import router as value_router

app = FastAPI(title="PBPE Marketplace API")

app.include_router(value_router)
```
