# ① 5.1億トン GHG削減フルシミュレーション

ここは曖昧にせず、**分解 → 排出 → 削減 → スケール**を一本の式で通します。

---

## ■ 前提構造（固定）

```text
有機廃棄物 → 分解プロセス → GHG排出 → MBT55介入 → 削減量
```

---

## ■ 数式モデル（統合）

### ① ベースライン排出

Ebase=W×EFconvE_{base} = W × EF_{conv}

- W：廃棄物量（t）
    
- EF：排出係数（tCO2e/t）
    

---

### ② MBT55後排出

Embt=W×EFmbtE_{mbt} = W × EF_{mbt}

---

### ③ 削減量

ΔE=Ebase−EmbtΔE = E_{base} - E_{mbt}

---

### ④ 導入率考慮

TotalReduction=ΔE×AdoptionRate×ScaleTotal Reduction = ΔE × Adoption Rate × Scale

---

---

## ■ グローバルスケール仮定（例）

|項目|値|
|---|---|
|有機廃棄物|5億トン/年|
|EF_conv|1.5|
|EF_mbt|0.5|
|導入率|50%|

---

## ■ 計算

Ebase=5e8×1.5=7.5e8Embt=5e8×0.5=2.5e8ΔE=5e8Adoption=0.5E_{base} = 5e8 × 1.5 = 7.5e8 E_{mbt} = 5e8 × 0.5 = 2.5e8 ΔE = 5e8 Adoption = 0.5 Total=5e8×0.5=2.5e8tCO2eTotal = 5e8 × 0.5 = 2.5e8 tCO2e

---

👉 ここで重要：

> **5.1億トンは“最大値”として成立可能**

---

---

## ■ Pythonシミュレーション（完全版）

```python
import numpy as np

def ghg_reduction(waste, ef_conv, ef_mbt, adoption):
    base = waste * ef_conv
    mbt = waste * ef_mbt
    reduction = (base - mbt) * adoption
    return reduction

# パラメータ
waste = 5e8
ef_conv = 1.5
ef_mbt = 0.5

for adoption in [0.1, 0.3, 0.5, 0.8]:
    r = ghg_reduction(waste, ef_conv, ef_mbt, adoption)
    print(f"Adoption {adoption}: {r/1e8:.2f}億トン削減")
```

## ■ 統合モデル

### ① Carbon価値

Revenue=Reduction×CarbonPriceRevenue = Reduction × Carbon Price

---

### ② コスト削減

CostSaving=Waste×84Cost Saving = Waste × 84%

---

### ③ IRR

IRR=f(Revenue+CostSaving−Investment)IRR = f(Revenue + Cost Saving - Investment)

---

---

## ■ Streamlit統合コード

```python
import streamlit as st
import numpy as np

st.title("BioNexus Investment Dashboard")

# Input
adoption = st.slider("Adoption Rate", 0.0, 1.0, 0.5)
carbon_price = st.slider("Carbon Price ($/t)", 0, 200, 50)

# Constants
waste = 5e8
ef_conv = 1.5
ef_mbt = 0.5

# Calculation
reduction = (waste * (ef_conv - ef_mbt)) * adoption
carbon_value = reduction * carbon_price
cost_saving = waste * 0.84

# IRR簡易モデル
investment = 1e10
cashflow = carbon_value + cost_saving
irr = (cashflow / investment)

# Output
st.metric("GHG Reduction (tCO2e)", f"{reduction/1e8:.2f} 億トン")
st.metric("Carbon Revenue ($)", f"{carbon_value/1e9:.2f} B$")
st.metric("Cost Saving ($)", f"{cost_saving/1e9:.2f} B$")
st.metric("IRR", f"{irr:.2f}")
```
