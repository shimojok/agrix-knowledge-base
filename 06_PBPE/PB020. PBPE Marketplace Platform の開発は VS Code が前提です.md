# 🔧 **VS Code を使う理由（PMOとしての公式判断）**

### ✔ 1. Python / FastAPI / Next.js を同時に扱える

PBPE Platform は **複数言語・複数モジュールの統合開発**なので、VS Code のワークスペース機能が必須。

### ✔ 2. GitHub 連携が強力

国際機関に提出するため、GitHub の CI/CD やリポジトリ構造が重要。 VS Code は GitHub と完全統合されている。

### ✔ 3. JSON / YAML / Mermaid / Markdown を同時編集できる

PBPE Platform はコードだけでなく、

- API仕様書
    
- アーキテクチャ図
    
- ホワイトペーパー
    
- 国際発表用スライド
    

なども同じリポジトリで管理するため、VS Code が最適。

### ✔ 4. ターミナル統合で Python / Node / Docker を同時実行できる

PBPE Marketplace Platform は **複数のサーバーを同時起動**するため、VS Code の統合ターミナルが必須。
