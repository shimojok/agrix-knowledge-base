## ✅ 修正のルール（簡潔に）

| 修正前 | 修正後 |
|---|---|
| `<div className="card">` | `<div style={{ backgroundColor: '#1e293b', border: '1px solid #334155', borderRadius: '12px', padding: '16px', boxShadow: '0 1px 3px rgba(0,0,0,0.5)' }}>` |

**この置き換えを、すべての `className="card"` に対して行います。**

## 📝 より簡単な方法

もし何度も同じスタイルを書くのが面倒なら、ファイルの先頭で `cardStyle` という定数を定義して、それを再利用する方法もあります。

### ファイル先頭に追加
```tsx
const cardStyle = {
  backgroundColor: '#1e293b',
  border: '1px solid #334155',
  borderRadius: '12px',
  padding: '16px',
  boxShadow: '0 1px 3px rgba(0,0,0,0.5)',
};
```

### カード部分で使用
```tsx
<div style={cardStyle}>
  {/* カードの中身 */}
</div>
```
