# 🌐 **日英切り替えの実装方式（最適解）**

React では i18n の実装方法がいくつかあるが、  
PBPE Marketplace に最適なのは **「軽量 i18n（JSON辞書方式）」**。

---

## 🥇 **方式：JSON 辞書 + React Context（最速・最軽量）**

### 1. 言語ファイルを作る  
`frontend/src/i18n/en.json`  
`frontend/src/i18n/ja.json`

例：

```json
{
  "dashboard": {
    "global_kpis": "Global KPIs",
    "impact": "Impact Breakdown",
    "market": "PBPE Credits Market",
    "finance": "PBPE Finance",
    "enterprise": "Enterprise Scope 3",
    "pbpe": "PBPE Issuance"
  }
}
```

日本語版：

```json
{
  "dashboard": {
    "global_kpis": "グローバルKPI",
    "impact": "インパクト内訳",
    "market": "PBPEクレジット市場",
    "finance": "PBPEファイナンス",
    "enterprise": "企業向けScope 3",
    "pbpe": "PBPE発行量"
  }
}
```

---

### 2. LanguageContext を作る  
`frontend/src/i18n/LanguageContext.tsx`

```tsx
import { createContext } from "react";

export const LanguageContext = createContext({
  lang: "en",
  setLang: (l: string) => {}
});
```

---

### 3. App.tsx で Provider を設定  
（すでにあなたの App.tsx は整理されているので、ここに追加するだけ）

```tsx
const [lang, setLang] = useState("en");

<LanguageContext.Provider value={{ lang, setLang }}>
  <AppRoutes />
</LanguageContext.Provider>
```

---

### 4. 翻訳関数を作る  
`frontend/src/i18n/useT.ts`

```tsx
import { useContext } from "react";
import en from "./en.json";
import ja from "./ja.json";
import { LanguageContext } from "./LanguageContext";

export const useT = () => {
  const { lang } = useContext(LanguageContext);
  const dict = lang === "ja" ? ja : en;

  return (key: string) => {
    const parts = key.split(".");
    return parts.reduce((o, k) => (o ? o[k] : key), dict);
  };
};
```

---

### 5. UI で翻訳を呼び出す  
例：Sidebar.tsx

```tsx
const t = useT();

<li><Link to="/dashboard/kpis">{t("dashboard.global_kpis")}</Link></li>
<li><Link to="/dashboard/impact">{t("dashboard.impact")}</Link></li>
<li><Link to="/dashboard/market">{t("dashboard.market")}</Link></li>
```

---

### 6. 言語切り替えボタンを Header に追加  
`frontend/src/components/layout/Header.tsx`

```tsx
const { lang, setLang } = useContext(LanguageContext);

<button onClick={() => setLang(lang === "en" ? "ja" : "en")}>
  {lang === "en" ? "日本語" : "English"}
</button>
```

- 追加コストが最小  
- Dashboard v3 の全ページに即適用  
- PBPE Marketplace の国際展開に最適  

というメリットしかない。
