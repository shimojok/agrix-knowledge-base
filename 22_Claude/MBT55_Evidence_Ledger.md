# MBT55 (原名NB菌) Evidence Ledger

最終更新：2026-08-18
証拠グレード基準：
- **E0**：未検証の仮説・アイデア（対外資料には使用不可）
- **E1**：関係者の伝聞・要約（一次情報ではない）
- **E2**：関係者による記述・証言（一次的だが第三者検証なし）
- **E3**：一次観察・記録（映像・写真・数値付き。ただし対照区/第三者計測なし）
- **E4**：第三者機関による計測・分析（例：登録分析機関の報告書）
- **E5**：特許・登録番号など第三者データベースで独立照合可能
- **E6**：査読付き公表・独立再現された結果

## 6. 除外・要注意項目

| 項目 | 理由 |
|---|---|
| DeepSeek生成JSON（13動画分析） | 実際の映像を見ずにタイトル・一般知識から合成されたものと本人確認済み。**Evidence Ledgerには一切採用しない** |
| セシウム→バリウム核変換の主張 | 化学反応と核反応のエネルギースケールが100万倍異なり、既知の物理法則と矛盾。対外資料には含めない。仮に類似現象を扱う場合は「バイオアキュムレーション（生物濃縮・移動）」として再構成すること |
| 「磁性菌体」による元素吸収効率化の主張 | 磁性細菌自体は実在するが、因果関係の科学的根拠が薄弱。対外資料には含めない |
| ¥4億〜50億 vs $400M〜$5.0B（043文書内の通貨単位混同） | 同一文書内で単位が変わり、約1,500〜2,000倍の差が生じている。マイクロソフト向け資料では必ず単位を再確認すること |
| $85.4 Trillion / 85.4兆円（NPV数値の通貨単位混同） | 世界GDPの8割に相当する非現実的な数値。同様に単位確認が必須 |

## 現時点の総括

最も証拠として強いのは、**E-02（第三者分析機関による報告書）**、**E-13（対照区付きの圃場記録）**、そして**E-07/E-07b（近隣複数事業者による独立採用という行動証拠）**です。次に優先すべき検証作業は、P-01〜P-06の照合（特許庁データベース・大学への照会）で、これは費用をかけずに今すぐ着手できます。

**記録が少ない理由についての補足**：発酵肥料・発酵飼料の採用により顕著な成果を上げた生産者は、収益向上と引き換えに、既存の農協体制からの逸脱・軋轢を覚悟する必要があり、公にすることを避ける傾向がある。E-07/E-07bの撮影に応じた生産者も、農協との関係悪化を覚悟の上で協力している。これは、証拠の少なさが「効果が乏しいこと」の反映ではなく、「公表することの社会的リスク」の反映である可能性を示唆する、記録すべき文脈である。
