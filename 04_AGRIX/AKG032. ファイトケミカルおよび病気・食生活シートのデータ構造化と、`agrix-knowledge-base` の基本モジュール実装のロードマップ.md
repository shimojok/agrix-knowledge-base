```Python
import json

# Process Disease-Diet Sheet (Sheet1)
df_dis = pd.read_excel(excel_disease_diet, sheet_name='Sheet1')

# First row has subcategories/factors, index 0 contains factor names, index 1 onwards are diseases
headers = df_dis.iloc[0].values
disease_data = []

for idx in range(1, len(df_dis)):
    row = df_dis.iloc[idx]
    disease_name = str(row.iloc[0]).strip()
    if disease_name == 'nan' or not disease_name:
        continue
    
    risk_factors = []
    for col_idx in range(1, len(headers)-1):
        val = row.iloc[col_idx]
        if str(val).strip() == '●':
            factor_name = str(headers[col_idx]).strip()
            risk_factors.append(factor_name)
    
    disease_data.append({
        "disease_id": f"DIS_{idx:03d}",
        "disease_name": disease_name,
        "dietary_risk_factors": risk_factors
    })

print(f"Parsed {len(disease_data)} diseases from Disease-Diet sheet.")
print("Example disease entry:", json.dumps(disease_data[0], ensure_ascii=False, indent=2))
```

```Python
# Parse Phytochemical Sheet: '分類'
df_phy = pd.read_excel(excel_phytochemical, sheet_name='分類')

phytochemical_entries = []
current_group = ""
current_subgroup = ""

for idx in range(1, len(df_phy)):
    row = df_phy.iloc[idx]
    c_group = str(row.iloc[0]).strip() if pd.notna(row.iloc[0]) else ""
    c_subgroup = str(row.iloc[1]).strip() if pd.notna(row.iloc[1]) else ""
    c_category = str(row.iloc[2]).strip() if pd.notna(row.iloc[2]) else ""
    c_name = str(row.iloc[3]).strip() if pd.notna(row.iloc[3]) else ""
    c_foods = str(row.iloc[5]).strip() if pd.notna(row.iloc[5]) else ""

    if c_group:
        current_group = c_group.split("（")[0].strip()
    if c_subgroup:
        current_subgroup = c_subgroup.split("（")[0].strip()

    if c_name and c_name != "nan":
        phytochemical_entries.append({
            "phytochemical_id": f"PHY_{len(phytochemical_entries)+1:03d}",
            "group": current_group,
            "subgroup": current_subgroup,
            "category": c_category,
            "compound_name": c_name,
            "source_foods": [f.strip() for f in c_foods.split("、") if f.strip() and f.strip() != "nan"]
        })

print(f"Parsed {len(phytochemical_entries)} phytochemical entries.")
print("Example entry:", json.dumps(phytochemical_entries[1], ensure_ascii=False, indent=2))
```

ファイトケミカルおよび病気・食生活シートのデータ構造化と、`agrix-knowledge-base` の基本モジュール実装のロードマップです。

**1. データ構造設計 (データモデリング)**

ナレッジベース検索・推論を効率化するため、JSON/Pydantic形式でスキーマを定義します。

- **Phytochemical (植物化学成分)**
   
    - `id`: ユニーク識別子 (例: `phyto_lycopene`)
        
    - `name`: 成分名 (例: リコピン)
       
    - `category`: 分類 (カロテノイド、ポリフェノール、イオウ化合物など)
       
    - `target_conditions`: 予防・改善が期待される症状/病気
     
    - `rich_food_sources`: 多く含む食材リスト
      
    - `bioavailability_tips`: 摂取効率を高める調理・食べ合わせのコツ
   
- **DietaryCondition (病気・食生活・症状)**
    
    - `id`: ユニーク識別子 (例: `cond_hypertension`)
    
    - `name`: 状態/病気名 (例: 高血圧)
    
    - `recommended_nutrients`: 推奨成分/ファイトケミカル
     
    - `recommended_foods`: 推奨食材
        
    - `foods_to_avoid`: 控えたい食材・成分

    - `evidence_level`: エビデンス強度 (A〜C)

**3. モジュール実装コード（プロトタイプ）**

データモデルおよびリポジトリのベース実装例です。

**スキーマ定義 (`src/agrix_kb/models/phytochemical.py`)**


```Python
from pydantic import BaseModel, Field
from typing import List, Optional

class Phytochemical(BaseModel):
    id: str
    name: str
    category: str
    target_conditions: List[str] = Field(default_factory=list)
    rich_food_sources: List[str] = Field(default_factory=list)
    bioavailability_tips: Optional[str] = None
```

**マッチャーサービス (`src/agrix_kb/services/matching.py`)**


```Python
from typing import List
from agrix_kb.models.phytochemical import Phytochemical

class KnowledgeMatchingService:
    def __init__(self, phytochemicals: List[Phytochemical]):
        self.phytochemicals = phytochemicals

    def find_by_condition(self, condition_id: str) -> List[Phytochemical]:
        """指定された症状・病気に効果的なファイトケミカルを検索"""
        return [
            item for item in self.phytochemicals 
            if condition_id in item.target_conditions
        ]
```
