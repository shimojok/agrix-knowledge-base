# Governance Rule

今回の重要な境界を再確認します。

```
Canonical Object
      ↓
Claim Extraction      ← 今回
      ↓
Evidence Retrieval
      ↓
Reconciliation
      ↓
Human Adjudication
```

したがって、

- 過去AIの「完成」記述を自動採用しない
- 過去AIの記述を自動排除もしない
- SourceにないClaimを追加しない
- Evidenceがない場合に推測で補完しない
- Retrieval Scoreを真偽判定に使わない

という運用で進めます。
