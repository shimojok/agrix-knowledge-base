# Governance Rules｜BioNexus Project Classification Registry v1.0

## 結論

以下を**正式に固定**します。

### Decision-01｜Classification Rule

> **BioNexusのVault Knowledge Assetは、Daily Note単位ではなく、Daily Note内の「Thread / Heading単位」でPROJECT 01〜06へ分類する。**

### Decision-02｜Multi-Project Rule

> **各Thread / Headingは、Primary Projectを1つ必須とし、必要に応じて複数のSecondary Projectを持つことを許可する。**

### Decision-03｜Raw Preservation Rule

> **元のVault、Daily Note、日付構造、リンク構造はRaw Layerとして変更・移動・破壊しない。**

### Decision-04｜Registry Rule

> **PROJECT分類は物理移動ではなく、「BioNexus Project Classification Registry v1.0」による論理分類として管理する。**

### Decision-05｜Reclassification Rule

> **将来Canonical Architectureが確定しても、Raw Sourceの分類履歴を上書きしない。Classification変更はRegistryのVersion更新として記録する。**

**以上を正式Classification Ruleとして固定します。**

# 7. Source Status Rule

すべてのノートを同じ扱いにしません。

```text
RAW
│
├── Historical Source
├── Development Record
├── Architecture Record
├── Governance Record
├── Canonical Candidate
└── Active Project Record
```

重要な原則：

> **Historical Source ≠ Canonical**

また、

> **最新ノート ≠ Canonical**

です。

Canonical化は、各PROJECTのReconstruction / Reconciliation工程で決定します。
