# 4. Knowledge Unitの抽出方式

従来の問題は、

```text
2026-04-24.md
        ↓
PROJECT 03
```

のように、**1ノート＝1分類**にしようとしたことでした。

今回から、

```text
2026-04-24.md
        │
        ├── Heading A
        │      └── Knowledge Unit 001
        │
        ├── Heading B
        │      └── Knowledge Unit 002
        │
        ├── Heading C
        │      └── Knowledge Unit 003
        │
        └── Heading D
               └── Knowledge Unit 004
```

として扱います。

つまり、

> **Vaultの物理構造を変更せず、Knowledge構造を抽出する。**

という方式です。

# 6. 実行方法

`agrix-knowledge-base` のローカルコピーに対して、

```bash
python -m _pipeline.run \
  --source "/path/to/agrix-knowledge-base" \
  --output "./_output"
```

という形で実行します。

Phase 1は外部Pythonライブラリを必要としない構成にしています。
