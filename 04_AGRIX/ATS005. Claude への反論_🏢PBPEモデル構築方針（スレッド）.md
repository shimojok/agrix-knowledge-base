# 3. むしろ「金融モデル」と「実証」を分離すべき

ここが今回の重要な修正点です。

PBPEには少なくとも**3種類のTruth Layer**を置くべきです。

```text
                 PBPE
                  │
       ┌──────────┼──────────┐
       ↓          ↓          ↓
  OBSERVED     VERIFIED    MODELED
  FACTS        EVIDENCE     VALUE
       │          │          │
       └──────────┼──────────┘
                  ↓
          PBPE Valuation
                  ↓
        Capital Allocation
```

### Layer A — Observed

実際に観測されたデータ。

例：

- 過去のMBT55試験
    
- 作物収量
    
- 土壌データ
    
- 廃棄量
    
- GHG関連データ
    
- コスト
    
- 市場価格
    

これは「誰が測定したか」「いつか」を明記する。

### Layer B — Verified

第三者が検証したデータ。

例えば、

- 大学
    
- 公的研究機関
    
- ISO等に対応した試験機関
    
- 独立分析機関
    
- 第三者監査
    

など。

### Layer C — Modeled

まだ観測されていない将来価値。

ここに、

- GHG削減
    
- 食料供給増加
    
- 土壌改善
    
- 投資収益
    
- 医療・社会コスト回避
    
- carbon value
    
- resilience value
    

などを入れる。

**この3つを混ぜないことがPBPEの核心です。**
