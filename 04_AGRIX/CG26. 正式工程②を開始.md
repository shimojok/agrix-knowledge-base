# AIの役割

Gemini/GemやChatGPT等には、

```
Source Retrieval
      ↓
Evidence Comparison
      ↓
Conflict Detection
      ↓
Reasoning
      ↓
Recommendation
```

までを許可します。

しかし、

```
Recommendation
      ↓
Verified
```

の自動昇格は許可しません。

最終的には、

```
Kaz / Human Authority
        ↓
Adjudication
        ↓
Canonical Dataset v1.1
```

です。
