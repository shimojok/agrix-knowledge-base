## 手順1：システム用ディレクトリの作成

PC上の作業用フォルダ（OneDrive内、または任意の開発用ディレクトリ）に、ナレッジ管理（`agrix-knowledge-base`）とは切り離したシステム専用のディレクトリ `bionexus-engine` とその内部フォルダを作成します。

**コマンドプロンプト（またはTerminal）での作成例：**

```Bash
mkdir bionexus-engine
cd bionexus-engine
mkdir src scripts chroma_db
```

**作成されるフォルダ構成：**

```Plaintext
bionexus-engine/
├── chroma_db/            ← 生成されたベクトルDBが保存される（Git管理対象外）
├── scripts/              ← インデックス作成・更新用スクリプト群
│   └── build_rag_index.py
└── src/                  ← 今後作成する各計算エンジン（pbpe, mbt, ghg等）
```

### 手順2：依存ライブラリのインストール

Python環境に必要なライブラリ群をインストールします。以下のコマンドを実行してください。

```Bash
pip install langchain langchain-community langchain-chroma langchain-openai chromadb python-dotenv
```

- **必要環境変数（API Key）：**
    
    OpenAIのEmbeddingモデルを使用するため、`bionexus-engine` 直下に `.env` ファイルを作成し、APIキーを設定してください。（※外部APIを使わない完全ローカルモデルへ変更することも可能です）
    
    ```Plaintext
    OPENAI_API_KEY=your_openai_api_key_here
    ```
    

### 手順3：インデックス化実行スクリプトの作成と実行

`agrix-knowledge-base` 内の全6,600+ノートを安全かつ高速に解析・ベクター化し、ローカルの `ChromaDB` に格納する Python スクリプトを作成します。

`bionexus-engine/scripts/build_rag_index.py` として以下を保存してください。

```Python
import os
import glob
from dotenv import load_dotenv
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import MarkdownHeaderTextSplitter, RecursiveCharacterTextSplitter
from langchain_chroma import Chroma
from langchain_openai import OpenAIEmbeddings

# 環境変数の読み込み (.env)
load_dotenv()

# --- 設定項目 ---
# TODO: ご自身の環境の agrix-knowledge-base の絶対パスまたは相対パスを指定してください
VAULT_PATH = "../agrix-knowledge-base"  
DB_DIR = "./chroma_db"

# 除外するフォルダ（下書きや一時ファイル、成果物スライドなど）
EXCLUDE_DIRS = ["00_inbox", "slides", ".git", ".obsidian"]

def is_excluded(file_path):
    for exc in EXCLUDE_DIRS:
        if f"/{exc}/" in file_path.replace("\\", "/"):
            return True
    return False

def load_and_process_vault():
    print("1. Obsidian Vault のスキャンを開始します...")
    all_md_files = glob.glob(f"{VAULT_PATH}/**/*.md", recursive=True)
    
    # 対象ファイルのフィルタリング
    target_files = [f for f in all_md_files if not is_excluded(f)]
    print(f"   - 総Markdownファイル数: {len(all_md_files)}")
    print(f"   - 解析対象ファイル数: {len(target_files)} (除外フォルダスキップ後)")

    # Markdown見出し構造に基づいた分割ルール
    headers_to_split_on = [
        ("#", "Header 1"),
        ("##", "Header 2"),
        ("###", "Header 3"),
    ]
    markdown_splitter = MarkdownHeaderTextSplitter(headers_to_split_on=headers_to_split_on)
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=150)

    all_chunks = []
    error_count = 0

    print("2. ノートの解析・構造分割（Chunking）を実行中...")
    for i, file_path in enumerate(target_files, 1):
        try:
            with open(file_path, "r", encoding="utf-8") as f:
                content = f.read()
            
            # 見出しで切り分けた上でメタデータ（ファイルパス）を保持
            docs = markdown_splitter.split_text(content)
            chunks = text_splitter.split_documents(docs)
            
            # 相対パスをソースとしてメタデータに登録
            rel_path = os.path.relpath(file_path, VAULT_PATH)
            for chunk in chunks:
                chunk.metadata["source"] = rel_path
                all_chunks.append(chunk)

        except Exception as e:
            error_count += 1

        if i % 500 == 0 or i == len(target_files):
            print(f"   - 進行状況: {i}/{len(target_files)} ファイル処理完了")

    print(f"   - 分割完了: 合計 {len(all_chunks)} チャンク生成 (エラー: {error_count}件)")
    return all_chunks

def build_vector_db(chunks):
    print("3. ベクトルデータベース (ChromaDB) への書き込みを開始します...")
    embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
    
    # バッチ処理で安全にインデックス化
    vector_db = Chroma.from_documents(
        documents=chunks,
        embedding=embeddings,
        persist_directory=DB_DIR
    )
    print(f"4. インデックス化完了！ データベース保存先: {os.path.abspath(DB_DIR)}")

if __name__ == "__main__":
    if not os.path.exists(VAULT_PATH):
        print(f"[エラー] 指定されたパスが見つかりません: {VAULT_PATH}")
        print("VAULT_PATH の設定を確認してください。")
    else:
        chunks = load_and_process_vault()
        if chunks:
            build_vector_db(chunks)
```

**実行手順：**

`bionexus-engine` ディレクトリに移動し、以下のコマンドを実行します。

```Bash
python scripts/build_rag_index.py
```

手順1〜3が完了すると、`chroma_db` フォルダ内に6,600+ノートの知識がベクトルインデックスとして安全に構築されます。実行時エラーやパスの設定等で確認が必要な点があればすぐにご指示ください。
