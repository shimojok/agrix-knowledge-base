# Governance Rules

1. **Core First**：設計変更は必ずCore Repositoryから開始する。
    
2. **Knowledge Before Code**：知識・ADR・Architectureを更新してから実装する。
    
3. **Registry Approval**：公開対象はKnowledge Registryで承認されたもののみ。
    
4. **Repository Traceability**：全リポジトリはRepository Atlasに登録する。
    
5. **Evidence Linkage**：技術・科学・事業の主張はEvidenceと対応付ける。
    
6. **Domain Isolation**：AGRIX・HealthBook・PBPEは独立したドメインとして実装し、共通標準のみCore Repositoryで管理する。
