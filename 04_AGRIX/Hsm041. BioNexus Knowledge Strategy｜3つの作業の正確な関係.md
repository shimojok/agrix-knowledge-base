## 具体的方法

Pythonが全Markdown等を読みます。

```text
6,000 Notes
      │
      ▼
Python Full-Text Scan
      │
      ▼
Markdown Parsing
      │
      ├── File
      ├── Heading
      ├── Section
      ├── Links
      ├── Date
      └── Metadata
      │
      ▼
Knowledge Object
```

例えば、

```text
2026-08-10.md
```

を人間が分割する必要はありません。

Pythonが、

```text
2026-08-10.md
│
├── Heading A
│      ↓
│   Knowledge Object 001
│
├── Heading B
│      ↓
│   Knowledge Object 002
│
└── Heading C
       ↓
    Knowledge Object 003
```

へ変換します。
