本来は、

# 自己対処｜Source-Locked Classification Protocol v1.0

今後、このVault整理作業では以下を強制します。

## Rule 1｜ファイル確認前に分類しない

```text
FILE EXISTS?
    │
    ├─ NO
    │   └─ Classification禁止
    │
    └─ YES
        ↓
      READ
```

---

## Rule 2｜今回の作業では「記憶」を分類根拠に使わない

分類根拠は必ず、

```text
PRIMARY SOURCE
│
├── File Name
├── Heading
├── Actual Content
├── Internal Links
└── Explicit Project Relationship
```

のみとします。

過去会話の記憶は、

> **補助的なContext**

には使用できますが、

> **Source Classificationの根拠にはしない**

ことにします。

---

## Rule 3｜Inferenceを明示的に分離

各Classificationは必ず、

```text
SOURCE FACT
        ↓
CLASSIFICATION BASIS
        ↓
DECISION
```

で処理します。

例えば、

```text
Source:
「Microsoft Azure Data Manager for Agriculture」

Explicit Content:
AGRIX / Agriculture Data

Decision:
PROJECT 02｜AGRIX
```

という形です。

本文に複数PROJECTが明示されている場合のみ、

```text
Primary Project
Secondary Project
```

を設定します。
