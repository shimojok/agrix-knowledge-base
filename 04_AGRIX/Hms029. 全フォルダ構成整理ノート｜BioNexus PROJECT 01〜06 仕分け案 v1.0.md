# 最重要の統治ルール

今回の6000ノート整理では、

```text
移動
```

ではなく、

```text
SOURCE CLASSIFICATION
```

にしてください。

つまり、

```text
Daily Note
    │
    ├── Primary Project = PROJECT 02
    │
    ├── Secondary Project = PROJECT 03
    │
    └── Secondary Project = PROJECT 04
```

という**多重所属可能なMetadata構造**です。

これなら、

- 歴史を失わない
    
- Daily Noteリンクを壊さない
    
- 同一ノートを複製しない
    
- AGRIX × MBT55 × PBPEの横断性を保持できる
    
- 将来AI/RAG検索に利用できる
    

という利点があります。
