# ✅ AI向け構造化クエリ（NotebookLM / Gemini 用）

以下をそのまま貼り付ければ、  
NotebookLM・Gemini が **モデル間の差分 → 経済モデルへの反映** を正確に推論できます。

---

## **Structured Technical Query (STQ‑001)**  
### **Task:**  
Compute and explain how the structural differences between the **MBT55 Carbon Absorption Model** and the **AGRIX Carbon Absorption Model** should be integrated into the **PBPE Marketplace Economic Model**.

---

## **Model Inputs**

### **1. MBT55 Carbon Absorption Model**
```json
{
  "model_id": "MBT55_CA",
  "variables": {
    "soil_microbe_flux": "F_m",
    "metabolic_chain_efficiency": "E_mc",
    "climate_factor": "C_f",
    "carbon_absorption_rate": "A_mbt55"
  },
  "core_equation": "A_mbt55 = F_m * E_mc * C_f"
}
```

### **2. AGRIX Carbon Absorption Model**
```json
{
  "model_id": "AGRIX_CA",
  "variables": {
    "crop_root_intensity": "R_i",
    "soil_structure_index": "S_s",
    "planetary_metabolism_factor": "P_m",
    "carbon_absorption_rate": "A_agrix"
  },
  "core_equation": "A_agrix = R_i * S_s * P_m"
}
```

---

## **3. PBPE Marketplace Economic Model**
```json
{
  "model_id": "PBPE_ECO",
  "variables": {
    "carbon_credit_price": "P_c",
    "yield_value": "Y_v",
    "green_premium": "G_p",
    "ghg_reduction_value": "V_ghg"
  },
  "core_equation": "V_ghg = (ΔA_total) * P_c"
}
```

---

## **Required Computation**

### **Step 1 — Compute Model Difference**
```json
{
  "operation": "difference",
  "definition": "ΔA = A_agrix - A_mbt55"
}
```

### **Step 2 — Integrate ΔA into PBPE Economic Model**
```json
{
  "operation": "integration",
  "definition": "ΔA_total = Σ(ΔA across all regions or production units)"
}
```

### **Step 3 — Compute Economic Impact**
```json
{
  "operation": "economic_projection",
  "definition": "V_ghg = ΔA_total * P_c"
}
```

---

## **Output Requirements**
```json
{
  "output": {
    "1": "Explain conceptual differences between MBT55_CA and AGRIX_CA",
    "2": "Show how ΔA is computed",
    "3": "Show how ΔA modifies PBPE economic outputs",
    "4": "Provide a final integrated formula",
    "5": "Provide policy or investment implications"
  }
}
```
