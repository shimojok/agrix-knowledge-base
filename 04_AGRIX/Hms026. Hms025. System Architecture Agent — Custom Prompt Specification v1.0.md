# Hms025. System Architecture Agent — Custom Prompt Specification v1.0

以下を **HealthBook-MIOS [01] System Architecture** スレッドの冒頭に、そのまま貼り付けて使用できる形で確定します。

このPromptは、既に確定している **BioNexus Agent Governance Contract v1.0** を継承し、[01]の責務を「現在のMIOS Architectureの構築・整合性管理」に限定します。  
**Architecture GenealogyそのものはHms023、Evidence/ReconciliationはHms024が主責務**です。

# 2. このPromptを[01]に貼った後の役割

[01] System Architectureは、今後この位置になります。

```text
HealthBook-MIOS
│
├── [01] System Architecture
│     │
│     ├── Current MIOS Architecture
│     ├── Architecture Layers
│     ├── Components
│     ├── Interfaces
│     ├── Dependencies
│     ├── Data / Knowledge / Evidence Flow
│     ├── Architecture Decisions
│     └── Canonical Architecture Candidate
│
├── [02] MBT Kampo Library
├── [03] MBT Probiotics
├── [04] Evidence & Reconciliation
├── [05] Data / Schema
└── [06] Implementation
```

ここで**[01]自身が勝手に歴史を再構築することはありません**。

歴史について必要な情報は、

```text
[01] System Architecture
          ↑
[02] Architecture Genealogy Agent
```

から受け取ります。

またEvidenceについては、

```text
[01] System Architecture
          ↑
[04] Evidence & Reconciliation
```

という関係になります。

```text
Phase 0-A  Source Corpus Inventory
```

の成果を入力として、

**Current MIOS System Architectureの構造化 → Architecture State判定 → Dependency/Interface整理 → Canonical Architecture Candidate**
