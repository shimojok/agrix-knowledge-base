# Project Phoenix 総合計画書 v1.0 — Section 01

## プロジェクトの目的と基本構想

Project Phoenixは、40年間に蓄積されたMBT55に関する知識と、既に構築されているAGRIX、HealthBook、PBPE等の資産を基盤として、**MBT55の生物学的機能を現実の農業・食料・環境・健康・金融システムへ接続するAI-native Platform Architectureを提示すること**を目的とする。最終的な成果物は単独のAIソフトウェアではなく、実装可能なシステムアーキテクチャ、Knowledge Architecture、Repository Architecture、AI Agent Architecture、Dashboard、Demonstration Systemによって構成される。

本プロジェクトの出発点はMBT55である。原典ではMBT55を、物質・エネルギー・電子・情報・元素の流れを変換し、土壌・水・廃棄物・生態系における秩序を再構成する「生体変換エンジン」と定義している。また、その統合機能として、微生物ギルド間相互作用、生態学的ハイパーサイクル、栄養カスケード、バイオセキュリティ、元素循環の再構成等が示されている。

MBT55を実社会へ展開する基本単位が**MSC（MBT Sustainable Cycle）**である。本計画におけるMSCは、**MBT55微生物群とMBT発酵機によって構成されるシステム**として扱う。原典でも、MBT55菌体とMBT発酵機によるMSCが、微生物生態系のハイパーサイクルを基盤として物質循環・情報循環・経済循環を接続するモデルとして記述されている。

Project Phoenixでは、このMSCを起点としてAGRIX Platformを構築する。基本構造は、

**MBT55 / MSC → AgriWare™ / SafetyChain™ → PBPE Marketplace**

である。

AgriWare™は、MSCによって生成される生物学的・資源的変化を農業生産へ接続するIntelligence Layerとして位置づける。一方、SafetyChain™は農産物の品質、機能性、鮮度、安全性、トレーサビリティ等を統合し、さらにPBPEによる価値評価・金融モデル化に必要となるデータを生成するLayerとして位置づける。この二つの機能を通じて、MBT55/MSCによる有機質廃棄物の資源化、土壌修復、農業生産性向上、炭素循環、GHG削減等を、測定可能な農業価値へ変換する。

その先に配置されるPBPE Marketplaceは、単なるImpact Dashboardではない。AGRIXが生成した実世界のImpactを、**Impact → Value → Asset → Finance → Marketplace**という階層で金融価値へ変換し、農業部門へ資本を流入させるためのFinancial Platformとして設計する。PBPEは現在の通貨ではないが、将来的に金融資産、価値交換媒体、さらに金融・通貨的Layerへ発展できる拡張性をArchitectureとして保持する。

HealthBookは、AGRIXと並ぶ第二のPlatformである。MBT55を共通の生物学的基盤として、腸内細菌バランス、代謝経路、ホルモン、ATP生産、フェノタイピング、問診、疾病リスク、MBT漢方代謝Library、MBT Probiotics Screening等を統合し、Human Metabolic Intelligenceへ展開する。原典でも、AGRIX/HealthBook Platformとフェノタイピングを接続し、農作物の生育管理とヒトの健康管理へ応用する方向が示されている。

したがってProject Phoenixの最終的な構造は、**MBT55を生物学的基盤、AGRIXを農業変革Platform、HealthBookをHuman Health Platform、PBPE Marketplaceを価値・金融Platformとして接続する統合Architecture**となる。PMOSはこれらを置き換えるものではなく、AGRIXとHealthBookによって実現される農業・食料・気候・健康・経済上の成果を統合的に表現するOutcome Modelとして位置づける。

このArchitectureによって、本プロジェクトは「AIを使ったシステムを作る」ことから、**生物学的知識をAI、データ、金融へ接続することで、食料生産問題、GHG削減、グローバルヘルス、農業金融を同時に変革するためのPlatform Architectureを提示すること**へ明確に焦点を定める。
