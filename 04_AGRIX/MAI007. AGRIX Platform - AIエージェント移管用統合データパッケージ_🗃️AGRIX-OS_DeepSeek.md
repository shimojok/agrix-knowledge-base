## 3. タスク管理データベース（SQLiteスキーマ + 初期データ）

### 3.1 スキーマ定義（SQL）

```sql
-- プロジェクト全体のタスク管理
CREATE TABLE projects (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    status TEXT CHECK(status IN ('planning', 'active', 'paused', 'completed', 'archived')),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 個別タスク
CREATE TABLE tasks (
    id TEXT PRIMARY KEY,
    project_id TEXT REFERENCES projects(id),
    title TEXT NOT NULL,
    description TEXT,
    priority INTEGER DEFAULT 0,
    status TEXT CHECK(status IN ('backlog', 'todo', 'in_progress', 'review', 'done', 'blocked')),
    assigned_agent TEXT,
    parent_task_id TEXT REFERENCES tasks(id),
    dependencies TEXT, -- JSON array of task IDs
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    completed_at TIMESTAMP
);

-- コード資産管理
CREATE TABLE code_assets (
    id TEXT PRIMARY KEY,
    path TEXT NOT NULL UNIQUE,
    module TEXT NOT NULL,
    file_type TEXT NOT NULL,
    description TEXT,
    status TEXT CHECK(status IN ('implemented', 'designed', 'pending', 'archived')),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 知識グラフノード（Pinecone同期用）
CREATE TABLE knowledge_nodes (
    id TEXT PRIMARY KEY,
    source_repo TEXT NOT NULL,
    file_path TEXT NOT NULL,
    content_hash TEXT NOT NULL,
    chunk_index INTEGER DEFAULT 0,
    content TEXT NOT NULL,
    metadata JSON,
    pinecone_id TEXT,
    synced_at TIMESTAMP
);
```

## 7. エージェントプロンプト集（Markdown形式）

```markdown
# docs/agents/prompts/orchestrator.md

あなたはAGRIX SystemのオーケストレーターAIです。
あなたの使命は、システム構築タスクを分解し、適切な専門エージェントに割り振り、進捗を管理することです。

## 行動原則
1. **タスク分解**: 与えられた指示を、実行可能なサブタスクに分解する
2. **エージェント割り振り**: 各タスクの性質に応じて、最適なエージェントを選択する
3. **進捗管理**: 各エージェントの実行状況を監視し、遅延やエラーを検知する
4. **統合**: 各エージェントの成果物を統合し、一貫性のあるシステムとして組み立てる

## 参照すべき知識
- Pinecone上の `agrix-os` および `vault-raw` 知識ベース
- システム知識グラフ（`knowledge_graph.json`）
- タスク管理データベース

## 禁止事項
- 実装やコード生成を自分で行わない（実装AIに委譲する）
- 検証を自分で行わない（検証AIに委譲する）
- 文書化を自分で行わない（文書化AIに委譲する）
```

```markdown
# docs/agents/prompts/implementer.md

あなたはAGRIX Systemの実装AIです。
あなたの使命は、Pinecone上の知識ベースを参照しながら、指示されたコードを生成・修正することです。

## 行動原則
1. **知識参照**: コード生成前に必ずPineconeで関連コード・設計書を検索する
2. **一貫性維持**: 既存コードのスタイル・パターンに従う
3. **説明責任**: 生成したコードには必ずコメントと説明を付与する
4. **テスト可能性**: テスト可能な単位でコードを生成する

## 参照すべき知識
- Pinecone上の `agrix-os` 知識ベース（既存コード）
- システム知識グラフ（`knowledge_graph.json`）
- コード資産インベントリ（`code_inventory.json`）

## 禁止事項
- Pineconeを参照せずにコードを生成しない
- 既存コードと矛盾するコードを生成しない
```

```markdown
# docs/agents/prompts/validator.md

あなたはAGRIX Systemの検証AIです。
あなたの使命は、実装AIが生成したコードをレビューし、ハルシネーションや論理的矛盾を検知・修正することです。

## 行動原則
1. **知識照合**: コードの内容をPinecone上の既存知識と照合する
2. **論理チェック**: コードの論理的一貫性を検証する
3. **ハルシネーション検知**: 事実に基づかない主張やコードを特定する
4. **修正提案**: 問題を特定した場合、具体的な修正案を提示する

## 参照すべき知識
- Pinecone上の `agrix-os` および `m3-core` 知識ベース
- システム知識グラフ（`knowledge_graph.json`）
- 設計仕様書

## 禁止事項
- 検証なしにコードを合格としない
- 修正案なしに不合格としない
```

```python
"""
このスレッドの成果物をAIエージェント用フォーマットに変換する
"""

import json
import sqlite3
import os
from pathlib import Path

def create_sqlite_db():
    """SQLiteデータベースを作成し、タスクとコード資産を投入する"""
    db_path = Path("data/agrix_agent.db")
    db_path.parent.mkdir(parents=True, exist_ok=True)
    
    conn = sqlite3.connect(str(db_path))
    cursor = conn.cursor()
    
    # スキーマ作成（上記SQL参照）
    cursor.executescript("""
        CREATE TABLE IF NOT EXISTS projects (
            id TEXT PRIMARY KEY,
            name TEXT NOT NULL,
            description TEXT,
            status TEXT,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        );
        CREATE TABLE IF NOT EXISTS tasks (
            id TEXT PRIMARY KEY,
            project_id TEXT REFERENCES projects(id),
            title TEXT NOT NULL,
            description TEXT,
            priority INTEGER DEFAULT 0,
            status TEXT,
            assigned_agent TEXT,
            parent_task_id TEXT REFERENCES tasks(id),
            dependencies TEXT,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            completed_at TIMESTAMP
        );
        CREATE TABLE IF NOT EXISTS code_assets (
            id TEXT PRIMARY KEY,
            path TEXT NOT NULL UNIQUE,
            module TEXT NOT NULL,
            file_type TEXT NOT NULL,
            description TEXT,
            status TEXT,
            created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
            updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        );
        CREATE TABLE IF NOT EXISTS knowledge_nodes (
            id TEXT PRIMARY KEY,
            source_repo TEXT NOT NULL,
            file_path TEXT NOT NULL,
            content_hash TEXT NOT NULL,
            chunk_index INTEGER DEFAULT 0,
            content TEXT NOT NULL,
            metadata JSON,
            pinecone_id TEXT,
            synced_at TIMESTAMP
        );
    """)
    
    # 初期タスクデータを投入
    with open("data/tasks.json", "r") as f:
        tasks_data = json.load(f)
    
    for task in tasks_data["tasks"]:
        cursor.execute("""
            INSERT OR REPLACE INTO tasks 
            (id, project_id, title, description, priority, status, assigned_agent, dependencies)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
        """, (
            task["id"], task["project_id"], task["title"], 
            task["description"], task["priority"], task["status"], 
            task["assigned_agent"], json.dumps(task["dependencies"])
        ))
    
    conn.commit()
    conn.close()
    print(f"✅ SQLiteデータベース作成完了: {db_path}")
```
