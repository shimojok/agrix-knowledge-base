# 3. Status Governance

今回特に重要なのはここです。

### SOURCE_CONFIRMED / REFERENCE

ソース上で概念・構造が確認できるもの。

### PENDING / PENDING_VALIDATION

追加測定・検証・Adjudicationが必要なもの。

たとえばM3-BioSynergy-Coreには、

- GHG field data
- Soil improvement data
- Enzyme activity data
- MBT55 composition

などの構造化データがあります。M3-BioSynergy-Core.txtTXT

一方、PBPE側のMethodology Standardsも、Baseline、Measurement Protocol、Data Quality、Verification、Uncertainty Assessmentを要求しています。PBPE-Marketplace.txtTXT

したがって、**「モデルに数値が存在する」ことと「実証されたCanonical Evidenceである」ことを分離**しています。
