# 🟦 **BioNexus‑vault を GitHub → Repomix → txt化する際の留意点**

Vaultは Obsidian の Markdown なので、Repomixでパッキングする際に以下を守ると **NotebookLMとRAGの精度が劇的に上がります**。

---

## ✔ **留意点1：フォルダ構造を維持したままパッキングする**  
Vaultは階層構造が「意味」を持っています。

例：  
```
BioNexus-vault/
   AGRIX/
   PBPE/
   MBT55/
   SafetyChain/
   HealthBook/
   Meta/
   AI-Logs/
```

この構造を Repomix が壊さないように、  
**--include-folders オプションを使う**のが最適です。

---

## ✔ **留意点2：画像・PDF・HTMLは除外する（NotebookLMが読めない）**  
NotebookLMは **テキストのみ**をベクトル化します。

除外対象：  
- PNG / JPG  
- PDF  
- HTML  
- CSV  
- Excel  
- JSON（構造が壊れる）

含めるべき：  
- .md  
- .txt  
- .xml（Repomix出力）

---

## ✔ **留意点3：1ファイルが大きすぎる場合は分割する**  
NotebookLMは **1ファイルあたりのサイズが大きいと精度が落ちる**。

目安：  
- 1ファイル 1〜3MB が最適  
- 10MBを超えると抽出精度が落ちる

BioNexus‑vaultは巨大なので、  
**フォルダごとに分割してパッキングする**のが正解。

---

## ✔ **留意点4：Repomix出力は必ず txt に変換する**  
NotebookLMは XMLより txtの方が安定します。

例：  
```
npx repomix --remote https://github.com/... --output vault.xml
```

→ その後、  
```
vault.xml → vault.txt に変換
```

## ✔ **STEP 2：RAG検索コード（Python）**

あなたはコードを書く必要はありません。  
僕が作るコードはこういう構造になります：

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.vectorstores import FAISS
from langchain.embeddings import HuggingFaceEmbeddings
import os

# 1. 17リポジトリを読み込む
docs = []
for file in os.listdir("local_rag"):
    with open(f"local_rag/{file}", "r", encoding="utf-8") as f:
        docs.append(f.read())

# 2. 分割
splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200)
chunks = splitter.create_documents(docs)

# 3. ベクトル化
embeddings = HuggingFaceEmbeddings(model_name="sentence-transformers/all-MiniLM-L6-v2")
db = FAISS.from_documents(chunks, embeddings)

# 4. 検索関数
def rag_search(query):
    return db.similarity_search(query, k=5)
```
