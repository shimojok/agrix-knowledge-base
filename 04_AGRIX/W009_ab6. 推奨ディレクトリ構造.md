### 推奨ディレクトリ構造 (`agrix-knowledge-base`)

ローカル環境のプロジェクトルート直下に、以下の構造を配置します。

```text
agrix-knowledge-base/
│
├── data/                                 # 初期JSON・浜田137リスクマトリックスデータ
│   ├── phytochemicals_diet.json
│   └── hamada_137_risk_matrix.json
│
├── models/                               # Pydanticデータモデル定義
│   ├── __init__.py
│   ├── phytochemical.py
│   └── hamada_matrix.py
│
├── repositories/                         # ファイル読み込み・検索層
│   ├── __init__.py
│   ├── phytochemical_repository.py
│   └── hamada_matrix_repository.py
│
├── analyzer/                             # 16リポジトリスケルトン解析モジュール
│   ├── __init__.py
│   └── repo_dependency_analyzer.py
│
├── bionexus_sim_engine.py                # 動的シミュレーション演算コア
├── ask_executive.py                      # エグゼクティブ問合せインターフェース (CLI)
├── app.py                                # Streamlit フロントエンドダッシュボード
├── extract_repo_skeleton.py              # コンテキスト最適化スレッドから受領の抽出スクリプト
└── requirements.txt                      # 依存ライブラリ一覧

```

### ディレクトリ＆空ファイル一括作成コマンド

ターミナル（Bash / PowerShell）でプロジェクトルートに移動し、以下のコマンドを実行するだけで一括作成が完了します。

#### macOS / Linux (Bash)

```bash
mkdir -p data models repositories analyzer

touch models/__init__.py \
      repositories/__init__.py \
      analyzer/__init__.py \
      data/phytochemicals_diet.json \
      data/hamada_137_risk_matrix.json \
      models/phytochemical.py \
      models/hamada_matrix.py \
      repositories/phytochemical_repository.py \
      repositories/hamada_matrix_repository.py \
      analyzer/repo_dependency_analyzer.py \
      bionexus_sim_engine.py \
      ask_executive.py \
      app.py \
      requirements.txt

```

#### Windows (PowerShell)

```powershell
New-Item -ItemType Directory -Force -Path data, models, repositories, analyzer

@("models\__init__.py", "repositories\__init__.py", "analyzer\__init__.py",
  "data\phytochemicals_diet.json", "data\hamada_137_risk_matrix.json",
  "models\phytochemical.py", "models\hamada_matrix.py",
  "repositories\phytochemical_repository.py", "repositories\hamada_matrix_repository.py",
  "analyzer\repo_dependency_analyzer.py",
  "bionexus_sim_engine.py", "ask_executive.py", "app.py", "requirements.txt") | ForEach-Object { New-Item -ItemType File -Force -Path $_ }

```
