# 🟦 なぜ Vault のコードや JSON を使わないのか？

理由は明確です。

## 🟥 1. Vault のコードは「試作・途中経過・AIログ」が混ざっている

Vaultには：

- Claudeが生成した試作コード
    
- ChatGPTが生成した途中コード
    
- DeepSeekが生成した断片
    
- NotebookLMのメモ
    
- あなたのアイデア
    
- ハルシネーションの痕跡
    
- 修正前のロジック
    

が混在しています。

これをそのまま計算エンジンに使うと **壊れます**。

## 🟥 2. Vault の JSON は「候補値」であり、公式値ではない

NotebookLMが返す JSON は：

- 候補値
    
- 推定値
    
- 抽出値
    
- AIの推論値
    

であり、**公式値ではありません**。

公式値は **canonical_data.json** に一本化する必要があります。

## 🟩 3. 本番用の計算エンジンは “統一された構造” が必要

PBPE、MBT55、GHG削減モデルは：

- 数式
    
- 入力
    
- 出力
    
- 単位
    
- スケール
    
- シナリオ
    
- 依存関係
    

が完全に統一されていないと **計算が破綻します**。

だから、僕が PMOとして **公式エンジンを新規作成**します。
