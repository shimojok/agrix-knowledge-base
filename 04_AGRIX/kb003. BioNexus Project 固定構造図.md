## 3. 各層の役割とスキーマ設計方針

### AGRIX Project (70%)

1. **MBT55 / MBT Sustainable Cycle**
    
    - 微生物群集の代謝ネットワーク、電子伝達系、炭素固定量（5.8 tCO₂e/ha/年）などの決定論的数理モデル。
        
2. **BioValley / AquaTower**
    
    - 資源循環・水耕/立体農業・水産養殖の物質フローおよびエネルギー収支計算。
        
3. **AGRIX Platform (AgriWare / SafetyChain / PBPE Marketplace)**
    
    - 農産物・有機資材の品質トレーサビリティおよび、MSC（物質・情報・経済）循環に基づくカーボンクレジット/分散型市場計算。
        
### HealthBook Project (30%)

1. **HealthBook Platform**
    
    - 200項目問診シート（揺らぎ表現解析）、137/123疾病リスク関連表、ファイトケミカル分類表を統合したライフログ・フェノタイピング基盤。
        
2. **MBT Probiotics Platform**
    
    - 生薬・ファイトケミカルの腸内細菌超高速代謝（mbt-kampolibrary）、短鎖脂肪酸（SCFA）生成量、腸管内分泌（GLP-1/PYY）刺激、ミトコンドリア ATP 産出効率モデル。
