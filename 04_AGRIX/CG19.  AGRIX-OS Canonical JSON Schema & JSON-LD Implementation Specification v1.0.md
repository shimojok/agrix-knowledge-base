```

      ↓
Structured Data
```

# 8. Evidence Object

Evidenceは独立Objectとして扱います。

```
{
  "evidence_id": "AGRIX-EVD-001",

  "evidence_type": "observation",

  "status": "OBSERVED",

  "description": "Source-reported observation",

  "source": {
    "repository": "M3-Core-Engine",
    "document": "..."
  },

  "measurement": {
    "value": null,
    "unit": null,
    "method": null
  },

  "replication": {
    "status": "UNKNOWN",
    "n": null
  },

  "independent_validation": {
    "status": "PENDING"
  }
}
```

重要なのは、**値がないこと自体をエラーにしない**ことです。

未測定なら、

```
null
+
PENDING
```

として保持します。

# 19. JSON-LD Context

```
{
  "@context": {
    "agr": "https://bionexus.example/ontology/agr ix#",

    "object_id": "@id",
    "canonical_name": "agr:canonicalName",
    "object_type": "agr:objectType",

    "domain": "agr:domain",
    "layer": "agr:layer",

    "evidence": "agr:evidence",
    "claims": "agr:claim",
    "models": "agr:model",

    "relationships": "agr:relationship",

    "source": "prov:wasDerivedFrom",
    "validated_by": "agr:validatedBy",

    "prov": "http://www.w3.org/ns/prov#"
  }
}
```

ここでW3C PROV系のProvenance概念を採用し、

```
Object
 ↓
```

これまでは、

```

       ↓

       ↓
```

でした。

今後は、

```
17 Repositories
       ↓
9 Repository Mapping
       ↓
29 Canonical Objects
       ↓
Adjudication
       ↓
Golden Dataset
       ↓
JSON Schema
       ↓
JSON-LD
       ↓
Knowledge Graph
       ↓
Reasoning Engine
```

となります。

つまり、**AIの「記憶」に依存するArchitectureから、外部化されたCanonical Knowledgeに依存するArchitectureへ移行します。**

これは、今回問題になった

- Memory duplication
- Hallucination
- Context loss
- AI間の意味の変質
- 長大なPrompt依存

を、プロンプト改善だけでなく**データアーキテクチャそのもので抑制するための設計**です。
