# Governance Rules

今後、

全Repositoryは

次の5つのレベルで管理します。

|Level|役割|AI対象|
|---|---|---|
|L0|Architecture Book|◎|
|L1|Repository Atlas|◎|
|L2|Knowledge Graph|◎|
|L3|Repository Source|○|
|L4|Executable Code|△|

AIが検索するのは

L0〜L2です。

L3以降は

必要になった時だけ参照します。
