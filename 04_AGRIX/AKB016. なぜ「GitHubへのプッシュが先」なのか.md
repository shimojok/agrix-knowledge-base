# 🟥 なぜ「GitHubへのプッシュが先」なのか（PMOとしての理由）

### ✔ 1. Repomixは「GitHubのリポジトリ」を入力にする

ローカルフォルダを直接パッキングすることもできますが、 **GitHub経由の方が階層構造が安定し、NotebookLMの理解精度が上がる。**

### ✔ 2. NotebookLMは「GitHubの構造」を前提にする

NotebookLMは、GitHubの階層をそのまま読み込むと **フォルダの意味（MBT55、PBPE、AGRIXなど）を理解しやすい。**

### ✔ 3. RAGは「GitHub → Repomix → txt」の流れが最も壊れない

GitHub → XML → txt → RAG この流れが最も安定する。

### ✔ 4. Azureデプロイ時に GitHub が必須

後で Azure App Service / Azure Functions に載せるとき、 GitHubがそのままデプロイ元になる。
