# 2. Golden Datasetの原則

## Rule 01 — Golden ≠ Proven

`Golden` は「科学的にすべて証明された」という意味ではありません。

ここでは、

> **AGRIX-OSが正式なCanonical Referenceとして採用したデータ**

を意味します。

その中に、

- VERIFIED
- OBSERVED
- CLAIM_ONLY
- MODEL_DERIVED
- PENDING
- SCENARIO

を保持します。

---

# 3. Rule 02 — Statusを絶対に失わない

例えば、

```
decomposition_rate_24h = 1.0
```

という値が存在しても、

```
status = MODEL_DERIVED
```

なら、

**Verified Evidenceとして扱ってはいけません。**

M3-Core-Engine自身も24時間分解率についてdirect metabolite CSV等の追加Evidenceを要求しています。

同様にN₂O/CH₄係数についてはfield measurementが必要と明記されています。M3-Core-Engine.txtTXT

# 17. Validation Rules

Golden Datasetに登録するには最低限、

### V01

`object_id` は一意。

### V02

全Objectに `source` が存在。

### V03

全Objectに `evidence_status` が存在。

### V04

数値を持つObjectには `unit` を要求。

### V05

Model-derived valueには `model_id` が必須。

### V06

Claimには `claim_id` が必須。

### V07

PENDINGにはvalidation requirementを要求。

### V08

ScenarioはVerified Evidenceへ自動昇格禁止。

### V09

AIによるstatus変更は禁止。

### V10

Freeze済Datasetは直接編集禁止。
