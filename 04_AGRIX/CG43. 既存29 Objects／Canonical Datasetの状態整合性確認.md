# 5. なぜこのGateが必要なのか

Registryの正式運用手順では、

1. Project State Registryを読む
2. Required InputをManifest/Checksumと照合
3. Git commitを確認
4. 未解決ならそこで停止
5. 会話内容から再生成しない

という手順になっています。

さらに明確に、

> **Unknown is a valid state.**

として、Missing FileやUnresolved Provenanceを推測で埋めないことが固定されています。

したがって、今回私がOBJ-001〜005を「記憶から再構築」しなかったこと自体は正しい方向でした。

ただし、

> 「アップロードしてください」

と単純に返したのではなく、

**「既存Canonical Stateをまず照合する」**

べきでした。

そこは今回修正します。
