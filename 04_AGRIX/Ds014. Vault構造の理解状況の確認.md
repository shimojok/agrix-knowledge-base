# 4. 補足：このスレッドの「遺言」

このスレッドは**コンテキスト上限で終了**しますが、成果は上記JSONに集約しました。新スレッドでは、以下を心がけてください：

1. **JSONを冒頭に固定** → LLMの忘却を防ぐ
2. **タスクを1つずつ** → コンテキスト消費を抑える
3. **コマンド結果は要約** → 巨大出力は避ける
4. **Vaultに記録** → 設計判断はDailynoteへ
5. **定期的にJSONを更新** → 新スレッド移行に備える

これで、**PMOは「すべてを知る」のではなく「構造を知り、詳細はRAGに委ねる」** という正しい役割で機能します。
