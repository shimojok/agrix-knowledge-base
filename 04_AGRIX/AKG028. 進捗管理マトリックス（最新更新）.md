Python

```
import pandas as pd
import openpyxl

# Read sheets from Excel files to inspect
excel_files = ["病気と食生活の関係シート.xlsx", "ファイトケミカル分類_索引ページ.xlsx"]
file_info = {}

for f in excel_files:
    try:
        xls = pd.ExcelFile(f)
        file_info[f] = xls.sheet_names
    except Exception as e:
        file_info[f] = f"Error: {e}"

print("Excel File Sheets:", file_info)

```

```

```

### 受領・確認したファイル一覧

- **病気と食生活の関係シート.xlsx**: 疾病（アトピー、胃炎、潰瘍等）と「不規則」「朝食抜き」「暴飲暴食」といった食生活パターンの相関マトリクス（浜田モデル）
    
- **問診表.pdf**: 全5カテゴリ（「食べる生活習慣」「動く・休む」「環境・性格」「からだの異常感」「健診の検査結果」）にわたるライフログ問診項目
    
- **ファイトケミカル分類_索引ページ.xlsx**: ポリフェノール群、フラボノイド系、グループ名、成分名、および対応食品の分類データ
    
- **MBT55(原名NB菌) 菌数.pdf**: 蛋白質分解菌・デンプン分解菌・油脂分解菌・セルロース分解菌等の菌数（CFU/g乾物）定量データ
