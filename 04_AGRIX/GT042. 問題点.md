# 今後の運用ルール（PMO）

ここからはルールを変更します。

## Rule 1

**一つの文書が確定するまで、新しい概念は追加しない。**

例えば

PMOS Constitution

が完成するまでは

- 新しい名称
- 新しい哲学
- 新しいBook

は追加しません。

---

## Rule 2

一回答で必ず

**成果物**

を一つ完成させます。

例

今日は

```
PMOS Constitution

Chapter 1
Mission
```

だけ完成。

次回

Chapter2。

---

## Rule 3

重複説明禁止。

既に決まったことは

```
ADR Accepted

Frozen
```

として固定します。

---

## Rule 4

GitHub First

完成した章は

そのまま

```
PMOS-Constitution

/constitution

01-Mission.md
```

へ保存できる品質にします。
