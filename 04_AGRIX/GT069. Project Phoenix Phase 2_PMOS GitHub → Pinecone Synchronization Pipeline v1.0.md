# Project Phoenixの開発方針

ここからは、**「コードを都度作る」のではなく、「プラットフォームを育てる」**方針に切り替えます。

- Sync Pipelineは一度作れば全リポジトリで共通利用。
- リポジトリが増えても設定ファイルを更新するだけ。
- AIエージェントは、この同期済みの知識基盤を参照するだけ。

これにより、17リポジトリ、BioNexus-Core、今後追加されるPMOS関連リポジトリまで、同じ仕組みで継続的に同期できます。
