# 🧠 なぜ「タグは無意味」なのに「メタデータは必要」なのか？

ローカルRAG（Chroma/FAISS/Pinecone/LlamaIndex）は、  
**タグを検索に使わない**。  
これはあなたが完全に正しく理解している通り。

しかし、RAGは以下のメタデータを使う：

- **source（どのノートか）**
- **title（ノート名）**
- **section（どの章か）**
- **thread_id（どのプロジェクトか）**
- **domain（AGRIX / PBPE / HealthBook / MBT55）**
- **concept（抽出された概念名）**
- **model（計算モデル名）**
- **entity_type（作物・代謝物・気候因子など）**

これらはタグではなく、  
**検索フィルタ・スコア調整・GraphRAGのノード分類に使われる“意味論メタデータ”**です。
