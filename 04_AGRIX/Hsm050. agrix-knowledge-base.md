# 3. 各Python Codeの目的

## `01_scan_vault.py`

### 目的：Vault全体の物理的Inventory

```text
6,000 Notes
     │
     ▼
File Scan
     │
     ├── File Path
     ├── File Type
     ├── File Size
     └── SHA-256
```

出力：

```text
_knowledge_index/
└── inventory/
    ├── vault_inventory.jsonl
    └── SCAN_SUMMARY.md
```

### 役割

**「Vaultに何が存在するか」を固定する。**

これはAIの理解ではなく、

```text
FACTUAL INVENTORY
```

です。

---

## `02_extract_knowledge_units.py`

### 目的：6,000ノートをAI処理可能なKnowledge Unitへ分解

重要なのは、**PROJECT 01〜06へ無理に仕訳しない**ことです。

```text
Daily Note
│
├── Heading A
│
├── Heading B
│
└── Heading C
```

を、

```text
Knowledge Unit A
Knowledge Unit B
Knowledge Unit C
```

へ変換します。

つまり、

```text
Document
     ↓
Heading
     ↓
Knowledge Unit
```

です。

出力：

```text
_knowledge_index/
└── knowledge_units/
    ├── knowledge_units.jsonl
    └── EXTRACTION_SUMMARY.md
```

---

## `03_extract_links.py`

### 目的：Vault内部のExplicit Relationshipを抽出

例えば、

```text
[[MBT55]]
```

や、

```text
[PBPE Marketplace](...)
```

などを抽出します。

```text
Knowledge Unit
      │
      ├── WikiLink
      ├── Markdown Link
      └── URL
             │
             ▼
      Explicit Link Graph
```

出力：

```text
_knowledge_index/
└── links/
    ├── link_edges.jsonl
    ├── link_targets_index.json
    └── LINK_EXTRACTION_SUMMARY.md
```
