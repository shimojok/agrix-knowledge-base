# 重要な修正

今回の確認で、当初の私の分類方法にも問題があったことが明確です。

**Daily Note単位だけでPROJECTを1つに仕訳する方法では不十分です。**

KazさんのVaultには、

```text
Daily Note
│
├── Section A → PROJECT 04
├── Section B → PROJECT 03
└── Section C → PROJECT 06
```

というノートが実際に存在します。

したがって、正式な最小単位は、

# **Daily Note → Heading / Thread → Project Classification**

です。

ただし、これは**Kazさんが6000ノートを手作業で分割する**という意味ではありません。

元ノートはそのまま保存します。

```text
RAW SOURCE
2026-xx-xx.md
        │
        ├── Heading A → Registry Record
        ├── Heading B → Registry Record
        └── Heading C → Registry Record
```

という**Registry側の参照分類**にします。
