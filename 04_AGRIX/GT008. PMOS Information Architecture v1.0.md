# Governance Rules

この公開リポジトリは、「説明資料」ではなく**PMOSの公式仕様**として運用します。

- **Architecture First**：設計変更はPMOS-Architectureを起点とする。
    
- **Repository Traceability**：すべてのリポジトリはRepository Atlasで追跡可能にする。
    
- **Evidence Separation**：主張・設計・実装・エビデンスを明確に分離する。
    
- **Knowledge Reuse**：同一コンテンツをArchitecture Book、GitHub Pages、Pinecone、AIエージェントで再利用する。
    
- **Version Governance**：Architecture Book、Repository Atlas、Knowledge Graphのバージョンを同期管理する。

## 私からの提案

ここまで設計すると、PMOS-Architectureは「GitHubリポジトリ」ではなく、**BioNexus Project全体の公開アーキテクチャ標準**になります。

そのため、私は次の成果物として **「PMOS Architecture Book v1.0」と「PMOS-Architecture」リポジトリを同一ソースから生成する構成**を提案します。つまり、一つのMarkdown知識ベースから、Architecture Book（PDF/プレゼン）、GitHub Pages、Repository Atlas、Pineconeインデックスを自動生成できるようにします。これにより、知識の重複管理を避け、更新内容がすべての成果物へ一貫して反映されます。
