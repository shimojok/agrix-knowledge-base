# PMOS Ontology v1.0

## Official Definition

> **PMOS Ontology is the formal semantic model that defines all concepts, entities, relationships, vocabulary, and governance rules used within the Planetary Metabolic Operating System.**

つまり

**PMOSで使用する全概念を定義する唯一の辞書**です。

# Governance Rules

PMOS Ontologyでは、概念を厳密に管理します。

|Rule|内容|
|---|---|
|One Concept, One Definition|同じ概念に複数の定義を持たせない。|
|Stable Identifier|概念IDは永続化し、名称変更してもIDは維持する。|
|Versioned Ontology|OntologyはSemantic Versioningで管理する。|
|Traceability|概念はRepository・ADR・Architecture Book・Evidenceへ追跡可能とする。|
|Evidence Required|科学・技術・事業に関する主張はEvidenceへのリンクを持つ。|
|Deprecation Policy|廃止概念は削除せず、Deprecatedとして管理する。|

# 全体アーキテクチャへの位置付け

ここまで設計した内容を統合すると、PMOSの知識基盤は次の4つの標準で構成されます。

|標準|役割|
|---|---|
|**PMOS Architecture Book**|外部へ示す全体アーキテクチャとビジョン|
|**Repository Atlas**|18リポジトリの役割・依存関係・責務を定義|
|**PKAS (PMOS Knowledge Architecture Standard)**|知識・文書・AI・リポジトリの構造標準|
|**PMOS Ontology**|概念・用語・意味・関係性の公式定義|

これら4つは独立した文書ではなく、相互に参照し合う「知識基盤」です。
