## Governance Rule

このコードは明確に以下を守ります。

```text
RAW KNOWLEDGE
     │
     ├── Read Only
     ├── No Move
     ├── No Rename
     ├── No Classification
     └── No AI Modification
```

つまり、**最初のPythonは「知識を変更する」のではなく、「Vaultの実態を機械的に把握する」ための基盤コード**です。

## 実行方法

`agrix-knowledge-base`のルートから：

```bash
python _knowledge_engine/01_scan_vault.py
```

または任意のVaultを指定できます。

```bash
python _knowledge_engine/01_scan_vault.py --vault .
```
