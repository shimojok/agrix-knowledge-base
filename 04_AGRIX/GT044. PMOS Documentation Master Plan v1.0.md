# 運用ルール（PMO）

今後は以下を固定ルールとします。

1. **新しい概念は追加せず、既存仕様を完成させる。**
2. **1セッションで最低1つの文書を完成させる。**
3. **完成した文書はADRに従って凍結（Frozen）する。**
4. **すべての文書はGitHub配置とPineconeインデックス化を前提に作成する。**
5. **MicrosoftやBill Gates氏向け提案書は、Core DocumentsとArchitecture Documentsを引用する構成とし、個別に一から作らない。**

この計画を**PMOS Documentation Master Plan v1.0**としてプロジェクトの基準計画とし、以後はこのロードマップに沿って成果物を着実に完成させます。memcite
