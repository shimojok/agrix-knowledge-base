# Governance Rules — MBT55 Evidence Architecture 決定事項

**正式決定しました。**

今後、MBT55（旧称NB菌）に関する資料・理論・実証・システム設計は、以下の構造を**PMOSの正式Architectureとして固定**します。

```
MBT55 Origin
      ↓
MBT55 Function
      ↓
Evidence
      ↓
Mechanism
      ↓
MSC
      ↓
AGRIX
      ↓
SafetyChain
      ↓
PBPE
      ↓
Planetary Impact
```

## 1. MBT55 Origin

- 旧称：NB菌
- 過去の現場資料
- 2011年岩沼津波・塩害試験
- 有機物資源化の初期実証
- 土壌・作物への適用履歴

→ **技術の起源を記録する層**

## 2. MBT55 Function

微生物群として記録された機能を、

- 有機物変換
- 栄養循環
- 土壌機能
- 病害抑制
- 作物生育
- バイオセキュリティ
- その他の観察機能

へ分類します。

→ **「何ができるか」を定義する層**

## 3. Evidence

Evidenceは混在させません。

```
E1 = Historical Observation
E2 = Mechanistic Evidence
E3 = Replicated Quantitative Evidence
```

特に、過去資料に記載された主張と、第三者による再現・定量検証は明確に分離します。

→ **科学的信頼性を守るための最重要Governance Layer**

## 4. Mechanism

MBT55を「菌種リスト」だけで説明せず、

```
Substrate
 ↓
Transformation
 ↓
Metabolites
 ↓
Cross-feeding
 ↓
Secondary Transformation
 ↓
Soil / Plant / Food
```

という**代謝カスケード／生態学的ハイパーサイクル**として構造化します。

## 5. MSC

MBT55を社会実装するシステムとして、

**MBT55 + Fermentation System + Organic Waste Feedstock**

を

> **MBT Sustainable Cycle（MSC）**

として固定します。

```
Organic Waste
      ↓
      MSC
      ↓
Biological Transformation
      ↓
Fertilizer / Feed / Humic Resources
      ↓
Agriculture
      ↓
Revenue + Resource Recovery
```

## 6. AGRIX

MSCから生産システムへ接続します。

```
MSC
 ↓
Soil Regeneration
 ↓
AgriWare™
 ↓
Crop Production
 ↓
SafetyChain™
 ↓
PBPE
```

ここから初めて、**農業・食品・金融・気候インパクト**へ展開します。
