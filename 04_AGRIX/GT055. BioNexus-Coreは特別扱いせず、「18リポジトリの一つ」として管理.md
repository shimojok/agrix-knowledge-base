# Pineconeも同じ

Pineconeへは

```
18 Repository

↓

Embedding

↓

Knowledge Graph
```

だけです。

途中で

```
Core優先

Enterprise優先
```

などは考えません。

検索結果の品質は、

- ドキュメント品質
- タグ
- メタデータ
- スコア

で判断します。

---

# これが今回の監査で一番大きな修正点

私は以前、

> 「PMOSを中心に新しい知識体系を作る」

という方向で考えていました。

しかし、現在の資産を見ると、**知識体系は既にGitHub上に存在しています。**

これから必要なのは、

- 各リポジトリを最新化する
- リポジトリ間のリンクを整理する
- Pineconeに取り込む
- AIエージェントが横断検索できるようにする

ことであり、新しい知識リポジトリを増やすことではありません。

---

## PMO方針（正式）

今後の管理単位は**18 GitHubリポジトリ**です。

- **Obsidian Vault**：研究・対話・追加知見のワークスペース
- **18 GitHubリポジトリ（BioNexus-Coreを含む）**：正式な知識資産
- **Pinecone**：18リポジトリを横断検索する知識インデックス
- **マルチAIエージェント**：AGRIX・HealthBook・PBPEなどの各システムで共通利用

この方針なら、既存の資産を最大限活かしながら、リポジトリ更新とAI基盤構築を同じ流れで進められます。
