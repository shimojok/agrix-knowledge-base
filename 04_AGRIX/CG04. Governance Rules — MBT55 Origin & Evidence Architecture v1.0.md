# Governance Rules — MBT55 Origin & Evidence Architecture v1.0

**Status：DRAFT → 今回正式策定**  
**Architecture ID：PMOS-MBT55-OEA-001**  
**Version：v1.0**  
**Parent Architecture：PMOS Knowledge & AI Governance Architecture v1.0**  
**Scope：MBT55 / NB菌 → MSC → AGRIX → SafetyChain → PBPE**

---

## 1. Purpose

本Architectureの目的は、MBT55（旧称NB菌）について40年間に蓄積された資料・現場記録・理論・検証結果を、単なる文書集合ではなく、

> **Origin → Function → Evidence → Mechanism → System → Impact**

という一貫した**Technology Provenance / Evidence Architecture**へ変換することである。

これにより、

1. MBT55の技術的起源を保存する
2. 過去の観察と科学的証拠を混同しない
3. 微生物機能を体系化する
4. 機能から代謝機構を構造化する
5. MSCへの実装関係を明示する
6. AGRIX / SafetyChain / PBPEへの因果接続を明示する
7. AIによるハルシネーションを抑制する
8. 将来の第三者検証・共同研究・事業譲渡に耐えるEvidence Chainを構築する

ことを目的とする。

# 3. Layer Definition

## Layer 01 — MBT55 Origin

### Definition

MBT55の技術的・歴史的起源を保存する。

### Primary Sources

- NB菌関連資料
- 過去の試験資料
- 2011年岩沼津波・塩害試験
- 現場写真
- 作物生育記録
- 発酵・土壌改良記録
- その他の原資料

### Rule

**Origin資料は改変せず原文を保存する。**

AIによる要約・再構成は原資料とは別Artifactとして管理する。

# 5. Layer 03 — Evidence

本ArchitectureではEvidenceを3階層に固定する。

## E1 — Historical Observation

過去の資料・現場観察・写真・記録。

```
E1
│
├── Field Observation
├── Historical Test
├── Photograph
├── Farmer Record
└── Operational Record
```

E1は**歴史的証拠として重要**だが、単独で一般化された科学的因果関係を証明するものではない。

---

## E2 — Mechanistic Evidence

機能や現象について、作用機序を支持する分析・実験等が存在するもの。

```
E2
│
├── Microbiological Evidence
├── Chemical Evidence
├── Metabolic Evidence
├── Soil Evidence
└── Mechanistic Evidence
```

---

## E3 — Replicated Quantitative Evidence

第三者または独立した条件下で再現され、定量的に評価された証拠。

```
E3
│
├── Replication
├── Control
├── Quantification
├── Statistical Evaluation
└── Independent Validation
```

### Critical Rule

```
E1 ≠ E2 ≠ E3
```

AIはEvidence Levelを勝手に昇格させてはならない。

# 6. Evidence Provenance Rule

全ての主張は以下のチェーンを持つ。

```
Claim
 ↓
Source
 ↓
Evidence Level
 ↓
Observation / Measurement
 ↓
Mechanism
 ↓

```

例えば、

```

        ↓

        ↓

        ↓

        ↓

```

とする。

「MBT55が原因である」とAIが勝手に補完してはならない。

MBT55の機能を、単なる菌種リストではなく**代謝ネットワーク**として記述する。

基本モデル：

```

    ↓

    ↓
Metabolites
    ↓
Microbial Cross-feeding
    ↓
Secondary Transformation
    ↓
```

### Metabolic Cascade

として管理する。

さらに複数の代謝経路が相互に次の反応を支える場合、

### Ecological Hypercycle

として上位モデル化する。

# 13. AI Governance

今回のArchitectureでは、AIに対する重要な制約を固定する。

### AI MUST

- Sourceを明示する
- Evidence Levelを明示する
- 推論と事実を分離する
- 不明なものはUnknownとする
- Mechanismを勝手に補完しない
- 数値を勝手に生成しない
- E1をE3へ昇格しない
- 原資料を改変しない

### AI MUST NOT

```
Historical Observation
       ↓
     [AI]
       ↓
Scientific Fact
```

という自動変換を行ってはならない。
