# 32. Validation Rules

v1.0では最低限、以下を必須Validation Ruleとします。

### Rule 1

`id` must be unique.

### Rule 2

`type` must belong to approved ontology classes.

### Rule 3

Relationshipのsubject/objectは存在するEntityを参照する。

### Rule 4

Evidence-dependent ClaimにはEvidence Referenceを要求する。

### Rule 5

InferenceをEvidenceとして登録しない。

### Rule 6

AI生成ClaimにはProvenanceを要求する。

### Rule 7

FROZEN Objectは直接変更しない。

### Rule 8

変更時は新Versionを生成する。

### Rule 9

Contradicted Claimを自動削除しない。

### Rule 10

Unknownを有効な状態として許可する。
