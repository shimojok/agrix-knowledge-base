# 代謝閉鎖度連動型金融モデル(Metabolic Closure Finance, MCF)

既存の炭素市場は「CO₂ 1トン」という単一の出力を、推計係数で売っています。MCFは**価値の単位を「閉じた代謝ループの機能」に移す**モデルです。ハイパーサイクルと栄養カスケードがどれだけ閉じているか、バイオセキュリティがどれだけ損失を防いでいるかを測り、それを金融の価格・金利・保険料に直接つなげます。

## データサイエンスの常識と違う3点

1. **保存則を制約にする**：予測の精度ではなく、C・N・P・電子の収支が閉じることを価値算定の条件にします。収支が閉じない数値は、そもそも価値になりません。
2. **証拠グレードを価格に織り込む**：実測・圃場記録・文献・シミュレーションで価値に掛ける係数(ヘアカット)を変えます。モデルが自分の不確実性に値段を付けます。
3. **生物リスクを金融リスクに換算する**：発酵・腐敗・病原の抑制を「期待損失の回避」として、金利や保険料に反映します。

## モデルの骨格

**① 閉鎖度(Closure Index)**

```
CI_X = R_X / (R_X + L_X)    X = C, N, P
R: 系内で再循環したフラックス  L: 系外への損失(ガス化・溶脱など)
```

段階効率の積 `G = Π η_i` をループ利得の運用指標とし、触媒フィードバック(代謝産物が前段を支える構造)の強さを測ります。

**② 価値の流れ**

- V_C：SOC増加・排出回避
- V_N：窒素肥料の代替、N₂O・溶脱の回避
- V_CH₄：メタン回避(家畜・廃棄物)
- V_B：バイオセキュリティ＝ΔP(事故・腐敗) × 想定損失額
- V_H：医療費回避(HealthBook、最も検証が重い)
- V_R：収量変動の縮小による資金調達コストの低下

**③ 統合評価(二重計上の防止)**

```
NPV = Σ_t [ Σ_s w(g_s)·p_s·Q_s(t) − Cost_t ] / (1 + r_t)^t
r_t = r_0 − δ · Resilience_t
```

すべての Q_s は**同一の収支(フラックス集合)から導出**し、基準シナリオとの差分だけを価値にします。w(g) は証拠グレード別の係数で、シミュレーション由来は発行対象外(0)、オプション価値の評価にのみ使います。

## 3つの金融商品

1. **閉鎖度連動ローン**：測定されたCIとレジリエンスに応じて金利が段階的に下がる、農家・事業者向け融資。
2. **バイオセキュリティ保証・パラメトリック保険**：SafetyChainの事故・腐敗データを支払い条件にします。独立した第三者データでの検証が前提です。
3. **多属性メタボリック・クレジット**：C・N・CH₄を同一収支から一括発行し、二重計上を構造的に排除します。

既存資料の「Carbon Loop Bond」の利回り(4.5〜6%)は、**このモデルのキャッシュフローから導出**する形に置き換えるのが筋です。

## 現実的な注意

- **係数は現時点で未推定です。**ヘアカット係数や ΔP、δ は仮置きで、買い手(保険会社・金融機関)との協議と実測で較正する必要があります。
- **ハイパーサイクルの閉鎖度とバイオセキュリティ効果の定量は、未実証の仮説です。**この金融モデルの最大の検証課題であり、**反証可能な形で提示**するほど提案の信頼性が上がります。
- **債券・保険・クレジットは規制対象です。**金融商品取引法や保険業法、既存のクレジット方法論(Verra等)との整合は、弁護士・専門家への相談を前提にしてください。

## 次の一手

最小プロトタイプとして、**1つのシステム(例：発酵槽1基＋圃場1か所)でCI算定→V_C・V_N・V_B→NPV→証拠グレード別の価値**を計算するシミュレーターを作ると、「何が実測されれば、どの価値が確定するか」が一目で示せます。まずこのシミュレーターの設計(入出力・パラメータ定義)から進めましょうか。
