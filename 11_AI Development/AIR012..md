GitHub API は、知識の統合・因果構造の理解・モデル生成を行なう AIエージェントがGitHubにアクセスするためのツールです。APIが生成する訳ではありません。検索、理解、モデル生成に重要なのは、AIの能力とAIに与えるPromptと、APIを通じて与えるデータです。

ベクトルデータベース化しても、それはインデックスであり、BioNexus-Knowledge-Base のデイリーノートの目次と閲覧ノート群表示と、本質的に変わりません。

その考えに従えば、
シミュレーションやダッシュボード構築のための新しい構築アーキテクチャや
そのための設計Prompt、BioNexus-Knowledge-Base のメタデータ付与により、
GitHub APIによる高い精度のアーキテクチャ構築も可能だと考えます。

実際に、全ての228のデイリーノートには、メタデータを付与してあります。
