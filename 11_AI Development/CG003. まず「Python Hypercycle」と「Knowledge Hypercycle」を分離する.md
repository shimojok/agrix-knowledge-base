# 15. JSONは「中間データ」ではなくKnowledge Infrastructureになる

ユーザーがおっしゃった

> 「生成されるJSONコードの格納」

は非常に重要です。

ただし、JSONを単なるAIの出力置場にはしません。

3種類に分けます。

### ① Source-derived JSON

```text
source → extraction → JSON
```

### ② Model JSON

```text
knowledge → model → JSON
```

### ③ Runtime JSON

```text
engine execution → result → JSON
```

この3つを混ぜない。

例えば、

```text
knowledge/
    source_objects/

model/
    metabolic_models/

runtime/
    simulation_results/
```

と分離します。

これにより、以前から重視している

```text
SOURCE
EVIDENCE
MODEL
DECISION
IMPLEMENTATION
```

の区別をPythonシステム側でも維持できます。
