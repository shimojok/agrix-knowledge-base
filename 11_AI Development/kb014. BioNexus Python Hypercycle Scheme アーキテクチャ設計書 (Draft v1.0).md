### 2. コアモジュールの役割・設計定義

#### ① **Knowledge Base Layer (`src/repositories/rag_knowledge_repository.py`)**

- **役割**: Vault 内（`agrix-knowledge-base`）の自然言語ナレッジ、論文、モデル根拠をリアルタイムでベクトル検索し、シミュレーションの定量的根拠として供給する。
    
#### ② **Data Profile Layer (`src/models/` & `src/repositories/`)**

- **`hamada_matrix.py` / `phytochemical.py`**: 浜田137疾患リスク、ファイトケミカル（ポリフェノール・テルペノイド等）、腸内細菌相・代謝物（SCFA, ATP, GLP-1）の厳密な型定義（Pydantic Schema）。

#### ③ **Hypercycle Engine Core (`bionexus_sim_engine.py`)**

- **役割**: 代謝シミュレーションを実行する計算機コア。
    
- **循環演算（Hypercycle Algorithm）**:
    
    1. 入力パラメータ（食事・生活習慣・ファイトケミカル介入量）を受領。
        
    2. 浜田マトリックスの疾患別ベースリスクスコアを補正。
        
    3. 代謝パラメータ（SCFA産生率、ATP産生効率、GLP-1シグナル強度）への影響度を重み付け連立計算。
        
    4. リスク削減率（%）と推奨アクションベクトルを出力。
        
#### ④ **Executive Control Interface (`app.py` & `scripts/ask_executive.py`)**

- **役割**: エグゼクティブ意思決定およびダッシュボード表示。
    
- 代謝演算結果とRAG検索根拠（ソースノートのパス・文脈）を統合して可視化。
