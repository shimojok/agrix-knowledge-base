🧭 これから行う作業の全体像

1. ローカルフォルダに移動  
2. Git を初期化  
3. GitHub リポジトリを登録  
4. 全ファイルを追加  
5. コミット  
6. GitHub にプッシュ  

この順番で進めれば 100%安全にプッシュできます。

---

🧱 STEP 1｜PowerShell を開く

Windows の場合：

- スタートメニュー → PowerShell  
- または「PowerShell」と検索して起動

---

🧱 STEP 2｜ローカルのフォルダに移動する

あなたの環境では次のコマンドです：

`

`

※ パスにスペースがある場合は必ず " " で囲む必要があります。

---

🧱 STEP 3｜Git を初期化する

`
git init
`

---

🧱 STEP 4｜GitHub のリポジトリを登録する

`
git remote add origin https://github.com/shimojok/agrix-knowledge-base.git
`

---

🧱 STEP 5｜全ファイルを追加する

`
git add .
`

---

🧱 STEP 6｜コミットする

`
git commit -m "Initial push of BioNexus-Knowledge-Base"
`

---

🧱 STEP 7｜GitHub にプッシュする

`

`

これで 最新の BioNexus-Knowledge-Base が GitHub に完全に反映されます。
