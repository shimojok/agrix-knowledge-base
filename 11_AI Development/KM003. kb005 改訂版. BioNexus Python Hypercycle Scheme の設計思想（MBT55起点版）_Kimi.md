1. ハイパーサイクルの正確な定義（MBT55起点）

ハイパーサイクル（Hypercycle）は、エイゲンの超循環理論に基づき、各反応の生成物が次の反応の触媒となる閉じた超循環です。
本Schemeにおける一次ハイパーサイクルは以下である：

```
[廃棄物基質（低エントロピー資源）]
        │
        ▼
┌─ 栄養カスケード（分解連鎖）──────────────────────────┐
│  リグニン/繊維素 ──(白腐菌等)──► フェノール/糖        │
│  糖 ──(糖転換菌群)──► 有機酸                          │
│  有機酸 ──(酸利用菌群)──► CO₂ + 酵素/ビタミン(制御信号) │
│  代謝産物 ──自己触媒的に──► 次段階分解の活性化（触媒還流）│
└────────────────────────────────────────────────────┘
        │
        ▼
[複数ギルドの動的平衡：分解者・変換者・制御者（120菌種、7-10核心種が機能85%）]
        │
        ▼
[成果：安定腐植質（炭素隔離）・ GHG削減（CH₄-94%, N₂O-78%）・ 高機能資材]
        │
        └────► 生成物が次のサイクルの基質/触媒として還流（ループ閉鎖）
```

Wilkinsonのフレームで言えば、MBT55反応器は地球生態系7基本プロセス
（エネルギー流・複数ギルド・ハイパーサイクル・生理学融合・炭素隔離等）を
1m³スケール・24時間時間スケールで再現したミニチュア・バイオスフィアであり、
この物理プロセスこそがBioNexus Pythonハイパーサイクルの「核触媒環」である。

5. コード実装例の差し替え（HealthBook中心 → MBT55起点）

旧版の `MetabolicPathwayEngine`（SCFA/ATP/GLP-1、HealthBook領域）を一次エンジンとしていたのを訂正し、
一次エンジンは MBT55生態学的ハイパーサイクルエンジン（MHT） とする：

```python
# src/bionexus_kb/agrix/mbt_hypercycle/mht_engine.py
from pydantic import BaseModel, Field
from bionexus_kb.core.base_model import BaseHypercycleEngine, HypercycleNodeResult

class SubstrateInput(BaseModel):
    carbon_kg: float = Field(..., description="投入基質の炭素量 (kg-C)")
    nitrogen_kg: float = Field(..., description="投入基質の窒素量 (kg-N)")
    temperature_c: float = Field(..., description="反応器温度 (°C)")
    ph: float = Field(..., description="pH")
    recalcitrant_ratio: float = Field(..., description="難分解性炭素比率 (0-1)")

class HypercycleOutput(BaseModel):
    humus_formation_rate: float = Field(..., description="腐植形成率 k_h")
    energy_efficiency: float = Field(..., description="エネルギー変換効率 η")
    ch4_suppression: float = Field(..., description="メタン抑制率")
    n2o_suppression: float = Field(..., description="N2O抑制率")
    net_carbon_sequestration_t: float = Field(..., description="正味炭素隔離量 (tCO2e)")
    ghg_reduction_t: float = Field(..., description="GHG削減量 (tCO2e)")

class MBTHypercycleEngine(BaseHypercycleEngine[SubstrateInput, HypercycleOutput]):
    """Microbial Hypercycle Theory (MHT) 計算コア
    Wilkinsonの7基本プロセスを実装したMBT55反応器の数理モデル。
    ハイパーサイクルの起点は土壌・廃棄物生態系の代謝連鎖である。"""
    node_id = "agrix.mbt_hypercycle.mht_engine"

    def process(self, x: SubstrateInput) -> HypercycleNodeResult[SubstrateInput, HypercycleOutput]:
        # ギルドカスケードの決定論的計算（RAGから抽出したγ_ij, k_h, ηを適用）
        eta = 0.92  # 最大エントロピー生産原理(MEP)に基づく変換効率
        k_h = 0.35 + 0.1 * (1 - x.recalcitrant_ratio)   # 腐植形成率
        # 嫌気ポケット排除によるGHG抑制（従来比）
        ch4_sup = 0.94
        n2o_sup = 0.78
        # 正味炭素隔離（10年スケール NCS）
        ncs = x.carbon_kg * k_h * (44/12) / 1000 * 10 * 0.31  # tCO2e換算
        out = HypercycleOutput(
            humus_formation_rate=round(k_h, 3),
            energy_efficiency=eta,
            ch4_suppression=ch4_sup,
            n2o_suppression=n2o_sup,
            net_carbon_sequestration_t=round(ncs, 2),
            ghg_reduction_t=round(x.carbon_kg * (44/12) / 1000 * 0.8, 2),
        )
        return HypercycleNodeResult(
            node_id=self.node_id, input_state=x, computed_metrics=out,
            metadata={"source": "03_MBT55/MHT, 04_AGRIX元素動態, 06_PBPE/NCS"}
        )
```

6. この改訂がもたらす設計上の帰結

7. HealthBookは「出力先」ではなく「派生適用」: MHT（一次理論）が腸内細菌相に流用される関係であり、コードの依存方向は `agrix.mbt_hypercycle → healthbook.pathways` の一方通行。
8. 70:30比率の根拠明確化: AGRIX側が物理的ハイパーサイクルの実体を担い、HealthBook側はその理論構造の人体適用であるため、計算資源・開発優先度ともにAGRIX 70%が正当化される。
9. RAGのナレッジ汚染防止: 一次プロセス（土壌・廃棄物代謝）と二次プロセス（腸内代謝）のコード・スキーマが混在することで生じるハルシネーション・手戻りリスクを構造的に排除する。
