## コード例の訂正版

kb005 で示した `HypercycleNodeResult` / `BaseHypercycleEngine` の抽象は流用できます。中身だけ、本義のMBT55代謝連鎖に差し替えます。

```python
# src/bionexus_kb/mbt_hypercycle/interaction_matrix.py
import numpy as np
from pydantic import BaseModel, Field
from bionexus_kb.core.base_model import BaseHypercycleEngine, HypercycleNodeResult

class GuildState(BaseModel):
    """機能ギルド別の菌体密度（120菌種を7-10核心種群に集約）"""
    densities: dict[str, float] = Field(..., description="種群ID → 密度 X_i")
    temperature_c: float
    ph: float

class HypercycleOutput(BaseModel):
    equilibrium_densities: dict[str, float]
    carbon_conversion_efficiency: float   # CCE
    humus_formation_rate: float           # HFR (k_h)
    net_carbon_sequestration: float       # NCS
    energy_efficiency: float              # η (≈0.92 が実証上限)

class MicrobialHypercycleEngine(BaseHypercycleEngine[GuildState, HypercycleOutput]):
    """dX_i/dt = μ_i X_i + Σ_j γ_ij X_i X_j - φ_i(T,pH) X_i"""
    node_id = "mbt_hypercycle.interaction_matrix"

    def process(self, input_data: GuildState) -> HypercycleNodeResult[GuildState, HypercycleOutput]:
        # γ_ij はRAGからノートDS0xx等の実測相互作用係数を注入（推定値は不可）
        gamma = self._load_interaction_matrix_from_rag()
        X = np.array(list(input_data.densities.values()))
        mu = self._growth_rates(input_data.temperature_c, input_data.ph)
        phi = self._stress_function(input_data.temperature_c, input_data.ph)

        dXdt = mu * X + X * (gamma @ X) - phi * X
        X_eq = X + dXdt  # 簡易オイラー積分。実装は解析的平衡点 or scipy.integrate.solve_ivp

        metrics = HypercycleOutput(
            equilibrium_densities=dict(zip(input_data.densities.keys(), X_eq)),
            carbon_conversion_efficiency=self._cce(X_eq),
            humus_formation_rate=self._hfr(X_eq),
            net_carbon_sequestration=self._ncs(X_eq),
            energy_efficiency=min(0.92, self._energy_efficiency(X_eq)),
        )
        return HypercycleNodeResult(
            node_id=self.node_id, input_state=input_data, computed_metrics=metrics,
            metadata={"source": "03_MBT55 / Wilkinson 7-process framework"}
        )
```

この $\gamma_{ij}$ 行列こそが、前回提示した「触媒結合行列と固有値解析」がそのまま使える場所です——比喩ではなく、ここでは実際に生態学の論文にある式そのものです。固有値解析でギルド間の安定性・優占構造（質量比効果：7-10種が機能の85%を担う）を検証できます。

## AGRIXの70%という比率の読み替え

kb005 の「AGRIX 70%:HealthBook 30%」構成比は、モジュールの行数配分としてではなく、**ナレッジベースのノート数比**（03+04+05+06 ≒ 2,044notes／07 ≒ 727notes、約74:26）として解釈するのが正確だと思います。実装順もこの比に合わせ、`mbt_hypercycle/` と `agrix/` を先に完成させてから `healthbook/` に着手する、という Kaz さんの方針とも一致します。

## 前回提案した「奇抜な発想」との整合

前回提示した13案のうち、$\gamma_{ij}$ 行列や化学量論的収支閉鎖（CCE/HFR/NCSの保存則）、Eigenのエラーカタストロフ閾値は、比喩ではなく**このノート群に既に定式化された理論そのもの**でした。むしろ流用先を間違えていただけで、方向性自体は合っています。逆に HealthBook 側の例（ATP/GLP-1エンジン）を出発点に据えたのは撤回します。
