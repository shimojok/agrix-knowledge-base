### 今回固定するADR-003 Conceptual Model v2.0

**中心は「GHGを金融化するモデル」ではなく、農業変革そのものを投資対象として評価するモデル**です。

```text
MSC / MBT55
      ↓
Agricultural Transformation
      ↓
┌──────────────────────────────┐
│ Agricultural Value Gateway   │
│                              │
│ Production                   │
│ Quality                      │
│ Biomass                      │
│ Soil                         │
│ Resource Circulation         │
│ Biosecurity                  │
│ Food Loss                    │
│ Climate                      │
│ Farm Economics               │
└──────────────────────────────┘
      ↓
Verification
      ↓
Verified Value / Impact Profile
      ↓
Economic Value + Risk Profile
      ↓
Finance
      ↓
Investment / Insurance / Climate
Finance / Development Finance
```

そして、**農業生産性を単純な「収量％」で扱わない**ことを正式な設計原則にします。

```text
Functional Agricultural Productivity
 =
Production Quantity
 × Harvest / Survival Rate
 × Biomass
 × Production Cycle
 × Quality
```

さらに、

```text
Crop
 ↓
Food / Feed
 ↓
Residue
 ↓
MSC / Fermentation
 ↓
Functional Agricultural Input
 ↓
Soil / Livestock
 ↓
Crop
```

という循環を、農業価値の一部としてモデル化します。

これは、旧AGRIX資料に記載されている「AGRIX層で物理生産・診断・証明を行い、そこから価値を測定する」という基本思想とも接続できます。ただし、旧資料にあるToken等の金融化部分は現在のPBPEガバナンスには継承しません。

### 影響領域も3層に分離します

**Layer 1 — Agricultural Transformation Outputs**

- Production
    
- Quality
    
- Biomass
    
- Resource
    
- Soil
    
- Biosecurity
    
- Food Loss
    
- Climate
    
- Farm Economics
    
- Circularity
    

**Layer 2 — Economic / Social Effects**

- Farmer Income
    
- Food Supply
    
- Food Price
    
- Insurance Risk
    
- Agricultural Asset Value
    
- Public Expenditure
    
- Regional Economy
    
- Health-system burden
    

**Layer 3 — Finance / Policy Effects**

- Agricultural Investment
    
- Climate Finance
    
- Insurance / Reinsurance
    
- International Development Finance
    
- Trade
    
- Sovereign Finance
    
- Corporate Scope 3
    
- Food-system Finance
    
- Infrastructure Finance
    

これにより、ユーザーが提示した「途上国食料問題、劣化土壌、食料安全保障、GHG、農業開発投資、気候金融、食料価格、物価上昇」に加えて、国家財政、保険、国際開発、循環経済等へ波及する構造を、**因果階層を崩さず**に扱えます。

### Evidenceも必須属性にします

各Valueについて、

1. Verified quantitative evidence
    
2. Experimental observation
    
3. Field case
    
4. Practitioner observation
    
5. Anecdotal / historical case
    

を明示します。

したがって、既存資料にある「保険料20–40%低下」「医療費削減」「24時間腐植化」等の数値は、現時点では**モデルの確定値にはせず、Evidence待ちの仮説・既存主張**として扱います。
