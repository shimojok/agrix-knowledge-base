🔷 2. 各モジュールの動作（STEP1〜3の統合）

① Fetcher Layer（投稿収集）
- ローカル Python スクリプト（cron / systemd timer）

- LinkedIn / GatesNotes / Threads をクロール
- Raw JSON を生成

出力：raw_posts.json

---

② Normalizer Layer（正規化）
- 全プラットフォームを統一フォーマットに変換
- タイムスタンプ、本文、タグ、URL を統一
- agrix‑knowledge‑base の schema に合わせる

---

③ BioNexus Router（選別・スコアリング）

- Semantic Similarity（embedding）
- Domain Match（PBPE / AGRIX / MBT55 / HealthBook）
- Impact Potential（Planetary Metabolism）

出力：scored_posts.json

---

④ Response Generator（返信案生成）
STEP3 の構造をそのまま使用：

- Context Builder  
- Knowledge Fusion（agrix‑knowledge‑base と統合）  
- Response Composer（LinkedIn / Threads 用）  
- Delivery Optimizer  

出力：response_candidates.md

---

⑤ Publisher / Sync Layer（保存・同期）
- GitHub の agrix‑knowledge‑base に自動 push  
- Obsidian Vault に自動同期  
- Pinecone に embedding して RAG に追加  
- Kaz のスマホで即時参照可能

🔥 3. 毎日自動で動く「Planetary Knowledge Engine」になる
