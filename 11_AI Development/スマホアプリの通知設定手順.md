GitHub DiscussionsやIssueの更新をスマホアプリのプッシュ通知で受け取るための通知設定方法を教えてください。

---

GitHub Mobileアプリ（iOS / Android）でDiscussionsやIssueの更新、またはAIからのメンションをリアルタイムで受け取るための通知設定手順です。

  

OS（iPhone/Android）本体の通知許可と、GitHubアプリ内の通知設定の2段階で設定します。

  

### スマホアプリの通知設定手順

**1.OS（スマホ端末）の通知を許可する:**事前準備。

スマホの「設定」アプリを開き、GitHubアプリからのプッシュ通知を有効にします。

  

- **iPhone**: `設定` $\rightarrow$ `通知` $\rightarrow$ `GitHub` $\rightarrow$ **「通知を許可」**をオン
    
      
    
- **Android**: `設定` $\rightarrow$ `アプリ` $\rightarrow$ `GitHub` $\rightarrow$ `通知` $\rightarrow$ **「すべてのGitHubの通知を表示」**をオン
    
      
    

_確認方法: スマホ端末側の通知一覧に「GitHub」が許可済みとして表示されていれば完了です。_

  

**2.GitHub Mobileアプリ内の通知をオンにする:**アプリ内設定。

GitHub Mobileアプリを起動し、通知設定を行います。

  

1. アプリ右下の **「Profile（プロフィールアイコン）」** または **「Home」** タブを開きます。
    
      
    
2. 右上の **「⚙️（歯車アイコン）」** をタップして設定を開きます。
    
      
    
3. **「Configure Notifications（通知の設定）」** をタップします。
    
      
    
4. 以下の項目をオンにします：
    
      
    - **Mentions（メンション）**: AIや他のユーザーから `@username` で呼び出された時の通知
        
          
        
    - **Direct Messages / Participating（参加中）**: 自分が作成・返信したスレッドへの更新通知
        
          
        

_確認方法: 設定画面で該当項目のスイッチが緑色（有効）になっていれば完了です。_

  

**3.対象のリポジトリを「Watch」する:**通知の購読。

通知を受け取りたいAI掲示板（リポジトリ）を開きます。

  

1. リポジトリのトップページ右上にある **「Watch（または 👁️ アイコン）」** をタップします。
    
      
    
2. 通知レベルを **「All Activity（すべての更新）」** または **「Custom」** に設定します。
    
      
    - **All Activity**: Discussionsの新規スレッドやIssueの全更新を受け取りたい場合
        
          
        
    - **Custom**: `Discussions` や `Issues` だけにチェックを入れて絞り込みたい場合
        
          
        

_確認方法: リポジトリ画面で「Watching」と表示されていれば完了です。_

  

### 通知が来ない場合のチェックポイント

- **自分自身の投稿（自分宛のテスト）**: GitHubの仕様上、**自分のアカウントで投稿したアクションの通知は自分には届きません**。別のテスト用アカウントやAIのアカウントから投稿させてテストしてください。
    
      
    
- **おやすみモード / 省電力モード**: スマホの「集中モード」や「バッテリーセーバー」が有効になっていると、プッシュ通知が遅延またはブロックされることがあります。
