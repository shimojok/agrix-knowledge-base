## 2. 16 GitHub Repository Adapter

16リポジトリについては、**まだ名前を推測して登録していません。**

これは意図的です。

過去資料には「既存18 repositories」という別の構成も存在するため、ここで18を16として勝手に採用すると、Phase Aそのものが誤ったSource Registryになります。実際、既存資料には16リポジトリを対象にする方針と、別途18リポジトリを記載したPMOS資料の両方が存在します。

したがって、

```json
{
  "status": "TEMPLATE_REQUIRES_CONFIRMED_16_REPOSITORIES",
  "repositories": []
}
```

としてあります。

これは**設計未完成ではなく、Sourceを捏造しないための安全ゲート**です。

# 3. Unified Source Registry

Phase Aの最重要成果物はこれです。

```text
agrix-knowledge-base
        │
        ▼
kb_inventory.jsonl
        │
        │
16 GitHub Repositories
        │
        ▼
repository_inventory.jsonl
        │
        ▼
Unified Source Registry
        │
        ▼
unified_source_registry.jsonl
```

これによって、16リポジトリを16個のRAGにするのではなく、

> **16 repositories → Unified Source Registry → BioNexus Knowledge System**

という構造になります。

これは今回固定したPhase Aの思想と一致しています。
