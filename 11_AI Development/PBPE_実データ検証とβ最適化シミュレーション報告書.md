- モデル: モンテカルロ 3,000シミュレーション × 30年、ショック発生率0.3回/年、LogNormal供給ショート

- 不確実性（気候・地政学リスク）が高まるほど最適βは上昇方向へシフトする構造は維持

## 第3章 FBC（Food Buffer Credit）メカニズム詳細設計

### 3-1. 基本構造

```
[MSC増産分 β×ΔY (85万t/年)]
        │ 預託
        ▼
[認定倉庫ローリング在庫] ──監査(四半期)──► [FBC発行: 1FBC = 1t備蓄権利]
        │                                      │
        │ 賞味期限管理(3年ローテーション)        │ 流通
        ▼                                      ▼
[更新出庫(市場販売)] ◄──償却(バーン)── [政府・機関投資家・民間]
                                              │
                              災害時: 政府が保証価格(3万円/t)で買取→ 在庫放出 → FBCバーン
```

### 3-2. 収支設計（シミュレーション結果より）

| 項目 | 値 | 備考 |
|---|---|---|
| 年間FBC発行量 | 85万FBC | β=0.17 × ΔY 500万t |
| FBC発行価格 | 25,000円/FBC | 農産物時価+加工費ベース |
| 流通残高(10年後) | 約95万FBC (≒238億円) | ローリング償却後の定常値 |
| 保管デミュラージュ | 500円/t/年 | 発行者の安定的収入源: **年間約477億円**(10年目) |
| 政府買取保証 | 30,000円/t | 災害時のみ発動(30万t/回 → **90億円/回**) |
| 更新出庫(市場販売) | 年間約57-68万t | 賞味期限3年のFIFOローテーション |

### 3-3. 償却・更新サイクルの設計詳細

1. **発行(Mint)**: MSC増産分の預託を第三者監査の上、1t=1FBCで発行。発行時に製造バッチ・倉庫位置を紐付け。
2. **ローリング償却(Rotate & Burn)**: 賞味期限到達前の在庫を通常市場で販売し、対応FBCをバーン。シミュレーションでは年間(inflow/3年)≒28万tのペースだが、実際の出庫は57-68万tに達するため**在庫は緩やかに増加傾向** → **上限キャップ(例: 120万t)到達時は発行一時停止ルールが必要**（本設計で新規に特定）。
3. **減耗償却(Spoilage Burn)**: 年5%の物理減耗に対応するFBCをバーンし、損失は発行者の自己負担（品質管理のインセンティブ）。
4. **災害償却(Emergency Burn)**: 政府が保証価格で買取→物理放出→FBCバーン。投資家は保証価格で円建て回収できるため**デフォルトリスクは政府保証に移転**。
5. **更新の資金循環**: 更新出庫の販売収入(市場価格)は次年度の新在庫調達費に充てる自己循環構造 → 財政負担ゼロを維持。

### 3-4. リスク管理

| リスク | 対策 |
|---|---|
| 在庫の過剰蓄積 | キャップ到達で発行停止 + βの年次見直し(β=0.17は動的最適値) |
| FBC価格変動 | 政府買取保証(3万円)がフロア機能 → 株式化しない「準通貨」設計 |
| 品質劣化・詐称 | 四半期監査 + バッチ単位トレーサビリティ(SafetyChain連携) |
| 政府財政リスク | 買取は災害年のみ・年額上限設定(例: 100万t) |

### 3-5. PBPE Marketplaceとの統合点

- FBCはPBPEクレジットポートフォリオの新カテゴリ「Food Buffer」として組み入れ可能
- ACIB債の担保資産としてFBC残高を充当（238億円規模の担保化）
- HALI保険モデルに「災害年の食料供給保証」として組み込み、保険料率低減効果を期待

## 第4章 結論と次のアクション

1. **Vi校正の結論**: 収益2⃣は **7.33兆円/年**（行政統計ベース）。精度向上によりPBPE金融工学の
   基礎パラメータとして実務利用可能な水準に到達。
2. **r_convの結論**: 資材の製品化戦略（低品位堆肥→土壌改良材/バイオ炭/飼料原料）で **5-10倍の
   収益差** が生じる。これは「製品設計=金融設計」というPBPEの中核命題を裏付ける。
3. **国際展開の結論**: 米国市場は日本の17倍規模。日本を実証ハブ、北米・EUを展開先とする
   段階戦略が合理的。
4. **FBCの結論**: β=0.17・85万tの備蓄プールは「デミュラージュ収入477億円/年」で運用可能な
   自己循環型の準通貨として設計可能。
