## 2. 災害備蓄プールの最適化比率 β シミュレーション

MSC増産分 $ \Delta Y_{\text{MSC}} $（500万t/年想定）のうち、比率 $ \beta $ を災害時食料備蓄としてプールした場合の社会コスト最小化をモンテカルロ法（n=8,000×30年）で求めました。

### 主要パラメータ
- 備蓄維持コスト: 15,000円/t/年
- 緊急輸入・人道コスト: 100,000円/t
- 気候ショック発生率: 0.3回/年
- ショック時供給ショート: 対数正規分布（平均約80万t）

### 結果

| 指標 | 値 |
|---|---|
| **最適備蓄化比率 β\*** | **0.17** |
| 最適備蓄量 | **85万t** |
| 年間備蓄コスト | 127.5億円 |
| 期待年間損失（β=0時） | 約300億円 |
| 期待年間損失（β=0.17時） | 約88.8億円 |
| **総社会コスト最小値** | **約216億円/年** |

**解釈:**
- **β = 0.17**（MSC増産分の17%を備蓄）が総社会コストを最小化します。
- 備蓄85万tは対象地域年間消費量の約**4.3%**に相当。FAO推奨の世界穀物備蓄基準（17〜18%）と比較して保守的ですが、**MSC増産分だけで賄える**ため財政負担はゼロです。
- 気候変動・地政学リスクが高まれば、緊急輸入コストが上昇し、最適βは**さらに上昇方向へシフト**します。PBPEモデルは「不確実性が高まるほど備蓄価値が増大」する自己強化構造を持ちます。

## 3. PBPE金融工学への統合

収益1⃣（バイオ価値創出）＋ 収益2⃣（廃棄物反転・約7.1兆円）＋ 備蓄プールによる財政支出回避 $ \Delta G_{\text{fiscal}} $ が統合され、以下の循環を形成します。

```
[MSC増産分 ΔY]
      │
      ├─► (1−β) × ΔY ──► 市場販売 ──► 農家所得・VIC発行 ──► 収益1⃣
      │
      └─► β × ΔY ──► 災害備蓄プール ──► 緊急時政府供給 ──► 社会損失低減
            │
            └─► 平時: ローリング在庫として食品ロス削減・価格安定化
```

この構造により、PBPE Marketplace の **ACIB債、ARSスワップ、HALI保険** の基礎パラメータ（クーポン率、還元率、掛け金）が実体データに裏付けられます。
