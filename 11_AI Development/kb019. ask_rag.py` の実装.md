### 1. `scripts/ask_rag.py` の実装

プロジェクト配下の `scripts/ask_rag.py` を以下の内容で保存・更新してください。

```Python
# scripts/ask_rag.py
import sys
import os

# プロジェクトルートをPythonパスに追加
sys.path.append(os.path.abspath(os.path.join(os.path.dirname(__file__), "..")))

from src.repositories.rag_knowledge_repository import RAGKnowledgeRepository

def main():
    print("=== AGRIX MBT-Hypercycle RAG Test ===")
    
    # リポジトリの初期化 (既存のRAGリポジトリ実装に依存)
    rag_repo = RAGKnowledgeRepository()
    
    # 生態学的ハイパーサイクル（MHT）に関する検証クエリリスト
    queries = [
        "Wilkinson Ecological Hypercycle Microbial Hypercycle Theory",
        "120菌種 共生ネットワーク 相互作用マトリックス gamma_ij",
        "炭素循環効率 CCE 腐植質形成率 HFR 正味炭素隔離量 NCS",
        "24時間高速分解 エントロピー生産極大化 MEP"
    ]
    
    for i, query in enumerate(queries, 1):
        print(f"\n--- [Test {i}] Query: {query} ---")
        try:
            # ナレッジ検索の実行（上位3件取得）
            results = rag_repo.search(query, top_k=3)
            if not results:
                print("⚠️ 該当するノートが見つかりませんでした。")
                continue
                
            for idx, res in enumerate(results, 1):
                # 参照ファイルパスとスコアを表示
                source = getattr(res, 'source', getattr(res, 'metadata', {}).get('source', 'Unknown'))
                print(f"\n  [{idx}] Source: {source}")
                content_snippet = getattr(res, 'content', str(res))[:200].replace('\n', ' ')
                print(f"      Snippet: {content_snippet}...")
        except Exception as e:
            print(f"❌ 検索エラーが発生しました: {e}")

if __name__ == "__main__":
    main()
```

※ `RAGKnowledgeRepository` のメソッド名（例: `.search()` や属性名）は、ご自身の既存コードに合わせて適宜調整されているかご確認ください。
