Windows の場合（Explorer）

🧱 STEP 2｜GitHub に新規リポジトリを作成する

GitHub にログインして：

1. 右上の ＋ をクリック  
2. New repository を選択  
3. Repository name に：

agrix-knowledge-base

と入力  
4. Public / Private を選択（Private 推奨）  
5. README は作らない（後で push するため）  
6. Create repository をクリック

---

🧱 STEP 3｜ローカルのコピーを GitHub にプッシュする

ターミナル（Mac）または PowerShell（Windows）で：

① コピーしたフォルダに移動
`
cd ~/path/to/agrix-knowledge-base
`

② Git 初期化
`
git init
`

③ GitHub リポジトリを登録
`
git remote add origin https://github.com/あなたのユーザー名/agrix-knowledge-base.git
`

④ 全ファイルを追加
`
git add .
`

⑤ コミット
`
git commit -m "Initial push of BioNexus-Knowledge-Base"
`

⑥ プッシュ
`
git push -u origin main
`

これで 最新の BioNexus-Knowledge-Base が GitHub に完全に反映されます。
