# 私の結論

今回の話を踏まえると、PBPEの中心軸は次の一文に置くのが最も適切だと思います。

> **PBPEは、MBT55/MSCによって生態学的ハイパーサイクルを農業生産システムに実装し、そこから生まれる生産性・資源循環・バイオセキュリティ・環境・健康・財政等の実体経済価値を可視化・検証し、その価値形成を金融資本によって拡大するためのインフラである。**

つまり、

**PBPE = Financial Model**

ではありません。

**PBPE = Real-Economy Value Transformation + Verification + Finance Infrastructure**

です。

そして、

**AGRIX = 生態学的農業生産システムを実装する側**

**PBPE = その結果生じる多部門価値を経済・金融システムへ接続する側**

という棲み分けになります。

これは、以前の「PBPEは金融側に寄りすぎている」という私の表現より、はるかに正確です。
