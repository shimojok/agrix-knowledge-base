１．収穫量の向上
- 漠然とした収穫総量の増加ではなく、トウモロコシやジャガイモ、桃やメロンなどの果実で説明したように、一般的に間引く必要があるところ、間引かなくとも、全ての果実が成長します。農業専門家から見ると、驚きの事象なのです。まず、ここで、2～４倍の収穫量を実現します。実際に夕張メロンの栽培支援では、4倍の収穫量となっています。
- 次は、一定の割合で病気や害虫により、生育が阻害されるのが一般的ですが、MBT55は、それを極限まで削減します。これは、土壌中の微生物の働きと、農作物の葉や根側で働く微生物によるものです。中国のハウスのスイカ栽培であれば、歩留まり50~60%のところ、95％程度まで向上させます。
- 次は、バイオマス量の増加です。例えば、ジャガイモなどは、実が多いだけでなく、大きく成長します。ほうれん草は、全長36センチの時が一番栄養価が高く味も優れています。一般的には、そこまで短期間に生育しません。ゴボウや里芋、長芋、レンコンなども、収穫重量が圧倒的に増加します。
- トマトの野菜工場では、通常、苗を通常より密集させて植え（密植）、トマトの実が3段目（第3花房）までついたところで茎の先端を止めます（摘心）。これにより、株の高さや成長スピードが完全に均一化され、工場製品のようにスケジュール通りの安定生産が可能になります。逆に言えば、それ以上の段の増加は、収穫量を落とします。MBT55/HMT液肥は、8段でもスピードが落ちず、確実に（糖度10～12度までコントロール）赤い実をつけさせます。収穫量は4倍にもなります。
- 稲作でも同様で、食味と同時に、１反あたり最大25俵の収穫実勢を誇ります。麦、大豆、トウモロコシも同様です。

２．品質の向上
- まず、葉や根、実の生物的組織が変わります。なよなよしないこと、かつ、筋がなく、強い作物ができます。ビタミンの生成量も多く、ポリフェノールなどのファイトケミカルの含有量も多く、鮮度保持力向上に寄与します。ジャガイモは二次成長をすることはなく、芽がでにくいことも特徴です。収穫袋で半年間、保管することもできます。
- ももやリンゴは、摺ることで色が変色します。これは酸化が始まったことを意味しますが、MBT55によるリンゴや桃、メロンなどは酸化時期を大きく延長させるのです。
- 北海道旭川市で人参の実験をしたことがあります。一般的な①化学肥料による人参、②有機栽培の人参、③MBT55/HMTによる人参の比較実験です。ビタミン、カロテン含有量は、①1：②1.2：③3~4でした。①は苦みが強く、②は雑な甘みがし、③は香りと共に事前な味だと評価されました、人参も大根も、包丁で切る際、外側の皮の部分を切ると、ストーンと下まで切れるものが高品質とされています。①は芯があり、包丁が芯で止まり、②は、表皮が荒く、病害虫が抽出されました。面白いのは、人参嫌いの子供たちが喜んで初めて食べたのです。親も同様ですが、一番驚いたのは、その人参を食べた主婦層の多くが、その後、妊娠したことです。なかなか子供ができない、栄養に問題があるのかと集まってきた夫婦が多くいたのですが、本物の栄養価を体験したようです。この話をすると、貴方は、懐疑的に受け取るでしょうから、データに掲載する必要はありません。事例として記録するだけでいいです。

# 2. 特に重要なのは「収量」を1個のKPIにしないこと

今回の説明によって、Agricultural Transformation Simulatorの**Yield Modelを大幅に高度化すべき理由**が明確になりました。

一般的な農業モデルでは、

```text
Baseline Yield
      ×
Yield Increase %
      =
New Yield
```

となりがちです。

しかし、今回のMBT55の説明では、少なくとも概念上、収量増加には複数のメカニズムがあります。

### A. 個体数・着果数の増加

間引きが必要とされる作物で、間引かずに生育するという現象。

```text
Potential Biological Units
        ↓
Survival / Development
        ↓
Harvestable Units
```

### B. 歩留まり向上

例えば資料で示されたスイカの例では、

```text
50–60% → 約95%
```

という**Loss-to-Yield Conversion**があります。

これは単純な「成長率」ではありません。

### C. 個体重量・バイオマス増加

```text
Number of products
        ×
Average biomass / unit
        =
Harvest biomass
```

したがって、

**「数が増える」＋「一個が大きくなる」**

を分離してモデル化する必要があります。

### D. 生育期間・生産サイクル

トマトの例では、

```text
通常：3段程度
MBT55/HMT：8段でも生育継続
```

という説明があります。

これは単純なyield upliftではなく、

> **Plant Growth Architecture / Production Cycle Extension**

という別の変数として扱うべきです。

## 10. ここで一つ、重要な線引きをします

添付資料には「PBPEクレジット」「PBPE債券」「新しい金融市場」等の旧PBPEモデルの記述もあります。

これは**今回のADR-003には継承しません**。

現在確定しているPBPEのガバナンスでは、

```text
PBPE
  ≠ Token
  ≠ Coin
  ≠ Currency
  ≠ Exchangeable Credit
```

です。

したがって、添付資料の**問題領域・価値連鎖・金融需要を抽出し、旧「PBPE Credit」等の実装概念は除外する**、という扱いにします。

# 結論

今回の内容を読むと、**先ほど作ったADR-003 Schemaをそのまま確定するのは早い**です。

先にADR-003の概念モデルを一段修正する必要があります。

特に変更すべきなのは、

### ① Yield

単純なYield Increaseではなく、

**Production Quantity × Survival/Harvest Rate × Biomass × Production Cycle**

として構造化する。

### ② Quality

価格プレミアムだけではなく、

**Nutritional / Functional / Freshness / Storage / Biological Quality**

として構造化する。

### ③ Resource

収穫物だけでなく、

**Crop → Residue → Fermentation → Agricultural Input → Soil**

という循環を入れる。

### ④ Investment

農地への投入資金だけでなく、

**MSCによる現地農業資材製造能力そのものをDevelopment Investment Assetとして扱う。**

### ⑤ Impact

19領域を直接計算するのではなく、

**Transformation → Economic/Social Effects → Finance/Policy Effects**

の3層に分ける。

### ⑥ Evidence

MBT55の実測値・実験値・フィールドケース・専門家観察・事例を混同しない。
