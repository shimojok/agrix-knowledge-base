- AIエージェントがローカルのデータベースを操作  
- AIエージェントがローカルのコードを実行  
- AIエージェントがローカルのRAGを使う

つまり、  
Kaz のローカル環境を「AIが自由に使えるようにする」ための基盤 です。

GitHub API は「外部のファイルを読む」だけですが、

Kaz のプロジェクトはローカル環境が中心なので、
