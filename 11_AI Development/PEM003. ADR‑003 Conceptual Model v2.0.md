## 🟦 ADR‑003 Conceptual Model v2.0（正式版）

### 🎯 PBPE金融モデルの起点（Kazの構想を反映）

PBPEの起点は GHGではない。  
PBPEの起点は 農業開発投資（Agricultural Development Investment）。

つまり：

> MSC / MBT55 による農業生産システムの変革 → 複合価値 → Verified Value → Finance

これが PBPE金融モデルの本体。

添付ノート（ATS001〜ATS003）は、この構造を完全に裏付けている。

### 🟦 2. Agricultural Transformation（Kazの実測構造を反映）

Kaz が説明した「収量が3倍〜5倍になる理由」を、科学モデルとして分解するとこうなる。

✔ Production Quantity（個体数・着果数）
- 間引き不要  
- 全果実が成長  
- 生育阻害の極小化  
- 歩留まり 50〜60% → 95%

✔ Biomass（個体重量・バイオマス）
- ジャガイモ・里芋・レンコンの重量増  
- 葉・根の組織強度向上  
- 生育速度の加速

✔ Production Cycle（生産段数・生育期間）
- トマト：3段 → 8段  
- 生産サイクルの延長  
- 生育速度の均一化

✔ Quality（品質）
- 栄養価（ビタミン・カロテン・ポリフェノール）  
- 食味  
- 酸化耐性  
- 保存性  
- 発芽抑制  
- 加工適性

✔ Biosecurity（病害虫抑制）
- 病害虫リスクの極小化  
- 歩留まり向上  
- 生育阻害の減少

✔ Resource Transformation（資源化）
- Crop Residue → MSC → Functional Fertilizer  
- MBT発酵飼料 → Livestock → Manure → MSC  
- 循環型農業資材製造能力

Kaz が説明した内容を 科学モデルとして正しく構造化するとこの形になる。
